# 不動産鑑定士試験 概要

## 試験の基本情報

| 項目 | 内容 |
|------|------|
| 正式名称 | 不動産鑑定士試験 |
| 実施機関 | 国土交通省（土地鑑定委員会） |
| 試験形式 | 短答式試験 → 論文式試験の2段階 |
| 合格率 | 短答式: 約30〜35%、論文式: 約14〜17%（最終合格率: 約5〜7%） |
| 受験資格 | なし（誰でも受験可能） |
| 短答式合格の有効期間 | 合格した年を含めて3年間（論文式を3回受験可能） |

## 短答式試験

| 項目 | 内容 |
|------|------|
| 試験日 | 毎年5月中旬（日曜日） |
| 試験時間 | 午前: 行政法規（120分）、午後: 鑑定理論（120分） |
| 出題形式 | 五肢択一式マークシート |
| 問題数 | 行政法規40問 + 鑑定理論40問 = 計80問 |
| 合格基準 | 総合点でおおむね7割以上、かつ各科目一定水準以上 |

### 科目別の配点と特徴

| 科目 | 問数 | 時間 | 特徴 |
|------|------|------|------|
| 行政法規 | 40問 | 120分 | 不動産関連法令の知識。暗記量が多い。法令数が約30と膨大 |
| 鑑定理論 | 40問 | 120分 | 不動産鑑定評価基準・留意事項からの出題が中心。体系的理解が必要 |

## 論文式試験

| 項目 | 内容 |
|------|------|
| 試験日 | 毎年8月上旬（3日間） |
| 出題形式 | 論述式 |

### 科目別の配点

| 科目 | 配点 | 試験日 | 時間 |
|------|------|--------|------|
| 民法 | 100点 | 1日目 | 120分 |
| 経済学 | 100点 | 1日目 | 120分 |
| 会計学 | 100点 | 2日目 | 120分 |
| 鑑定理論（論文） | 200点 | 2日目・3日目 | 120分×2 |
| 鑑定理論（演習） | 100点 | 3日目 | 120分 |
| **合計** | **600点** | | |

### 各科目の特徴

#### ★★★ 鑑定理論（300点）— 最重要・配点の半分

- 論文（200点）: 鑑定評価基準の趣旨・背景を論述
- 演習（100点）: 実際の鑑定評価書を想定した計算問題
- 鑑定評価基準の暗記と深い理解が不可欠

#### ★★ 民法（100点）

- 総則、物権、債権（契約）、相続が中心
- 宅建の権利関係より格段に深い論述力が要求される
- 判例の射程・趣旨を論じる問題が多い

#### ★★ 経済学（100点）

- ミクロ経済学: 消費者理論、生産者理論、市場均衡、厚生経済学、ゲーム理論
- マクロ経済学: IS-LM分析、AD-AS分析、経済成長論、国際マクロ
- 数式・グラフを用いた論述が必要

#### ★ 会計学（100点）

- 財務会計が中心: 企業会計原則、金融商品会計、減損会計、リース会計、連結会計等
- 管理会計: CVP分析、標準原価計算、意思決定会計
- 計算問題と理論問題の両方が出題

## 合格戦略

### 短答式（まず突破すべき関門）

| 科目 | 目標得点 | 攻略法 |
|------|----------|--------|
| 行政法規 | 30/40（75%） | 法令ごとの頻出条文を確実に暗記。過去問の反復が最重要 |
| 鑑定理論 | 32/40（80%） | 鑑定評価基準の逐条理解。留意事項との対応関係を整理 |

### 学習の優先順位（短答式）

1. **鑑定理論**（最優先）: 論文式でも最重要科目。短答式で基礎固めしておくと後が楽
2. **行政法規**: 暗記量が膨大なため早期着手。頻出法令から優先的に

### 学習期間の目安

- 短答式のみ: 500〜800時間
- 短答式+論文式（最終合格）: 2,000〜3,500時間
- 標準的な学習期間: 1.5〜2年（働きながらの場合）
