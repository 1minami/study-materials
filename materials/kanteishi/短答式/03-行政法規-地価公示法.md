# 行政法規 — 地価公示法 ★★★

> 毎年1〜2問出題。不動産鑑定士試験に直結する法律。地価公示の仕組み・標準地・公示価格の効力を正確に理解する。

## 1. 法の目的と概要

### 目的（第1条）

- 都市及びその周辺の地域等において、**標準地**を選定し、その正常な価格を公示することにより、一般の土地の取引価格に対して**指標**を与え、公共の利益となる事業に必要な土地の取得に対する**適正な補償金の額の算定等**に資し、もって適正な地価の形成に寄与する

### 地価公示の仕組み

```
土地鑑定委員会
  ├→ 標準地の選定（毎年1回）
  ├→ 2人以上の不動産鑑定士の鑑定評価を求める
  ├→ 鑑定評価の結果を審査し、正常な価格を判定
  └→ 官報で公示（毎年3月下旬）
```

## 2. 標準地 ★★★

### 選定基準

| 項目 | 内容 |
|------|------|
| 選定者 | **土地鑑定委員会** |
| 対象地域 | **都市計画区域その他の土地取引が相当程度見込まれるもの**として国土交通省令で定める区域 |
| 選定基準 | 土地の利用状況、環境等が**当該地域において通常と認められる**一団の土地 |
| 選定頻度 | **毎年1回** |

### 重要ポイント

- 標準地は「標準的な土地」であり、最有効使用の土地ではない
- 建物その他の定着物がある土地 → **更地として**の正常な価格を公示（建物は考慮しない）

## 3. 正常な価格 ★★★

### 定義（第2条第2項）

- **自由な取引が行われるとした場合**におけるその取引において**通常成立すると認められる価格**
- 土地の使用収益を制限する権利が存しないものとして算定

### 鑑定評価の方法

| 項目 | 内容 |
|------|------|
| 鑑定評価を行う者 | **2人以上**の不動産鑑定士 |
| 選任者 | 土地鑑定委員会 |
| 近傍類地の取引価格 | 考慮する（**必ず**） |
| 地代等から算定した推定価格 | 考慮する |
| 同等の効用を有する土地の造成費 | 考慮する |
| **基準日** | **毎年1月1日** |

### 鑑定評価における留意点

- 近傍類地の取引価格から算定される推定の価格を基準とし、必要に応じて収益還元法による価格等を勘案
- 取引価格には**投機的取引等による異常な価格**を排除

## 4. 公示の手続き ★★

### 公示事項

1. 標準地の**所在の郡、市、区、町村及び字並びに地番**
2. 標準地の**単位面積当たりの正常な価格**
3. 標準地の**地積及び形状**
4. 標準地及びその周辺の土地の**利用の現況**
5. その他国土交通省令で定める事項

### 公示の方法

| 項目 | 内容 |
|------|------|
| 公示方法 | **官報**で公示 |
| 公示時期 | 毎年**3月下旬**（基準日: 1月1日） |
| 閲覧 | 市町村長は図面等を一般の閲覧に供する |
| 書面の送付 | 土地鑑定委員会は関係市町村長に書面等を送付 |

## 5. 公示価格の効力 ★★★

### 一般の土地取引に対する効力

- 都市計画区域等内で土地の取引を行う者は、公示価格を**指標として**取引を行うよう**努めなければならない**
- → **努力義務**（法的拘束力なし）

### 公的機関に対する効力（規準）★★★

| 場面 | 効力 |
|------|------|
| **不動産鑑定士の鑑定評価** | 公示価格を**規準**としなければならない（義務） |
| **土地収用の補償金** | 公示価格を**規準**として算定（義務） |
| **公共事業用地の取得価格** | 公示価格を**規準**として算定（義務） |
| **国土利用計画法の価格審査** | 公示価格を**規準**として審査（義務） |

### 「規準」の意味 ★★

- 対象土地と標準地の**位置、地積、環境等の土地の客観的価値に作用する諸要因**についての比較を行い、その結果に基づき、標準地の公示価格と対象土地の価格との間に**均衡を保たせる**こと
- 単に公示価格を参考にするだけでは足りない

## 6. 都道府県地価調査との比較 ★★

| 項目 | 地価公示 | 都道府県地価調査 |
|------|----------|------------------|
| 根拠法 | 地価公示法 | 国土利用計画法施行令 |
| 実施主体 | **土地鑑定委員会** | **都道府県知事** |
| 基準日 | **1月1日** | **7月1日** |
| 対象地域 | 都市計画区域等 | 都市計画区域**外も含む** |
| 鑑定評価 | **2人以上**の鑑定士 | **1人以上**の鑑定士 |
| 公示方法 | 官報 | 都道府県の公報 |
| 標準地の呼称 | 標準地 | 基準地 |
