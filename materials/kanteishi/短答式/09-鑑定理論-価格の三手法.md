# 鑑定理論 — 価格の三手法（鑑定評価の方式）★★★

> 不動産鑑定評価の中核。原価法・取引事例比較法・収益還元法の3手法を体系的に理解する。

## 1. 三手法の概要

### 鑑定評価の三方式

| 方式 | 手法 | 求める試算価格 | 着目する側面 |
|------|------|---------------|-------------|
| **原価方式** | 原価法 | **積算価格** | 費用性（コスト） |
| **比較方式** | 取引事例比較法 | **比準価格** | 市場性（マーケット） |
| **収益方式** | 収益還元法 | **収益価格** | 収益性（インカム） |

### 三手法の適用原則 ★★★

- 鑑定評価に当たっては、原則として**3手法を併用**し、それぞれの試算価格を調整して鑑定評価額を決定する
- 地域分析及び個別分析により対象不動産の性格を明確にした上で、**最も適切と認められる手法**を適用
- 対象不動産の種類、所在地域、資料の活用可能性等に応じて、適切に手法を選択・適用

---

## 2. 原価法 ★★★

### 基本的な考え方

- 対象不動産の**再調達原価**を求め、これに**減価修正**を行って試算価格（積算価格）を求める
- 「同じものを今造ったらいくらか」から出発し、古くなった分を引く

### 計算式

```
積算価格 = 再調達原価 − 減価額
```

### 再調達原価 ★★★

| 項目 | 内容 |
|------|------|
| 定義 | 対象不動産を**価格時点**において再調達することを想定した場合に必要とされる適正な原価の総額 |
| 土地 | 取得原価 + 造成費 + 付帯費用 |
| 建物 | **直接法**（標準的な建設費に基づく）又は **間接法**（類似の建物の建設費から求める） |
| 建物及びその敷地 | 土地の再調達原価 + 建物の再調達原価 + 付帯費用 |

#### 再調達原価を求める方法

| 方法 | 内容 |
|------|------|
| **直接法** | 対象不動産の再調達原価を**直接的**に求める。材料費・労務費・経費等を積算 |
| **間接法** | 類似の不動産から**間接的**に求める。近隣の類似不動産の建設費を基に補正 |

### 減価修正 ★★★

#### 減価の要因

| 要因 | 内容 |
|------|------|
| **物理的減価** | 経年劣化、損傷、摩耗等 |
| **機能的減価** | 設計の不良、型式の旧式化、設備の不適合等 |
| **経済的減価** | 近隣地域の衰退、不動産と環境との不適合等 |

#### 減価修正の方法

| 方法 | 内容 |
|------|------|
| **耐用年数に基づく方法** | 経過年数/耐用年数の割合で減価。定額法・定率法等 |
| **観察減価法** | 対象不動産を実際に観察し、各減価の要因に基づく減価額を求める |

- 原則として**両方を併用**する
- 耐用年数に基づく方法のみでは物理的減価の把握に偏るため、観察減価法で補完

#### 耐用年数の種類

| 種類 | 内容 |
|------|------|
| **経済的耐用年数** | 経済的に使用可能な期間。鑑定評価で重視 |
| **物理的耐用年数** | 物理的に存続可能な期間 |
| **機能的耐用年数** | 機能的に陳腐化するまでの期間 |
| **法定耐用年数** | 税務上の耐用年数（鑑定評価では参考にとどめる） |

### 原価法の適用が特に有効な場合

- **建物**及び**建物及びその敷地**の鑑定評価
- **造成地**の鑑定評価
- 市場における取引事例が少ない場合

## 3. 取引事例比較法 ★★★

### 基本的な考え方

- 対象不動産と**類似の不動産の取引事例**を収集し、適切な**事例の選択**と必要な**修正・補正**を行い、試算価格（比準価格）を求める
- 「似た不動産がいくらで取引されたか」から価格を求める

### 計算式

```
比準価格 = 取引事例の取引価格
          × 事情補正
          × 時点修正
          × 地域要因の比較（標準化補正）
          × 個別的要因の比較
```

### 手順 ★★★

#### Step 1: 事例の収集と選択

**収集範囲**:
- 同一需給圏内の**近隣地域又は類似地域**から収集
- 必要やむを得ない場合は近隣地域の**周辺の地域**から収集

**選択基準（採用できない事例）** ★★:
- **投機的取引**と認められる事例
- **特殊な事情**があり、これが取引価格に影響を与えている場合で、適切な補正ができない事例
- 取引時点が**あまりにも古い**事例

#### Step 2: 事情補正 ★★

- 取引事例に**特殊な事情**がある場合、その影響を排除する補正
- 売り急ぎ、買い急ぎ、縁故取引、隣接地の併合目的等

#### Step 3: 時点修正 ★★

- 取引時点から**価格時点**までの**価格変動**を修正
- 地価変動率、物価変動等を考慮

#### Step 4: 地域要因の比較（標準化補正・地域要因比較）★★

```
取引事例の所在する近隣地域 → 対象不動産の近隣地域
（地域要因の優劣を比較し補正）
```

#### Step 5: 個別的要因の比較 ★★

- 取引事例の個別的要因と対象不動産の個別的要因を比較し補正
- 画地条件（間口、奥行、形状等）、接面道路、環境条件等

### 取引事例比較法の適用が特に有効な場合

- **更地**の鑑定評価
- **自用の建物及びその敷地**の鑑定評価
- 市場における取引事例が豊富な場合

## 4. 収益還元法 ★★★

### 基本的な考え方

- 対象不動産が将来生み出すであろう**純収益**の現在価値の総和を求めて試算価格（収益価格）を得る
- 「この不動産からどれだけ収益が得られるか」から価格を求める
- **賃貸用不動産又は賃貸以外の事業用不動産**の鑑定評価に特に有効
- **自用の不動産**であっても、賃貸を想定して適用すべき

### 二つの方法

| 方法 | 内容 |
|------|------|
| **直接還元法** | 一期間の純収益を還元利回りで還元して収益価格を求める |
| **DCF法** | 複数期間の純収益と復帰価格を割引率で割り引いて収益価格を求める |

### 直接還元法 ★★★

#### 計算式

```
収益価格 = 純収益（a） ÷ 還元利回り（R）
```

#### 純収益の求め方

```
総収益（賃料収入等）
  − 総費用（維持管理費、修繕費、公租公課、損害保険料、空室等損失相当額等）
  = 純収益
```

**総収益の構成**:
- 支払賃料
- 共益費収入
- 駐車場収入
- 礼金・更新料等の一時金の運用益・償却額

**総費用の構成**:
- 維持管理費
- 修繕費（大規模修繕費の年平均額を含む）
- 公租公課（固定資産税・都市計画税）
- 損害保険料
- 空室等損失相当額
- 貸倒れ損失相当額

#### 還元利回り ★★★

- 一期間の純収益から対象不動産の価格を直接求める際に使用する利回り
- **求め方**:
  1. 類似の不動産の取引事例との比較から求める
  2. 借入金と自己資金の加重平均利回りから求める
  3. 土地と建物に係る還元利回りの加重平均から求める
  4. 割引率との関係から求める

### DCF法 ★★★

#### 計算式

```
収益価格 = Σ（各期の純収益 ÷ (1+割引率)^n） + 復帰価格 ÷ (1+割引率)^N
```

| 要素 | 内容 |
|------|------|
| 各期の純収益 | 保有期間中の各期間の純収益 |
| 割引率 | 各期の純収益を現在価値に割り引く率 |
| 復帰価格 | 保有期間満了時の売却予想価格 |
| N | 保有期間（分析期間） |

#### 割引率 ★★

- 将来の収益を現在価値に割り引く際の率
- 還元利回りとの関係: 一般に 割引率 ≒ 還元利回り + 純収益の変動率

#### 直接還元法とDCF法の比較

| | 直接還元法 | DCF法 |
|---|-----------|-------|
| 期間 | **一期間** | **複数期間** |
| 収益変動 | 安定的な収益を前提 | 期間ごとの変動を明示的に考慮 |
| 適用場面 | 収益が安定している場合 | 収益の変動が見込まれる場合、証券化対象不動産 |
| 複雑さ | シンプル | 詳細だが前提条件への依存度大 |

## 5. 賃料の鑑定評価（賃料の三手法）★★

### 新規賃料を求める手法

| 手法 | 求める試算賃料 | 内容 |
|------|---------------|------|
| **積算法** | **積算賃料** | 基礎価格 × 期待利回り + 必要諸経費等 |
| **賃貸事例比較法** | **比準賃料** | 類似の賃貸事例から比較して求める |
| **収益分析法** | **収益賃料** | 企業の総収益から不動産に帰属する部分を求める |

### 積算法の計算式

```
積算賃料 = 基礎価格 × 期待利回り + 必要諸経費等
```

| 要素 | 内容 |
|------|------|
| 基礎価格 | 対象不動産の価格（更地価格 or 建物及びその敷地の価格） |
| 期待利回り | 不動産の経済価値に即応する適正な利回り |
| 必要諸経費等 | 減価償却費、維持管理費、公租公課、損害保険料、資本収益 |

### 継続賃料を求める手法 ★★

| 手法 | 求める試算賃料 | 内容 |
|------|---------------|------|
| **差額配分法** | — | 実際の賃料と適正賃料との差額を契約当事者間で配分 |
| **利回り法** | — | 基礎価格 × 継続賃料利回り + 必要諸経費等 |
| **スライド法** | — | 現行賃料を定める際に基礎となった純賃料に変動率を乗じ、必要諸経費等を加算 |
| **賃貸事例比較法** | — | 新規賃料と同様に賃貸事例から比較 |

## 6. 試算価格の調整と鑑定評価額の決定 ★★★

### 試算価格の調整

- 各手法で求めた試算価格の**再吟味**を行い、**説得力に係る判断**を行う
- 各試算価格の**整合性**を検討

### 調整の着目点

1. 各手法の**適用において採用した資料の特性**
2. 各手法に共通する**価格形成要因に係る判断の整合性**
3. 各手法の**適用手順の妥当性**
4. 各手法が**地域分析及び個別分析の結果と適合しているか**

### 鑑定評価額の決定

- 試算価格の調整を経て、対象不動産の鑑定評価における**最も説得力のある価格**を鑑定評価額として決定
- 単純な平均ではなく、各手法の説得力を考慮した**総合的な判断**
