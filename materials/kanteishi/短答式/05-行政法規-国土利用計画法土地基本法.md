# 行政法規 — 国土利用計画法・土地基本法 ★★

> 国土利用計画法は毎年1問程度、土地基本法は隔年出題。土地取引規制と土地政策の基本理念を理解する。

## Part 1: 国土利用計画法

### 1. 法の目的

- 国土利用計画の策定に関し必要な事項を定めるとともに、**土地利用基本計画の作成**、**土地取引の規制**に関する措置等を講ずることにより、国土の**総合的かつ計画的な利用**を図る

### 2. 国土利用計画の体系

```
全国計画（国が策定）
└→ 都道府県計画
    └→ 市町村計画
```

### 3. 土地利用基本計画 ★

- **都道府県**が定める
- 5地域に区分: ①都市地域 ②農業地域 ③森林地域 ④自然公園地域 ⑤自然保全地域
- 地域の重複あり

### 4. 土地取引の届出制度 ★★★

#### 事後届出制（原則）

| 項目 | 内容 |
|------|------|
| 届出義務者 | **権利取得者**（買主） |
| 届出先 | **市町村長を経由して都道府県知事** |
| 届出期限 | 契約締結日から**2週間以内** |
| 届出対象面積 | 下表参照 |
| 審査対象 | **利用目的のみ**（価格は審査しない） |

**届出が必要な面積**:

| 区域 | 面積要件 |
|------|----------|
| 市街化区域 | **2,000㎡以上** |
| 市街化区域以外の都市計画区域 | **5,000㎡以上** |
| 都市計画区域外 | **10,000㎡以上**（1ha） |

**届出不要の場合**:
- 当事者の一方又は双方が**国・地方公共団体等**の場合
- **民事調停法に基づく調停**による場合
- **農地法3条1項の許可**を受けることを要する場合
- 滞納処分、強制執行、担保権の実行による場合

#### 事前届出制（注視区域・監視区域）★★

| | 注視区域 | 監視区域 |
|---|----------|----------|
| 指定者 | 都道府県知事 | 都道府県知事 |
| 指定要件 | 地価の相当な程度の上昇のおそれ | 地価の急激な上昇のおそれ |
| 届出時期 | **契約締結前**（事前届出） | **契約締結前**（事前届出） |
| 届出対象面積 | 事後届出と同じ | **都道府県規則で定める面積以上**（引下げ可能） |
| 審査対象 | **利用目的 + 価格** | **利用目的 + 価格** |
| 届出後の制限 | **6週間**は契約不可（勧告期間） | **6週間**は契約不可 |

#### 許可制（規制区域）★

| 項目 | 内容 |
|------|------|
| 指定者 | 都道府県知事 |
| 指定要件 | 投機的取引が相当範囲に集中し、地価が急激に上昇するおそれ |
| 制限 | 土地売買等の契約には**都道府県知事の許可**が必要 |
| 無許可の効果 | 契約は**無効** |
| 審査対象 | 利用目的 + 価格 |

※ 現在まで規制区域が指定された実績はない

### 5. 勧告と公表 ★★

| 制度 | 勧告の内容 | 従わない場合 |
|------|------------|------------|
| 事後届出 | 利用目的の変更 | **公表**できる（罰則なし） |
| 事前届出 | 利用目的の変更、価格の引下げ | **公表**できる（罰則なし） |

- 届出をしなかった場合 → **6ヶ月以下の拘禁刑又は100万円以下の罰金**
- 虚偽の届出 → 同上

> ※2025年6月1日施行の改正刑法により、従来の「懲役」と「禁錮」は「拘禁刑」に一本化されました。

### 6. 遊休土地制度

- 取得後**2年**を経過した一定面積以上の土地で、所有者が利用していない場合
- 都道府県知事が利用促進の**助言**、**勧告**を行うことができる

## Part 2: 土地基本法

### 1. 法の目的 ★

- 土地についての基本理念を定め、国・地方公共団体・事業者・国民の責務を明らかにし、土地に関する施策の基本事項を定めることにより、適正な土地の利用及び管理並びにこれらの確保を図り、国民経済の健全な発展と国民生活の安定向上に寄与する

### 2. 基本理念 ★★

| 理念 | 内容 |
|------|------|
| **公共の福祉優先** | 土地は公共の利害に関係する特性を有するため、公共の福祉が優先される |
| **適正な利用及び管理** | 土地は所在する地域の自然的・社会的・経済的・文化的条件に応じて適正に利用し管理されるべき |
| **投機的取引の抑制** | 土地は投機的取引の対象とされてはならない |
| **価値の増加に伴う負担の適正化** | 土地の価値の増加に伴う利益に応じた適切な負担 |
| **管理の確保** | 土地の所有者等は周辺地域の良好な環境の確保等に資するよう適正に管理する責務 |

### 3. 責務 ★

| 主体 | 責務 |
|------|------|
| 国 | 土地に関する施策を総合的に策定・実施する責務 |
| 地方公共団体 | 国の施策と連携しつつ地域の実情に応じた施策を策定・実施 |
| 事業者 | 基本理念にのっとり土地の利用及び管理を行う責務 |
| 国民 | 基本理念にのっとり土地の利用及び管理を行う責務 |

### 4. 基本的施策 ★

- 土地利用計画の策定
- 土地取引の規制
- 社会資本の整備との関連における利益に応じた適切な負担
- 税制上の措置
- 公的土地評価の適正化、情報の提供
- 調査の実施
- 土地に関する施策の融合的な推進
