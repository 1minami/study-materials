# 行政法規 — 不動産登記法 ★★

> 毎年1〜2問出題。登記の種類と手続き、表示登記と権利登記の違いを正確に理解する。

## 1. 不動産登記制度の概要

### 目的

- 不動産の表示及び不動産に関する権利を**公示**するための登記制度を定め、国民の権利の保全を図り、取引の安全と円滑に資する

### 登記の対象

| 対象 | 例 |
|------|-----|
| 土地 | 一筆の土地ごとに登記 |
| 建物 | 一個の建物ごとに登記（区分建物含む） |

### 登記記録の構成

```
登記記録
├── 表題部（表示に関する登記）
│   ├── 土地: 所在、地番、地目、地積
│   └── 建物: 所在、家屋番号、種類、構造、床面積
└── 権利部
    ├── 甲区（所有権に関する登記）
    │   └── 所有権保存、所有権移転、差押え等
    └── 乙区（所有権以外の権利に関する登記）
        └── 抵当権、地上権、賃借権、地役権等
```

## 2. 表示に関する登記 ★★

### 表題登記の申請義務

| 場面 | 申請義務者 | 期限 |
|------|------------|------|
| 新築建物 | 所有者 | **1ヶ月以内** |
| 土地の表題登記（新たに生じた土地） | 所有者 | **1ヶ月以内** |
| 建物の滅失 | 所有者（共有の場合は持分の有無にかかわらず各共有者） | **1ヶ月以内** |
| 地目・地積の変更 | 所有者 | **1ヶ月以内** |
| 建物の種類・構造・床面積の変更 | 所有者 | **1ヶ月以内** |
| 土地の分筆・合筆 | 所有者 | 任意（義務なし） |

### 職権による表示登記

- **登記官**は、職権で表示に関する登記をすることができる
- 権利に関する登記は職権ではできない

### 分筆・合筆の制限

**合筆の制限**（以下のいずれかに該当する場合は合筆不可）:
- 接続していない土地
- 地目が相互に異なる土地
- 表題部所有者又は所有権の登記名義人が相互に異なる土地
- 所有権の登記がない土地と所有権の登記がある土地
- 所有権の登記以外の権利に関する登記がある土地（承役地の地役権を除く）

## 3. 権利に関する登記 ★★

### 登記の基本原則

| 原則 | 内容 |
|------|------|
| **共同申請主義** | 登記権利者と登記義務者が共同して申請（原則） |
| **申請主義** | 当事者の申請又は官公署の嘱託による（職権は原則不可） |
| **形式的審査主義** | 登記官は申請の形式面のみ審査（実質的な権利関係は審査しない） |
| **対抗力** | 登記をすることで第三者に対抗できる（177条） |
| **公信力なし** | 登記に公信力はない（登記を信頼しても保護されるとは限らない） |

### 単独申請が可能な場合 ★★

- **所有権保存登記**: 表題部所有者又はその相続人等
- **相続又は法人の合併による権利の移転**: 登記権利者の単独申請
- **判決による登記**: 確定判決を得た者の単独申請
- **仮登記**: 仮登記権利者の単独申請（仮登記義務者の承諾あり、又は裁判所の仮登記を命ずる処分あり）
- **登記名義人の氏名等の変更**: 登記名義人の単独申請

### 登記の種類

| 登記の種類 | 内容 |
|------------|------|
| **所有権保存登記** | 初めての所有権の登記 |
| **所有権移転登記** | 所有権の移転（売買、相続、贈与等） |
| **抵当権設定登記** | 抵当権の設定 |
| **仮登記** | 本登記の順位を保全するための登記 |
| **予告登記** | （廃止済み） |

### 仮登記 ★★

| 項目 | 内容 |
|------|------|
| 種類 | 1号仮登記（物権変動は生じているが書類が揃わない）、2号仮登記（請求権の保全） |
| 効力 | 仮登記に基づく本登記がされた場合、**仮登記の順位**による |
| 対抗力 | 仮登記のみでは**対抗力なし** |
| 申請 | 仮登記権利者の**単独申請**可（仮登記義務者の承諾書添付、又は仮登記を命ずる処分の正本添付） |
| 抹消 | 仮登記名義人の**単独申請**可、又は仮登記名義人の承諾があれば利害関係人の単独申請可 |

## 4. 登記識別情報 ★

| 項目 | 内容 |
|------|------|
| 交付対象 | 登記をすることによって権利を取得する登記名義人に通知 |
| 内容 | **12桁の英数字の組み合わせ** |
| 用途 | 次回の登記申請時に本人確認手段として提供 |
| 提供できない場合 | 事前通知制度又は資格者代理人による本人確認制度 |

## 5. 筆界特定制度

| 項目 | 内容 |
|------|------|
| 目的 | 土地の筆界の位置を特定する手続き |
| 申請者 | 土地の所有権登記名義人等 |
| 特定者 | **筆界特定登記官** |
| 効力 | 新たに筆界を創設するものではない。確認行為 |
| 不服 | 筆界特定に不服がある場合は**境界確定の訴え**提起可能 |
