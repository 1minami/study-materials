# 行政法規 — その他の法令 ★〜★★

> 農地法、宅建業法、品確法、都市再開発法、マンション関連法、環境関連法、税法等をまとめて整理。

## 1. 農地法 ★★

### 許可制度の体系

| 条文 | 行為 | 許可権者 | 備考 |
|------|------|----------|------|
| **3条** | 農地の権利移動（農地→農地） | **農業委員会** | 農地のまま権利移動 |
| **4条** | 農地の転用（自己の農地） | **都道府県知事**（4ha超は農林水産大臣との協議） | 農地を農地以外に |
| **5条** | 転用目的の権利移動 | **都道府県知事**（同上） | 3条+4条の複合 |

### 重要ポイント

- **市街化区域内**の農地の転用（4条・5条）→ **農業委員会への届出**で足りる（許可不要）
- 3条許可を受けずにした行為 → **無効**
- 4条・5条の無許可 → 都道府県知事が**原状回復命令**可能

### 農地の定義

- 耕作の目的に供される土地（現況主義: 登記地目にかかわらず、現に耕作されているか否かで判断）
- 採草放牧地も農地法の規制対象（3条・5条）

## 2. 宅地建物取引業法 ★★

### 鑑定士試験での出題ポイント

宅建試験ほど深く出題されないが、以下の基本事項は押さえる:

| テーマ | 要点 |
|--------|------|
| 免許 | 国土交通大臣免許（2以上の都道府県）又は都道府県知事免許 |
| 免許の有効期間 | **5年**（更新可） |
| 宅建士 | 事務所に従業者5人に1人以上の**専任の宅建士** |
| 営業保証金 | 主たる事務所: 1,000万円、従たる事務所: 500万円 |
| 重要事項説明 | **宅建士**が**説明**し、**記名**する（35条） |
| 37条書面 | 契約成立後遅滞なく交付。宅建士の記名 |
| 報酬 | 国土交通大臣の定める額を超えてはならない |

## 3. 都市再開発法 ★★

### 市街地再開発事業の種類

| | 第一種事業 | 第二種事業 |
|---|-----------|-----------|
| 手法 | **権利変換方式** | **管理処分方式（用地買収）** |
| 施行者 | 個人、組合、再開発会社、地方公共団体、都市再生機構等 | **地方公共団体、都市再生機構**のみ |
| 対象 | 一般的な再開発 | 公共性が高く緊急性のある大規模再開発 |

### 権利変換の仕組み

- 従前の権利者 → 施設建築物の一部（床）と施設建築敷地の共有持分に変換
- 地上権・借家権も原則として権利変換の対象
- 権利変換を希望しない者 → **金銭給付**の申出（**30日以内**）

### 施行区域の要件

- 高度利用地区、都市再生特別地区等の区域内
- 耐火建築物の建築面積の合計が区域内の建築面積の合計のおおむね**1/3以下**
- 十分な公共施設がない等

## 4. 土地区画整理法 ★★

### 基本的な仕組み

```
施行前の土地
  ↓ 換地処分
施行後の土地（換地）+ 保留地 + 公共施設用地
```

### 施行者

| 施行者 | 認可等 |
|--------|--------|
| 個人施行 | 都道府県知事の**認可** |
| 組合施行 | 都道府県知事の**認可**（7人以上の地権者で設立） |
| 区画整理会社 | 都道府県知事の**認可** |
| 地方公共団体 | 都道府県知事の**認可**（都道府県は国土交通大臣の認可） |
| 国土交通大臣 | — |
| 都市再生機構・地方住宅供給公社 | 都道府県知事の**認可** |

### 仮換地 ★★

- 施行者は換地処分前に**仮換地**を指定できる
- 仮換地指定の効果 → 仮換地を使用収益できるが、所有権は従前の土地に残る
- 従前の土地は使用収益停止

### 換地処分 ★

- **都道府県知事への届出**（関係権利者に通知）
- 換地処分の公告の**翌日**から換地は従前の土地とみなされる
- 保留地は施行者が取得
- 清算金の徴収・交付

### 建築行為等の制限

- 施行地区内で**建築物の新築・改築・増築**、**5トン超の移動が容易でない物件の設置・堆積**をしようとする者は、**都道府県知事の許可**が必要

## 5. マンション関連法 ★

### マンションの管理の適正化の推進に関する法律

| 項目 | 内容 |
|------|------|
| 管理業者 | **国土交通大臣**の登録（有効期間**5年**） |
| 管理業務主任者 | 管理業者の事務所に**30管理組合に1人以上** |
| マンション管理士 | **国土交通大臣**の登録。名称独占資格 |
| マンション管理適正化推進計画 | **市町村**が作成 |

### マンションの建替え等の円滑化に関する法律

| 項目 | 内容 |
|------|------|
| 建替組合 | 区分所有者の**4/5以上**の同意で設立認可申請 |
| 認可 | **都道府県知事**の認可 |
| 権利変換 | 従前のマンションの区分所有権 → 新たなマンションの区分所有権 |
| 除却の必要性の認定 | 耐震性不足等 → 特定行政庁の認定 → **マンション敷地売却** |

## 6. 住宅の品質確保の促進等に関する法律（品確法）★

| 項目 | 内容 |
|------|------|
| 瑕疵担保責任の特例 | 新築住宅の**構造耐力上主要な部分**及び**雨水の浸入を防止する部分**の瑕疵 → **引渡しから10年間**の担保責任（特約で短縮不可） |
| 住宅性能表示制度 | 任意の制度。登録住宅性能評価機関が評価 |
| 住宅紛争処理 | 建設住宅性能評価書が交付された住宅 → 指定住宅紛争処理機関に紛争処理申請可 |

## 7. 環境関連法 ★

### 土壌汚染対策法

| 項目 | 内容 |
|------|------|
| 調査契機 | 有害物質使用特定施設の廃止時、3,000㎡以上の土地の形質変更時 |
| 区域指定 | **要措置区域**（対策が必要）、**形質変更時要届出区域** |
| 要措置区域 | 都道府県知事が**汚染の除去等の措置**を講ずべきことを指示 |
| 形質変更時要届出区域 | 形質変更は**14日前**までに都道府県知事に届出 |

### 自然公園法

| 公園の種類 | 指定者 |
|------------|--------|
| 国立公園 | **環境大臣** |
| 国定公園 | **環境大臣**（都道府県知事の申出に基づく） |
| 都道府県立自然公園 | **都道府県** |

- 特別地域内の建築物の新改増築等 → **環境大臣又は都道府県知事の許可**
- 普通地域内の一定行為 → **環境大臣又は都道府県知事への届出**

### 文化財保護法

- 重要文化財の現状変更 → **文化庁長官の許可**
- 埋蔵文化財の発掘 → 文化庁長官に**届出**（**30日前**まで）
- 周知の埋蔵文化財包蔵地の土木工事 → **60日前**までに届出

### 盛土規制法（宅地造成及び特定盛土等規制法）

| 項目 | 内容 |
|------|------|
| 規制区域 | 宅地造成等工事規制区域、特定盛土等規制区域 |
| 規制対象 | 盛土・切土等で災害発生のおそれのある工事 |
| 許可 | **都道府県知事**の許可 |

## 8. 税法 ★★

### 不動産取得税（地方税法）

| 項目 | 内容 |
|------|------|
| 課税主体 | **都道府県** |
| 課税客体 | 不動産（土地・家屋）の取得 |
| 標準税率 | **4%**（住宅・土地は特例で**3%**） |
| 非課税 | 相続・法人の合併による取得、国・地方公共団体の取得 |
| 免税点 | 土地: 10万円、家屋新築: 23万円、家屋売買: 12万円 |

### 固定資産税（地方税法）

| 項目 | 内容 |
|------|------|
| 課税主体 | **市町村**（東京23区は都） |
| 納税義務者 | **1月1日**時点の固定資産課税台帳の登録者 |
| 標準税率 | **1.4%** |
| 免税点 | 土地: 30万円、家屋: 20万円 |
| 住宅用地の特例 | 小規模住宅用地（200㎡以下）: 課税標準**1/6**、一般住宅用地: **1/3** |

### 登録免許税

| 登記の種類 | 税率 |
|------------|------|
| 所有権保存登記 | **0.4%** |
| 所有権移転登記（売買） | **2%** |
| 所有権移転登記（相続） | **0.4%** |
| 抵当権設定登記 | **0.4%** |

### 譲渡所得（所得税法）

| 区分 | 所有期間 | 税率 |
|------|----------|------|
| 短期譲渡所得 | **5年以下** | 所得税30% + 住民税9% |
| 長期譲渡所得 | **5年超** | 所得税15% + 住民税5% |

- 所有期間の判定: 取得日から**譲渡した年の1月1日**まで
- 居住用財産の3,000万円特別控除あり
