# 行政法規 — 都市計画法・建築基準法 ★★★

> 毎年合計4〜6問出題。行政法規の最頻出分野。都市計画の体系と建築規制を横断的に理解する。

## Part 1: 都市計画法

### 1. 都市計画の体系 ★★★

```
都市計画区域
├── 市街化区域（すでに市街地 or おおむね10年以内に市街化を図る区域）
│   └── 用途地域を必ず定める
├── 市街化調整区域（市街化を抑制すべき区域）
│   └── 原則として用途地域を定めない
└── 非線引き区域（区分されていない区域）
    └── 用途地域を定めることができる

準都市計画区域（都市計画区域外で、土地利用の整序が必要な区域）
└── 用途地域を定めることができる
```

### 2. 用途地域 ★★★

| 用途地域（13種類） | 特徴 |
|---------------------|------|
| 第一種低層住居専用地域 | 低層住宅のための地域。最も厳しい制限 |
| 第二種低層住居専用地域 | 小規模店舗（150㎡以下）も可 |
| 第一種中高層住居専用地域 | 中高層住宅。大学、病院、500㎡以下の店舗可 |
| 第二種中高層住居専用地域 | 1,500㎡以下の店舗・事務所可 |
| 第一種住居地域 | 3,000㎡以下の店舗・事務所・ホテル可 |
| 第二種住居地域 | パチンコ店、カラオケボックス可 |
| 準住居地域 | 幹線道路沿い。自動車関連施設可 |
| 田園住居地域 | 農業と調和した低層住宅地域 |
| 近隣商業地域 | 近隣住民の日用品供給。ほとんどの商業施設可 |
| 商業地域 | 商業の利便増進。ほぼ全ての建築物可 |
| 準工業地域 | 環境悪化のおそれのない工業。住宅・商業も可 |
| 工業地域 | 工業の利便増進。住宅は建築可能だが学校・病院不可 |
| 工業専用地域 | 工業専用。住宅建築不可 |

### 3. 地区計画 ★★

- 用途地域の上乗せ・きめ細かな規制
- **市町村**が都市計画に定める
- 地区計画の区域内で建築等を行う場合 → **市町村長に届出**（**着手30日前**まで）
- 届出に対して市町村長は勧告できる

### 4. 都市計画の決定手続き ★★

| 都市計画 | 決定権者 |
|----------|----------|
| 都市計画区域の指定 | **都道府県**（2以上の都府県にまたがる場合は**国土交通大臣**） |
| 区域区分 | **都道府県** |
| 用途地域等 | **市町村**（ただし都道府県が定める場合もあり） |
| 地区計画 | **市町村** |

### 5. 開発許可制度 ★★★

#### 開発行為の定義

- 主として**建築物の建築**又は**特定工作物の建設**の用に供する目的で行う**土地の区画形質の変更**

#### 許可が必要な面積要件

| 区域 | 許可が必要な規模 |
|------|------------------|
| 市街化区域 | **1,000㎡以上**（三大都市圏の既成市街地等は**500㎡以上**） |
| 市街化調整区域 | **面積にかかわらず全て**許可必要 |
| 非線引き区域 | **3,000㎡以上** |
| 準都市計画区域 | **3,000㎡以上** |
| 都市計画区域外 | **10,000㎡以上**（1ha） |

#### 許可不要の例外 ★★

- 農林漁業用建築物（市街化区域以外）
- 公益上必要な建築物（駅舎、図書館、公民館等）
- 都市計画事業・土地区画整理事業等の施行として行う開発行為
- 非常災害のため応急措置として行う開発行為

#### 市街化調整区域での建築制限

- 開発許可を受けた区域以外 → 原則として建築物の建築・建築物の改築不可
- **都道府県知事の許可**が必要

### 6. 都市計画制限 ★★

| 都市計画 | 制限内容 | 許可権者 |
|----------|----------|----------|
| 都市計画施設の区域内 | 建築物の建築には許可が必要 | **都道府県知事** |
| 市街地開発事業の施行区域内 | 建築物の建築・工作物の建設等に許可が必要 | **都道府県知事** |
| 風致地区内 | 建築物の建築、宅地造成等に許可が必要 | **都道府県知事** |

## Part 2: 建築基準法

### 1. 用語の定義 ★★

| 用語 | 定義 |
|------|------|
| 建築物 | 土地に定着する工作物のうち、屋根及び柱若しくは壁を有するもの |
| 特殊建築物 | 学校、病院、劇場、百貨店、共同住宅、倉庫、工場等 |
| 建築 | 新築、増築、改築、移転 |
| 大規模の修繕 | 主要構造部の一種以上について行う過半の修繕 |
| 大規模の模様替 | 主要構造部の一種以上について行う過半の模様替 |

### 2. 建築確認 ★★

#### 確認が必要な建築物

| 建築物 | 新築 | 増改築・移転 | 大規模修繕・模様替 | 用途変更 |
|--------|------|------------|------------------|----------|
| 特殊建築物（200㎡超） | ○ | ○ | ○ | ○ |
| 大規模建築物（木造: 高さ13m超 or 軒高9m超 or 3階以上 or 延べ面積500㎡超 / 非木造: 2階以上 or 延べ面積200㎡超） | ○ | ○ | ○ | × |
| 上記以外（都市計画区域等内） | ○ | ○（10㎡以下は不要） | × | × |

### 3. 単体規定（全国適用）★

- **構造耐力**: 自重、積載荷重、積雪荷重、風圧、地震力等に対して安全
- **防火**: 耐火建築物、準耐火建築物の要件
- **避難**: 直通階段、避難階段、排煙設備
- **居室の採光・換気**: 有効面積の基準
- **シックハウス対策**: ホルムアルデヒド発散建築材料の制限

### 4. 集団規定（都市計画区域等内で適用）★★★

#### 建蔽率 ★★★

| 用途地域 | 指定建蔽率 |
|----------|------------|
| 第一種・第二種低層住居専用、田園住居 | 30, 40, 50, 60% |
| 第一種・第二種中高層住居専用 | 30, 40, 50, 60% |
| 第一種・第二種住居、準住居 | 50, 60, 80% |
| 近隣商業 | 60, 80% |
| 商業 | 80% |
| 準工業 | 50, 60, 80% |
| 工業、工業専用 | 30, 40, 50, 60% |

**建蔽率の緩和**:
- 角地: +10%
- 防火地域内の耐火建築物: +10%
- 上記両方: +20%
- 指定建蔽率80%の地域 + 防火地域内の耐火建築物 → **制限なし**

#### 容積率 ★★★

- **指定容積率**: 都市計画で定めた数値
- **前面道路幅員による制限**: 前面道路幅員 × 法定乗数（住居系: 4/10、その他: 6/10）
- **適用**: 指定容積率と前面道路幅員による容積率の**小さい方**

#### 高さ制限 ★★

| 制限の種類 | 対象 |
|------------|------|
| 絶対高さ制限 | 第一種・第二種低層住居専用地域、田園住居地域（10m or 12m） |
| 道路斜線制限 | 全用途地域 |
| 隣地斜線制限 | 低層住居専用地域・田園住居地域**以外** |
| 北側斜線制限 | 低層住居専用・田園住居・中高層住居専用地域 |
| 日影規制 | 中高層建築物（商業・工業・工業専用地域以外） |

#### 防火地域・準防火地域 ★★

| 地域 | 制限 |
|------|------|
| 防火地域 | 3階以上 or 延べ面積100㎡超 → **耐火建築物**、それ以外 → 耐火 or 準耐火 |
| 準防火地域 | 4階以上 or 延べ面積1,500㎡超 → **耐火建築物**、それ以外 → 段階的制限 |

### 5. 建築協定 ★

- 土地の所有者等の**全員の合意**で締結
- **特定行政庁**の認可が必要
- 建築協定区域隣接地の所有者は、認可公告後いつでも加入可能
- 認可後に土地所有者となった者にも効力あり
