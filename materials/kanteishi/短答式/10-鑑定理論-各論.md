# 鑑定理論 — 各論 ★★★

> 鑑定評価基準の各論部分。類型別の評価手法、証券化対象不動産、賃料評価等を整理する。

## 1. 類型別の鑑定評価 ★★★

### 更地の鑑定評価

| 手法 | 適用 | 備考 |
|------|------|------|
| 取引事例比較法 | ★★★ 最重要 | 更地の取引事例が豊富な場合に特に有効 |
| 収益還元法 | ★★★ | 賃貸を想定した土地残余法、又は建物及びその敷地として収益価格を求め土地に配分 |
| 原価法 | ★★ | 造成地の場合に適用（素地価格＋造成費＋付帯費用） |
| 開発法 | ★★ | 開発可能な更地で、最有効使用が建物の建築を前提とする場合 |

### 建物及びその敷地の鑑定評価

| 手法 | 適用 | 備考 |
|------|------|------|
| 原価法 | ★★★ | 再調達原価を求め、減価修正。建物と敷地を一体として |
| 取引事例比較法 | ★★ | 類似の建物及びその敷地の取引事例から |
| 収益還元法 | ★★★ | 賃貸用不動産に特に有効。直接還元法又はDCF法 |

### 借地権の鑑定評価 ★★

| 手法 | 内容 |
|------|------|
| 取引事例比較法 | 借地権の取引事例から比準 |
| 収益還元法 | 借地権者に帰属する純収益を還元 |
| 借地権割合法 | 更地価格 × 借地権割合 |
| 借地権残余法 | 建物及びその敷地の収益価格から建物価格と底地価格を控除 |

### 底地の鑑定評価 ★★

| 手法 | 内容 |
|------|------|
| 収益還元法 | 底地に帰属する純収益（地代）を還元 |
| 取引事例比較法 | 底地の取引事例から比準（事例が少ないことが多い） |
| 更地価格−借地権価格 | 控除法（あくまで参考） |

### 区分所有建物及びその敷地の鑑定評価 ★

- 専有部分と敷地利用権を**一体**として評価
- 原価法、取引事例比較法、収益還元法を適用
- 一棟全体の効用と専有部分の位置・階層・向き等を考慮

## 2. 貸家及びその敷地の鑑定評価 ★★

### 基本的な考え方

```
貸家及びその敷地の価格 = 自用の建物及びその敷地の価格 − 賃借人の権利相当額
```

### 手法の適用

| 手法 | 内容 |
|------|------|
| 収益還元法 | 賃料収入に基づく純収益を還元。最も重要 |
| 原価法 | 積算価格から賃借人の権利相当額を控除 |
| 取引事例比較法 | 貸家及びその敷地の取引事例から比準 |

### 賃借人の権利相当額

- 建物賃借権の対価、造作買取請求権、立退料等を考慮
- 契約の内容（残存期間、賃料水準、契約条件）に依存

## 3. 証券化対象不動産の鑑定評価 ★★★

### 対象

- 投資信託（J-REIT）、特定目的会社（TMK）、不動産ファンド等が取得・保有する不動産

### 特別の留意事項

| 項目 | 内容 |
|------|------|
| 手法の適用 | **DCF法を適用しなければならない**。直接還元法又はDCF法により求められた収益価格を中心に判断 |
| エンジニアリングレポート | ER（建物の物理的状況調査報告書）を活用 |
| 収支項目 | 各収支項目を**明確に**把握し、適切に査定 |
| 割引率・還元利回り | 類似の不動産に係る取引事例との比較等から求める。査定根拠を明確に |
| 復帰価格 | 保有期間満了時の転売想定価格。適切に査定 |

### DCF法の収支項目の詳細

#### 運営収益

| 項目 | 内容 |
|------|------|
| 貸室賃料収入 | 各テナントの契約賃料に基づく |
| 共益費収入 | 共用部分の維持管理費相当 |
| 水道光熱費収入 | テナントからの水光熱費回収額 |
| 駐車場収入 | 駐車場の賃料収入 |
| その他収入 | 看板使用料、自販機収入、アンテナ基地局使用料等 |
| 空室等損失 | 空室率に基づく損失額（控除） |
| 貸倒れ損失 | 賃料の回収不能見込額（控除） |

#### 運営費用

| 項目 | 内容 |
|------|------|
| 維持管理費 | BM費（ビルメンテナンス） |
| 水道光熱費 | 共用部分+貸室部分 |
| 修繕費 | 経常的な修繕費 |
| PMフィー | プロパティマネジメント報酬 |
| テナント募集費用 | 仲介手数料、広告費等 |
| 公租公課 | 固定資産税・都市計画税 |
| 損害保険料 | 火災保険等 |
| その他費用 | 町会費等 |

#### 資本的支出

- 大規模修繕費、設備更新費等
- 経年による資本的支出の増加を考慮

## 4. 開発法 ★★

### 基本的な考え方

- 更地について、最有効使用の建物の建築を想定し、完成後の建物及びその敷地の価格から、建築費・発注者利益等を控除して土地の価格を求める

### 計算式

```
開発法による価格 = 完成後の建物及びその敷地の価格（販売総額）
                 − 建築費
                 − 付帯費用（設計料、販売費等）
                 − 発注者利益
                 − 投下資本の利息
```

### 適用が有効な場合

- 建物の建築が最有効使用と認められる更地
- 分譲マンションの敷地
- 戸建住宅分譲素地
- 開発許可が見込まれる開発素地

## 5. 賃料の各論 ★★

### 新規賃料と継続賃料の違い ★★★

| | 新規賃料 | 継続賃料 |
|---|----------|----------|
| 場面 | 新たに賃貸借契約を締結する場合 | 既存の賃貸借契約の賃料を改定する場合 |
| 特徴 | 市場賃料（正常賃料） | 契約の経緯、当事者間の個別事情を考慮 |
| 手法 | 積算法、賃貸事例比較法、収益分析法 | 差額配分法、利回り法、スライド法、賃貸事例比較法 |

### 賃料の種類

| 種類 | 定義 |
|------|------|
| **正常賃料** | 正常価格と同一の市場概念の下で成立する適正な賃料 |
| **限定賃料** | 限定価格と同一の市場概念の下で成立する適正な賃料 |
| **継続賃料** | 賃貸借等の継続に係る特定の当事者間で成立するであろう適正な賃料 |

### 継続賃料の特殊性

- 契約当事者間の**個別的な事情**が反映される
- **契約の経緯**、**経過期間**、**賃料改定の経緯**を考慮
- 直近合意時点と価格時点の間の**事情の変更**が必要（賃料増減の根拠）

## 6. 地価公示法との関連 ★★

### 不動産鑑定士が公示区域内の土地の正常価格を求める場合

- **公示価格を規準としなければならない**（地価公示法第8条）
- 規準 = 対象土地の価格と公示価格との間に**均衡を保たせる**こと

### 規準の手順

1. 対象不動産の近隣地域又は同一需給圏内の類似地域にある**標準地**を選択
2. 標準地の公示価格と対象土地の価格形成要因を比較
3. 対象土地の試算価格と公示価格との間に均衡を確認

## 7. 鑑定評価書 ★★

### 必要的記載事項

1. 鑑定評価額
2. 鑑定評価の対象となった不動産の表示
3. 鑑定評価の条件
4. 価格時点
5. 鑑定評価の依頼目的
6. 鑑定評価を行った年月日
7. 価格の種類
8. 鑑定評価の方法（手法の適用、試算価格の調整）
9. 対象不動産の確認に関する事項
10. 鑑定評価に関する利害関係の有無
11. 関与した不動産鑑定士の氏名
12. その他

### 鑑定評価書の交付

- 鑑定業者は依頼者に対して鑑定評価書を**交付しなければならない**
- 不動産鑑定士は鑑定評価書に**署名押印**しなければならない

## 8. 不動産鑑定評価基準に関する実務指針（留意事項）★★

### 短答式で問われる主要な留意事項

| テーマ | 留意事項の要点 |
|--------|---------------|
| 取引事例の収集 | 同一需給圏を基本。投機的取引は排除 |
| 建物の残存耐用年数 | 実際の維持管理状態を重視。法定耐用年数に固執しない |
| 還元利回り・割引率 | 地域、用途、築年数、権利関係に応じた利回りの査定 |
| 証券化対象不動産 | DCF法必須。ER活用。収支項目の明確化 |
| 継続賃料 | 直近合意時点の確認。事情変更の有無 |
