# 行政法規 — 不動産の鑑定評価に関する法律 ★★★

> 鑑定士試験の根幹となる法律。毎年2〜3問出題。法の目的、鑑定士制度、業務規制を正確に理解する。

## 1. 法の目的と定義

### 目的（第1条）

- 不動産の鑑定評価に関する法律は、不動産の鑑定評価に関し、**不動産鑑定士**の資格を定め、不動産鑑定業の登録制度を設ける等により、不動産の鑑定評価の**適正**を図り、もって**国民経済の健全な発展に寄与する**ことを目的とする

### 重要な定義

| 用語 | 定義 |
|------|------|
| 不動産の鑑定評価 | 不動産の経済価値を判定し、その結果を価額に表示すること |
| 不動産鑑定士 | 不動産鑑定士試験に合格し、国土交通大臣の登録を受けた者 |
| 不動産鑑定業 | 他人の求めに応じ報酬を得て、不動産の鑑定評価を業として行うこと |
| 不動産鑑定業者 | 不動産鑑定業の登録を受けた者（個人・法人） |

## 2. 不動産鑑定士の資格・登録 ★★★

### 試験制度

- 国土交通大臣が毎年1回以上実施
- **土地鑑定委員会**が試験事務を行う
- 不正受験者には合格の取消し、2年以内の受験禁止

### 登録制度

| 項目 | 内容 |
|------|------|
| 登録先 | **国土交通大臣** |
| 登録簿 | 不動産鑑定士登録簿 |
| 実務修習 | 登録には実務修習の修了が必要 |
| 登録拒否事由 | 禁錮以上の刑（執行終了から3年未経過）、懲戒処分による登録消除（3年未経過）等 |

### 登録拒否事由（主要なもの）★★

- 心身の故障により不動産鑑定士の業務を適正に行うことができない者
- 禁錮以上の刑に処せられ、執行終了から**3年**を経過しない者
- この法律の規定に違反して罰金の刑に処せられ、執行終了から**3年**を経過しない者
- 懲戒処分により登録を消除され、**3年**を経過しない者
- 懲戒処分により業務禁止の処分を受け、その期間中に登録の消除を申請し、期間満了していない者

### 変更登録・死亡届等

- 登録事項に変更があったとき → **遅滞なく**変更登録申請
- 死亡・失踪宣告 → 相続人・利害関係人が**30日以内**に届出

## 3. 不動産鑑定士の義務 ★★★

### 主要な義務

| 義務 | 内容 | 条文 |
|------|------|------|
| **誠実義務** | 良心に従い、誠実に鑑定評価を行う | 第15条 |
| **公正義務** | 自己の鑑定評価に関して不当な影響を与える行為をしない | 第15条 |
| **秘密保持義務** | 業務上知り得た秘密を正当な理由なく漏らしてはならない（鑑定士でなくなった後も同様） | 第16条 |
| **名義貸し禁止** | 自己の名義を他人に使用させてはならない | 第17条 |
| **信用失墜行為の禁止** | 鑑定士の信用を傷つけるような行為をしてはならない | 第18条 |
| **鑑定評価書への署名押印** | 鑑定評価を行ったときは鑑定評価書に署名押印する | 第39条 |

### 秘密保持義務の重要ポイント

- **退職後・登録消除後も継続**する
- 「正当な理由」がある場合は例外（裁判所への証言等）
- 違反は**1年以下の懲役又は100万円以下の罰金**

## 4. 不動産鑑定業の登録 ★★★

### 登録制度

| 項目 | 内容 |
|------|------|
| 登録先 | 事務所を設置する都道府県の区域の**都道府県知事**（2以上の都道府県 → **国土交通大臣**） |
| 登録の有効期間 | **5年**（5年ごとに更新） |
| 登録簿 | 不動産鑑定業者登録簿（一般の閲覧に供する） |
| 登録免許税 | 登録時に必要 |

### 登録拒否事由（主要なもの）

- **事務所ごとに1人以上の専任の不動産鑑定士を置いていない**場合
- 登録の取消しから**5年**を経過しない法人で、取消処分の聴聞公示日前60日以内に役員であった者がその取消しから5年を経過しない場合
- 暴力団員等

### 変更届出

- 登録事項に変更 → **30日以内**に届出
- 廃業等 → **30日以内**に届出

## 5. 不動産鑑定業者の業務規制 ★★

### 主要な規制

| 規制 | 内容 |
|------|------|
| 鑑定評価の引受け | 事務所に設置した不動産鑑定士に鑑定評価を行わせなければならない |
| 書面の交付 | 依頼者に鑑定評価書を交付しなければならない |
| 業務の制限 | 自己の利害関係のある不動産について鑑定評価を行ってはならない（缶詰条項） |
| 秘密保持 | 業者としても秘密保持義務あり |
| 帳簿の備付け | 事務所ごとに帳簿を備え付け、保存しなければならない |
| 従業者証明書 | 従業者に証明書を携帯させなければならない |

### 鑑定評価書の記載事項

- 対象不動産の所在、地番等
- 鑑定評価の条件
- 鑑定評価額
- 鑑定評価の方法
- 鑑定評価を行った不動産鑑定士の氏名
- その他国土交通省令で定める事項

## 6. 監督処分・懲戒 ★★

### 不動産鑑定士に対する懲戒処分

| 処分 | 内容 |
|------|------|
| 戒告 | 将来を戒める |
| 業務禁止 | **2年以内**の期間を定めて業務を禁止 |
| 登録の消除 | 登録を消除する（最も重い処分） |

### 処分事由

- 不動産鑑定士の義務違反
- 不動産の鑑定評価に関し不正又は著しく不当な行為

### 不動産鑑定業者に対する監督処分

| 処分 | 内容 |
|------|------|
| 指示 | 業務改善等を指示 |
| 業務停止 | **1年以内**の期間を定めて業務の全部又は一部を停止 |
| 登録の取消し | 登録を取り消す |

### 処分権者

- 国土交通大臣登録業者 → **国土交通大臣**（業務地の知事も指示・停止可能）
- 知事登録業者 → **当該知事**（他の知事は通知のみ）

## 7. 土地鑑定委員会 ★★

| 項目 | 内容 |
|------|------|
| 設置場所 | **国土交通省** |
| 委員数 | **7人**（両議院の同意を得て国土交通大臣が任命） |
| 任期 | **3年**（再任可） |
| 主な職務 | 地価公示、不動産鑑定士試験の実施、鑑定評価基準の制定 |

## 8. 罰則（主要なもの）

| 違反行為 | 罰則 |
|----------|------|
| 不正鑑定評価 | **2年以下の懲役又は100万円以下の罰金** |
| 秘密漏洩 | 1年以下の懲役又は100万円以下の罰金 |
| 名義貸し | 1年以下の懲役又は100万円以下の罰金 |
| 無登録営業 | 1年以下の懲役又は100万円以下の罰金 |
| 業務停止命令違反 | 1年以下の懲役又は100万円以下の罰金 |
