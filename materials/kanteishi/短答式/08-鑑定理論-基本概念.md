# 鑑定理論 — 基本概念 ★★★

> 不動産鑑定評価基準の総論部分。鑑定評価の基本的な考え方・用語・原則を体系的に理解する。短答式40問中の中核。

## 1. 不動産の鑑定評価とは

### 定義

- 不動産の鑑定評価とは、不動産の**経済価値**を判定し、これを**貨幣額**をもって表示すること
- 不動産の鑑定評価は、その対象である不動産の**現実の利用状況**（現況）のみならず、その不動産の**最有効使用**を前提として行う

### 不動産の価格の特徴

| 特徴 | 説明 |
|------|------|
| **個別性** | 同じ不動産は2つとない。立地・面積・形状・法規制等が異なる |
| **地域性** | 不動産の価格はその存する地域の特性に影響される |
| **市場の不完全性** | 不動産市場は情報の非対称性、取引の個別性等により不完全 |
| **価格の多元性** | 同一の不動産でも、利用方法や主体により複数の価格が成立しうる |

## 2. 不動産の価格を形成する要因 ★★★

### 価格形成要因の分類

```
価格形成要因
├── 一般的要因（マクロ的な要因）
│   ├── 自然的要因（地質、地盤、気象等）
│   ├── 社会的要因（人口、家族構成、都市化等）
│   ├── 経済的要因（景気、物価、金利、財政等）
│   └── 行政的要因（法規制、税制、都市計画等）
├── 地域要因（地域の特性を形成する要因）
│   ├── 住宅地域: 日照、交通、公共施設等
│   ├── 商業地域: 繁華性、顧客の流動、交通等
│   └── 工業地域: 輸送の便、労働力等
└── 個別的要因（個々の不動産の特性）
    ├── 土地: 地積、形状、接面道路、画地条件等
    └── 建物: 建築年次、構造、設計、設備等
```

### 一般的要因 ★★

| 分類 | 主な要因 |
|------|----------|
| 自然的要因 | 地質、地盤の状態、土壌、気象条件、自然災害リスク |
| 社会的要因 | 人口の状態、家族構成・世帯分離の状態、都市形成・公共施設の状態、教育投資の状態、不動産の取引・使用収益の慣行、建築様式の状態、情報化の進展 |
| 経済的要因 | 貯蓄・消費・投資の水準、財政・金融の状態、物価・賃金・雇用の状態、税負担の状態、国際化の状態 |
| 行政的要因 | 土地利用規制、住宅政策、都市計画、税制、公共投資 |

### 地域要因 ★★

| 地域の種類 | 主な地域要因 |
|------------|-------------|
| 住宅地域 | 日照・通風・乾湿、地勢・地盤、街路幅員・配置、都心との距離、交通施設の状態、商業施設の配置、公共施設・公益施設の配置、汚水・ゴミ処理施設、情報通信基盤、公園・緑地、景観、眺望、自然環境 |
| 商業地域 | 商業収益の状態、繁華性の程度、顧客の流動の状態、商業背後地の状態、交通施設との距離、高度利用の程度 |
| 工業地域 | 幹線道路・鉄道・港湾・空港との距離、労働力確保の難易、用排水・動力供給の状態、関連産業との近接性 |

### 個別的要因 ★★

**土地の個別的要因**:
- 地積、形状（間口・奥行等）
- 高低、角地等の接面街路との関係
- 接面街路の幅員、構造、系統、連続性
- 都市計画法等の公法上の規制
- 日照、通風、乾湿の状態
- 埋蔵文化財・地下埋設物の有無
- 土壌汚染の有無

**建物の個別的要因**:
- 建築年次、面積、高さ、構造、材質
- 設計、設備の状態
- 施工の質・量
- 維持管理の状態
- 耐震性、有害物質（アスベスト等）の使用の有無

## 3. 不動産の類型 ★★★

### 土地の類型

| 類型 | 定義 |
|------|------|
| **更地** | 建物等の定着物がなく、使用収益を制約する権利の付着していない宅地 |
| **建付地** | 建物等の用に供されている宅地（自用の建物等の敷地） |
| **借地権** | 借地借家法に基づく借地権（建物所有目的の地上権・賃借権） |
| **底地** | 借地権の付着している宅地の所有権 |
| **区分地上権** | 工作物所有を目的として地下又は空間の範囲を定めた地上権 |

### 建物及びその敷地の類型

| 類型 | 定義 |
|------|------|
| **自用の建物及びその敷地** | 所有者が自ら使用する建物とその敷地 |
| **貸家及びその敷地** | 建物所有者が建物を賃貸している場合の建物とその敷地 |
| **借地権付建物** | 借地権の上に建物がある場合の建物と借地権 |
| **区分所有建物及びその敷地** | マンション等の区分所有建物の専有部分と敷地利用権 |

## 4. 最有効使用の原則 ★★★

### 定義

- 不動産の価格は、その不動産の**最有効使用**を前提として把握される価格を標準として形成される
- **最有効使用**とは、その不動産の効用が最高度に発揮される可能性に最も富む使用

### 最有効使用の判定基準

最有効使用は以下の条件を**全て**満たす使用:
1. **物理的に可能**な使用
2. **法的に許容**される使用
3. **経済的に合理的**と認められる使用
4. 上記を満たす使用のうち**最も収益性の高い**使用

### 重要ポイント

- 現実の使用が最有効使用でない場合 → **最有効使用を前提**として鑑定評価を行う
- 最有効使用は、**良識と通常の使用能力**を持つ人による合理的かつ合法的な使用を前提
- 投機的な使用は最有効使用には該当しない

## 5. 不動産の価格に関する諸原則 ★★★

| 原則 | 内容 | 説明 |
|------|------|------|
| **需要と供給の原則** | 価格は需要と供給の相互関係で決まる | 需要増→価格上昇、供給増→価格下降 |
| **変動の原則** | 価格は常に変動する | 価格形成要因は常に変化 |
| **代替の原則** | 代替可能な不動産の価格は相互に影響 | 近隣の類似不動産との均衡 |
| **最有効使用の原則** | 最有効使用を前提として価格形成 | 上記参照 |
| **均衡の原則** | 価格は各要素の均衡で決まる | 土地と建物のバランス等 |
| **収益逓増及び逓減の原則** | 投資は収益が逓減し始める点が最有効 | 追加投資の限界 |
| **収益配分の原則** | 総収益は各生産要素に配分される | 土地帰属分の把握 |
| **寄与の原則** | 各要素は全体の収益への寄与度で評価 | 部分の価値=全体への寄与 |
| **適合の原則** | 環境に適合する使用が最高価格を形成 | 地域との調和 |
| **競争の原則** | 超過利潤は競争を招く | 競争→利潤の平準化 |
| **予測の原則** | 将来の動向の予測に基づく | 価格は将来の便益の現在価値 |

## 6. 地域分析と個別分析 ★★★

### 地域分析

| 項目 | 内容 |
|------|------|
| 目的 | 対象不動産がどのような地域に存するかを明らかにし、地域の標準的な使用を判定 |
| 対象 | **同一需給圏**（代替・競争関係が成立する地域の範囲） |
| 分析内容 | 近隣地域の特性、類似地域との比較、地域要因の分析 |

### 近隣地域と類似地域 ★★

| | 近隣地域 | 類似地域 |
|---|----------|----------|
| 定義 | 対象不動産の価格形成に**直接的に**影響を与える地域 | 近隣地域と**類似する特性**を有する地域 |
| 特徴 | 地域の特性がおおむね**同質**（用途的に同質な地域） | 近隣地域の地域要因と**類似する**地域要因を有する |
| 範囲 | 対象不動産の存する地域 | 同一需給圏内に存する |

### 個別分析

- 対象不動産の**個別的要因**を分析し、対象不動産の**最有効使用**を判定
- 地域分析で判定した標準的使用を前提として、個別的要因の優劣を分析

## 7. 鑑定評価の条件 ★★

### 対象確定条件

| 条件 | 内容 |
|------|------|
| **現状所与** | 現実の状態を所与として鑑定評価 |
| **独立鑑定評価** | 対象不動産を対象確定条件に基づく不動産の部分を独立に鑑定評価 |
| **部分鑑定評価** | 対象不動産を対象確定条件に基づく不動産の部分として鑑定評価 |
| **併合鑑定評価** | 隣接する土地を併合した状態を前提に鑑定評価 |
| **分割鑑定評価** | 一体の土地を分割した状態を前提に鑑定評価 |

### 地域要因又は個別的要因についての想定上の条件

- **条件設定の要件**: ①実現性、②合法性、③関係当事者及び第三者の利益を害するおそれがないこと、④鑑定評価書の利用者の利益を害するおそれがないこと

### 調査範囲等条件

- 調査の範囲に制約がある場合に付す条件
- 条件の内容と根拠を鑑定評価書に記載

## 8. 価格の種類 ★★★

| 価格の種類 | 定義 | 求め方 |
|------------|------|--------|
| **正常価格** | 市場性を有する不動産について、現実の社会経済情勢の下で合理的と考えられる条件を満たす市場で形成されるであろう市場価値を表示する適正な価格 | 原則 |
| **限定価格** | 市場性を有する不動産について、市場が相対的に限定される場合の適正な価格（隣接不動産の併合等） | 限定された市場を前提 |
| **特定価格** | 法令等による社会的要請を背景とする評価目的の下で、正常価格の前提となる諸条件を満たさない場合の価格（民事再生法等） | 特定の前提条件 |
| **特殊価格** | 市場性を有しない不動産の経済価値を適正に表示する価格（文化財等） | 市場性なし |

### 正常価格の成立条件

1. 市場参加者が**自由意思**で取引を行う
2. 売り急ぎ、買い急ぎ等の**特殊な事情**がない
3. 対象不動産の情報が十分に**公開**されている
4. 取引当事者が対象不動産について**通常の知識**を有する
