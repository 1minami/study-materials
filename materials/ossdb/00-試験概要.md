# 試験概要

> OSS-DB Silver（Ver.3.0）の試験情報と、このテキストの使い方。運用管理が半分以上を占める。

## 1. 試験の基本情報

| 項目 | 内容 |
|---|---|
| 試験名 | OSS-DB Exam Silver（オープンソースデータベース技術者認定試験） |
| 実施団体 | LPI-Japan |
| 試験バージョン | **Ver.3.0** |
| 基準 RDBMS | **PostgreSQL 12 以上**（公式は「2023年2月時点で14まで対応」）。このテキストは **PostgreSQL 14** を基準に書く |
| 出題数 | 約**50問** |
| 試験時間 | 90分（公式の出題範囲ページには記載なし。市販対策書の記載による） |
| 受験料 | 16,500円（税込） |
| 合格ライン | 非公開 |
| 形式 | CBT（テストセンター / オンライン）。ほぼ選択式で、一部キーボード入力あり |

- ⚠ PostgreSQL 15 で関数名が変わったものがある（例: `pg_start_backup()` → `pg_backup_start()`）。試験は14基準なので**旧名**で覚える。該当箇所は本文で注記する

## 4. このテキストの読み方

- 見出しの **★** は出題頻度の目安（★★★ = 毎回出る）

- **太字**は暗記対象のキーワード
- 右サイドバーの学習メモは章ごとにブラウザへ保存される（宅建版とは別の保存先）
