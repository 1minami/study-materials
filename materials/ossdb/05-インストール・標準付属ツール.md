# インストール・標準付属ツール

> S2.1 インストール方法（重要度2）＋ S2.2 標準付属ツールの使い方（重要度5）。合わせて7問前後。initdb・pg_ctl のオプションと、psql のメタコマンドが定番。

## 1. インストールの流れ ★★

### インストール方法の種類

| 方法 | 内容 |
|---|---|
| **パッケージ** | OS のパッケージ管理（dnf / yum、apt）や、PostgreSQL 公式リポジトリ（PGDG）のパッケージを入れる。一般的な方法 |
| **ソースコード** | ソースを入手してビルドする。インストール先やビルドオプションを細かく選べる |
| インストーラ | Windows・macOS 向けのグラフィカルなインストーラ |

### ソースコードからのインストール

```
./configure          # 環境チェックと Makefile の生成（--prefix でインストール先を指定）
make                 # ビルド（GNU make が必要）
make check           # リグレッションテスト（任意。一般ユーザーで実行する）
make install         # インストール（書き込み権限のあるユーザーで実行）
```

- **configure** の主なオプション: **`--prefix=ディレクトリ`**（インストール先。デフォルト **`/usr/local/pgsql`**）、`--with-openssl`（SSL 対応）、`--without-readline`、`--without-zlib`、`--with-perl` / `--with-python`（PL/Perl・PL/Python）
- ⚠ **readline**（psql の行編集・履歴）と **zlib**（pg_dump の圧縮）は**デフォルトで必須**。無ければ configure がエラーになる（`--without-〜` で外せる）
- `make world` / `make install-world`: ドキュメントと **contrib**（追加モジュール）も含めてビルド・インストール
- contrib だけ追加するなら、`contrib/` ディレクトリで `make` → `make install`

### インストール後の作業

1. PostgreSQL 管理用の OS ユーザー（通常 **`postgres`**）を作る
2. データベースクラスタ用のディレクトリを作り、所有者を postgres にする
3. postgres ユーザーで **initdb** を実行してデータベースクラスタを作る
4. **pg_ctl start** でサーバを起動する
5. 必要に応じて環境変数（PATH、**PGDATA** など）を設定する

- ⚠ PostgreSQL サーバは **root（管理者権限）では起動できない**。initdb も root では実行できない
- パッケージ版は systemd のサービス（例: `systemctl start postgresql-14`）で起動・停止することが多い

## 2. データベースクラスタと initdb ★★★

### データベースクラスタ

- **1つのサーバ（postgres プロセス群）が管理するデータベースの集まり**。ディスク上では1つのディレクトリ（**データディレクトリ**）
- ⚠ 「クラスタ」は複数サーバの集合のことではない。**1インスタンスが管理するデータベース群**
- initdb 直後に作られるデータベース: **template0**、**template1**、**postgres** の3つ
  - **template1**: CREATE DATABASE のデフォルトの**複製元**（→ 08章）
  - **template0**: 変更してはいけない素のテンプレート
  - **postgres**: 接続先がないときに使うデフォルトのデータベース

### initdb の主なオプション

| オプション | 意味 |
|---|---|
| **`-D ディレクトリ`** / `--pgdata` | データベースクラスタを作る場所。省略時は環境変数 **PGDATA** |
| **`-E エンコーディング`** / `--encoding` | テンプレートデータベースの**文字エンコーディング**（例: `UTF8`）。省略時はロケールから決まる |
| **`--locale=ロケール`** | ロケール（照合順序・文字種別など）をまとめて指定 |
| `--lc-collate` / `--lc-ctype` 等 | ロケールを項目ごとに指定 |
| **`--no-locale`** | ロケールを使わない（= **`--locale=C`**） |
| **`-U ユーザー名`** / `--username` | データベースのスーパーユーザー名。省略時は **initdb を実行した OS ユーザー名** |
| **`-W`** / `--pwprompt` | スーパーユーザーのパスワードを対話で設定 |
| **`-A 認証方式`** / `--auth` | pg_hba.conf に書く認証方式。省略時は **trust**（警告が出る） |
| **`-k`** / `--data-checksums` | **データチェックサム**を有効にする（ページ破損を検出できる。後から変えるには pg_checksums が必要） |
| `-X ディレクトリ` / `--waldir` | WAL の格納場所を別ディレクトリにする |

- ⚠ **-D で指定するディレクトリは空か、存在しないこと**（中身があるとエラー）
- ⚠ ロケール（特に **LC_COLLATE・LC_CTYPE**）は**データベース作成後に変更できない**。C ロケールにすると並べ替えが速く、LIKE の前方一致でインデックスを使いやすい
- `pg_ctl initdb -D ディレクトリ` でも同じことができる

### データディレクトリの中身

| ファイル / ディレクトリ | 内容 |
|---|---|
| **base/** | データベースごとのサブディレクトリ（名前は**データベースの OID**）。テーブル・インデックスのファイル |
| **global/** | クラスタ全体で共有するカタログ（pg_database、pg_authid など） |
| **pg_wal/** | **WAL ファイル**（10 より前は pg_xlog） |
| **pg_xact/** | トランザクションのコミット状態（10 より前は pg_clog） |
| **pg_tblspc/** | テーブルスペースへの**シンボリックリンク** |
| **postgresql.conf** | メインの設定ファイル（→ 06章） |
| **pg_hba.conf** | クライアント認証の設定ファイル（→ 06章） |
| pg_ident.conf | OS ユーザー名と DB ユーザー名の対応表 |
| **postgresql.auto.conf** | **ALTER SYSTEM** が書き込む設定ファイル（手で編集しない） |
| **PG_VERSION** | メジャーバージョン番号 |
| **postmaster.pid** | 起動中のサーバの PID など。**二重起動を防ぐ**。停止すると消える |
| postmaster.opts | 前回起動したときのコマンドラインオプション |

- ⚠ パッケージ版では設定ファイルがデータディレクトリの外（例: Debian 系の `/etc/postgresql/14/main/`）に置かれることがある
- `pg_controldata`: データディレクトリの制御情報（クラスタの状態、最新チェックポイントの位置、データチェックサムの有無など）を表示する

## 3. pg_ctl（起動・停止） ★★★

### サブコマンド

| コマンド | 動作 |
|---|---|
| **`pg_ctl start`** | サーバを起動 |
| **`pg_ctl stop`** | サーバを停止 |
| **`pg_ctl restart`** | 停止して起動し直す |
| **`pg_ctl reload`** | 設定ファイルを**再読み込み**（SIGHUP を送る。サーバは止まらない） |
| **`pg_ctl status`** | 起動しているか確認 |
| **`pg_ctl promote`** | スタンバイサーバを**昇格**させる（プライマリにする） |
| `pg_ctl kill シグナル PID` | プロセスにシグナルを送る（Windows 用） |
| `pg_ctl initdb` | initdb を実行 |

### 主なオプション

| オプション | 意味 |
|---|---|
| **`-D ディレクトリ`** | データディレクトリ（省略時は PGDATA） |
| **`-l ファイル`** | サーバのログ（標準出力・標準エラー）の出力先。start / restart で使う |
| **`-m モード`** | 停止モード（smart / fast / immediate） |
| `-o "オプション"` | postgres コマンドへ渡すオプション（例: `-o "-p 5433"`） |
| **`-w`** / `-W` | 処理の完了を**待つ** / 待たない。**デフォルトは待つ**（-w） |
| `-t 秒` | 待つ最大秒数（デフォルト 60秒） |

### 停止モード

| モード | 動作 | シグナル |
|---|---|---|
| **smart** | 新しい接続を拒否し、**すべてのクライアントが切断するまで待って**から停止 | SIGTERM |
| **fast**（**デフォルト**） | 実行中のトランザクションを**ロールバック**し、クライアントを**強制切断**してから正常に停止 | SIGINT |
| **immediate** | 正常な終了処理をせず**即座に終了**。次回起動時に**クラッシュリカバリ**（WAL からの復旧）が走る | SIGQUIT |

- ⚠ **デフォルトの停止モードは fast**（9.5 より前は smart だった）
- ⚠ immediate でもコミット済みのデータは失われない（WAL から復旧する）。ただし起動に時間がかかる
- 例: `pg_ctl stop -D /var/lib/pgsql/data -m smart`

## 4. 接続のための環境変数と .pgpass ★★

### 環境変数

| 環境変数 | 意味 | 使うもの |
|---|---|---|
| **PGDATA** | データディレクトリ | initdb・pg_ctl・postgres（**サーバ側**） |
| **PGHOST** | 接続先ホスト | psql などのクライアント |
| **PGPORT** | 接続先ポート番号 | クライアント（サーバ側でも起動ポートの既定に使う） |
| **PGUSER** | 接続ユーザー名 | クライアント |
| **PGDATABASE** | 接続先データベース名 | クライアント |
| PGPASSWORD | パスワード（ps で見えるおそれがあり**非推奨**） | クライアント |
| PGPASSFILE | パスワードファイルの場所 | クライアント |
| PGCLIENTENCODING | クライアント側の文字エンコーディング | クライアント |

### クライアントの接続先のデフォルト

| 項目 | 指定がないとき |
|---|---|
| ホスト | **Unix ドメインソケット**（ローカル接続。Windows は localhost） |
| ポート | **5432** |
| ユーザー名 | **OS のユーザー名** |
| データベース名 | **ユーザー名と同じ名前** |

- ⚠ データベース名を省略すると「ユーザー名と同名のデータベース」に接続しようとする。無ければ `database "xxx" does not exist` エラー

### パスワードファイル（.pgpass）

- ホームディレクトリの **`~/.pgpass`** に書くと、パスワード入力を省略できる（Windows は `%APPDATA%\postgresql\pgpass.conf`）
- 書式: **`ホスト名:ポート:データベース名:ユーザー名:パスワード`**（`*` で何にでも一致）
- ⚠ パーミッションを **0600**（所有者だけ読み書き）にしないと**無視される**

## 5. psql の起動オプション ★★★

```
psql [オプション] [データベース名 [ユーザー名]]
```

| オプション | 意味 |
|---|---|
| **`-d データベース`** | 接続先データベース |
| **`-U ユーザー`** | 接続ユーザー |
| **`-h ホスト`** | 接続先ホスト |
| **`-p ポート`** | 接続先ポート |
| **`-c "SQL"`** | SQL（またはメタコマンド）を1つ実行して終了 |
| **`-f ファイル`** | ファイルの SQL を実行して終了 |
| **`-l`** | **データベースの一覧**を表示して終了 |
| `-W` / `-w` | パスワード入力を必ず求める / 求めない |
| **`-A`** | 桁揃えしない（unaligned）出力 |
| **`-t`** | 列名・件数の行を出さず、**データ行だけ**出力 |
| `-F 文字` | -A のときの列の区切り文字（デフォルトは縦棒） |
| **`-x`** | **拡張表示**（1列1行の縦表示） |
| `-o ファイル` | 結果をファイルへ出力 |
| `-q` | メッセージを抑える |
| `-v 名前=値` | psql 変数を設定 |
| **`-1`** | -f のファイル全体を**1つのトランザクション**で実行 |
| **`-E`** | メタコマンドが内部で実行する **SQL を表示**する |
| `-X` | 起動時に **~/.psqlrc** を読まない |

- 例: `psql -U postgres -d sampledb -h 192.168.1.10 -p 5432`
- 例: `psql -At -c "SELECT count(*) FROM t" sampledb` → 件数の数字だけ出る（スクリプト向け）

## 6. psql のメタコマンド ★★★

- **`\`（バックスラッシュ）で始まる psql 独自のコマンド**。SQL ではないので**末尾の `;` は不要**
- **`+`** を付けると詳細表示（例: `\dt+` でサイズ・説明も出る）、**`S`** を付けるとシステムオブジェクトも出す（例: `\dS`）
- 名前のパターンを付けると絞り込める（例: `\dt emp*`）

### 一覧・定義の表示

| コマンド | 表示するもの |
|---|---|
| **`\l`** | **データベース**の一覧 |
| **`\d`** | テーブル・ビュー・シーケンスなどの一覧 |
| **`\d 名前`** | そのテーブルなどの**定義**（列・型・インデックス・制約） |
| **`\dt`** | **テーブル** |
| **`\di`** | **インデックス** |
| **`\dv`** | **ビュー** |
| **`\ds`** | **シーケンス** |
| `\dm` | マテリアライズドビュー |
| **`\df`** | **関数** |
| **`\dn`** | **スキーマ** |
| **`\du`** / `\dg` | **ロール（ユーザー）** |
| **`\dp`** / **`\z`** | テーブルなどの**アクセス権限** |
| **`\db`** | **テーブルスペース** |
| `\dx` | インストール済みの拡張機能 |
| `\dT` | データ型 |
| `\dd` | オブジェクトのコメント |

- ⚠ `\d` 系の頭文字: **t**able、**i**ndex、**v**iew、**s**equence、**f**unction、**n**amespace（スキーマ）、**u**ser、**p**rivilege、**b**（ta**b**lespace）。**`\ds` はスキーマではなくシーケンス**

### 接続・入出力・その他

| コマンド | 動作 |
|---|---|
| **`\c データベース [ユーザー]`** / `\connect` | **別のデータベース（ユーザー）に接続し直す** |
| `\conninfo` | 現在の接続情報を表示 |
| **`\i ファイル`** | ファイルの SQL を実行 |
| **`\o ファイル`** | 以降の**結果をファイルへ**出力（引数なしで画面に戻す） |
| **`\copy`** | **クライアント側**のファイルとの間でデータをコピー（→ 07章） |
| **`\x`** | 拡張表示の切り替え |
| **`\timing`** | SQL の**実行時間**の表示を切り替え |
| `\e` | エディタで直前の SQL を編集 |
| **`\!` コマンド** | **OS のシェルコマンド**を実行 |
| `\echo 文字列` | 文字列を表示 |
| **`\set 名前 値`** | psql 変数を設定（引数なしで一覧） |
| `\pset` | 出力形式の設定（`\pset null '(null)'` など） |
| `\encoding` | クライアントエンコーディングの表示・変更 |
| `\password [ユーザー]` | パスワードを変更（平文をログに残さない） |
| **`\?`** | **メタコマンド**のヘルプ |
| **`\h [SQL コマンド]`** | **SQL 文**の構文ヘルプ（例: `\h CREATE TABLE`） |
| **`\q`** | psql を終了 |

- ⚠ **`\?` はメタコマンドのヘルプ、`\h` は SQL のヘルプ**
- 主な psql 変数: **AUTOCOMMIT**（off で自動コミットしない → 04章）、**ON_ERROR_STOP**（on でエラー時にスクリプトを中断。デフォルトは続行）
- 起動時に **`~/.psqlrc`** が読み込まれる（`\set` や `\timing` などを書いておける）

## 7. その他のコマンドラインツール ★★★

- いずれも**対応する SQL を実行するラッパー**。接続オプション（`-h`・`-p`・`-U`・`-W`）は psql と同じ

### createdb / dropdb

| コマンド | 対応する SQL | 主なオプション |
|---|---|---|
| **`createdb [DB名]`** | CREATE DATABASE | `-O 所有者`、`-E エンコーディング`、`-T テンプレート`、`-D テーブルスペース`、`-l ロケール` |
| **`dropdb DB名`** | DROP DATABASE | `-i`（確認する）、`--if-exists`、`-f` / `--force`（接続を切断して削除。13〜） |

- ⚠ createdb で DB 名を省略すると、**接続ユーザー名と同じ名前**のデータベースを作る
- ⚠ dropdb は DB 名の省略不可

### createuser / dropuser

| コマンド | 対応する SQL |
|---|---|
| **`createuser [ユーザー名]`** | CREATE ROLE ... LOGIN |
| **`dropuser ユーザー名`** | DROP ROLE |

| createuser のオプション | 付与する属性 |
|---|---|
| **`-s`** / `--superuser` | SUPERUSER |
| **`-d`** / `--createdb` | CREATEDB |
| **`-r`** / `--createrole` | CREATEROLE |
| `-l` / `-L` | LOGIN（**デフォルト**）/ NOLOGIN |
| **`-P`** / `--pwprompt` | パスワードを対話で設定 |
| `--replication` | REPLICATION |
| `--interactive` | 未指定の属性（スーパーユーザーにするか等）を対話で聞く |

- ⚠ createuser の `-s`・`-d`・`-r` は**スーパーユーザー・DB作成・ロール作成**。`-d` は「削除」ではない
- ⚠ createuser の **-U は「接続するユーザー」**（作るユーザー名ではない）。作るユーザー名は最後の引数

### メンテナンス系

| コマンド | 対応する SQL | 主なオプション |
|---|---|---|
| **`vacuumdb`** | VACUUM | **`-a`**（全データベース）、`-d DB`、`-t テーブル`、**`-f`**（FULL）、**`-z`**（VACUUM + ANALYZE）、**`-Z`**（**ANALYZE のみ**）、`-F`（FREEZE）、`-j`（並列） |
| `reindexdb` | REINDEX | `-a`、`-t`、`-i インデックス`、`-s`（システムカタログ） |
| `clusterdb` | CLUSTER | `-a`、`-t` |

- ⚠ vacuumdb の **`-z` は VACUUM と ANALYZE の両方**、**`-Z` は ANALYZE だけ**（大文字・小文字の違い）

### その他

| コマンド | 用途 |
|---|---|
| **pg_dump / pg_dumpall / pg_restore** | 論理バックアップとリストア（→ 07章） |
| **pg_basebackup** | 物理バックアップ（→ 07章） |
| **pg_isready** | サーバが**接続を受け付けているか**確認（終了ステータス 0 = 受付中、1 = 拒否中、2 = 応答なし） |
| pg_controldata | データディレクトリの制御情報を表示 |
| pg_upgrade | メジャーバージョンアップ（→ 01章） |
| pg_resetwal | WAL をリセットする（壊れて起動できないときの最終手段。データを失うおそれ） |
| pg_config | インストールされた PostgreSQL のビルド情報・パスを表示 |
