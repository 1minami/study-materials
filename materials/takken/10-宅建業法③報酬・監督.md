# 宅建業法③ 報酬・監督・8種制限

> 8種制限と報酬計算は毎年出題。数字の暗記が合否を分ける。

## 1. 8種制限（自ら売主制限）★★★

宅建業者が**自ら売主**となり、**買主が宅建業者でない**場合に適用される8つの制限。

- ⚠ 宅建業者**間**の取引（買主も業者）には適用されない
- ⚠ 業者が**媒介・代理**をするだけの取引や、売主が業者でない取引には適用されない
- 買主が業者でなければ、売主業者が媒介業者を通して契約しても適用される

### ① クーリング・オフ（37条の2）

→ 前章参照

### ② 損害賠償額の予定等の制限（38条）

- 債務不履行による解除に伴う**損害賠償額の予定＋違約金**の**合計**が代金の**20%**を超えてはならない
- 超える特約 → **20%を超える部分のみ無効**（特約全体が無効になるのではない）
- 損害賠償額の予定を**定めなかった**場合 → 実際の損害額を立証して請求でき、**20%の上限はない**

### ③ 手付の額等の制限（39条）★★

- 手付の額は代金の**20%**以下（20%を超える額の手付を受領できない）
- 受領した手付は、どのような性質のものでも**解約手付**とみなされる
  - **買主**は手付を**放棄**して解除できる
  - **売主業者**は手付の**倍額を現実に提供**して解除できる（口頭の申出だけでは不可）
  - 解除できるのは**相手方が履行に着手するまで**（自分が着手していても相手方が未着手なら可）
- これに反する特約で**買主に不利**なものは無効
  - 無効の例: 「買主は手付放棄による解除ができない」「売主は手付を返還するだけで解除できる」「売主は履行に着手した後も倍額提供で解除できる」
  - 有効の例: 「買主は手付の**半額を放棄**すれば解除できる」（買主に有利）

### ④ 手付金等の保全措置（41条・41条の2）★★★

- 「手付金等」: 契約締結日以後、**引渡し前**に支払われる金銭で、代金に充当されるもの（手付金・**中間金**・内金を含む）
- 保全措置を講じた**後**でなければ手付金等を**受領できない**
- 業者が保全措置を講じない → 買主は手付金等の**支払いを拒否**できる（債務不履行にならない）

**未完成物件**（契約時に工事完了前）:

| 項目 | 内容 |
|----------|-------------|
| 保全が必要な場合 | 代金の**5%超**又は**1,000万円超** |
| 保全方法 | ① 銀行等による**保証**（保証委託契約）② 保険事業者による**保証保険** |

**完成物件**（契約時に工事完了済み）:

| 項目 | 内容 |
|----------|---------------------|
| 保全が必要な場合 | 代金の**10%超**又は**1,000万円超** |
| 保全方法 | ①銀行等による保証 ②保証保険 ③**指定保管機関**による保管（手付金等寄託契約＋質権設定契約） |

- 保全の要否は、既に受領した額と**これから受領する額の合計**で判断
  - 例: 完成物件・代金5,000万円 → 手付400万円（8%）は保全不要／その後の中間金200万円を受け取ると合計600万円（12%）→ 中間金の受領前に**600万円全額**について保全が必要
- 保全措置が不要な場合:
  - 金額が上記の基準以下
  - **買主への所有権移転登記がされた**とき、又は**買主が所有権の登記をした**とき
- 保証・保険の期間は、少なくとも**引渡しまで**
- 書面の交付に代えて、買主の承諾を得て電磁的方法で行うことも可

### ⑤ 自己の所有に属しない物件の売買契約の制限（33条の2）

- **他人物**売買: 原則として契約（予約を含む）**不可**
  - 例外: 業者が物件を**取得する契約**（予約を含む）を締結している場合は可
  - ⚠ 取得契約が**停止条件付き**（農地法の許可を条件とする等）の場合は**不可**
- **未完成物件**: 原則として契約不可
  - 例外: **手付金等の保全措置**を講じた場合（又は保全措置不要の場合）は可

### ⑥ 契約不適合責任の特約の制限（40条）★★

- 原則: 民法の規定より**買主に不利な特約は無効**
- 例外: 買主が不適合を売主に**通知すべき期間**を「**引渡しの日から2年以上**」とする特約は有効
- 無効となった場合 → **民法の規定**が適用（買主が不適合を**知った時から1年以内**に通知）
- 無効の例: 「契約不適合責任を一切負わない」「引渡しから1年以内に通知」「損害賠償請求のみ可・解除不可」「売主に帰責事由がある場合のみ責任を負う」

### ⑦ 割賦販売契約の解除等の制限（42条）

- 賦払金の支払いがない場合、**30日以上**の相当の期間を定めて**書面で催告**し、その期間内に支払いがないときでなければ:
  - 契約を**解除**できない
  - **残りの賦払金全額**の支払いを請求できない
- ⚠ 口頭の催告や、30日未満の期間を定めた催告では解除不可
- これに反する特約は無効

### ⑧ 所有権留保等の禁止（43条）

- 割賦販売では、原則として**引渡しまで**に**登記等の売主の義務を履行**しなければならない（所有権留保の禁止）
- 例外として所有権を留保できる場合:
  - 受領した額が代金の**30%以下**
  - 30%を超えて受領していても、買主が残代金について抵当権・先取特権の登記、保証人を立てる**見込みがない**とき
- 引渡し＋30%超を受領した後は、担保目的で物件を**譲り受けてはならない**（譲渡担保の禁止）
- 提携ローン付き売買でも同様

## 2. 報酬 ★★★

### 基本ルール

- 報酬の上限は**国土交通大臣**が定める（告示）
- 上限を超えて報酬を受領してはならない
  - ⚠ 依頼者が承諾しても上限を超えて受領できない
- **不当に高額の報酬を要求**する行為も禁止（実際に受領しなくても違反）
- 報酬額は**事務所ごと**に掲示

### 売買・交換の媒介報酬（税抜き）

| 取引価格 | 報酬限度額 |
|----------|-----------|
| 200万円以下 | 取引価格 × **5%** |
| 200万円超〜400万円以下 | 取引価格 × **4%** + 2万円 |
| 400万円超 | 取引価格 × **3%** + 6万円 |

- 上記は**依頼者の一方から**受領できる限度額
- 売主・買主双方から媒介の依頼を受けた場合は、**それぞれから**上記の額まで受領できる
- 取引価格は**税抜き**（建物の消費税を除いた額）で計算する（土地は非課税）
- **交換**の場合: 交換する物件の価額に差があるときは、**高い方**の価額を基準とする

### 売買の代理報酬

- 媒介報酬の**2倍**まで（依頼者の一方から）
- 代理の依頼者から受け取る額＋相手方から受け取る額の**合計**も、媒介報酬の**2倍以内**
- 複数の業者が関与（例: 売主側A＝代理、買主側B＝媒介）:
  - 各業者は自分の依頼者からそれぞれの限度額まで
  - **全業者の受領額の合計**が、媒介報酬の**2倍以内**

### 低廉な空家等の特例（2024年7月1日改正）

- 対象: 売買代金（税抜き）が**800万円以下**の宅地建物の売買・交換
- 媒介の報酬上限: **30万円**（税抜き。税込33万円）— **売主・買主どちらからでも**受領できる
- 代理の報酬上限: 媒介の2倍＝**60万円**（税抜き。税込66万円）。相手方からも受領する場合は双方合計でこの額以内
- **あらかじめ依頼者に説明し、その合意を得ること**が必要
- 通常の計算式による上限が30万円を超える場合は通常の計算式による（特例は上限を引き上げるもの）

> 改正前（2024年6月30日以前）は「**400万円**以下・**18万円**・**売主から**のみ」。改正で対象金額・上限額が拡大し、買主からも受領できるようになった。

### 長期の空家等の貸借の特例（2024年7月1日新設）

- 対象: **1年を超えて**居住その他の使用がなされていない建物等の貸借
- 貸主・借主から受ける報酬の**合計**の上限: 借賃の**2ヶ月分＋消費税**（通常は1ヶ月分＋消費税）
- 借主から受けられる額は通常どおり（居住用は0.5ヶ月分、承諾があれば1ヶ月分）。上乗せ分は**貸主**から受ける
- **あらかじめ依頼者に説明し、その合意を得ること**が必要

### 賃貸の媒介報酬

- 貸主・借主双方から受領する合計が**賃料の1ヶ月分**以内（税抜き）
- **居住用建物**: 依頼者の一方から受領できるのは賃料の**0.5ヶ月分**以内
  - 媒介の依頼を受けるにあたって依頼者の**承諾**を得ていれば、一方から1ヶ月分まで可（合計1ヶ月分以内）
- 居住用以外（店舗・事務所・宅地）: 一方からの制限なし（合計1ヶ月分以内であればよい）
  - **権利金**（返還されないもの）の授受がある場合 → 権利金の額を**売買代金とみなして**売買の計算式で算定してもよい（⚠ 居住用建物には使えない）
- 貸借の**代理**: 合計で借賃の1ヶ月分以内

### 消費税

- 報酬額に**消費税**を加算して請求可能
  - **課税事業者**: 報酬額 × **1.1**
  - **免税事業者**: 報酬額 × **1.04**（仕入れに係る消費税相当額）
- 土地は非課税、建物は課税（取引価格は建物の消費税を除いて計算）

### 報酬以外に受領できるもの

- 依頼者の**依頼**による広告の料金（依頼のない通常の広告費は請求不可）
- 依頼者の**特別の依頼**による支出を要する特別の費用で、事前に依頼者の**承諾**があるもの（遠隔地への現地調査の費用等）
- ⚠ 「重要事項説明の費用」「契約書作成費用」等の名目で報酬とは別に受領することは不可

## 3. 監督処分 ★★

### 処分の種類と処分権者

| 処分 | 処分権者 | 内容 |
|------|----------|------|
| 指示処分 | 免許権者 + 業務地の知事 | 必要な指示 |
| 業務停止処分 | 免許権者 + 業務地の知事 | **1年以内**の期間を定めて業務の全部又は一部の停止 |
| 免許取消処分 | **免許権者のみ** | 免許の取消し |

- 業務地の知事が処分したとき → 遅滞なく**免許権者に報告**（大臣免許の場合は大臣へ、他県知事免許の場合はその知事へ通知）
- 国土交通大臣は、消費者保護に関する規定（重要事項説明・誇大広告等）の違反を理由に処分しようとするとき → あらかじめ**内閣総理大臣に協議**

### 指示・業務停止処分の主な事由

- 業務に関し取引の関係者に**損害**を与えた、又は与えるおそれが大
- 取引の**公正を害する**行為をした
- 他の法令に違反し、宅建業者として不適当
- **宅建士が処分**を受けた場合で、業者の責めに帰すべき理由がある
- 業務停止処分の事由: 名義貸し、営業保証金の届出前の事業開始、専任宅建士の不足、誇大広告、35条・37条違反、守秘義務違反、指示処分違反 など

### 必要的免許取消事由（取り消さなければならない）

- **欠格事由**に該当するに至った（法人の役員・政令で定める使用人が該当した場合を含む）
- **免許換え**が必要なのに免許を受けていないことが判明した
- 免許を受けてから**1年以内に事業を開始しない**、又は引き続いて**1年以上事業を休止**した
- 廃業等の届出がなく、破産・解散・廃業の事実が判明した
- **不正の手段**により免許を受けた
- 業務停止処分事由に該当し、**情状が特に重い**
- **業務停止処分に違反**した

### 任意的免許取消事由（取り消すことができる）

- 営業保証金を供託した旨の**届出をしない**（催告到達から1か月以内）
- 業者の**事務所の所在地**や業者の**所在**（法人は役員の所在）を**確知できない** → **官報で公告**し、公告の日から**30日**を経過しても申出がないとき（聴聞不要）
- 免許に付された**条件に違反**した

### 処分の手続き

- 指示・業務停止・免許取消のいずれも、事前に**聴聞**を行う
  - 聴聞の期日の**1週間前**までに通知し、期日・場所を公示
  - 聴聞の審理は**公開**で行う
  - ⚠ 指示処分でも聴聞が必要（行政手続法上の弁明の機会の付与では足りない）
- **業務停止処分**・**免許取消処分**をしたとき → その旨を**公告**（⚠ 指示処分は公告不要）
- 免許権者は処分の内容を**宅建業者名簿**に記載

### 指導・報告・立入検査

- 国土交通大臣: すべての宅建業者に対して
- 都道府県知事: その都道府県の区域内で宅建業を営む業者に対して
- 宅建業の適正な運営を確保するため、**報告**を求め、**立入検査**を行うことができる

## 4. 住宅瑕疵担保履行法 ★★

### 資力確保措置

- **新築住宅の売主**である宅建業者に義務付け
- 買主が宅建業者の場合は不要
- ⚠ 新築住宅の**媒介・代理**をした業者には義務なし
- 「新築住宅」: 新たに建設された住宅で、まだ人の居住の用に供したことのないもの（建設工事完了から**1年以内**のもの）

### 措置の方法

| 方法 | 内容 |
|------|------|
| 保証金の供託 | 基準日前10年間に引き渡した新築住宅の戸数に応じた額を供託 |
| 保険への加入 | 住宅瑕疵担保責任保険法人との間で保険契約を締結 |

- 保証金の供託:
  - 供託所: **主たる事務所の最寄りの供託所**
  - 戸数の算定: 床面積**55㎡以下**の住宅は**2戸で1戸**と数える
  - 有価証券による供託も可
  - 基準日に供託額が基準額を**超える** → **免許権者の承認**を受けて超過額を取り戻せる
- 保険契約の要件:
  - 保険金額**2,000万円以上**
  - 有効期間: 引渡しから**10年以上**
  - 売主業者が保険料を支払い、買主が保険金を請求できるもの

### 届出

- 基準日: 毎年**3月31日**
- 基準日から**3週間以内**に、保証金の供託・保険契約の締結の状況を**免許権者に届出**
- 届出をしない場合: 基準日の翌日から起算して**50日を経過した日以降**、新たに**新築住宅の売買契約**を締結してはならない

### 供託所の所在地等の説明

- 保証金を供託している業者 → 新築住宅の**売買契約を締結するまで**に、買主に対し、供託所の所在地等を記載した**書面を交付して説明**（承諾があれば電磁的方法も可）
- ⚠ 説明は宅建士でなくてもよい

### 保険の対象

- **構造耐力上主要な部分**と**雨水の浸入を防止する部分**の瑕疵
- 期間: 引渡しから**10年間**
- 売主業者が倒産するなどして瑕疵担保責任を履行できない場合、買主は保険法人に保険金を直接請求できる

## 5. その他の重要ルール

### 従業者証明書

- 従業者に携帯させなければ、その者を業務に従事させてはならない
- 対象: 代表者（社長）、非常勤役員、**一時的に事務を補助する者**（アルバイト等）も含む
- 取引の関係者から請求があったときは提示義務
- 宅建士証とは別のもの（⚠ 宅建士証の提示で**代えることはできない**）

### 帳簿・従業者名簿

| 帳簿 | 保存期間 |
|------|----------|
| 帳簿 | 事業年度末に閉鎖し**5年間**保存（自ら新築住宅の売主は**10年**） |
| 従業者名簿 | 最終記載から**10年間**保存 |

- いずれも**事務所ごと**に備える（案内所には不要）
- 帳簿: 取引のあった**都度**記載。取引の関係者に閲覧させる義務はない
- 従業者名簿: 取引の関係者から**請求**があれば**閲覧**させなければならない
  - 記載事項: 氏名、従業者証明書の番号、生年月日、主たる職務内容、**宅建士であるか否か**、従業者となった年月日・従業者でなくなった年月日
- パソコンのハードディスク等への記録・保存も可（必要に応じ紙面に表示できること）

### 標識

- **すべての事務所・案内所**に掲示（契約締結等を行わない案内所や、現地の物件所在場所も含む）
- 他の業者が売主の場合: 代理・媒介業者が設置する案内所の標識には**売主の商号等**を記載
- クーリング・オフの適用がある案内所では、標識にその旨を表示
