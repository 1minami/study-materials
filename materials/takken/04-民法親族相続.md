# 民法親族・相続

> 相続分・遺言・遺留分は頻出。配偶者居住権は近年の改正論点。

## 0. 親族の基本

- **親族**の範囲: **6親等内**の血族、**配偶者**、**3親等内**の姻族
- 婚姻: 男女とも**18歳**から可能
- 夫婦の一方が**日常の家事**に関して第三者と法律行為をした → 他方も**連帯**して責任を負う
- **夫婦別産制**（762条）: 夫婦財産契約がなければ、婚姻前から有する財産・婚姻中に**自己の名で得た**財産は、その者の**特有財産**（夫婦の共有にはならない）。どちらに属するか不明な財産は**共有と推定**
- 養子: 養子は縁組の日から養親の**嫡出子**の身分を取得（実親との親子関係も存続。特別養子を除く）

## 1. 相続 ★★★

### 相続人と法定相続分

| 順位 | 相続人 | 配偶者との相続分 |
|------|--------|------------------|
| 常に | 配偶者 | — |
| 第1順位 | 子（代襲: 孫→ひ孫…） | 配偶者1/2、子1/2 |
| 第2順位 | 直系尊属（父母→祖父母） | 配偶者2/3、直系尊属1/3 |
| 第3順位 | 兄弟姉妹（代襲: 甥姪まで） | 配偶者3/4、兄弟姉妹1/4 |

- 先順位の相続人が1人でもいれば、後順位の者は相続人にならない
- 同順位の相続人が複数いれば、その相続分を**頭数で均等**に分ける
- 配偶者は、**法律上の婚姻**をしている者に限る（内縁の配偶者は相続人にならない）
- 計算例: 配偶者と子2人 → 配偶者1/2、子は各1/4／配偶者と兄2人 → 配偶者3/4、兄は各1/8

### 重要ポイント

- **代襲相続**: 相続人（子・兄弟姉妹）が相続開始**前に死亡**、**相続欠格**、**廃除**により相続権を失った場合、その者の子が代わって相続
  - ⚠ **相続放棄**は代襲原因にならない
  - 代襲相続人の相続分は、被代襲者が受けるべきだった相続分と同じ（代襲相続人が複数なら均等に分ける）
- 子の代襲: 再代襲あり（孫→ひ孫→…）
- 兄弟姉妹の代襲: **甥姪まで**（再代襲なし）
- **嫡出子と非嫡出子**: 相続分は同等（2013年改正）
- **養子**: 実子と同じ相続分（実親と養親の双方の相続人になる）
- **半血兄弟姉妹**（父母の一方のみを同じくする兄弟姉妹）: 全血の兄弟姉妹の**1/2**
- **胎児**: 相続については既に生まれたものとみなす（死産の場合は適用なし）
- **同時死亡の推定**: 数人が死亡し、死亡の先後が不明 → 同時に死亡したものと推定 → 互いに相続しない（代襲相続は生じる）

### 相続欠格・廃除

| 制度 | 内容 | 手続き |
|---|---|---|
| **相続欠格** | 被相続人等を故意に死亡させ刑に処せられた、詐欺・強迫で遺言をさせた・妨げた、**遺言書を偽造・変造・破棄・隠匿**した 等 | 法律上**当然に**相続権を失う（手続き不要） |
| **廃除** | **遺留分を有する**推定相続人が被相続人を**虐待**・重大な侮辱、その他著しい非行 | 被相続人が**家庭裁判所に請求**（遺言でも可） |

- ⚠ 廃除の対象は遺留分を有する推定相続人のみ → **兄弟姉妹**は廃除できない（遺言で相続させなければ足りる）
- 欠格・廃除の効果は本人のみ → その子は**代襲相続**できる

### 相続の承認・放棄 ★★

| 種類 | 内容 | 期間・方法 |
|------|------|------|
| 単純承認 | 権利義務を無限に承継 | — |
| 限定承認 | 相続によって得た財産の限度で債務・遺贈を弁済 | 3ヶ月以内に家庭裁判所に申述（**相続人全員**が共同で） |
| 相続放棄 | 初めから相続人とならなかったものとみなす | 3ヶ月以内に家庭裁判所に申述（**各自単独**で） |

- **熟慮期間**: **自己のために相続の開始があったことを知った時**から**3ヶ月**（家庭裁判所に請求して伸長可）
- **法定単純承認**（単純承認したものとみなされる場合）:
  - 相続財産の全部又は一部を**処分**した（⚠ **保存行為**や短期賃貸借＝建物3年・土地5年以内の賃貸は除く）
  - 熟慮期間内に限定承認・放棄をしなかった
  - 限定承認・放棄の後に、相続財産を**隠匿**・**消費**した
- ⚠ 相続開始**前**の相続放棄は**できない**（家庭裁判所の許可を得ても不可）
- 一度した承認・放棄は、熟慮期間内でも**撤回できない**（詐欺・強迫等による取消しは可）
- 相続放棄の効果: **遡及的**に相続人とならなかったものとみなす → 他の相続人の相続分が増える／次順位の者が相続人になる
- 相続放棄をしても代襲相続は発生しない
- 相続放棄をした者は、放棄時に相続財産を**現に占有**しているときは、他の相続人等に引き渡すまで**保存**義務を負う

### 遺産分割 ★

- 相続開始から遺産分割までは、相続財産は共同相続人の**共有**
- 共同相続人の**協議**で分割（**全員**の参加・合意が必要。法定相続分と異なる分割も可）。協議が整わないときは家庭裁判所に請求
- **遺産分割の禁止**: 被相続人は遺言で、相続開始から**5年以内**の分割禁止が可能（共同相続人の合意でも5年以内の禁止可）
- 遺産分割の効果: **相続開始時に遡及**（ただし第三者の権利を害せない）
- 法定相続分を超える部分: 登記等の対抗要件を備えなければ第三者に対抗不可（899条の2）
- 遺産分割協議の**合意解除**・再分割は可能／共同相続人の一人が協議で負担した債務を履行しなくても、他の相続人は協議を**解除できない**（判例）
- **預貯金債権**: 遺産分割前でも、各共同相続人は一定額（法定相続分の1/3、1金融機関150万円まで）を**単独で払戻し**できる
- **金銭債務**（借金）: 遺産分割の対象とならず、法定相続分に応じて**当然に分割**して承継（債権者は法定相続分で各相続人に請求可）
- **相続開始から10年**を経過した後の遺産分割では、原則として**特別受益・寄与分**を考慮せず、法定相続分（又は指定相続分）で分割（2023年改正）

### 特別受益と寄与分

- **特別受益**: 共同相続人が被相続人から**遺贈**、婚姻・養子縁組・生計の資本としての**生前贈与**を受けた場合 → 相続財産に加えて相続分を計算（持戻し）
  - 婚姻期間**20年以上**の夫婦の一方が他方に居住用不動産を遺贈・贈与 → 持戻し免除の意思表示があったものと**推定**
- **寄与分**: 被相続人の事業に関する労務の提供・財産上の給付、療養看護等により財産の維持・増加に**特別の寄与**をした**相続人** → 寄与分を加算
- **特別寄与料**: **相続人以外の親族**（例: 長男の妻）が無償で療養看護等をして特別の寄与 → 相続人に**金銭**を請求可能
  - 特別寄与者が相続の開始及び相続人を知った時から**6か月**、又は相続開始から**1年**を経過すると家庭裁判所に請求できない

## 2. 遺言 ★★

### 遺言の基本

- **15歳**以上であれば遺言できる（法定代理人の同意不要。制限行為能力者も単独で可）
- 成年被後見人は、事理弁識能力を一時回復した時に、医師**2人以上**の立会いで遺言できる
- 2人以上の者が**同一の証書**で遺言すること（**共同遺言**）は**禁止**（夫婦でも不可）
- 遺言は、遺言者の**死亡の時**から効力を生ずる（停止条件付き遺言は条件成就時）

### 遺言の方式

| 方式 | 要件 | 家庭裁判所の検認 |
|------|------|------|
| **自筆証書遺言** | 遺言者が**全文・日付・氏名**を**自書**＋**押印**（財産目録はパソコン作成・通帳のコピー添付も可。ただし目録の**毎葉**に署名押印） | **必要**（保管制度利用時は不要） |
| **公正証書遺言** | 証人2人以上の立会い + 遺言者が遺言の趣旨を公証人に**口授** + 公証人法の定めにより公証人が作成（2026年4月改正: 筆記・読み聞かせ等の細目は公証人法に委任され、電磁的記録による作成も可能に） | **不要** |
| **秘密証書遺言** | 遺言者が署名押印 + 封入し証書と同じ印で**封印** + 公証人1人・証人2人以上に提出 | **必要** |

- 自筆証書の日付は特定できることが必要（「令和○年○月吉日」は**無効**）
- 自筆証書の加除・変更: 場所を指示し、変更した旨を付記して署名し、変更の場所に押印
- **検認**: 遺言書の保管者・発見した相続人は、相続開始を知った後、遅滞なく家庭裁判所に提出して検認を請求
  - ⚠ 検認は遺言書の状態を確認する手続きにすぎず、検認を経なくても遺言は**無効にならない**（過料の制裁あり）
  - 封印のある遺言書は、家庭裁判所で相続人等の立会いがなければ開封できない

### 証人・立会人になれない者

- 未成年者
- **推定相続人・受遺者**及びその**配偶者・直系血族**
- 公証人の配偶者、四親等内の親族、書記・使用人

### 遺言の撤回

- 遺言者は**いつでも**、遺言の方式に従って、遺言の全部又は一部を撤回できる（前の遺言と同じ方式である必要はない）
- 前の遺言と後の遺言が抵触 → 抵触部分は**後の遺言で撤回**したものとみなす
- 遺言と抵触する**生前処分**（遺贈するとした土地を生前に売却等） → **撤回**したものとみなす
- 遺言者が故意に**遺言書を破棄**した、遺贈の目的物を破棄した → 撤回したものとみなす
- **撤回権の放棄**は不可（「この遺言は撤回しない」と書いても撤回できる）

### 自筆証書遺言書保管制度

- 遺言者が自ら**法務局**（遺言書保管所）に出頭して保管を申請できる
- 保管された遺言書は**家庭裁判所の検認が不要**になる

### 遺贈

- **包括遺贈**（財産の全部又は○分の1を遺贈）: 受遺者は**相続人と同一**の権利義務を有する（債務も承継。放棄は3か月以内に家庭裁判所へ）
- **特定遺贈**（特定の財産を遺贈）: 受遺者は遺言者の死亡後**いつでも**放棄できる
- 受遺者が遺言者より**先に死亡** → 遺贈は効力を生じない（受遺者の相続人は承継しない。代襲なし）

## 3. 遺留分 ★★

### 遺留分の割合

| 相続人 | 遺留分の割合（総体的遺留分） |
|--------|-------------|
| 配偶者のみ | 1/2 |
| 子のみ | 1/2 |
| 配偶者＋子 | 1/2 |
| 配偶者＋直系尊属 | 1/2 |
| 直系尊属のみ | **1/3** |
| 兄弟姉妹 | **遺留分なし** |

- 各人の遺留分 = 総体的遺留分 × 法定相続分
  - 例: 相続人が配偶者と子2人、遺産6,000万円 → 総体的遺留分3,000万円 → 配偶者1,500万円、子は各750万円
- 遺留分算定の基礎となる財産には、相続開始前**1年間**の贈与（相続人への贈与は**10年間**の特別受益）が加算される（当事者双方が遺留分権利者に損害を加えることを知っていた贈与は期間制限なし）

### 遺留分侵害額請求権（1046条）★★

- 2019年改正: **金銭請求**に一本化（従来の遺留分減殺請求のような物権的効力はない → 遺贈・贈与自体は有効）
- 遺留分を侵害する遺言も**無効ではない**（侵害された者が金銭を請求できるだけ）
- 請求は**意思表示**で足りる（裁判上の請求は不要）
- **期間制限**:
  - 相続の開始及び遺留分を侵害する贈与・遺贈を**知った時**から**1年**（消滅時効）
  - 相続開始の時から**10年**
- 受遺者等が直ちに金銭を準備できない場合、裁判所は支払いについて期限を許与できる

### 遺留分の放棄

- 相続開始**前**の遺留分の放棄 → **家庭裁判所の許可**を受けたときに限り有効
- 相続開始**後**の放棄 → 自由にできる
- ⚠ 共同相続人の一人が遺留分を放棄しても、**他の共同相続人の遺留分は増えない**
- ⚠ 遺留分を放棄しても**相続人の地位は失わない**（相続放棄とは別。相続開始後に相続できる）

## 4. 配偶者居住権（2020年施行）★

### 配偶者居住権（1028条）

- **要件**: 被相続人の配偶者が、被相続人の財産に属した建物に**相続開始時に居住**していたこと
  - ⚠ 被相続人が相続開始時に居住建物を**配偶者以外の者と共有**していた場合は成立しない
- **内容**: 居住建物の**全部**について**無償**で使用収益できる
- **取得方法**: **遺産分割**（協議・審判）、**遺贈**、死因贈与
- **存続期間**: 配偶者の**終身**（遺産分割協議・遺言等で別段の定めも可能）
- **譲渡不可**（相続もされない。配偶者の死亡で消滅）
- 配偶者は**善管注意義務**を負い、居住建物の**所有者の承諾**なく**改築・増築**や**第三者に使用収益**させることはできない
  - 違反 → 所有者は相当期間を定めて是正を催告し、是正されなければ配偶者居住権を消滅させられる
- 通常の必要費（固定資産税・修繕費等）は**配偶者**が負担
- **登記**: 居住建物の所有者は、配偶者居住権の設定登記を備えさせる**義務**がある。登記をすれば**第三者に対抗**できる

### 配偶者短期居住権（1037条）

- 被相続人の財産に属した建物に、相続開始時に**無償で居住**していた配偶者に、法律上当然に認められる
- 存続期間:
  - 居住建物について配偶者を含む共同相続人間で遺産分割をする場合 → 遺産分割により帰属が確定した日、又は相続開始から**6ヶ月**を経過する日のいずれか**遅い日**まで
  - それ以外（遺贈等で第三者が取得） → 居住建物取得者が消滅の**申入れ**をした日から**6ヶ月**を経過する日まで
- **登記不要**（登記できない）。第三者に対抗できない
- 譲渡不可
