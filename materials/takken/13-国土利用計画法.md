# 国土利用計画法

> 毎年1問出題。届出制（事後届出）の対象面積と届出期間が頻出。

## 1. 土地取引の届出制度 ★★★

### 3つの届出制

| 制度 | 発動 | 届出時期 | 届出先 |
|------|------|----------|--------|
| 事後届出制 | **原則**（常に適用） | 契約締結日から**2週間以内** | 市町村長経由 → 都道府県知事 |
| 事前届出制（注視区域） | 知事が指定した場合 | 契約締結**前** | 同上 |
| 事前届出制（監視区域） | 知事が指定した場合 | 契約締結**前** | 同上 |

- 現在、注視区域・監視区域の指定実績はほぼない → **事後届出が出題の中心**
- 注視区域・監視区域・規制区域内の土地については事後届出は**不要**（それぞれの制度で規制される）

### 事後届出の流れ

1. 土地売買等の**契約を締結**
2. **権利取得者**（買主・借主など権利を取得する側）が、契約締結日から**2週間以内**に、土地が所在する**市町村長を経由**して**都道府県知事**に届出
3. 知事は、**利用目的**が土地利用基本計画等に適合しない場合 → 土地利用審査会の意見を聴いて、利用目的の変更を**勧告**（届出日から**3週間以内**。合理的な理由があれば3週間の範囲で延長可）
4. 勧告に従わない → 知事はその旨と勧告の内容を**公表できる**
5. 勧告に基づき利用目的が変更された → 知事は、必要に応じて土地に関する権利の処分についての**あっせん**等に努める

- ⚠ 届出は「契約**前**」ではなく「契約**後**」。売主は届出義務を負わない
- ⚠ 届出をしなくても、勧告に従わなくても、**契約自体は有効**
- 勧告のほか、利用目的について必要な**助言**をすることもできる

### 事後届出の対象面積 ★★★

| 区域 | 面積要件 |
|------|----------|
| 市街化区域 | **2,000㎡以上** |
| 市街化区域以外の都市計画区域（市街化調整区域・非線引き区域） | **5,000㎡以上** |
| 都市計画区域外（準都市計画区域を含む） | **10,000㎡（1ha）以上** |

### 一団の土地の判断（買いの一団）

- 面積は、**権利取得者**が取得する土地の合計で判断する（**買いの一団**）
  - 例: 市街化区域でAがBから1,200㎡、Cから1,000㎡を一団の土地として購入 → 合計2,200㎡ → Aは**各契約について届出が必要**
- 売主側で合計しない
  - 例: 市街化区域でDが所有する3,000㎡を、Eに1,500㎡、Fに1,500㎡に分けて売却 → E・Fそれぞれ1,500㎡ → **届出不要**
- 当初の計画に基づき、時期をずらして順次取得する場合も一団の土地として合計する

### 届出が必要な「土地売買等の契約」

- 次の3つの要件をすべて満たす契約（**予約**を含む）
  1. 土地に関する権利（所有権・地上権・賃借権）の**移転・設定**であること
  2. **対価**の授受を伴うこと
  3. **契約**であること
- 該当するもの: 売買、**交換**、譲渡担保、代物弁済、**売買の予約**、地上権・賃借権の設定・移転で**権利金**等の一時金（返還されないもの）の授受があるもの
- **該当しないもの**:
  - 対価がない: **贈与**、権利金の授受のない賃借権の設定（地代・賃料のみ）
  - 契約でない: **相続**、**時効取得**、法人の合併、土地収用、遺産分割
  - 権利の性質が違う: **抵当権**・質権の設定、**使用貸借**
- ⚠ **予約**の段階で届出をした場合、その後の予約完結権の行使時には届出不要
- ⚠ 停止条件付き契約は、**契約締結時**に届出（条件成就時ではない）

### 届出義務者

- **事後届出**: **権利取得者**（買主）が届出
- 事前届出: 当事者双方

### 届出事項

- 当事者の氏名・住所
- 契約締結年月日
- 土地の所在・面積
- 権利の種類・内容
- 権利取得後の土地の**利用目的**
- **対価の額**（金銭以外の場合は時価で見積もった額）

### 知事の勧告

| 制度 | 審査対象 | 勧告 |
|------|----------|------|
| 事後届出 | **利用目的のみ** | 利用目的の変更を勧告（届出から**3週間以内**） |
| 事前届出 | 利用目的＋対価 | 契約中止等の勧告（届出から**6週間以内**） |

- 事後届出では**価格の審査はない**（対価の額は届出事項だが、勧告の対象ではない）
- 勧告に従わない場合: 公表できるが、**罰則はない**（契約も有効）
- **届出をしなかった場合**: **罰則あり**（6ヶ月以下の拘禁刑又は100万円以下の罰金）

> ※2025年6月1日施行の改正刑法により、従来の「懲役」と「禁錮」は「拘禁刑」に一本化されました。

### 届出不要の場合 ★

- 当事者の一方又は双方が**国・地方公共団体**等の場合
- 民事調停法による**調停**に基づく場合
- 農地法**3条1項の許可**を受けた場合（⚠ 農地法**5条**の許可を受けた場合は届出が**必要**）
- 裁判所の競売（民事執行法）による場合
- 面積要件未満（買いの一団で判断）
- 注視区域・監視区域・規制区域内の土地

## 2. 規制区域

- 知事が指定（現在指定実績なし）
- 規制区域内で土地売買等の契約をする場合 → 当事者が知事の**許可**を受ける
- **許可なくした契約は無効**（効力を生じない）

## 3. 遊休土地制度

- 事後届出等をして取得した一定規模以上の土地が、取得後**2年**を経過しても利用されていない場合等に、知事が**遊休土地**である旨を通知
- 通知を受けた者は、通知の日から**6週間以内**に、その土地の利用・処分に関する計画を知事に**届出**
- 知事は、計画が不適当な場合に**勧告**できる
