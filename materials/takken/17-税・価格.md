# 税・価格

> 毎年2〜3問出題。不動産取得税・固定資産税・譲渡所得は頻出。数字の正確な暗記が必要。

## 1. 不動産取得税 ★★★

### 基本

| 項目 | 内容 |
|------|------|
| 課税主体 | **都道府県**（不動産所在地の都道府県） |
| 課税対象 | 不動産の**取得**（売買、交換、贈与、新築、増改築等） |
| 納税義務者 | 不動産の**取得者**（個人・法人を問わない） |
| 税率 | 原則**4%**（住宅・土地は特例で**3%**。特例は2027年3月31日までの取得が対象で、延長の有無は令和9年度税制改正で要確認） |
| 課税標準 | **固定資産課税台帳の登録価格**（台帳に登録されていない不動産は知事が決定） |
| 徴収方法 | **普通徴収**（納税通知書による） |
| 税の種類 | **普通税**（使途を特定しない税。⚠ 目的税ではない） |
| 納期 | 納税通知書で指定。具体的な納期は**都道府県の条例**で定める（⚠「4月・7月・12月・2月」は**固定資産税**の納期） |

### 「取得」の範囲

- **有償・無償**を問わない（売買・**交換**・**贈与**も課税）
- **登記の有無**を問わない（未登記でも課税）
- 家屋の**改築**で価格が増加した場合 → 改築を家屋の取得とみなし、**増加した価格**を課税標準として課税
- 家屋が**新築**された場合: 最初の使用又は譲渡が行われた日に取得があったとみなし、その所有者・譲受人に課税
  - 新築後**6か月**を経過しても使用・譲渡がない → 6か月を経過した日に取得があったとみなし、**その時の所有者**に課税（宅建業者等が売り渡す新築住宅は**1年**）

### 非課税

- **相続**による取得
- **法人の合併**による取得
- **共有物の分割**による取得（分割前の**持分を超えない**部分に限る）
- **包括遺贈**・相続人に対する特定遺贈による取得
- 国・地方公共団体等による取得
- ⚠ **贈与**・**交換**・相続人以外への特定遺贈・**売買**は課税される

### 免税点（2026年4月改正で引上げ）★

| 対象 | 金額 |
|------|------|
| 土地 | **16万円**未満 |
| 建築による家屋 | **66万円**未満（1戸あたり） |
| その他の家屋 | **34万円**未満（1戸あたり） |

- 2026年4月1日以後の取得に適用（旧: 土地10万円・建築23万円・その他12万円）。改正初年度のため要注意
- 免税点は課税標準額で判定

### 新築住宅の課税標準の特例 ★★

- 床面積**40㎡以上240㎡以下** → 課税標準から**1,200万円**を控除（2026年4月改正: 下限50㎡→40㎡に緩和。貸家は従来から40㎡以上）
- 認定長期優良住宅: **1,300万円**を控除（適用期限は2031年3月31日まで延長）
- 新築住宅の特例は、**個人・法人**を問わず、**自己居住用でなくても**（賃貸用でも）適用される
- 床面積は、共同住宅の場合は独立的に区画された部分ごとに判定

### 宅地の課税標準の特例

- 宅地評価土地の課税標準 → 固定資産税評価額 × **1/2**（2027年3月31日までの取得が対象。延長の有無は令和9年度税制改正で要確認）

### 中古住宅の特例

- 自己居住用で床面積**40㎡以上240㎡以下**（2026年4月改正: 下限50㎡→40㎡） → 新築時期に応じた額を控除
- ⚠ 中古住宅の特例は**個人**が**自己の居住用**として取得した場合に限られる（法人・賃貸用は適用なし）

## 2. 固定資産税 ★★★

### 基本

| 項目 | 内容 |
|------|------|
| 課税主体 | **市町村**（東京23区は都） |
| 課税対象 | 土地、家屋、償却資産 |
| 納税義務者 | 毎年**1月1日**（賦課期日）現在の所有者（登記簿・課税台帳に登記・登録されている者） |
| 税率 | 標準税率**1.4%**（制限税率なし） |
| 課税標準 | **固定資産課税台帳の登録価格** |
| 徴収方法 | **普通徴収**（納期は原則4月・7月・12月・2月中で市町村の条例で定める） |

- 年の途中で売却しても、その年度の固定資産税は**1月1日現在の所有者**が**全額**納付する義務を負う（売主・買主間の日割り精算は契約上の問題）
- ⚠ **質権者**・**100年より長い存続期間の地上権者**は、所有者ではなくこれらの者が納税義務者
- 所有者として登記されている個人が1月1日前に死亡している → 1月1日に現に所有している者（相続人等）が納税義務者
- 市町村は、一定の要件のもとで**使用者**を所有者とみなして課税できる（所有者不明の場合）

### 免税点

| 対象 | 金額 |
|------|------|
| 土地 | **30万円**未満 |
| 家屋 | **30万円**未満 |
| 償却資産 | **180万円**未満 |

- 2027年4月改正（令和9年度分から）: 家屋**20万円→30万円**、償却資産**150万円→180万円**に引上げ（土地30万円は据置 → 土地・家屋とも30万円）
- 免税点は、同一の市町村内で同一の者が所有する土地・家屋それぞれの課税標準の**合計額**で判定
- 市町村は、財政上等の特別の必要がある場合、条例で免税点未満でも課税できる

### 住宅用地の課税標準の特例 ★★

| 区分 | 特例 |
|------|------|
| 小規模住宅用地（200㎡以下の部分） | 課税標準 × **1/6** |
| 一般住宅用地（200㎡超の部分） | 課税標準 × **1/3** |

- 200㎡は住宅**1戸あたり**で判定（賃貸マンションの敷地も戸数×200㎡まで小規模住宅用地）
- 住宅用地の特例は**賃貸用住宅**の敷地にも適用される
- 特定空家等に係る勧告を受けた土地 → 住宅用地の特例の対象外

### 新築住宅の税額の特例

- 床面積**40㎡以上240㎡以下**（2026年4月改正: 下限50㎡→40㎡に緩和、上限280㎡→240㎡に縮小）
- **120㎡以下**の部分について税額**1/2**に減額（120㎡を超える住宅は120㎡分のみ減額）
- 期間: 一般住宅**3年間**、3階建て以上の耐火・準耐火建築物**5年間**、認定長期優良住宅**5年間**（マンションは7年間）
- ⚠ 「課税標準」ではなく「**税額**」の1/2（住宅用地の特例＝課税標準との違い）

### 固定資産課税台帳の閲覧・縦覧・審査

- 納税義務者等は、自己の資産について固定資産課税台帳を**閲覧**できる
- **縦覧**: 土地・家屋の納税者は、**他の土地・家屋の価格**と比較できるよう、土地価格等縦覧帳簿・家屋価格等縦覧帳簿を縦覧できる（毎年**4月1日から4月20日**又は最初の納期限の日のいずれか**遅い日**まで）
- 登録価格に不服 → **固定資産評価審査委員会**に審査の申出（納税通知書の交付を受けた日後**3ヶ月以内**）
- 価格の据置（原則**3年**に1度の**評価替え**。基準年度の価格を第2年度・第3年度も据え置く）
- 市町村長は、固定資産評価員の評価に基づいて価格を決定し、毎年**3月31日**までに固定資産課税台帳に登録

## 3. 所得税（譲渡所得）★★

### 不動産の譲渡所得

- **分離課税**（他の所得と合算しない）
- 譲渡所得 = 譲渡価額 −（取得費 + 譲渡費用）− 特別控除
  - 取得費が不明・少額の場合 → 譲渡価額の**5%**を概算取得費とできる

### 長期譲渡所得と短期譲渡所得

| 区分 | 所有期間 | 税率 |
|------|----------|------|
| 長期譲渡所得 | 譲渡年の1月1日で**5年超** | 所得税15% + 住民税5% |
| 短期譲渡所得 | 譲渡年の1月1日で**5年以下** | 所得税30% + 住民税9% |

- 所有期間は取得日〜譲渡年の**1月1日**で判定（実際の譲渡日ではない）
  - 例: 2021年4月に取得 → 2026年1月1日時点で4年9か月 → 2026年中の譲渡は**短期**（2027年中の譲渡なら長期）
- 相続・贈与で取得した場合は、被相続人・贈与者の取得日を**引き継ぐ**

### 居住用財産の3,000万円特別控除 ★★

- 居住用財産（マイホーム）を譲渡した場合 → 譲渡所得から**3,000万円**を控除
- **所有期間の長短を問わない**（短期譲渡でも適用可）
- 居住しなくなった日から**3年**を経過する日の属する年の**12月31日**までの譲渡なら適用可
- 適用除外:
  - **配偶者**、**直系血族**、生計を一にする親族、同族会社等の**特別関係者**への譲渡
  - **前年・前々年**にこの特例（又は買換え特例・譲渡損失の特例等）の適用を受けている
  - この特例の適用を受けるためだけの入居、仮住まい、別荘等
- 3,000万円控除により譲渡所得が0円になる場合も、**確定申告**が必要

### 居住用財産の軽減税率

- 所有期間が譲渡年の1月1日で**10年超**のマイホーム
- 課税長期譲渡所得のうち6,000万円以下の部分: 所得税**10%** + 住民税4%
- 6,000万円超の部分: 所得税15% + 住民税5%
- 3,000万円控除と**併用可能**（3,000万円控除後の金額に軽減税率を適用）
- 前年・前々年にこの特例の適用を受けていないこと／特別関係者への譲渡は適用外

### 特定の居住用財産の買換え特例

- 所有期間**10年超**・居住期間**10年以上**のマイホームを譲渡
- 譲渡価額**1億円以下**
- 買換資産: 居住用部分の床面積**50㎡以上**、敷地面積**500㎡以下**
- 課税**繰延べ**（非課税ではない。買換資産を将来譲渡したときに課税）
- 3,000万円控除・軽減税率とは**併用不可**

### 収用等の特別控除

- 公共事業等のために土地等を収用された場合 → **5,000万円**の特別控除
- 3,000万円控除と**併用可能**（ただし同一年の控除額の合計は**5,000万円**が限度。合計8,000万円にはならない）

### 特別控除の重複適用

- 同一年中に複数の特別控除の適用がある場合、控除額の合計は年間**5,000万円**が限度

## 4. 登録免許税 ★

### 基本

| 項目 | 内容 |
|------|------|
| 課税主体 | **国** |
| 課税対象 | 不動産の登記 |
| 納税義務者 | 登記を受ける者（複数の場合は**連帯**して納付） |
| 課税標準 | 所有権の登記等 → **固定資産課税台帳の登録価格**／抵当権の設定登記 → **債権金額** |
| 納付方法 | 原則として**現金納付**（3万円以下は印紙納付も可） |

- ⚠ 抵当権設定登記の課税標準は、不動産の価額ではなく**債権金額**（根抵当権は**極度額**）
- 固定資産課税台帳に価格が登録されていない不動産 → 登記官が認定した価額

### 主な税率

| 登記の種類 | 本則税率 | 住宅特例 |
|-----------|----------|----------|
| 所有権保存登記 | 0.4% | **0.15%** |
| 所有権移転登記（売買） | 2% | **0.3%** |
| 抵当権設定登記 | 0.4% | **0.1%** |
| 所有権移転登記（相続・法人の合併） | 0.4% | — |
| 所有権移転登記（贈与・遺贈・交換） | 2% | — |

- 土地の**売買**による所有権移転登記は、期限付きの特例で軽減税率（1.5%）が適用される
- 住宅特例の要件:
  - **個人**が受ける登記であること（⚠ **法人**には適用なし）
  - 自己の**居住用**家屋であること（⚠ 賃貸用・別荘には適用なし）
  - 床面積**50㎡以上**
  - **新築**又は**取得後1年以内**に登記を受けること
  - 中古住宅は、新耐震基準に適合していること（1982年1月1日以後の建築等）
  - 所有権移転の軽減税率は**売買**・**競落**による取得に限る（贈与・交換・相続は対象外）
  - ⚠ 住宅特例は、過去に適用を受けていても**何度でも**適用可能
- ⚠ 住宅特例は**家屋**のみが対象（敷地＝土地の登記には適用されない）

## 5. 印紙税 ★

### 基本

- 課税文書の**作成者**が納税義務者（共同作成した場合は**連帯**して納税義務）
- 課税文書に収入印紙を貼付し、**消印**して納付
- 印紙を貼り忘れても**契約の効力には影響しない**

### 課税文書

- **不動産の譲渡**に関する契約書（売買契約書・交換契約書・贈与契約書）
- **地上権・土地の賃借権**の設定・譲渡に関する契約書
- **建設工事の請負**に関する契約書
- **金銭の受取書**（記載金額**5万円以上**。営業に関しないものは非課税）
- 契約書の**写し**・副本でも、契約当事者の署名押印があるなど契約の成立を証明するものは課税
- **仮契約書**・**予約契約書**、契約内容を**変更**する契約書（重要事項の変更）も課税

### 課税されない文書

- 記載金額が**1万円未満**の契約書
- **建物の賃貸借**契約書（⚠ 土地の賃貸借契約書は課税）
- **抵当権設定契約書**、**委任状**、使用貸借契約書
- 国・地方公共団体が作成した文書
- 営業に関しない金銭の受取書（個人が自宅を売却して受け取る代金の領収書等）

### 記載金額の判定

| 文書 | 記載金額 |
|---|---|
| **交換**契約書（双方の価額を記載） | **高い方**の価額 |
| 交換契約書（交換差金のみ記載） | **交換差金** |
| **贈与**契約書 | 記載金額**なし**（評価額が記載されていても譲渡の対価ではない）→ 200円 |
| 土地の賃借権設定契約書 | **権利金**等（後日返還されないもの）の額（⚠ **地代**・**敷金**は記載金額に含まない） |
| **消費税額**が区分記載された契約書 | 消費税額を**除いた**金額 |
| 1通の契約書に売買と請負が併記（区分記載） | 原則として売買の金額（請負の金額の方が大きければ請負の金額） |
| 契約金額を**増額**する変更契約書 | **増加額** |
| 契約金額を**減額**する変更契約書 | 記載金額なし（200円） |

### 国等との共同作成

- 国・地方公共団体と私人が共同で作成した文書 → **国等が保存**するものは**私人**が作成したものとみなし**課税**、**私人が保存**するものは国等が作成したものとみなし**非課税**

### 過怠税

- 印紙を貼り忘れた場合: 過怠税（印紙税額の**3倍**。自己申告の場合は**1.1倍**）
- 印紙に**消印**をしなかった場合: 消印されていない印紙の額面に相当する過怠税

## 6. 地価公示法 ★

### 基本

| 項目 | 内容 |
|------|------|
| 実施者 | **土地鑑定委員会** |
| 公示区域 | **都市計画区域**その他の土地取引が相当程度見込まれる区域（国土利用計画法の**規制区域を除く**） |
| 標準地の鑑定 | **2人以上**の不動産鑑定士が鑑定評価 |
| 基準日 | 毎年**1月1日** |
| 公示内容 | 標準地の単位面積当たりの**正常な価格** |

### 公示の手続き

1. **土地鑑定委員会**が、公示区域内から**標準地**を選定（自然的・社会的条件からみて類似の利用価値を有すると認められる地域において、土地の利用状況・環境等が**通常と認められる一団の土地**）
2. **2人以上**の不動産鑑定士が鑑定評価
   - 不動産鑑定士は、近傍類地の**取引価格**から算定される推定の価格、**地代等**から算定される推定の価格、同等の効用を有する土地の**造成費用**の額を**勘案**して鑑定評価
3. 土地鑑定委員会が鑑定評価の結果を**審査**し、必要な**調整**を行って、正常な価格を**判定**
4. 土地鑑定委員会が**官報**で**公示**（標準地の所在地、単位面積当たりの価格、価格判定の基準日、地積・形状、標準地及び周辺の土地の利用の現況 等）
5. 土地鑑定委員会は、関係**市町村長**に、公示事項を記載した書面・図面を送付 → 市町村長は事務所で**一般の閲覧**に供する

- 「正常な価格」: 土地について、自由な取引が行われるとした場合に通常成立すると認められる価格
  - 土地に**建物**その他の定着物がある場合や、地上権等の**権利**が存する場合 → それらが**存しないもの**として（更地として）算定

### 公示価格の効力

- 都市計画区域等で土地の取引を行う者: 公示価格を**指標**として取引するよう**努めなければならない**（努力義務）
- 不動産鑑定士が公示区域内の土地について正常な価格を求める鑑定評価を行う場合: 公示価格を**規準**としなければならない
- 公共事業用地の取得価格の算定、収用委員会の補償金の算定: 公示価格を**規準**として算定
- 「規準とする」: 対象土地の価格を求めるにあたり、類似の利用価値を有する標準地との位置・地積・環境等の比較を行い、両者の価格に**均衡**を保たせること

### 不動産鑑定評価基準

#### 価格の種類

| 価格 | 内容 |
|---|---|
| **正常価格** | 市場性を有する不動産について、合理的と考えられる条件を満たす市場で形成されるであろう市場価値 |
| **限定価格** | 隣接不動産の併合を目的とする売買など、市場が相対的に限定される場合の価格（例: 借地権者が底地を購入） |
| **特定価格** | 法令等による社会的要請を背景とする評価目的の下で、正常価格の前提となる諸条件を満たさない場合の価格（例: 民事再生法の早期売却） |
| **特殊価格** | 文化財等の一般的に市場性を有しない不動産の価格 |

#### 鑑定評価の3手法

| 手法 | 内容 |
|------|------|
| 原価法 | 価格時点における**再調達原価**を求め、**減価修正**して試算価格（**積算価格**）を求める（土地は造成地・埋立地等で適用可） |
| 取引事例比較法 | 多数の取引事例を収集し、**事情補正**・**時点修正**・地域要因・個別要因の比較を行って試算価格（**比準価格**）を求める |
| 収益還元法 | 対象不動産が将来生み出すと期待される**純収益**の**現在価値**の総和から試算価格（**収益価格**）を求める |

- 鑑定評価にあたっては、原則として**複数の手法を併用**すべき（地域分析・個別分析により適用できる手法を判断）
- 取引事例比較法: **投機的取引**の事例は採用できない／特殊な事情を含む事例は**事情補正**できる場合に限り採用可
- 収益還元法: **賃貸用**不動産のほか、**自用**の不動産にも適用できる（賃貸を想定）
  - **直接還元法**（一期間の純収益を還元利回りで還元）と **DCF法**（連続する複数期間の純収益と復帰価格を現在価値に割り引いて合計）がある
- 最有効使用の原則: 不動産の価格は、その不動産の効用が最高度に発揮される可能性に最も富む使用（最有効使用）を前提として把握される

## 7. 贈与税（住宅取得等資金の贈与の非課税）★

**直系尊属から住宅取得等資金の贈与を受けた場合の非課税**（2026年12月31日までの贈与）

| 項目 | 要件 |
|---|---|
| 贈与者 | 父母・祖父母などの**直系尊属**（年齢制限なし） |
| 贈与の対象 | 住宅の新築・取得・増改築のための**金銭**（⚠ **住宅そのもの**の贈与は対象外） |
| 非課税限度額 | 省エネ等住宅 **1,000万円** / それ以外 **500万円** |
| 受贈者 | 贈与年の**1月1日**で**18歳以上**の直系卑属。贈与年の合計所得金額 **2,000万円以下**（床面積40㎡以上50㎡未満は**1,000万円以下**） |
| 家屋 | **国内**にあること（⚠ 国外の住宅は対象外）。床面積**40㎡以上240㎡以下**、2分の1以上が受贈者の居住用 |
| 取得・居住時期 | 原則として贈与年の翌年**3月15日**までに取得し居住（又は遅滞なく居住することが確実） |

- 暦年課税の基礎控除（110万円）・相続時精算課税と**併用**できる
- 適用には贈与税の**申告**が必要（納付税額がゼロでも）
