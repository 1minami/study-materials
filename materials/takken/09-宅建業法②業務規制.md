# 宅建業法② 業務規制

> 重要事項説明（35条）と37条書面は毎年複数問出題。最頻出分野。

## 1. 宅地建物取引士 ★★★

### 宅建士になるまでの流れ

1. 宅建試験に合格（合格は一生有効）
   - 不正の手段で受験した者 → 知事は**合格決定の取消し**・受験の禁止ができ、さらに**3年以内**の期間を定めて受験を禁止できる
2. 試験を行った**都道府県知事**の**登録**を受ける
   - 要件: **2年以上の実務経験**（又は国土交通大臣の登録を受けた登録実務講習の修了）
   - 登録は一生有効（有効期間なし）
3. 登録をしている知事に**宅建士証の交付**を申請
   - 交付申請前**6か月以内**に行われる、登録知事が指定する講習（法定講習）を受講
   - ⚠ 試験合格の日から**1年以内**に交付を受ける場合は講習が免除
4. 宅建士証の交付を受けて初めて「宅地建物取引士」となる（登録だけでは宅建士の事務はできない）

### 登録の欠格事由

- 宅建業に係る営業に関し成年者と同一の行為能力を有しない**未成年者**
  - ⚠ 免許と違い、法定代理人が欠格かどうかに関係なく登録できない
- 破産者で復権を得ない者、拘禁刑以上・一定の罰金刑から5年、暴力団員等 など（免許の欠格事由と概ね同じ）
- 不正登録等で**登録消除処分**を受け、その処分の日から**5年**を経過しない者
- 登録消除処分の聴聞公示後に、自ら登録の消除を申請した者で、消除の日から**5年**を経過しない者
- **事務禁止処分**を受け、その禁止期間中に本人の申請により登録が消除され、まだ禁止期間が満了しない者
- **心身の故障**により宅建士の事務を適正に行えない者として省令で定めるもの

### 変更の登録・死亡等の届出

- 登録事項（**氏名・住所・本籍**、勤務先の宅建業者の**商号・免許番号**等）に変更 → **遅滞なく**、登録知事に**変更の登録**を申請
  - 氏名・住所が変わった場合は、あわせて宅建士証の**書換え交付**を申請
  - ⚠ 宅建業者の変更の届出（30日以内・住所は対象外）とのひっかけに注意
- 死亡等の届出（登録知事へ、**30日以内**）

| 事由 | 届出義務者 | 起算日 |
|---|---|---|
| 死亡 | **相続人** | 死亡の事実を**知った日** |
| 破産・拘禁刑・一定の罰金刑・暴力団員等 | **本人** | 該当した日 |
| 心身の故障 | 本人又は**法定代理人**・**同居の親族** | 該当した日 |

### 登録の移転

- 登録知事の管轄外の都道府県にある宅建業者の**事務所で業務に従事**し、又は従事しようとするとき → 申請**できる**（任意）
- 申請先: 移転先の知事に対し、**現在の登録知事を経由**して申請
- ⚠ **住所を移転しただけ**では登録の移転はできない（勤務地が変わることが必要）
- ⚠ **事務禁止処分の期間中**は登録の移転を申請できない
- 移転すると、従前の宅建士証は**効力を失う**
  - 移転の申請とともに宅建士証の交付を申請すると、移転先の知事は**従前の宅建士証の残りの有効期間**を有効期間とする宅建士証を交付（講習不要。新たに5年ではない）
  - 新しい宅建士証は、従前の宅建士証と**引換え**に交付

### 宅建士証

- 有効期間: **5年**
- 更新: 申請により更新。更新前**6か月以内**に行われる法定講習を受講（更新時は合格1年以内の免除なし）
- 提示義務:
  - **重要事項説明**をするとき → 相手方から請求がなくても**必ず**提示
  - **取引の関係者から請求**があったとき → 提示
  - ⚠ 37条書面の交付時は、請求がなければ提示義務なし
- 宅建士証の住所欄にシールを貼って提示しても差し支えない（個人情報保護への配慮）

### 宅建士証の返納・提出

| 場面 | 手続き | 相手方 |
|---|---|---|
| 登録が**消除**された／宅建士証が**失効**した | 速やかに**返納** | 交付を受けた知事 |
| **事務禁止処分**を受けた | 速やかに**提出** | 交付を受けた知事 |
| 事務禁止期間が満了 | **返還請求**をすると直ちに返還される | — |

- ⚠ 事務禁止期間が満了しても、**返還請求をしなければ**自動的には返還されない

### 宅建士に対する監督処分

| 処分 | 処分権者 | 内容 |
|---|---|---|
| 指示処分 | 登録知事 + 行為地の知事 | 必要な指示 |
| 事務禁止処分 | 登録知事 + 行為地の知事 | **1年以内**の期間を定めて宅建士の事務を禁止 |
| 登録消除処分 | **登録知事のみ** | 登録を消除（**必要的**） |

- 処分事由: 他の事務所の専任宅建士である旨の表示を許した、名義貸し、事務に関し不正・著しく不当な行為
- 登録消除事由: 欠格事由に該当、不正手段による登録・宅建士証の交付、情状が特に重い、事務禁止処分違反
- 宅建士証の交付を受けていない登録者が**宅建士としてすべき事務を行い情状が特に重い** → 登録消除
- 行為地の知事が処分したとき → 遅滞なく**登録知事に通知**

## 2. 媒介契約 ★★★

### 3種類の媒介契約

| 項目 | 一般媒介 | 専任媒介 | 専属専任媒介 |
|------|----------|----------|-------------|
| 他の業者への依頼 | **可能** | **不可** | **不可** |
| 自己発見取引 | **可能** | **可能** | **不可** |
| 有効期間 | 制限なし | **3ヶ月以内** | **3ヶ月以内** |
| レインズ登録 | 義務なし | **7日以内** | **5日以内** |
| 業務報告 | 義務なし | **2週間に1回以上** | **1週間に1回以上** |

- 媒介契約規制（34条の2）の対象は**売買・交換**の媒介・代理のみ（**貸借**の媒介には適用なし → 書面不要）
- ⚠ **一般媒介**でも媒介契約書面の交付は**必要**
- レインズ登録期間は**休業日を除いて**数える（契約締結の日の翌日から起算）
- 一般媒介には、他に依頼した業者を明示する義務のある「**明示型**」と、明示義務のない「非明示型」がある

### 有効期間と更新

- 専任媒介・専属専任媒介の有効期間: 3ヶ月を超える期間を定めた場合 → **3ヶ月**に短縮（契約全体が無効になるのではない）
- 更新は依頼者の**申出**がある場合に限る（自動更新の特約は**無効**）
  - 更新後の有効期間も、更新の時から**3ヶ月**を超えることができない
- 期間・更新・レインズ登録・業務報告に関する規定に反する特約は**無効**

### 媒介契約書面

- 宅建業者は、媒介契約を締結したときは**遅滞なく**書面を作成し、**宅建業者が記名押印**して依頼者に交付
  - ⚠ **宅建士**の記名は不要（35条・37条書面との違い）
  - 依頼者の承諾があれば**電磁的方法**による提供も可
  - ⚠ 承諾は**書面又は電磁的方法**で得る（**口頭**の承諾は不可。35条・37条書面の電磁的提供も同じ）
- 価額・評価額について**意見を述べる**ときは、その**根拠を明らか**にしなければならない（口頭でも可・書面は不要）

### 媒介契約書面の記載事項

- 宅地建物を特定するために必要な表示
- 売買すべき**価額**又はその**評価額**
- 他の業者に重ねて依頼することの許否、許す場合に他の業者を明示する義務の存否
- 既存建物の場合: 依頼者に対する**建物状況調査**を実施する者のあっせんに関する事項
- 有効期間・解除に関する事項
- 指定流通機構（レインズ）への**登録**に関する事項（**一般媒介**でも記載が必要）
- 報酬に関する事項
- 標準媒介契約約款に基づくか否かの別 など

### 業務報告・レインズ

- 媒介の目的物について**売買・交換の申込み**があったとき → **遅滞なく**依頼者に報告（**一般媒介**を含むすべての媒介契約）
- レインズに登録した業者 → 登録を証する書面を**遅滞なく依頼者に引渡し**
- 登録物件の契約が成立 → **遅滞なく**レインズ（指定流通機構）に**通知**
- レインズへの登録事項: 所在・規模・形質・売買すべき価額・法令上の制限・専属専任媒介である場合はその旨 など（⚠ 依頼者の氏名・住所は登録事項ではない）

## 3. 重要事項説明（35条書面）★★★

### 基本ルール

- **契約成立前**に行う
- **宅建士**が記名した書面を交付して説明（**専任**の宅建士でなくてもよい）
- 宅建士が**宅建士証を提示**して説明（請求がなくても提示）
- 相手方の承諾を得て**電磁的方法**による提供も可能
- 説明場所に制限はない（事務所以外の喫茶店・相手方の自宅等でも可）
- テレビ会議等の **IT重説**も可（図面等を視認でき、双方向でやりとりできる環境・事前の書面送付が必要）
  - ⚠ IT重説でも宅建士証の提示は**省略できない**（画面上で相手方が視認できたことを確認する）
- 重要事項説明書の**作成**は宅建士でなくてもよい（**記名・説明**は宅建士）
- 相手方が**宅建業者**の場合: 書面（35条書面）の**交付は必要**だが、**説明は不要**
  - 宅建士の記名は必要

### 説明すべき相手方

| 取引態様 | 説明の相手方 |
|----------|-------------|
| 売買・交換 | **買主・交換の相手方** |
| 賃借 | **借主** |

- 売主・貸主に対する説明義務はない
- 複数の業者が関与 → **すべての業者**に説明義務（代表して1社の宅建士が説明してもよいが、責任は全業者が負う）

### 供託所等に関する説明（35条の2）

- 相手方（**宅建業者を除く**）に対し、**契約成立前**に説明しなければならない
  - 保証協会の社員でない → 営業保証金を供託した**主たる事務所の最寄りの供託所**とその所在地
  - 保証協会の社員 → 社員である旨、**保証協会の名称・住所・事務所の所在地**、保証協会が弁済業務保証金を供託した**供託所**とその所在地
- ⚠ 供託している**金額**は説明事項ではない
- ⚠ 書面の交付は不要（**口頭**で可）、**宅建士**が説明する必要もない

### 共通の説明事項（売買・貸借共通）★★★

- 登記された権利の種類・内容・登記名義人（又は表題部の所有者）
  - ⚠ 引渡しまでに抵当権を抹消する予定でも、現に登記されていれば説明が必要
- 法令に基づく制限の概要（貸借は売買より範囲が狭い）
- 私道に関する負担（⚠ **建物の貸借**では不要）
- 飲用水・電気・ガスの供給施設、排水施設の整備状況（未整備なら整備の見通し・特別の負担）
- 工事完了時の形状・構造（**未完成物件**の場合）
- 既存建物の場合: **建物状況調査**（実施後**1年以内**のもの。鉄筋コンクリート造等の共同住宅等は2年以内）の実施の有無及び結果の概要
- 代金・借賃**以外**に授受される金銭の額・目的（手付・敷金・礼金など。貸借も対象）
- **契約の解除**に関する事項
- **損害賠償額の予定**・違約金に関する事項
- **手付金等の保全措置**の概要（業者が自ら売主の場合）
- **支払金・預り金の保全措置**の有無・概要（50万円未満等は除く）
- 宅地造成及び特定盛土等規制法の**造成宅地防災区域**内か否か
  - ⚠ 造成宅地防災区域・土砂災害警戒区域・津波災害警戒区域・水害ハザードマップは**貸借**でも説明が必要
- **土砂災害警戒区域**内か否か／**津波災害警戒区域**内か否か
- **水防法**に基づく水害ハザードマップにおける物件の所在地
- 建物の**石綿（アスベスト）**使用の調査結果が**記録されているとき**はその内容（⚠ 調査の実施自体は義務ではない）
- 建物の**耐震診断**の内容（**昭和56年5月31日以前**に新築工事に着手した建物で、耐震診断を受けているとき。⚠ 診断の実施自体は義務ではない）

### 売買・交換のみの説明事項

- 既存建物の**設計図書・点検記録等の保存状況**
- **ローンのあっせん**の内容・ローン不成立時の措置
- **契約不適合責任**の履行に関する措置（保証保険契約の締結等）を講ずるかどうか・その概要
- 住宅性能評価を受けた**新築住宅**であるときはその旨
- 割賦販売の場合: 現金販売価格、割賦販売価格、引渡しまでに支払う金銭の額・賦払金の額・支払時期・方法
- ⚠ 代金の額・支払時期、引渡時期、移転登記の申請時期は35条の説明事項ではない（37条書面の記載事項）
- 法令上の制限の例: 地域における歴史的風致の維持及び向上に関する法律の**歴史的風致形成建造物**（増築等の届出・15条1項2項）の概要
- ⚠ **天災その他不可抗力**による損害の負担は35条の説明事項ではない（37条の任意的記載事項）

### 貸借のみの説明事項

- 台所、浴室、便所等の**設備の整備状況**（建物の貸借）
- **契約期間**・契約の更新に関する事項
- **定期借地権**・**定期建物賃貸借**・**終身建物賃貸借**であるときはその旨
- 用途その他の**利用の制限**に関する事項
- **敷金**その他契約終了時に精算する金銭の精算に関する事項
- **管理の委託先**（氏名・住所。管理業者の登録番号）
- 宅地の貸借: 契約終了時における宅地上の**建物の取壊し**に関する事項
- ⚠ 借賃の額・支払時期は35条の説明事項ではない（37条書面の記載事項）

### 区分所有建物（マンション）の追加事項

| 説明事項 | 売買 | 貸借 |
|---|---|---|
| 敷地に関する権利の種類・内容 | ○ | × |
| 共用部分に関する規約の定め（案を含む） | ○ | × |
| 専有部分の用途その他の利用制限に関する規約の定め | ○ | **○** |
| 専用使用権に関する規約の定め | ○ | × |
| 修繕積立金・管理費の額、**滞納額** | ○ | × |
| 計画的修繕積立金の規約の定め・既に積み立てられている額 | ○ | × |
| 修繕の実施状況の記録 | ○ | × |
| 管理の委託先（氏名・住所） | ○ | **○** |

- ⚠ 貸借で説明が必要なのは「**専有部分の用途制限**」と「**管理の委託先**」の2つのみ

## 4. 37条書面 ★★★

### 基本ルール

- **契約成立後、遅滞なく**交付
- **宅建士**が記名した書面を交付（**専任**の宅建士でなくてもよい）
- ⚠ 書面の**交付**自体は宅建士でなくてもよい（記名が宅建士であればよい）
- 説明義務はない（交付のみ）
- 相手方の承諾を得て電磁的方法も可能
- 相手方が**宅建業者**でも省略できない（交付・宅建士の記名ともに必要）
- 35条書面に記載した事項でも、37条書面への記載は省略できない

### 交付の相手方

| 業者の立場 | 交付の相手方 |
|---|---|
| 自ら当事者（売主・買主） | 契約の**相手方** |
| 代理 | 契約の**相手方**＋**代理を依頼した者** |
| 媒介 | 契約の**各当事者**（売主・買主双方、貸主・借主双方） |

- 自ら貸主となる貸借は宅建業に該当しない → 37条書面の交付義務なし
- 複数の業者が関与 → すべての業者に交付義務

### 必要的記載事項（必ず記載）

| 記載事項 | 売買・交換 | 貸借 |
|---|---|---|
| 当事者の氏名（名称）・住所 | ○ | ○ |
| 宅地建物を特定するために必要な表示 | ○ | ○ |
| 既存建物の構造耐力上主要な部分等の状況について**当事者双方が確認した事項** | ○ | **×** |
| 代金・交換差金・借賃の額、支払時期・方法 | ○ | ○ |
| 宅地建物の**引渡時期** | ○ | ○ |
| **移転登記の申請時期** | ○ | **×** |

### 任意的記載事項（定めがある場合のみ記載）

| 記載事項 | 売買・交換 | 貸借 |
|---|---|---|
| 代金・借賃以外の金銭の額・授受の時期・目的 | ○ | ○ |
| **契約の解除**に関する定め | ○ | ○ |
| 損害賠償額の予定・違約金に関する定め | ○ | ○ |
| 天災その他不可抗力による損害の負担（危険負担） | ○ | ○ |
| ローンのあっせんに関する定めがある場合: 不成立時の措置 | ○ | × |
| **契約不適合責任**又はその履行に関する措置の定め | ○ | × |
| **租税公課**の負担に関する定め | ○ | × |

- 既存建物で、構造耐力上主要な部分等について当事者双方が確認した事項が**ない**場合 → 「**無**」と記載する（記載しないのは違反）
- ローン特約・天災等の負担など**任意的記載事項**は、定めが**ない**ときは記載不要
- ⚠ **宅建業者間**の取引でも37条書面の交付は必要（78条2項の適用除外は8種制限等で、37条は含まない）

### 35条書面と37条書面の比較

| 項目 | 35条書面 | 37条書面 |
|------|----------|----------|
| 時期 | 契約成立**前** | 契約成立**後**、遅滞なく |
| 宅建士の関与 | **記名＋説明** | **記名のみ** |
| 交付先 | 買主・借主 | **両当事者** |
| 宅建士証の提示 | 必要 | 不要（請求があれば提示） |
| 相手方が宅建業者 | 交付必要・説明不要 | 交付必要 |

## 5. 業務上の規制 ★★

### 誇大広告等の禁止（32条）

- 所在・規模・形質、利用の制限、環境・交通、代金・借賃・支払方法、ローンのあっせん について、著しく事実に相違する表示、実際よりも著しく優良・有利であると誤認させる表示は禁止
- ⚠ 実際に誤認した人や損害がなくても、**表示した時点で違反**
  - 取引が成立しなくても監督処分・罰則の対象
- 「**利用の制限**」には、都市計画法等の**公法上**の制限だけでなく、借地権の有無等の**私法上**の制限も含まれる
- 売る意思のない物件・存在しない物件の広告（**おとり広告**）も誇大広告にあたる
- インターネット広告で、成約済み物件を掲載し続けることも誇大広告にあたる

### 広告開始時期の制限（33条）・契約締結時期の制限（36条）

| 規制 | 対象の取引 | 内容 |
|---|---|---|
| 広告開始時期の制限 | 売買・交換・**貸借**すべて | 工事完了前の物件は、**開発許可・建築確認**等の処分があった後でなければ広告不可 |
| 契約締結時期の制限 | **売買・交換**のみ | 同様の処分があった後でなければ契約締結（代理・媒介を含む）不可 |

- ⚠ **貸借**の代理・媒介は、建築確認前でも**契約は可能**（広告は不可）
- 建築確認の**申請中**である旨を表示しても広告はできない

### 取引態様の明示（34条）

- 取引態様（自ら売買、代理、媒介の別）を明示する時期:
  - **広告**をするとき
  - **注文を受けた**とき（遅滞なく。**口頭**でも可）
- ⚠ 広告で明示していても、注文を受けたときに改めて明示が必要

### 業務に関する禁止事項（47条・47条の2）

- 重要な事項（35条・37条の事項、取引条件、業者の資力・信用等）について、**故意に事実を告げず**、又は**不実のことを告げる**行為
- **不当に高額の報酬を要求**する行為（⚠ 実際に受領しなくても要求した時点で違反）
- **手付について貸付けその他信用の供与**をして契約締結を誘引する行為
  - 禁止: 手付の**貸付け**・**分割払い**・**後払い**
  - ⚠ 手付の**減額**、ローンのあっせんは信用の供与ではない → 可
- 利益を生ずることが確実であると誤解させる**断定的判断**の提供
- 契約を締結させるため、又は申込みの撤回・解除を妨げるための**威迫**
- その他の禁止行為:
  - 相手方が契約を締結しない旨の意思を表示したのに勧誘を継続すること
  - 迷惑を覚えさせるような時間（深夜等）の電話・訪問による勧誘
  - 契約締結の判断に必要な時間を与えることを拒むこと
  - 申込みの撤回時に、既に受領した**預り金の返還を拒む**こと
  - 相手方が手付を放棄して契約を解除しようとしたのに、正当な理由なく拒み・妨げること

### 守秘義務（45条）

- 正当な理由なく業務上知り得た秘密を漏らしてはならない
- 宅建業を営まなくなった後も同様
- 宅建業者の**従業者**も、従業者でなくなった後も同様
- 「正当な理由」がある例: 裁判の**証人**として証言する、依頼者本人の**承諾**がある、法令に基づく調査に応じる

### 不当な履行遅延の禁止（44条）

- 登記、引渡し、代金の支払いを不当に遅延する行為は禁止
- ⚠ 対象は**登記・引渡し・取引に係る対価の支払**の3つ

### クーリング・オフ（37条の2）★★★

- **適用**: 宅建業者が**自ら売主**となる売買（買主が宅建業者でない場合）
- **事務所等以外の場所**で買受けの申込み又は契約をした買主が対象
- 事務所等（クーリング・オフ**できない**場所）:
  - 事務所
  - 継続的に業務を行うことができる施設を有する場所で事務所以外のもの
  - 一団の宅地建物の分譲を行う、土地に定着する建物内の案内所（**専任の宅建士**設置義務あり）
  - 売主業者から代理・媒介の依頼を受けた業者の事務所・案内所
  - 宅建業者が**専任の宅建士**を置くべき展示会場等
  - **買主が申し出た**場合の買主の**自宅**・**勤務先**
- クーリング・オフ**できる**場所の例:
  - **テント張り**・仮設小屋の案内所（土地に定着していない）
  - 喫茶店・ホテルのロビー（⚠ 買主の申出があっても）
  - **売主業者が申し出た**買主の自宅・勤務先
- 判断の基準: **申込みをした場所**で判断
  - 事務所等以外で申込み → 事務所で契約 → クーリング・オフ**できる**
  - 事務所等で申込み → 事務所等以外で契約 → クーリング・オフ**できない**
- **方法**: 買主が**書面**で行う（**電磁的方法は不可**）
- **効力発生**: 書面を**発した時**（発信主義）
- クーリング・オフができなくなる場合:
  - 業者からクーリング・オフができる旨及びその方法を**書面で告げられた日から起算して8日**を経過したとき（告げられた日を含めて8日）
  - 買主が物件の**引渡しを受け、かつ代金の全部を支払った**とき（どちらか一方だけなら、まだできる）
- 告げていない場合 → 8日の期間は進行しない（引渡し＋代金全額支払いまではいつでも可）
- 効果:
  - 業者は**損害賠償・違約金を請求できない**
  - 業者は**速やかに**、受領した手付金その他の金銭を返還
  - 買主に不利な特約は**無効**（買主に有利な特約は有効。例: 期間を10日に延長）

## 6. 宅建士が行う事務のまとめ

| 事務 | 内容 |
|------|------|
| 重要事項の説明 | 宅建士が宅建士証を提示して説明 |
| 35条書面への記名 | 宅建士が記名 |
| 37条書面への記名 | 宅建士が記名 |

- いずれも**専任**の宅建士である必要はない
- 媒介契約書面への記名押印は**宅建業者**が行う（宅建士の事務ではない）

## 7. 犯罪収益移転防止法 ★

- 宅建業者は**特定事業者**。**特定業務** = 宅地建物の**売買**又はその代理・媒介（⚠ **貸借は対象外**）
- **取引時確認**（本人特定事項・取引目的・職業等）を行い、確認記録・取引記録を作成して**7年間**保存
- **疑わしい取引の届出**: 収受した財産が犯罪収益である疑い等があると認められる → 速やかに**行政庁**に届出
  - 契約締結**後**に疑いが生じた場合も届出が必要
  - ⚠ 届出後に契約締結を禁止する規定はない
  - ⚠ 届出をしたこと・しようとしていることを顧客等に**漏らしてはならない**
