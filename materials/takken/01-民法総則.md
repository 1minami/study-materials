# 民法総則

> 権利関係（問1〜問14）の基礎。意思表示・代理・時効は毎年出題される超頻出分野。

## 1. 制限行為能力者 ★★

### 意思能力

- 意思表示をした時に**意思能力**を有しなかったとき → その法律行為は**無効**（取消しではない）
- 例: 泥酔者・重度の認知症の者がした契約

### 種類と保護者

| 種類 | 要件 | 保護者 | 同意権 | 取消権 | 代理権 |
|------|------|--------|--------|--------|--------|
| 未成年者 | 18歳未満 | 法定代理人（親権者・未成年後見人） | ○ | ○ | ○ |
| 成年被後見人 | 精神上の障害により事理弁識能力を**欠く常況** | 成年後見人 | × | ○ | ○ |
| 被保佐人 | 事理弁識能力が**著しく不十分** | 保佐人 | ○（13条1項） | ○ | △（審判） |
| 被補助人 | 事理弁識能力が**不十分** | 補助人 | △（審判） | △（審判） | △（審判） |

- 成年被後見人は、成年後見人の**同意を得て**した行為でも取り消せる（同意の意味がないため同意権なし）
- 被保佐人が保佐人の同意を要する主な行為（13条1項）: 借財・保証、**不動産**その他重要な財産の権利の得喪を目的とする行為、訴訟行為、贈与・和解、相続の承認・放棄・遺産分割、新築・改築・増築・大修繕、**建物3年・土地5年を超える賃貸借**
- 被補助人に補助開始の審判をするには、**本人以外**の請求による場合、**本人の同意**が必要
- 成年後見人が成年被後見人に代わって、その居住用の建物又は敷地を売却・賃貸・抵当権設定等をするには、**家庭裁判所の許可**が必要

### 重要ポイント

- **未成年者の例外**: 単に権利を得る行為・義務を免れる行為、処分を許された財産の処分、営業を許された未成年者のその営業に関する行為 → 取消不可
- **成年被後見人**: 日用品の購入その他日常生活に関する行為 → 取消不可
- **制限行為能力者の詐術**: 行為能力者であると信じさせるため**詐術**を用いた → 取り消すことができない
- **取消しの効果**: 初めから無効（遡及効）。制限行為能力者の返還義務は「**現に利益を受けている限度**」（現存利益）
  - 生活費に使った分は現存利益あり（返還必要）、浪費した分は現存利益なし（返還不要）
- 取消しは、制限行為能力者**本人**も、法定代理人等の同意なく単独でできる（取消しを取り消すことはできない）

### 追認

- **法定代理人・保佐人・補助人** → いつでも追認できる
- **制限行為能力者本人** → 行為能力者となった後（取消しの原因となっていた状況が消滅した後）、かつ**取消権を有することを知った後**でなければ追認できない
  - ⚠ 被保佐人・被補助人（成年被後見人を除く）は、保佐人・補助人の**同意を得れば**能力回復前でも追認できる
- **法定追認**（125条）: 追認できる時以後に、全部又は一部の**履行**、履行の**請求**、**担保**の供与、取得した権利の全部又は一部の**譲渡**、強制執行 等 → 追認したものとみなす
- **取消権の期間制限**: 追認できる時から**5年**、行為の時から**20年**で時効消滅

### 相手方の催告権（20条）

- 相手方は、**1か月以上**の期間を定めて、追認するかどうか確答すべき旨を催告できる
- 確答がない場合の効果は、**催告した相手**による:

| 催告の相手 | 期間内に確答がない場合 |
|---|---|
| 行為能力者となった**本人** | **追認**したものとみなす |
| 法定代理人・保佐人・補助人（権限内の行為） | **追認**したものとみなす |
| **被保佐人**・（同意を要する審判を受けた）**被補助人**本人（保佐人等の追認を得るよう催告） | **取消し**たものとみなす |

- ⚠ 未成年者・成年被後見人**本人**に対する催告は効果がない（意思表示の受領能力がない）

## 2. 意思表示 ★★★

### 心裡留保（93条）

- 表意者が真意でないことを知ってした意思表示（冗談・嘘）
- **原則**: 有効
- **例外**: 相手方が表意者の真意でないことを知り、又は知ることができたとき → **無効**
- 例外で無効となる場合も、**善意**の第三者に対抗できない

### 通謀虚偽表示（94条）★★★

- 相手方と通じてした虚偽の意思表示（例: 差押えを逃れるため、AとBが通謀して土地をBに仮装譲渡）
- **効果**: 当事者間では**無効**
- **94条2項**: 無効を**善意の第三者**に対抗できない
  - 第三者は**善意**であれば足りる（**無過失不要**）
  - 第三者は**登記不要**（Aは登記のない善意の第三者Cにも無効を主張できない）
  - 転得者が善意なら、直接の第三者が悪意でも保護される（判例）
  - 直接の第三者が善意なら、その後の転得者は悪意でも保護される（絶対的構成・判例）
- 「第三者」にあたる者: 仮装譲受人からの**譲受人**、仮装譲受人の不動産に**抵当権**の設定を受けた者、仮装譲受人の不動産を**差し押さえた**債権者
- 「第三者」にあたらない者: 仮装譲受人の**一般債権者**（差押え前）、土地の仮装譲渡における**土地上の建物の賃借人**

### 錯誤（95条）★★

- **要件**: 次の錯誤で、その錯誤が法律行為の目的及び取引上の社会通念に照らして**重要なもの**であること
  1. 意思表示に対応する意思を欠く錯誤（**表示の錯誤**。例: 1万円と書くつもりで10万円と書いた）
  2. 表意者が法律行為の基礎とした事情についての認識が真実に反する錯誤（**動機の錯誤**。例: 近くに駅ができると誤信して土地を買った）
- **動機の錯誤**: その事情が法律行為の基礎とされていることが**表示**されていたときに限り取消可能（黙示の表示でもよい）
- **効果**: **取消し**可能（2020年改正で無効→取消しに変更）
  - 取消しができるのは**表意者**（又はその代理人・承継人）。⚠ 相手方からは取り消せない
- **制限**: 表意者に**重大な過失**があるときは取消不可
  - ただし、相手方が表意者の錯誤を**知り又は重大な過失で知らなかった**とき、相手方も**同一の錯誤**に陥っていたとき（共通錯誤）は取消可能
- 錯誤による取消しは、**善意でかつ過失がない**第三者に対抗できない

### 詐欺（96条）★★

- **効果**: 取消し可能
- **第三者詐欺**（相手方以外の者が詐欺をした）: 相手方が詐欺の事実を**知り、又は知ることができた**ときに限り取消可能
- **96条3項**: 詐欺による取消しは、**善意でかつ過失がない**第三者に対抗できない
  - ここでの「第三者」は**取消し前**に利害関係に入った者（取消し後の第三者は対抗問題→物権の章参照）

### 強迫（96条）★★

- **効果**: 取消し可能
- 第三者による強迫でも、相手方の善意・悪意を問わず**常に取消し可能**（詐欺と異なる）
- 強迫による取消しは**善意無過失の第三者にも対抗できる**（詐欺との重要な違い）

### 意思表示の比較表

| 類型 | 当事者間の効果 | 第三者への対抗 |
|------|------|---------------------|
| 心裡留保（原則） | 有効 | — |
| 心裡留保（相手方が悪意・有過失） | 無効 | **善意**の第三者に対抗不可 |
| 通謀虚偽表示 | 無効 | **善意**の第三者に対抗不可（無過失不要・登記不要） |
| 錯誤 | 取消し | **善意無過失**の第三者に対抗不可 |
| 詐欺 | 取消し | **善意無過失**の第三者に対抗不可 |
| 強迫 | 取消し | **すべての第三者に対抗できる** |

## 3. 代理 ★★★

### 代理の基本構造

- **有権代理の要件**: ①代理権の存在 ②**顕名**（本人のためにすることを示す） ③代理権の範囲内の行為
- **顕名なしの場合**: 代理人自身のためにしたものとみなす。ただし相手方が代理人であることを**知り又は知ることができた**ときは本人に効果帰属
- **代理人の行為能力**: 代理人は**行為能力者である必要はない**
  - 制限行為能力者が代理人としてした行為は、行為能力の制限を理由に**取り消せない**（本人が制限行為能力者を代理人に選んだ以上、自己責任）
  - ⚠ 例外: 制限行為能力者が**他の制限行為能力者の法定代理人**としてした行為は取り消せる
- **代理行為の瑕疵**: 詐欺・強迫・錯誤・善意悪意等は、原則として**代理人**を基準に判断
  - 本人の指図に従って代理人が行為をした場合、本人は自ら知っていた事情について代理人の不知を主張できない

### 代理権の消滅事由

| 消滅事由 | 任意代理 | 法定代理 |
|---|---|---|
| 本人の**死亡** | 消滅 | 消滅 |
| 本人の**破産**手続開始 | 消滅 | 消滅しない |
| 代理人の**死亡** | 消滅 | 消滅 |
| 代理人の**破産**手続開始・**後見開始**の審判 | 消滅 | 消滅 |

- ⚠ 本人の**後見開始**の審判では代理権は消滅しない
- ⚠ 代理人が**保佐開始**・**補助開始**の審判を受けても代理権は消滅しない

### 自己契約・双方代理（108条）

- **自己契約**: 代理人が自ら本人の相手方となる契約
- **双方代理**: 同一人が当事者双方の代理人となる契約
- **原則**: 禁止（**無権代理**とみなす → 本人が追認すれば有効）
- **例外**: 本人があらかじめ**許諾**した場合、**債務の履行**（例: 登記申請の双方代理）の場合
- 利益相反行為（代理人と本人の利益が相反する行為）も無権代理とみなす（本人の許諾があれば可）

### 代理権の濫用（107条）

- 代理人が自己又は第三者の利益を図る目的で、代理権の範囲内の行為をした
- **効果**: 相手方がその目的を**知り又は知ることができた**とき → **無権代理**とみなす

### 復代理

| | 任意代理人 | 法定代理人 |
|---|---|---|
| 選任 | 本人の**許諾**を得たとき、又は**やむを得ない事由**があるときのみ | **いつでも**自己の責任で選任可能 |
| 本人に対する責任 | 本人との委任契約に基づく**債務不履行**の一般原則による | **全責任**（やむを得ない事由で選任した場合は**選任・監督**についての責任のみ） |

- 復代理人は**本人の代理人**（代理人の代理人ではない）→ 本人に対して直接権利義務を負う
- 復代理人を選任しても、代理人の代理権は消滅しない
- 代理人の代理権が消滅すると、復代理人の代理権も消滅する

### 無権代理 ★★★

- 無権代理行為は、本人が追認しなければ本人に効果が帰属しない
- **本人の選択肢**: **追認** or **追認拒絶**
  - 追認・追認拒絶は、無権代理人・相手方のどちらに対してもできる（ただし無権代理人に対してした場合、相手方がその事実を知るまでは相手方に対抗できない）
- **追認の効果**: 別段の意思表示がなければ、**契約時に遡って**有効（ただし第三者の権利を害せない）
- **相手方の権利**:

| 権利 | 相手方の要件 | 内容 |
|---|---|---|
| **催告権**（114条） | **悪意でも可** | 相当の期間を定めて本人に追認するか催告。期間内に確答がない → **追認拒絶**とみなす |
| **取消権**（115条） | **善意**（過失があっても可） | 本人が**追認するまで**は契約を取り消せる |
| **無権代理人の責任追及**（117条） | **善意無過失** | 無権代理人に**履行**又は**損害賠償**を請求（相手方が選択） |

- 117条の責任を追及できない場合:
  - 相手方が代理権のないことを**知っていた**
  - 相手方が**過失**により知らなかった（⚠ ただし無権代理人自身が代理権のないことを知っていたときは追及**できる**）
  - 無権代理人が**制限行為能力者**であった

### 無権代理と相続

| 相続のパターン | 結論 |
|---|---|
| **無権代理人**が本人を**単独相続** | 無権代理人は追認を**拒絶できない**（契約は当然に有効） |
| **本人**が無権代理人を相続 | 本人は追認を**拒絶できる**（ただし無権代理人の責任＝117条の損害賠償責任は相続する） |
| 無権代理人が他の相続人と**共同相続** | 他の共同相続人**全員**が追認しない限り、無権代理人の相続分についても当然には有効とならない |
| 本人が追認拒絶した後に死亡し、無権代理人が相続 | 追認拒絶の効果は確定 → 無権代理行為は有効にならない |

### 表見代理 ★★

| 類型 | 条文 | 要件 |
|------|------|------|
| 代理権授与の表示による表見代理 | 109条 | 本人が第三者に代理権を与えた旨を**表示** + 相手方が**善意無過失** |
| 権限外の行為の表見代理 | 110条 | **基本代理権**あり + 権限外の行為 + 相手方が権限内と信ずべき**正当な理由** |
| 代理権消滅後の表見代理 | 112条 | かつて代理権あり + 消滅後の行為 + 相手方が消滅について**善意無過失** |

- 表見代理が成立すると、本人は無権代理であることを主張できず、契約の効果が本人に帰属する
- 表見代理が成立する場合でも、相手方は表見代理を主張せず、無権代理人の責任（117条）を追及することもできる（判例）
- 109条・110条、112条・110条の**重畳適用**も認められる

## 4. 時効 ★★★

### 取得時効

| 要件 | 期間 |
|------|------|
| 所有の意思 + 平穏公然 + 占有開始時に**善意無過失** | **10年** |
| 所有の意思 + 平穏公然 | **20年** |

- 善意無過失は**占有開始時**に判断（途中で悪意になっても10年で取得できる）
- 「所有の意思」のない占有（**賃借人**・受寄者の占有）では、何年占有しても取得時効は成立しない
- **占有の承継**: 前の占有者の占有期間を**併せて**主張できる（その場合、前の占有者の瑕疵＝悪意・有過失も承継）
  - 例: 前主が善意無過失で7年占有、自分が悪意で3年占有 → 前主の占有と併せて**10年**で取得できる
- 賃借権・地上権・地役権（継続的に行使され、外形上認識できるもの）も時効取得できる

### 消滅時効

| 権利 | 起算点 | 期間 |
|--------|------|------|
| 債権（一般） | 権利を行使することができることを**知った時**（主観的起算点） | **5年** |
| 債権（一般） | 権利を行使することができる時（客観的起算点） | **10年** |
| 生命・身体の侵害による損害賠償請求権（債務不履行） | 客観的起算点 | **20年** |
| 不法行為による損害賠償請求権 | 損害及び加害者を知った時 | **3年**（生命・身体の侵害は**5年**） |
| 不法行為による損害賠償請求権 | 不法行為の時 | **20年** |
| 債権・所有権以外の財産権（地上権・地役権等） | 権利を行使することができる時 | **20年** |
| 確定判決等で確定した権利 | 確定の時 | **10年**（短期の時効期間でも10年に延長） |

- ⚠ **所有権**は消滅時効にかからない
- いずれか早い方が到来した時点で時効が完成する

### 時効の完成猶予・更新

| 事由 | 効果 |
|------|------|
| 裁判上の請求・支払督促・調停 | 終了まで完成猶予 → 確定判決等で権利が確定すれば**更新**（取下げ等で終了した場合は終了から**6か月**の完成猶予） |
| 強制執行・担保権の実行 | 終了まで完成猶予 → 終了で**更新** |
| 仮差押え・仮処分 | 終了から**6か月**の完成猶予（更新なし） |
| **催告** | 催告から**6か月**の完成猶予（猶予期間中の**再度の催告**は効力なし） |
| **協議を行う旨の合意**（書面・電磁的記録） | 合意から**1年**（又は定めた1年未満の期間、拒絶通知から6か月）の完成猶予。再度の合意も可だが通算**5年**まで |
| **承認** | **更新**（承認の時から新たに進行） |
| 天災等 | 障害が消滅した時から**3か月**の完成猶予 |

- 「完成猶予」= 一定期間時効が完成しない／「更新」= それまでの期間がリセットされ、ゼロから再スタート
- **承認**: 債務者が一部弁済・支払猶予の申入れ・利息の支払いをすることも承認にあたる
  - 承認には、相手方の権利について処分の**行為能力・権限は不要**（被保佐人も単独で承認できる）
- ⚠ 催告による完成猶予中にした協議の合意、協議の合意による完成猶予中にした催告は、いずれも完成猶予の効力なし

### 時効の援用・放棄

- **時効の援用**: 当事者が援用しなければ、裁判所は時効によって裁判できない
  - 消滅時効の援用権者: 債務者のほか、**保証人**・**物上保証人**・抵当不動産の**第三取得者**など権利の消滅について正当な利益を有する者
  - ⚠ **後順位抵当権者**は、先順位抵当権の被担保債権の消滅時効を援用**できない**（判例）
- 時効の効力は、その**起算日に遡る**（取得時効なら占有開始時から所有者だったことになる）
- **時効利益の放棄**: 時効完成**前**の放棄は**不可**（あらかじめ放棄する特約は無効）。完成**後**は放棄可能
- 時効完成後に、時効完成を知らずに債務を**承認**した場合 → 信義則上、その後は時効の援用**不可**（判例）

## 5. 条件・期限

### 条件

- **停止条件**: 条件成就で効力**発生**（例: 試験に合格したら車をあげる）
- **解除条件**: 条件成就で効力**消滅**（例: 試験に落ちたら奨学金の支給を打ち切る）
- 条件の成否が未定の間も、当事者は相手方の利益を害してはならない／その権利を処分・相続・保存・担保に供することができる
- 条件の成就によって**不利益を受ける**当事者が故意に条件の成就を**妨げた** → 相手方は条件が**成就したもの**とみなすことができる
- 条件の成就によって**利益を受ける**当事者が**不正に**条件を成就させた → 相手方は条件が**成就しなかったもの**とみなすことができる
- 不法な条件を付した法律行為: **無効**／不能の停止条件: **無効**／不能の解除条件: 無条件（有効）
- 単に債務者の意思のみにかかる停止条件（随意条件）: **無効**

### 期限

- **確定期限**: 到来時期が確定している（例: 2026年4月1日）
- **不確定期限**: 到来は確実だが時期は不確定（例: 父が死亡したとき）
- 期限は**債務者の利益**のために定めたものと推定される
- 期限の利益の放棄: 可能。ただし相手方の利益を害することはできない
- **期限の利益の喪失**（137条）: 債務者が**破産手続開始**の決定を受けた、**担保を滅失・損傷・減少**させた、**担保を供する義務**を履行しない
