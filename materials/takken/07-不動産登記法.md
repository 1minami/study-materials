# 不動産登記法

> 毎年1問出題。登記の申請手続き、仮登記、登記できる権利の知識が問われる。

## 1. 不動産登記制度の基本 ★

### 登記の目的

- 不動産の物理的状況（表示に関する登記）と権利関係（権利に関する登記）を公示する
- 取引の安全と円滑に資する
- 登記記録は**1筆の土地・1個の建物ごと**に作成される

### 登記の種類

| 種類 | 内容 | 申請義務 | 登記官の職権 |
|------|------|------|-------------|
| 表示に関する登記 | 土地・建物の物理的状況（所在、地番、地目、地積、床面積等） | **あり**（多くは1か月以内） | 職権で登記できる |
| 権利に関する登記 | 所有権、抵当権、賃借権等の権利関係 | 原則**なし**（例外: 相続登記・住所等変更登記） | 原則として申請による（職権不可） |

### 表示に関する登記の申請義務（1か月以内）

| 登記 | 申請義務者 | 期間 |
|---|---|---|
| 土地の**表題登記** | 新たに生じた土地・表題登記のない土地の所有権を取得した者 | 取得の日から**1か月以内** |
| 建物の**表題登記** | **新築**した建物・表題登記のない建物の所有権を取得した者 | 取得の日から**1か月以内** |
| 地目・地積の**変更**の登記 | 表題部所有者又は所有権の登記名義人 | 変更の日から**1か月以内** |
| 建物の表題部の**変更**の登記（種類・構造・床面積等） | 表題部所有者又は所有権の登記名義人 | 変更の日から**1か月以内** |
| 土地・建物の**滅失**の登記 | 表題部所有者又は所有権の登記名義人 | 滅失の日から**1か月以内** |

- 申請を怠ると**10万円以下の過料**
- ⚠ **分筆**・**合筆**の登記は義務ではない（表題部所有者又は所有権の登記名義人が申請した場合に行う）
- 建物の**分割**・**合併**の登記も、所有者の申請による（義務なし）

### 登記記録の構成

| 部分 | 記載事項 |
|------|----------|
| 表題部 | 不動産の物理的現況（所在、地番、地目、地積、家屋番号、種類、構造、床面積等）、表題部所有者 |
| 権利部（甲区） | **所有権**に関する事項（所有権保存登記、所有権移転登記、差押え、仮処分等） |
| 権利部（乙区） | **所有権以外**の権利に関する事項（抵当権、地上権、賃借権、地役権等） |

- 表題部所有者は、所有権の登記がされると抹消される（以後は甲区の登記名義人が所有者として公示される）

### 登記事項証明書等

- **何人も**（利害関係がなくても）、手数料を納付して**登記事項証明書**の交付を請求できる
- 登記所に出向かず、**オンライン**で請求し、郵送で受け取ることもできる
- 地図・建物所在図・地図に準ずる図面の写しの交付も、何人も請求できる
- 登記簿の**附属書類**（申請書・添付書類）の閲覧 → 請求人が**利害関係**を有する部分等に限られる（正当な理由が必要）

## 2. 登記の申請 ★★

### 申請主義

- 登記は、法令に別段の定めがある場合を除き、**当事者の申請**又は官公署の**嘱託**がなければすることができない

### 共同申請の原則

- 権利に関する登記は、**登記権利者**と**登記義務者**が**共同**で申請（60条）
  - 登記権利者: 登記によって登記上直接に**利益**を受ける者（売買の買主）
  - 登記義務者: 登記によって登記上直接に**不利益**を受ける登記名義人（売買の売主）
- 共同申請の理由: 登記義務者を関与させることで、登記の**真正**を確保するため

### 単独申請が認められる場合 ★★

| 場合 | 申請者 |
|------|--------|
| **所有権保存登記** | 表題部所有者又はその相続人その他の一般承継人 等 |
| **相続**・**法人の合併**による権利の移転の登記 | 登記権利者（相続人・存続法人） |
| **相続人に対する遺贈**による所有権移転の登記 | 登記権利者（受遺者である相続人） |
| 登記名義人の**氏名・住所の変更**（更正）の登記 | 登記名義人 |
| **判決**による登記（登記手続を命ずる確定判決） | 勝訴した一方の当事者 |
| **仮登記**（仮登記義務者の**承諾**がある・仮登記を命ずる**処分**がある） | 仮登記権利者 |
| **仮登記の抹消** | 仮登記名義人（又は仮登記名義人の承諾がある利害関係人） |
| 収用による所有権移転の登記 | 起業者 |

- ⚠ **相続人以外**の者に対する遺贈 → 共同申請（受遺者と遺言執行者又は相続人全員）
- ⚠ **売買**・**贈与**・**時効取得**による所有権移転 → 共同申請
- **一般承継人による申請**: 登記権利者・登記義務者が申請前に死亡 → その**相続人**が申請できる（例: 売主が登記前に死亡 → 売主の相続人が登記義務者として買主と共同申請）

### 代理人による申請

- 登記の申請は、代理人（司法書士等）によってもできる
- 委任による代理人の権限は、**本人の死亡**、本人である法人の**合併**による消滅、法定代理人の死亡・代理権の消滅によっても**消滅しない**（民法の原則の例外）

### 登記識別情報

- 登記名義人が登記を申請する場合に、本人確認のために提供する情報（**12桁**の英数字の組み合わせ）
- 登記官は、その登記により**申請人自らが登記名義人となる**場合に、登記完了後速やかに、申請人に登記識別情報を**通知**する
  - 申請人があらかじめ通知を希望しない旨を申し出た場合は通知されない
- 登記済証（権利証）に代わるもの
- 共同申請で**登記義務者**の登記識別情報を提供する
- 登記識別情報を提供できない場合（失念・失効等）:
  - **事前通知制度**: 登記官が登記義務者に、申請があった旨と、申請内容が真実であれば**2週間以内**（海外在住者は4週間）に申し出るべき旨を通知
  - **資格者代理人**（司法書士等）による本人確認情報の提供
  - **公証人**の認証
- ⚠ 登記識別情報は**再通知**されない（失念しても再発行なし）

### 登記の申請方法

- 書面申請（登記所の窓口に持参 or **郵送**）
- オンライン申請（電子申請）
- 登記原因を証する情報（売買契約書等）の提供が必要

### 登記の順位

- 同一の不動産について登記した権利の順位は、法令に別段の定めがある場合を除き、登記の**前後**による
- 同一の不動産に関し同時に2以上の申請がされた場合 → **同時**にされたものとみなす

## 3. 所有権に関する登記 ★★

### 所有権保存登記

- 所有権の登記がない不動産について、初めてする所有権の登記
- 申請できる者（**単独申請**）:
  - **表題部所有者**又はその**相続人その他の一般承継人**
  - 所有権を有することが**確定判決**によって確認された者
  - **収用**によって所有権を取得した者
  - **区分建物**の場合: 表題部所有者から**直接**所有権を取得した者（分譲マンションの購入者）
    - 敷地権付き区分建物の場合は、敷地権の登記名義人の**承諾**が必要
- ⚠ 表題部所有者から所有権を取得した者（区分建物以外）は、所有権保存登記を申請できない → 表題部所有者が保存登記をした後に、所有権移転登記をする

### 所有権移転登記

- 売買、贈与、相続、時効取得等の原因で申請（相続・合併・相続人への遺贈以外は**共同申請**）
- 時効取得 → 「時効取得」を原因とする**所有権移転**登記（保存登記ではない）

### 相続登記の義務化（2024年4月施行）★

- 相続（**相続人に対する遺贈**を含む）により所有権を取得した者は、自己のために相続の開始があったことを**知り**、かつ、所有権を取得したことを**知った日**から**3年以内**に、所有権移転登記を申請しなければならない
- 法定相続分で登記した後に**遺産分割**があった → 法定相続分を超えて取得した者は、遺産分割の日から**3年以内**に登記を申請
- 正当な理由なく怠ると**10万円以下の過料**
- 施行日（2024年4月1日）**前**に開始した相続も対象（施行日から3年以内）
- **相続人申告登記**: 相続登記の申請義務を負う者が、期間内に登記官に対し、相続が開始した旨と自らが相続人である旨を**申し出る** → 申請義務を履行したものとみなされる（登記官が職権で付記）
  - 申出は**単独**ででき、他の相続人の分も含めて代理して申し出ることもできる

### 住所等変更登記の義務化（2026年4月施行）★

- 所有権の登記名義人の**氏名・名称・住所**に変更があったときは、変更日から**2年以内**に変更登記の申請義務（76条の5）
- 正当な理由なく怠ると**5万円以下の過料**
- 登記官は**職権**で変更登記が可能（自然人は本人の申出がある場合に限る — 76条の6）
- 相続登記義務化（3年・10万円以下）との比較で出題されやすい: **住所変更は2年・5万円以下**

### 国内連絡先の登記（2024年4月施行）★

- 所有権の登記名義人が**国内に住所を有しない**とき → **国内連絡先**となる者の氏名・名称及び住所等も**登記事項**（73条の2第1項2号）
- 国内連絡先となる者がいない場合は、その旨（国内連絡先なし）を登記する

### 所有不動産記録証明書（2026年2月2日施行）

- 何人も、**自らが所有権の登記名義人として記録されている不動産の一覧**の証明書の交付を請求できる（119条の2）
- 相続人等の一般承継人は、**被承継人（被相続人）分**の交付も請求可能 → 相続登記漏れの防止

### 共有の登記

- 共有の登記をする場合、申請情報に各共有者の**持分**を記載
- 共有物分割禁止の定め（5年以内）は、登記をしなければ第三者に対抗できない

### 買戻しの特約の登記

- 不動産の売買と**同時に**登記しなければ第三者に対抗不可（所有権移転登記の**付記登記**として行う）
- 買戻し期間: **10年**以内（定めがなければ5年）
- 売買契約の日から**10年**を経過した場合 → 登記権利者（売買の買主側）は**単独**で買戻しの特約の登記の抹消を申請できる

## 4. 登記できる権利 ★

- 所有権、地上権、永小作権、地役権、先取特権、質権、抵当権（根抵当権を含む）、**賃借権**、**配偶者居住権**、採石権

### 登記できないもの

- **占有権**
- **留置権**
- 入会権
- ⚠ **使用借権**（使用貸借による権利）も登記できない
- ⚠ **配偶者短期居住権**も登記できない

### 主な登記のルール

- 抵当権の設定登記: 共同申請（抵当権者が登記権利者、設定者が登記義務者）。**債権額**・**債務者**等を記載
- 抵当権の**順位の変更**: 順位を変更する各抵当権者の**合意**＋利害関係人の**承諾** → 登記が**効力発生要件**
- 被担保債権を弁済しても、抵当権の登記は自動的には抹消されない（抹消登記の申請が必要）
- **付記登記**: 既存の登記に付記して、その一部を変更・更正するもの（順位は主登記の順位による）
  - 例: 登記名義人の住所変更、抵当権の移転、買戻しの特約

## 5. 仮登記 ★★

### 仮登記の種類

| 種類 | 場合 | 例 |
|------|------|------|
| 1号仮登記 | 物権変動は**既に生じている**が、登記の申請に必要な情報（登記識別情報・第三者の許可書等）を提供できない場合 | 売買は成立したが登記識別情報を提供できない |
| 2号仮登記 | 物権変動は**まだ生じていない**が、将来の権利変動の**請求権**を保全する場合（始期付き・停止条件付きを含む） | **売買予約**、農地法の許可を条件とする売買 |

### 仮登記の特徴

- 仮登記には**対抗力がない**（**順位保全効**のみ）
- 仮登記に基づく**本登記**をしたとき → 本登記の順位は**仮登記の順位**による（仮登記後になされた第三者の登記に優先する）
- 仮登記の申請:
  - 原則どおり**共同申請**も可
  - 仮登記義務者の**承諾**があるとき、又は裁判所の**仮登記を命ずる処分**があるときは、仮登記権利者が**単独**で申請可能
  - 仮登記の申請では、登記識別情報の提供は**不要**
- **仮登記に基づく本登記**（所有権に関する仮登記の場合）:
  - 登記上の**利害関係を有する第三者**（仮登記後に所有権移転登記・抵当権設定登記を受けた者等）がいる場合は、その第三者の**承諾**があるときに限り申請できる
  - 登記官は、本登記をするとき、**職権**でその第三者の登記を**抹消**する
- **仮登記の抹消**:
  - **仮登記名義人**が**単独**で申請可能（登記識別情報の提供が必要）
  - 登記上の**利害関係人**も、仮登記名義人の**承諾**があれば単独で申請可能

### 仮登記担保

- 金銭債務の不履行を条件として所有権移転の仮登記 → 仮登記担保法の適用（清算金の支払いが必要）

## 6. 区分建物の登記

- 区分建物の表題登記: 区分建物を新築した**原始取得者**（分譲業者等）が申請
  - ⚠ 原始取得者から区分建物を取得した者は表題登記を申請できない（原始取得者が申請し、取得者は所有権保存登記を申請）
  - 原始取得者が死亡した場合 → その**相続人**も、被相続人を表題部所有者とする表題登記を申請できる
- 区分建物が属する**一棟の建物**の表題登記: 一棟の建物に属する**他の区分建物**と**一括**して申請しなければならない
- **敷地権**の登記: 専有部分と分離処分できない敷地利用権（敷地権）は、区分建物の登記記録の表題部に記録される
  - 敷地権の登記後は、土地の登記記録に**敷地権である旨**の登記がされ、原則として土地だけの所有権移転登記等はできない

## 7. 分筆・合筆の登記

- 表題部所有者又は所有権の登記名義人の**申請**による（登記官が職権でする場合もある）
- **合筆**できない場合:
  - 相互に**接続**していない土地
  - **地目**又は地番区域が**異なる**土地
  - 表題部所有者又は所有権の登記名義人が**異なる**土地、**持分**が異なる土地
  - 所有権の登記がある土地と**所有権の登記がない**土地
  - 所有権等の登記以外の権利に関する登記（**抵当権**等）がある土地（一定の場合を除く）

## 8. 登記の効力

### 対抗力

- 登記をすれば第三者に対抗できる
- 登記には**公信力がない**（真実の権利関係と異なる登記を信頼して取引しても保護されない場合がある → 民法94条2項類推適用の問題）

### 登記請求権

- 物権変動があった場合、登記権利者は登記義務者に対し登記手続への協力を請求できる
- 登記義務者が応じない → **登記手続を命ずる確定判決**を得て、単独で登記を申請できる

## 9. 筆界特定制度

- 筆界（公法上の境界。登記された時にその土地の範囲を区画するものとされた線）が明らかでない場合に、**筆界特定登記官**が、筆界調査委員の意見を踏まえて筆界の現地における位置を特定する制度
- 申請できる者: 土地の**所有権登記名義人**等
- 筆界特定は、**所有権の範囲**を確定するものではない（所有権の範囲は裁判で争う）
- 筆界特定がされた後も、筆界確定訴訟を提起できる（判決が確定すると、筆界特定はその判決と抵触する範囲で効力を失う）
