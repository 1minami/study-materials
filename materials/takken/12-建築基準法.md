# 建築基準法

> 毎年2問出題。建蔽率・容積率の計算、用途制限、単体規定・集団規定が頻出。

## 1. 建築確認 ★★

### 建築確認が必要な建築物（2025年4月1日施行の改正法ベース）

| 区分 | 対象 | 新築 | 増改築・移転 | 大規模修繕・模様替 | 用途変更 |
|------|------|------|-------------|-------------------|---------|
| **新1号建築物** | 200㎡超の特殊建築物（劇場、病院、学校、百貨店、共同住宅等） | ○ | ○ | ○ | ○ |
| **新2号建築物** | 1号以外で、**2階以上**又は**延べ面積200㎡超**の建築物 | ○ | ○ | ○ | — |
| **新3号建築物** | 1号・2号以外で、都市計画区域・準都市計画区域・準景観地区等内の建築物 | ○ | ○ | — | — |

- 新1号・新2号は**全国どこでも**（都市計画区域外でも）建築確認が必要
- 新3号は都市計画区域・準都市計画区域等の**区域内のみ**（区域外の平屋200㎡以下は確認不要）
- **防火・準防火地域外**で、増築・改築・移転に係る部分の床面積が**10㎡以内** → 建築確認**不要**
- **防火・準防火地域内**: 増築・改築・移転は面積にかかわらず建築確認必要
- **用途変更**: 用途を変更して**200㎡超の特殊建築物**にする場合に確認が必要
  - ⚠ **類似の用途**相互間の変更（例: 劇場→映画館、ホテル→旅館）は確認不要
  - 用途変更の工事完了時は、完了検査の申請ではなく建築主事等への**届出**
- ⚠ 建築物の**除却**（取壊し）は建築確認不要（床面積10㎡超なら都道府県知事への届出）

> ※**2025年4月1日施行の改正建築基準法**により、建築確認の対象区分が再編されました。旧法の「木造大規模（高さ13m超 or 軒高9m超）」「非木造大規模（2階以上 or 200㎡超）」の区分は廃止され、構造種別を問わず**新2号建築物**（2階以上 又は 200㎡超）に統合されました。
>
> また、旧「**4号建築物**」（都市計画区域等内の小規模木造住宅）に対する **建築確認の特例審査省略（旧4号特例）も縮小・廃止** され、多くの小規模住宅でも構造関係規定の審査が必要になりました。あわせて建築物省エネ法の改正により、原則として全ての新築建築物で **省エネ基準適合義務化** されています。

### 建築確認の手続き

1. **建築主**が**建築主事等**又は**指定確認検査機関**に確認申請（工事着手**前**）
2. 確認済証の交付
   - 審査期間: 新1号・新2号は受理から**35日以内**（合理的な理由があれば35日の範囲で延長可）、新3号は**7日以内**
   - 確認済証の交付を受けた**後**でなければ工事に着手できない
3. 工事着工
4. 中間検査（特定工程を含む場合）→ 中間検査合格証の交付後でなければ次の工程に進めない
5. 工事完了 → 建築主が**完了検査を申請**（工事完了日から**4日以内**に建築主事等に**到達**するように）
6. 建築主事等は申請受理から**7日以内**に検査 → 適合していれば**検査済証**を交付

### 検査済証の交付前の使用制限

- 新1号・新2号建築物の**新築**等 → **検査済証の交付を受けた後**でなければ使用できない
- 例外として仮に使用できる場合:
  - **特定行政庁**が安全上・防火上・避難上支障がないと認めたとき（仮使用の認定）
  - 建築主事等又は指定確認検査機関が国土交通大臣の定める基準に適合すると認めたとき
  - 完了検査の申請が受理された日から**7日**を経過したとき
- ⚠ 新3号建築物は、検査済証の交付前でも使用できる

## 2. 単体規定（全国適用）★

### 主な単体規定

| 規定 | 内容 |
|------|------|
| 構造耐力 | 自重、積載荷重、積雪荷重等に対して安全な構造 |
| 防火壁 | 延べ面積1,000㎡超の建築物は防火壁等で区画（耐火・準耐火建築物を除く） |
| 居室の採光 | 住宅の居室: 床面積の**1/7以上**（一定の照明設備を設ける場合は1/10まで緩和） |
| 居室の換気 | 床面積の**1/20以上**（換気設備を設ければ不要） |
| 石綿（アスベスト） | 建築材料への使用禁止（添加・吹付けも禁止） |
| シックハウス | クロルピリホス使用禁止、ホルムアルデヒド制限（居室を有する建築物は原則として**換気設備**の設置が必要） |
| 避雷設備 | 高さ**20m**超の建築物 |
| 非常用の昇降機 | 高さ**31m**超の建築物 |
| 居室の天井の高さ | **2.1m以上**（一室で高さが異なる場合は平均の高さ） |
| 地階の居室 | 住宅の居室等を地階に設ける場合は、からぼり等の防湿措置 |

- ⚠ 採光の規定は**住宅・学校・病院等の居室**に適用（事務所・店舗の居室には採光規定なし）
- 共同住宅の共用階段: 幅120cm以上（直上階の居室の床面積の合計が200㎡超の場合 等）

### 既存不適格建築物

- 法令の改正前から存在し、改正後の規定に適合しなくなった建築物 → 違反建築物ではなく、そのまま使用できる
- 増改築・大規模修繕等を行う場合は、原則として現行の規定に適合させる必要がある

## 3. 集団規定（都市計画区域・準都市計画区域内で適用）★★★

### 道路の定義 ★★

- **道路**: 幅員**4m以上**（特定行政庁が指定する区域では6m以上）の次のもの
  - 道路法による道路（国道・県道・市町村道）
  - 都市計画法・土地区画整理法等による道路
  - 集団規定が適用されるに至った際に**現に存在する道**
  - 道路法等による新設・変更の事業計画があり、**2年以内**に事業が執行される予定として特定行政庁が指定したもの
  - 特定行政庁から**位置の指定**を受けて築造する私道（**位置指定道路**）
- **2項道路**（みなし道路）: 集団規定が適用されるに至った際に**現に建築物が立ち並んでいた**幅員4m未満の道で、**特定行政庁が指定**したもの
  - 道路の**中心線から2m**後退した線が道路の境界線とみなされる（セットバック）
  - 片側が**崖地・川・線路敷地**等の場合 → 崖地等の側の境界線から**4m**の線が道路の境界線
  - セットバック部分は建蔽率・容積率の敷地面積に**算入しない**
  - セットバック部分には建築物・塀を建てられない
  - 幅員**1.8m未満**の道を2項道路に指定する場合は、あらかじめ**建築審査会の同意**が必要

### 接道義務

- 建築物の敷地は、道路に**2m以上**接しなければならない
  - ⚠ **自動車専用道路**（高速道路等）に接していても接道したことにならない
- 接道義務の例外:
  - 幅員4m以上の道（道路に該当しないもの）に2m以上接する建築物で、利用者が少数の一定の用途・規模のものとして**特定行政庁が認めた**もの（建築審査会の同意不要）
  - 敷地の周囲に**広い空地**を有する建築物等で、特定行政庁が支障がないと認めて**建築審査会の同意**を得て**許可**したもの
- 地方公共団体は、特殊建築物・3階以上の建築物・延べ面積1,000㎡超の建築物等について、**条例**で接道義務を**付加**（強化）できる
  - ⚠ 条例で接道義務を**緩和**することはできない

### 道路内の建築制限

- 建築物・擁壁は、道路内に又は道路に突き出して建築・築造してはならない
- 例外:
  - **地盤面下**に設ける建築物（地下街等）
  - 公衆便所・巡査派出所等の公益上必要な建築物で、特定行政庁が通行上支障がないと認めて**建築審査会の同意**を得て**許可**したもの
  - **公共用歩廊**（アーケード）等で、特定行政庁が**建築審査会の同意**を得て**許可**したもの

### 用途制限

- 各用途地域で建築できる建物・できない建物が定められている
- 用途地域の指定のない区域（市街化調整区域を除く）でも、大規模集客施設（床面積10,000㎡超の店舗・映画館等）は建築できない

| 建築物 | 建築できない用途地域 |
|---|---|
| 神社・寺院・教会、巡査派出所、公衆電話所、**診療所**、**保育所**、公衆浴場 | なし（**すべての用途地域で可**） |
| 住宅・共同住宅・寄宿舎・下宿・図書館・老人ホーム | **工業専用地域** |
| 幼稚園・小学校・中学校・高等学校 | **工業地域・工業専用地域** |
| 大学・高等専門学校・専修学校・**病院** | 第一種・第二種低層住居専用、田園住居、工業、工業専用 |
| ホテル・旅館 | 低層住居専用、中高層住居専用、田園住居、工業、工業専用（第一種住居地域は3,000㎡以下のみ可） |

- 特定行政庁が**許可**した場合は、本来建築できない用途地域でも建築できる（利害関係者の公開による意見聴取・建築審査会の同意が必要）
- 敷地が2つの用途地域にまたがる → 敷地の**過半**が属する地域の用途制限を**敷地全体**に適用

### 建蔽率 ★★★

- 建蔽率 = 建築面積 ÷ 敷地面積

| 用途地域 | 都市計画で定める建蔽率 |
|---|---|
| 低層住居専用・中高層住居専用・田園住居・工業専用 | 30・40・50・60% |
| 第一種・第二種住居・準住居・準工業 | 50・60・80% |
| 近隣商業 | 60・80% |
| **商業** | **80%**（都市計画で定めない） |
| 工業 | 50・60% |
| 用途地域の指定のない区域 | 30・40・50・60・70%（特定行政庁が定める） |

#### 建蔽率の緩和

| 条件 | 緩和 |
|------|------|
| **防火地域**内の**耐火建築物等**（建蔽率80%の地域を除く） | **+10%** |
| **準防火地域**内の**耐火建築物等**又は**準耐火建築物等** | **+10%** |
| 特定行政庁指定の**角地** | **+10%** |
| 防火・準防火の緩和と角地の両方に該当 | **+20%** |

- 敷地が防火地域の内外にわたる場合、敷地内の建築物の**全部が耐火建築物等**であれば、敷地の全部が防火地域内にあるものとみなす

#### 建蔽率制限がない（100%）場合

- **防火地域**内の**耐火建築物等**で、指定建蔽率が**80%**の地域内にある場合 → **制限なし**
- 巡査派出所、公衆便所、公共用歩廊等
- 公園・広場・道路・川等の内にある建築物で特定行政庁が許可したもの

### 敷地面積の最低限度

- 用途地域に関する都市計画で、建築物の敷地面積の最低限度を定めることができる
- 最低限度を定める場合は**200㎡**を超えてはならない
- 適用除外: 建蔽率制限のない防火地域内の耐火建築物等、公衆便所・巡査派出所等

### 容積率 ★★★

- 容積率 = 延べ面積 ÷ 敷地面積
- 商業地域は20〜130%（200%〜1300%）など、用途地域ごとに都市計画で定める

#### 前面道路による制限

- 前面道路の幅員が**12m未満**の場合、次の数値と指定容積率を比較して**小さい方**が適用:
  - 住居系（低層住居専用・中高層住居専用・田園住居・第一種・第二種住居・準住居）: 幅員 × **4/10**（特定行政庁指定区域では6/10）
  - その他（商業系・工業系・用途地域の指定のない区域）: 幅員 × **6/10**（特定行政庁指定区域では4/10又は8/10）
- 前面道路が**2以上**ある → 幅員の**最大**のものを基準とする
- 幅員**15m以上**の道路（**特定道路**）に接続する幅員6m以上12m未満の前面道路で、特定道路から**70m以内**の敷地 → 前面道路の幅員に一定の数値を加算して計算できる（特定道路による緩和）
- 例: 第一種住居地域（指定容積率300%）、前面道路6m → 6 × 4/10 = 240% < 300% → **240%**

#### 延べ面積に算入しない部分（容積率の緩和）

- **エレベーターの昇降路**の部分（すべての建築物）
- **共同住宅・老人ホーム等**の**共用の廊下・階段**の部分
- **地階**の住宅・老人ホーム等の用途に供する部分 → その建築物の住宅等の用途に供する部分の床面積の合計の**1/3**を限度に算入しない
- 自動車車庫等の部分 → 延べ面積の**1/5**を限度に算入しない
- 住宅等の機械室（給湯設備等）で特定行政庁が認めるもの

### 敷地が2つの区域にまたがる場合

| 規制 | ルール |
|------|--------|
| 建蔽率 | **加重平均**（面積按分） |
| 容積率 | **加重平均**（面積按分） |
| 用途制限 | **過半が属する地域**の制限が適用 |
| 防火規制 | **建築物**が防火・準防火地域にまたがる → **厳しい方**（防火壁で区画した場合は例外） |

### 高さ制限 ★

| 制限 | 適用地域 |
|------|----------|
| 絶対高さ制限（10m or 12m） | 第一種・第二種低層住居専用地域、田園住居地域 |
| 道路斜線制限 | **すべての区域**（用途地域の指定のない区域を含む） |
| 隣地斜線制限 | 低層住居専用地域・田園住居地域**以外** |
| 北側斜線制限 | 低層住居専用地域、田園住居地域、第一種・第二種中高層住居専用地域 |
| 日影規制 | 商業地域・工業地域・工業専用地域**以外**で、地方公共団体の**条例**で指定する区域 |

- 北側斜線制限: 第一種・第二種中高層住居専用地域で**日影規制**の対象区域に指定されている場合は**適用されない**
- 日影規制の対象建築物:
  - 低層住居専用地域・田園住居地域 → 軒の高さ**7m超**又は**地階を除く階数3以上**
  - その他の区域 → 高さ**10m超**
- ⚠ 日影規制の対象区域**外**にある高さ10m超の建築物でも、冬至日に対象区域内に日影を生じさせる場合は規制を受ける
- 絶対高さ10mの地域でも、一定の空地・敷地規模を有し、特定行政庁が認めたものは12mまで可

### 防火地域・準防火地域 ★★

| 区分 | 規制内容 |
|------|----------|
| 防火地域 | **階数3以上**（地階を含む）又は延べ面積**100㎡超** → **耐火建築物等**／それ以外 → 耐火建築物等又は**準耐火建築物等** |
| 準防火地域 | 地階を除く**階数4以上**又は延べ面積**1,500㎡超** → 耐火建築物等／延べ面積**500㎡超1,500㎡以下**又は地階を除く**階数3** → 耐火建築物等又は準耐火建築物等 |

- 防火地域・準防火地域内の建築物:
  - 外壁の開口部で延焼のおそれのある部分に**防火戸**等の防火設備を設ける
  - **屋根**は、市街地の火災を想定した火の粉による火災の発生を防止するための構造とする
  - 外壁が**耐火構造**であれば、外壁を**隣地境界線に接して**設けることができる
- 防火地域内の**看板・広告塔**等で、**屋上**に設けるもの又は**高さ3m超**のもの → 主要な部分を**不燃材料**で造り又は覆う
- 高さ2m以下の門・塀は規制の対象外
- 建築物が防火地域と準防火地域にまたがる場合 → **全部**について防火地域の規定が適用（防火地域外で防火壁で区画されていれば、その外側は準防火地域の規定）
- 建築物が防火地域・準防火地域と指定のない区域にまたがる場合 → 全部について防火地域・準防火地域の規定が適用（防火壁で区画した外側を除く）

## 4. 建築協定

- **市町村の条例**で定める区域内で、土地の所有者及び借地権者（**土地の所有者等**）が締結
- 締結: 土地の所有者等の**全員の合意**で建築協定書を作成し、代表者が**特定行政庁**に提出して**認可**を受ける
  - 借地権の目的となっている土地については、**借地権者**の合意があれば足りる（その土地の所有者の合意は不要）
- 認可の**公告**の日以後に土地の所有者等となった者にも効力が及ぶ
  - ⚠ 協定に合意しなかった者の土地を承継した者には効力が及ばない
- 変更・廃止

| 手続き | 合意 | 認可 |
|---|---|---|
| 締結 | **全員**の合意 | 特定行政庁の認可 |
| 変更 | **全員**の合意 | 特定行政庁の認可 |
| 廃止 | **過半数**の合意 | 特定行政庁の認可 |

- **一人協定**: 土地の所有者が1人しかいない区域（分譲予定地等）で、その1人が建築協定を定めて特定行政庁の認可を受けられる
  - 認可の日から**3年以内**に、区域内の土地の所有者等が**2以上**となった時から、通常の建築協定と同じ効力を生じる
