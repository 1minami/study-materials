# 土地区画整理法

> 毎年1問出題。仮換地・換地処分の効果と建築制限が問われる。

## 1. 土地区画整理事業の概要

### 目的

- 公共施設の整備改善及び宅地の利用の増進を図る
- 道路・公園等の公共施設を整備し、土地の区画を整理する
- 施行区域: 都市計画区域内の土地に限られる

### 施行者

| 施行者 | 概要 |
|--------|------|
| 個人施行者 | 宅地の所有者又は借地権者が1人又は数人で施行（規準・事業計画を定めて知事の認可） |
| 土地区画整理組合 | 宅地の所有者又は借地権者が**7人以上**で設立 |
| 区画整理会社 | 宅地の所有者又は借地権者を株主等とする会社 |
| 地方公共団体 | 都道府県又は市町村 |
| 国土交通大臣 | 国の利害に重大な関係がある場合 |
| 都市再生機構・地方住宅供給公社 | — |

- 民間施行（個人・組合・区画整理会社）は、都市計画で定められた施行区域**外**でも施行できる
- 公的施行（地方公共団体・国土交通大臣・機構等）は、都市計画事業として**施行区域内**でのみ施行

### 土地区画整理組合の設立

- 宅地の所有者又は借地権者**7人以上**が共同して、**定款**及び**事業計画**を定める
- 施行地区内の宅地の**所有者**の**2/3以上**、及び**借地権者**の**2/3以上**のそれぞれの同意
  - さらに、同意した者の宅地の地積と借地権の目的となっている宅地の地積の合計が、総地積の合計の**2/3以上**であること
- **都道府県知事**の**認可**が必要（認可で組合が成立し法人となる）
- 組合員: 施行地区内の宅地の所有者及び借地権者は、設立に同意しなかった者も含めて**全員当然に組合員**
  - ⚠ **未登記の借地権**は、市町村長に**申告**しなければ組合員として扱われない
- 組合は、事業に要する費用に充てるため、組合員に**賦課金**を課すことができる
- 施行地区内の宅地の所有権・借地権を承継した者も、組合員としての権利義務を承継する

## 2. 換地計画 ★

### 換地計画の決定・認可

- 施行者は、施行地区内の宅地について**換地計画**を定める
- 個人施行者・組合・区画整理会社・市町村・機構等 → 換地計画について**都道府県知事の認可**を受ける
- 地方公共団体等が施行する場合 → 換地計画を**2週間**公衆の縦覧に供し、利害関係者は**意見書**を提出できる

### 換地

- 従前の宅地に代えて、新たな宅地（換地）を定める
- **照応の原則**: 換地は従前の宅地の位置・地積・土質・水利・利用状況・環境等が照応するように定める
- 宅地の所有者の**申出又は同意**があれば、換地を定めないことができる（金銭で清算）
- **清算金**: 換地と従前の宅地の価値に不均衡がある場合に、金銭で清算

### 減歩

- 道路・公園等の公共施設用地を生み出すため、各宅地の面積を減少させる
- **公共減歩**: 公共施設用地の確保
- **保留地減歩**: 事業費に充てるための保留地の確保

### 保留地

- 換地として定めない土地
- 換地処分の公告の**翌日**に施行者が取得し、売却して事業費に充てる
- ⚠ 公的施行の場合、保留地を定められるのは、事業施行後の宅地価額の総額が施行前の総額を超える場合の**差額の範囲内**に限られる

## 3. 仮換地 ★★★

### 仮換地の指定

- 施行者は、換地処分を行う前に、工事のため又は換地処分を行うため必要がある場合、従前の宅地に代えて**仮換地**を指定できる
- 指定の手続き（あらかじめ得る同意・意見）:

| 施行者 | 必要な手続き |
|---|---|
| 個人施行者 | 従前の宅地・仮換地となるべき宅地の所有者等の**同意** |
| 組合 | **総会**（その部会・総代会）の**同意** |
| 区画整理会社 | 施行地区内の宅地の所有者・借地権者のそれぞれ2/3以上の同意 |
| 地方公共団体・国土交通大臣・機構等 | **土地区画整理審議会**の**意見**を聴く |

- 仮換地の指定は、仮換地となるべき土地の所有者及び従前の宅地の所有者に、仮換地の位置・地積・**効力発生の日**を**通知**して行う

### 仮換地の指定の効果

- 従前の宅地の所有者等は、仮換地の指定の**効力発生日**から**換地処分の公告の日**まで:
  - **仮換地**を、従前の宅地と同じ内容で**使用収益できる**
  - **従前の宅地**は**使用収益できなくなる**
- 仮換地に使用収益の障害となる物件がある等の特別の事情 → 施行者は**使用収益開始日**を効力発生日と**別に定める**ことができる
- 従前の宅地の所有権・抵当権等は**従前の宅地に存続**（仮換地に移転しない）
  - 従前の宅地を**売却**できる（売買・抵当権設定・登記は**従前の宅地**について行う）
  - 従前の宅地を買った者は、**仮換地**を使用収益できる

### 仮換地の所有権

- ⚠ 仮換地の**所有権**は、その土地の**元の所有者**（仮換地となった土地の従前の所有者）に残ったまま（施行者や仮換地の指定を受けた者に移るのではない）
- 仮換地の元の所有者は、仮換地の指定の効力発生日から換地処分の公告の日まで、その土地を**使用収益できない**
- 仮換地の指定により使用収益する者がいなくなった**従前の宅地**は、**施行者が管理**する

### 使用収益の停止

- 施行者は、仮換地を指定しないで、従前の宅地の使用収益を**停止**させることもできる（損失は補償）

## 4. 換地処分 ★★★

### 手続き

1. 換地計画に係る区域の**全部**について工事が**完了した後**、遅滞なく換地処分を行う
   - 規準・規約・定款・施行規程に別段の定めがあれば、工事完了**前**でも換地処分できる
2. 換地処分は、関係権利者に換地計画で定められた関係事項を**通知**して行う
3. 個人施行者・組合・区画整理会社・市町村・機構等 → 遅滞なく**都道府県知事に届出**
4. **換地処分の公告**
   - 国土交通大臣が施行 → **国土交通大臣**が公告
   - その他 → **都道府県知事**が公告

### 換地処分の効果 ★★

| 時期 | 効果 |
|---|---|
| 公告の日の**終了時** | 換地を定めなかった従前の宅地の権利が**消滅**／行使する利益がなくなった**地役権**が消滅／仮換地の指定の効力・建築行為等の制限が終了 |
| 公告の日の**翌日** | 換地が従前の宅地と**みなされる**（所有権・抵当権等が換地に移行）／**清算金**が確定／**保留地**を施行者が取得／公共施設の用に供する土地が**管理者**に帰属 |

- **地役権**は、換地処分の公告の翌日以後も**従前の宅地**の上に存続する（行使する利益がなくなったものは消滅）
- 公共施設は、換地処分の公告の翌日に、原則としてその所在する**市町村**の管理に属する

### 換地処分に伴う登記

- 施行者は、換地処分の公告があった場合、**直ちに**その旨を管轄**登記所に通知**
- 施行者は、遅滞なく、事業による変動に係る**登記**を**申請又は嘱託**する
- 換地処分の公告後、この登記がされるまでは、施行地区内の土地・建物について**他の登記をすることができない**
  - 例外: 登記の申請人が確定日付のある書類により、公告**前**に登記原因が生じたことを証明した場合

## 5. 建築等の制限 ★★

### 施行地区内の制限（76条）

- 事業の施行の障害となるおそれがある以下の行為 → **許可**が必要:
  - 土地の**形質の変更**
  - 建築物その他の工作物の**新築・改築・増築**
  - 政令で定める移動の容易でない物件（重量**5トン**超）の設置・堆積
- 許可権者:
  - 国土交通大臣が施行 → **国土交通大臣**
  - その他 → **都道府県知事**（市の区域内で個人施行者・組合・区画整理会社・市が施行する場合は**市長**）
  - ⚠ 施行者（組合等）の許可ではない。知事等は許可をしようとするときは**施行者の意見**を聴く
- 制限の期間:
  - 組合施行 → 組合の**設立認可の公告**の日後から
  - 個人施行・区画整理会社 → 施行の**認可の公告**の日後から
  - 地方公共団体・国土交通大臣 → **事業計画の決定の公告**の日後から
  - 終期 → **換地処分の公告**がある日まで
- 違反した者（又はその承継人） → 知事等は原状回復・建築物の移転・除却を**命ずる**ことができる

## 6. 費用の負担

- 施行者が負担
- 組合施行の場合: **賦課金**として組合員に賦課可能
- 公的施行で、施行後の宅地価額の総額が施行前より減少した場合 → 施行者は差額に相当する**減価補償金**を所有者等に交付

## 7. まとめ

| ポイント | 内容 |
|----------|------|
| 組合設立 | 7人以上 + 所有者・借地権者それぞれ2/3以上の同意 + 知事の認可 |
| 組合員 | 施行地区内の所有者・借地権者は全員当然に組合員 |
| 仮換地指定後 | 仮換地を使用収益、従前の宅地は使用収益不可（処分は従前の宅地で行う） |
| 仮換地の所有権 | 元の所有者に残る（使用収益できない） |
| 換地処分の時期 | 原則として全工事完了後 |
| 換地処分の効力発生 | **公告の翌日**（権利の消滅は公告の日の終了時） |
| 建築制限 | 事業計画公告等〜換地処分公告まで知事等の許可必要 |
| 登記 | 施行者が申請・嘱託。完了まで他の登記不可 |
