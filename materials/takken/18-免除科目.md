# 免除科目（5問免除）

> 問46〜50の5問。住宅金融支援機構、景品表示法、統計、土地・建物の知識。登録講習修了者は免除。

## 1. 住宅金融支援機構 ★★

### 機構の目的

- 一般の金融機関による住宅の建設等に必要な資金の融通を**支援**する（証券化支援が中心）
- 一般の金融機関による融通を補完するための**災害復興建築物**の建設等に必要な資金の貸付け

### 機構の業務

| 業務 | 内容 |
|------|------|
| 証券化支援業務（買取型）★ | 民間金融機関の住宅ローン債権を**買い取り**、それを担保とするMBS（資産担保証券）を発行して資金を調達 |
| 証券化支援業務（保証型） | 民間金融機関の住宅ローンについて住宅融資保険を引き受け、その住宅ローンを担保とするMBSについて期日どおりの元利払いを**保証** |
| 融資保険業務 | 民間金融機関の住宅ローンについて**住宅融資保険**を引き受ける |
| 直接融資業務 | 一般の金融機関による融通が困難な分野に限定（**限定的**） |
| 団体信用生命保険業務 | 機構の融資を受けた者が死亡等した場合に、保険金で債務を弁済 |
| 情報提供業務 | 住宅の建設等をしようとする者等に対する情報の提供、相談、援助 |

### 直接融資の対象（限定的）

- **災害復興**建築物・**災害予防**関連の住宅の建設・購入・補修
- 合理的土地利用建築物（市街地の土地の合理的な利用に寄与するもの）の建設
- **マンションの共用部分**の改良
- 子どもを育成する家庭・**高齢者**向けの賃貸住宅の建設・改良
- 高齢者の家庭に適した良好な居住性能・居住環境を有する住宅とするための改良（**高齢者向け返済特例**: 借入者本人の死亡時に一括して元金を償還する方法も可）

### 業務の委託

- 機構は、業務の一部（貸付けの審査・回収等）を**金融機関**・**債権回収会社**・**地方公共団体**等に委託できる

### フラット35（証券化支援業務・買取型）★★

| 項目 | 内容 |
|------|------|
| 金利 | **全期間固定金利**（金利は取扱金融機関ごとに異なる） |
| 融資対象 | 申込者本人又は親族が居住する住宅の**建設・購入**（**中古住宅**も可）、**借換え** |
| 床面積 | 戸建て: **70㎡以上** / マンション: **30㎡以上** |
| 融資限度額 | **8,000万円** |
| 融資割合 | 購入価額の**100%**以内 |
| 返済期間 | **15年以上35年以下**（60歳以上は10年以上） |
| 保証人 | **不要** |
| 保証料 | **不要** |
| 繰上返済手数料 | **不要** |

- 住宅の建設・購入に**付随する土地・借地権の取得**資金も対象
- 住宅の**改良**（リフォーム）資金のみは、原則として証券化支援業務の対象外
- 機構の技術基準に適合する住宅であることが必要（適合証明書）

### 機構が行わない業務

- 一般的な住宅建設・購入のための直接融資（これは民間金融機関が行う）

## 2. 景品表示法（不当景品類及び不当表示防止法）★★

### 景品類の制限

- 不動産業における景品類の提供の制限（公正競争規約）: 懸賞により提供する景品類 → 取引価額の**20倍**又は**10万円**のいずれか低い額、かつ懸賞に係る取引予定総額の**2%**以内
- 懸賞によらない景品類（総付景品） → 取引価額の**10分の1**又は**100万円**のいずれか低い額の範囲内

### 不動産の表示に関する公正競争規約

#### 広告開始時期の制限

- 未完成物件: **開発許可・建築確認後**でなければ広告不可（建築確認申請中である旨を表示しても不可）
- 宅建業法33条と同趣旨

#### 必要な表示事項

- 取引態様（売主、代理、媒介の別）
- 物件の所在地
- 交通の利便性（最寄り駅からの所要時間等）
- 価格（土地の価格、建物の価格）
- 面積
- 建築条件付き土地の場合は、建築条件の内容

#### 表示基準 ★

| 項目 | 基準 |
|------|------|
| 徒歩所要時間 | 道路距離**80m = 1分**（**1分未満の端数は切り上げ**） |
| 自転車の所要時間 | 道路距離を明示して、走行に通常要する時間を表示 |
| 電車等の所要時間 | **通勤時**（朝の通勤ラッシュ時）の所要時間を明示。乗換えを要するときはその旨を明示（乗換え・待ち時間を含む） |
| 新築 | 建築後**1年未満**かつ居住の用に供されたことが**ない**もの |
| 面積 | メートル法で表示。1畳 = **1.62㎡以上**（各室の壁心面積を畳数で除した数値） |
| 写真・動画 | 取引物件の写真を使用。建築工事完了前などで他の建物の写真を使う場合は、取引物件と外観が類似するものに限り、その旨を明示 |
| 価格 | **1区画・1戸あたり**の価格を表示（すべての価格を表示することが困難な場合は、最低価格・最高価格・最多価格帯とその戸数等） |
| 管理費・修繕積立金 | 1戸あたりの月額（すべてを表示できない場合は最低額と最高額） |

- 道路距離は、物件の区画のうち駅から最も近い地点（マンションは建物の出入口）を起点とする
- **私道負担**部分がある場合は、その旨と面積を表示
- 物件が**市街化調整区域**内の土地である場合は、「市街化調整区域。宅地の造成及び建物の建築はできません。」と明示
- 物件が**接道義務**を満たしていない場合は、「再建築不可」又は「建築不可」と明示

#### 特定用語の使用基準

- 「完全」「完璧」「絶対」「万全」、「日本一」「業界一」「超」「最高」「最高級」「特選」「厳選」、「格安」「堀出」「土地値」等 → **合理的な根拠**を示す資料がない限り使用できない
- 「新発売」: 新たに造成・建築された物件について、一般消費者に対し**初めて**購入の申込みの勧誘を行うこと（一定期間に限る）

#### 不当表示の禁止 ★

| 禁止事項 | 例 |
|----------|-----|
| おとり広告 | 実在しない物件、**売却済み**の物件、取引する意思のない物件の広告 |
| 不当な二重価格表示 | 過去の販売価格を比較対照価格とする場合、①公表日・値下げ日を明示、②値下げの**直前の価格**で、値下げ前**2か月以上**実際に販売のため公表していた価格、③値下げの日から**6か月以内**の表示、④物件の価値に同一性、を満たさなければ不当表示（2022年9月改正。旧: 3か月以上） |
| 不実表示 | 実際と異なる表示 |
| 有利誤認表示 | 実際よりも著しく有利であると誤認させる表示 |
| 優良誤認表示 | 実際よりも著しく優良であると誤認させる表示 |

- インターネット広告で、成約済みの物件を**削除せず掲載し続ける**ことも、おとり広告にあたる

### 措置命令・課徴金

- 不当表示 → **内閣総理大臣**（消費者庁長官に委任）・**都道府県知事**は、違反行為の差止め等の**措置命令**を出せる（違反行為が既になくなっている場合も可）
- 優良誤認表示・有利誤認表示 → **課徴金**納付命令の対象

## 4. 土地の知識 ★

### 地形と宅地としての適否

| 地形 | 宅地としての適否 |
|------|------------------|
| 台地・段丘 | **適する**（地盤が安定、水はけが良い。洪水・地震に対しても比較的安全） |
| 洪積台地 | **適する** |
| 丘陵地 | 概ね適する（造成次第。切土部は良好だが、盛土部は地盤沈下・崩壊に注意） |
| 扇状地 | やや注意（土石流の危険。谷の出口に位置する場合は特に注意） |
| 自然堤防 | 比較的適する（周囲より高く、砂質・砂礫質で地盤も比較的良好） |
| 三角州・後背湿地 | **不適**（地盤軟弱、浸水リスク、地震時の液状化） |
| 旧河道（旧河川跡） | **不適**（地盤軟弱、液状化リスク） |
| 埋立地 | 注意（液状化リスク。一般に干拓地より安全） |
| 干拓地 | **不適**（海面以下の場合あり。浸水のおそれ大） |
| 崖錐 | **不適**（崩壊リスク） |
| がけ地 | **不適** |

### 宅地選定の注意点

- **台地の縁辺部**: 集中豪雨時に崖崩れの危険
- **台地上の浅い谷**（谷底低地）: 豪雨時に**浸水**しやすく、地盤も軟弱なことが多い
- **谷の出口**（扇状地の扇頂部）: **土石流**の危険
- **地すべり地**: 地すべり地形（馬蹄形の滑落崖、等高線の乱れ）は再び地すべりを起こしやすい。棚田等に利用されていることが多い
- **断層**: 断層に沿って地盤の強度が弱く、崩壊・地すべりが起こりやすい
- **等高線**: 間隔が**密**な所は**急傾斜**、**疎**な所は緩傾斜。等高線が山頂から見て**張り出している**部分は**尾根**、**くい込んでいる**部分は**谷**
- 山地から平野に移り変わる所の**崖錐**・**扇状地**は、崩壊・土石流の危険

### 液状化

- **砂質**の緩い地盤 + **地下水位が高い** → 地震時に液状化しやすい
- 埋立地、旧河道、三角州、後背湿地、砂丘間の低地等でリスクが高い

## 5. 建物の知識 ★

### 建築構造

| 構造 | 特徴 |
|------|------|
| 木造 | 軽量、施工容易。防火性能に注意。**在来軸組工法**（柱・梁）、**枠組壁工法**（ツーバイフォー: 壁で支える） |
| 鉄骨造（S造） | 粘り強い（靱性大）。**火災に弱い**（耐火被覆が必要）。錆びやすい（防錆処理が必要） |
| 鉄筋コンクリート造（RC造） | 圧縮に強い（コンクリート）＋引張に強い（鉄筋）。**耐火性・耐久性**あり。自重が重い |
| 鉄骨鉄筋コンクリート造（SRC造） | RC造の中心に鉄骨。高層建築向き |
| 補強コンクリートブロック造 | ブロックの空洞部に鉄筋を入れてコンクリートを充填 |

### 木造の知識

- 木材は**乾燥**しているほど強度が大きい（含水率が小さいほど強い）
- 木材の強度は、繊維方向（縦方向）の方が直角方向より大きい
- **筋かい**・**耐力壁**を釣合いよく配置して、地震・風圧などの水平力に抵抗させる
- 土台は、基礎に**アンカーボルト**で緊結する
- 木造の外壁のうち、鉄網モルタル塗その他の軸組が腐りやすい構造である部分の下地には、防水紙等を使用

### 鉄筋コンクリート造の知識

- コンクリートは**アルカリ性**で鉄筋の錆を防ぐ。経年で**中性化**すると鉄筋が錆びやすくなる
- 鉄筋に対する**かぶり厚さ**を確保する（耐力壁以外の壁・床は2cm以上、耐力壁・柱・梁は3cm以上、基礎は6cm以上 等）
- コンクリートの引張強度は、圧縮強度の約1/10

### 建築材料

- コンクリート: 圧縮力に強く、引張力に弱い
- 鉄筋: 引張力に強い。錆びやすいためコンクリートで被覆（かぶり厚さ）
- 鉄骨: 粘り強いが、高温で強度低下（要耐火被覆）
- 鉄とコンクリートは、熱膨張率がほぼ**等しい**ため一体化できる

### 基礎

| 種類 | 用途 |
|------|------|
| 直接基礎（布基礎・ベタ基礎・独立基礎） | 良好な地盤。支持層が浅い場合 |
| 杭基礎 | 軟弱地盤。支持層が深い場合 |

- 同一の建築物で異なる構法の基礎を**併用**することは、原則として避ける（不同沈下のおそれ）

### 地震に対する構造

| 構造 | 内容 |
|---|---|
| **耐震**構造 | 建物の柱・梁・壁などを強くし、地震の揺れに**耐える** |
| **制震**（制振）構造 | ダンパー等の制震部材で地震の揺れを**吸収**する |
| **免震**構造 | 建物と基礎の間に積層ゴム等の免震装置を設置し、揺れを建物に**伝えにくく**する（既存建物の耐震改修にも利用可） |
