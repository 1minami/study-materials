# 区分所有法（建物の区分所有等に関する法律）

> 毎年1問出題。集会の決議要件（普通決議・特別決議・建替え決議）が最頻出。
> ⚠️ **2026年4月1日施行の大改正（令和7年法律第47号）**: 決議の**出席者ベース化**、建替え決議の**3/4緩和類型**、**所在等不明区分所有者の除外**、新決議類型・管理命令制度の新設。2026年度試験の最重要改正論点。

## 1. 区分所有建物の基本 ★

### 専有部分と共用部分

| 種類 | 内容 | 例 |
|------|------|-----|
| 専有部分 | 区分所有権の目的となる建物の部分 | 各住戸 |
| 法定共用部分 | 構造上共用に供される部分 | 廊下、階段、エレベーター |
| 規約共用部分 | 規約で共用部分とされた部分 | 集会室、管理人室 |

- 共用部分の持分割合: **専有部分の床面積の割合**による（規約で別段の定め可能）
- 共用部分の持分は専有部分の処分に従う（分離処分の禁止）

### 敷地利用権

- 専有部分と敷地利用権は**分離処分できない**（規約で別段の定め可能）

### 区分所有者の責務・国内管理人（2026改正で新設）

- **区分所有者の責務**（5条の2）: 区分所有者は、管理が適正かつ円滑に行われるよう**相互に協力**しなければならない
- **国内管理人**（6条の2）: 国内に住所・居所を有しない区分所有者は、国内に住所等を有する者から**管理人を選任できる**（保存行為、集会招集通知の受領、議決権行使等の権限）

## 2. 管理組合と管理者 ★

### 管理組合

- 区分所有者は当然に管理組合の構成員（全員で構成）
- 区分所有者が2人以上になれば当然に成立

### 管理者

- 集会の決議で選任・解任（**普通決議**）
- 管理者は区分所有者以外からも選任可能
- 管理者の権限: 共用部分の保存行為、集会の決議の実行、規約で定めた行為
- 管理者は少なくとも毎年**1回**集会を招集しなければならない

## 3. 集会 ★★★

### 招集

- 管理者が少なくとも毎年1回招集
- 区分所有者（議決権を有しない者を除く）の**1/5以上**で議決権の**1/5以上**を有する者は、管理者に集会の招集を請求できる（規約で減ずること可能）
- 招集通知: 会日より少なくとも**1週間前**に、会議の目的たる事項**及び議案の要領**を示して発する（2026改正: 議案の要領は全決議事項で必須に。期間は規約で**伸長のみ可**〔従来の「伸縮」から変更 — 短縮不可〕。建替え決議等は2ヶ月前）

### 決議要件 ★★★（2026改正: 出席者ベースへ変更）

普通決議・特別決議は「**出席した**区分所有者及びその議決権」ベースに変更。書面・電磁的方法・代理人による議決権行使も**出席扱い**。

| 事項 | 要件 |
|------|------|
| **普通決議** | **出席した**区分所有者及びその議決権の各**過半数** |
| **特別決議** | 区分所有者及び議決権の各過半数が出席し、**出席した**区分所有者及びその議決権の各**3/4以上** |
| **大規模滅失の復旧** | 区分所有者及び議決権の各過半数が出席し、出席した区分所有者及びその議決権の各**2/3以上**（改正前は全体の3/4） |
| **建替え決議** | （出席ベースではなく全体の）区分所有者及び議決権の各**4/5以上**。**耐震性不足等の場合は3/4以上に緩和** |

### 普通決議事項

- 共用部分の管理（保存行為は各自単独で可能）
- 管理者の選任・解任
- 共用部分の軽微変更

### 特別決議事項（出席者の3/4以上）

- 規約の設定・変更・廃止
- 共用部分の重大変更（形状又は効用の著しい変更を伴うもの）
  - 議決要件は規約で**1/2超まで引下げ可**（2026改正: 従来の「区分所有者の定数のみ過半数まで減」から変更）
  - **瑕疵の除去・バリアフリー化**に必要な変更は**2/3以上**に緩和（2026改正）
- 義務違反者に対する専有部分の使用禁止・競売請求
- 管理組合法人の設立・解散
- 管理組合法人による区分所有権等の取得（2026改正で新設）

### 所在等不明区分所有者の除外（2026改正で新設）★

- **裁判所の裁判**により、所在等不明の区分所有者を集会の決議から**除外**できる（38条の2）
- 除外された者は**議決権を有しない** → 決議の母数から外れる

### 共有の場合の議決権行使者

- 専有部分が数人の共有 → 共有者は**持分の価格の過半数**で議決権を行使すべき者1人を定める（2026改正で決定方法を明文化）

### 小規模滅失の復旧

- 建物の価格の**1/2以下**の滅失 → **各区分所有者が単独**で復旧可能
- 集会の決議でも可能（普通決議）

## 4. 規約 ★★

- 設定・変更・廃止: **特別決議**（過半数出席＋出席者の3/4以上）
- 一部の区分所有者の権利に特別の影響を及ぼすとき → その者の**承諾**が必要
- 最初に建物の専有部分の全部を所有する者（分譲業者等）は、公正証書により**単独で**規約を設定できる
- 規約の保管: 管理者（管理者がないときは規約で定める者）が保管
- 利害関係人の閲覧請求: 正当な理由がある場合を除き拒否不可（電磁的記録の規約は、承諾を得て**電磁的方法による提供**も可 — 2026改正）

## 5. 義務違反者への措置 ★

| 措置 | 決議要件 | 訴訟の要否 |
|------|----------|------------|
| 行為の停止等の請求 | **普通決議** or 訴訟外でも可 | 訴訟外も可能 |
| 使用禁止の請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |
| 競売の請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |
| 占有者への引渡請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |

## 6. 復旧と建替え等のまとめ

| 事由 | 要件 |
|------|------|
| 小規模滅失（1/2以下） | 各自単独 or 普通決議 |
| 大規模滅失（1/2超） | 過半数出席＋出席者の各**2/3以上**（2026改正） |
| 建替え | 区分所有者及び議決権の各**4/5以上**（緩和事由あれば**3/4以上**） |

### 建替え決議（4/5以上 → 緩和事由ありは3/4以上）★★

- 招集通知は会日の**2ヶ月前**までに発する（規約で伸長のみ可）
- 通知に加え、建替えに関する**説明会**を1ヶ月前までに開催
- 建替えに参加しない者に対して区分所有権の**売渡請求**が可能
- **3/4に緩和される客観的事由**（2026改正・62条2項）:
  1. 耐震性の不足
  2. 火災に対する安全性の不足
  3. 外壁等の剥落により周辺に危害を生ずるおそれ
  4. 給排水管等の配管設備の腐食・劣化（改修困難なもの）
  5. バリアフリー基準への不適合

### 新設された決議類型（2026改正）★

いずれも区分所有者及び議決権（敷地売却系は敷地利用権の持分価格も）の各**4/5以上**。建替え決議と同じ**3/4緩和**あり。

| 決議 | 内容 |
|------|------|
| 建物更新決議（64条の5） | 建物を取り壊さず主要構造部分の効用を維持・回復する大規模改修 |
| 建物敷地売却決議（64条の6） | 建物とその敷地をまとめて売却 |
| 建物取壊し敷地売却決議（64条の7） | 建物を取り壊して敷地を売却 |
| 取壊し決議（64条の8） | 建物の取壊しのみ |

## 7. 専有部分の管理に関する裁判所の命令（2026改正で新設）★

| 制度 | 内容 |
|------|------|
| 所有者不明専有部分管理命令（46条の2） | 区分所有者不明・所在不明の専有部分につき、裁判所が利害関係人の請求で**管理人**を選任 |
| 管理不全専有部分管理命令（46条の8） | 管理不適当で他人の権利を侵害するおそれのある専有部分につき管理人を選任 |
| 管理不全共用部分管理命令（46条の13） | 同上（共用部分版） |

- 民法の所有者不明土地・建物管理制度（2023年施行）の**区分所有建物版**（民法の同制度は専有部分・共用部分には適用されない）
