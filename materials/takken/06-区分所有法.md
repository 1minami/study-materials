# 区分所有法（建物の区分所有等に関する法律）

> 毎年1問出題。集会の決議要件（普通決議・特別決議・建替え決議）が最頻出。
> ⚠️ **2026年4月1日施行の大改正（令和7年法律第47号）**: 決議の**出席者ベース化**、建替え決議の**3/4緩和類型**、**所在等不明区分所有者の除外**、新決議類型・管理命令制度の新設。2026年度試験の最重要改正論点。

## 1. 区分所有建物の基本 ★

### 専有部分と共用部分

| 種類 | 内容 | 例 |
|------|------|-----|
| 専有部分 | 区分所有権の目的となる建物の部分 | 各住戸 |
| 法定共用部分 | 構造上共用に供される部分 | 廊下、階段、エレベーター |
| 規約共用部分 | 規約で共用部分とされた部分 | 集会室、管理人室 |

- 共用部分の持分割合: **専有部分の床面積の割合**による（規約で別段の定め可能）
  - 床面積は、壁その他の区画の**内側線**で囲まれた部分の水平投影面積（**内法**面積）
- 共用部分の持分は専有部分の処分に従う（共用部分の持分だけを分離して処分できない）
- 共用部分は区分所有者**全員の共有**（一部共用部分は、これを共用すべき区分所有者の共有）
  - 規約で別段の定め可能。ただし**管理者**以外の区分所有者でない者を共用部分の所有者と定めることはできない
- **法定共用部分**は、登記なくして第三者に対抗できる（民法177条の適用なし。そもそも登記できない）
- **規約共用部分**は、**共用部分である旨の登記**をしなければ第三者に対抗できない

### 敷地利用権

- 専有部分と敷地利用権は**分離処分できない**（規約で別段の定め可能）
- 分離処分禁止に違反する処分は無効。ただし、**善意の相手方**には無効を主張できない（分離処分禁止の旨の登記＝敷地権の登記がされた後は主張できる）
- 各区分所有者の敷地利用権の割合は、原則として**専有部分の床面積の割合**による（規約で別段の定め可能）

### 先取特権・特定承継人の責任

- 区分所有者は、共用部分等について他の区分所有者に対して有する債権（**管理費**・**修繕積立金**等）、規約・集会の決議に基づく債権について、債務者の**区分所有権**（共用部分の持分・敷地利用権を含む）及び建物に備え付けた**動産**の上に**先取特権**を有する（管理者・管理組合法人の債権も同様）
- これらの債権は、債務者たる区分所有者の**特定承継人**（中古マンションの買主・競売の買受人等）に対しても請求できる
  - ⚠ 滞納管理費は買主にも請求できる（前の所有者も債務を免れない）

### 区分所有者の責務・国内管理人（2026改正で新設）

- **区分所有者の責務**（5条の2）: 区分所有者は、管理が適正かつ円滑に行われるよう**相互に協力**しなければならない
- **国内管理人**（6条の2）: 国内に住所・居所を有しない区分所有者は、国内に住所等を有する者から**管理人を選任できる**（保存行為、集会招集通知の受領、議決権行使等の権限）

## 2. 管理組合と管理者 ★

### 管理組合

- 区分所有者は当然に管理組合の構成員（全員で構成）
- 区分所有者が2人以上になれば当然に成立

### 管理者

- 集会の決議で選任・解任（**普通決議**）
- 管理者は区分所有者以外からも選任可能
- 管理者の権限: 共用部分の保存行為、集会の決議の実行、規約で定めた行為
- 管理者は少なくとも毎年**1回**集会を招集しなければならない
- 管理者は、集会において、毎年1回一定の時期に、その事務に関する**報告**をしなければならない
- 管理者に不正な行為その他職務を行うに適しない事情 → **各区分所有者**が裁判所に**解任を請求**できる
- 管理者の**代理権に加えた制限**は、**善意の第三者**に対抗できない
- 管理者は、規約又は集会の決議により、その職務に関し区分所有者のために**原告又は被告**となることができる（規約による場合は遅滞なく区分所有者に通知）
- 管理者は、職務に関し区分所有者を**代理**する（共用部分の損害保険金・損害賠償金の請求・受領を含む）

### 管理組合法人

- 設立: **特別決議**（過半数出席＋出席者の3/4以上）で法人となる旨・名称・事務所を定め、主たる事務所の所在地で**登記**をすることで成立
- **理事**・**監事**を必ず置く（監事は理事・使用人と兼任不可）
  - 理事の任期: **2年**（規約で**3年以内**の別段の期間を定められる）
  - 理事が数人 → 各自が法人を**代表**（規約・集会の決議で代表理事等を定めることも可）
- 管理組合法人が成立すると、**管理者**に関する規定は適用されない（理事が代わりに職務を行う）
- 管理組合法人の財産で債務を完済できない → 区分所有者は共用部分の持分割合に応じて弁済の責任を負う

## 3. 集会 ★★★

### 招集

- 管理者が少なくとも毎年1回招集
- 区分所有者（議決権を有しない者を除く）の**1/5以上**で議決権の**1/5以上**を有する者は、会議の目的たる事項を示して、管理者に集会の招集を請求できる（規約で減ずること可能）
  - 請求から**2週間以内**に、請求の日から**4週間以内**の日を会日とする招集通知が発せられなかった → 請求した区分所有者が**自ら招集**できる
- **管理者がない**とき → 区分所有者の1/5以上で議決権の1/5以上を有する者が集会を招集できる（規約で減ずること可能）
- 区分所有者**全員の同意**があれば、**招集手続を省略**して集会を開ける
- 招集通知: 会日より少なくとも**1週間前**に、会議の目的たる事項**及び議案の要領**を示して発する（2026改正: 議案の要領は全決議事項で必須に。期間は規約で**伸長のみ可**〔従来の「伸縮」から変更 — 短縮不可〕。建替え決議等は2ヶ月前）

### 決議要件 ★★★（2026改正: 出席者ベースへ変更）

普通決議・特別決議は「**出席した**区分所有者及びその議決権」ベースに変更。書面・電磁的方法・代理人による議決権行使も**出席扱い**。

| 事項 | 要件 |
|------|------|
| **普通決議** | **出席した**区分所有者及びその議決権の各**過半数** |
| **特別決議** | 区分所有者及び議決権の各過半数が出席し、**出席した**区分所有者及びその議決権の各**3/4以上** |
| **大規模滅失の復旧** | 区分所有者及び議決権の各過半数が出席し、出席した区分所有者及びその議決権の各**2/3以上**（改正前は全体の3/4） |
| **建替え決議** | （出席ベースではなく全体の）区分所有者及び議決権の各**4/5以上**。**耐震性不足等の場合は3/4以上に緩和** |

### 招集通知の宛先

- 専有部分が共有 → **議決権を行使すべき者**（定められていなければ共有者の1人）に通知すれば足りる
- 区分所有者が通知を受けるべき場所を管理者に通知した → その場所に、通知していない → **専有部分の所在場所**に宛てて発すれば足りる
- 建物内に住所を有する区分所有者・通知場所を通知しない区分所有者に対しては、**規約**に定めがあれば、建物内の見やすい場所に**掲示**して通知できる

### 議決権の行使

- 議決権の割合: 規約に別段の定めがない限り、**共用部分の持分割合**（専有部分の床面積の割合）
- 議決権は、**書面**又は**代理人**によっても行使できる（規約又は集会の決議で**電磁的方法**も可）→ いずれも**出席**として数える
- **書面又は電磁的方法による決議**: 区分所有者**全員の承諾**があれば、集会を開かずに書面等で決議できる（全員の書面等による**合意**があれば決議があったものとみなす）
- **占有者**（賃借人等）は、会議の目的たる事項につき**利害関係**を有する場合、集会に出席して**意見を述べる**ことができる（⚠ **議決権はない**）
  - 招集者は、招集通知を発した後遅滞なく、集会の日時・場所・目的事項・議案の要領を建物内の見やすい場所に**掲示**

### 議事録・決議の効力

- 議長は、書面又は電磁的記録で**議事録**を作成。書面の場合は、**議長**及び集会に出席した**区分所有者2人**が署名
- 議事録は規約と同様に保管し、利害関係人の閲覧に供する
- 規約及び集会の決議は、区分所有者の**特定承継人**（買主等）に対しても効力を生ずる
- **占有者**も、建物・敷地・附属施設の**使用方法**について、区分所有者が規約・集会の決議に基づいて負う義務と同一の義務を負う

### 普通決議事項

- 共用部分の管理（**保存行為**は各区分所有者が**単独**で可能）
- 管理者の選任・解任
- 共用部分の軽微変更（形状又は効用の**著しい変更を伴わない**もの）
- 共用部分についての**損害保険契約**の締結（管理に関する事項とみなされる）
- 小規模滅失の復旧
- ⚠ 普通決議事項は、規約で別段の定め（理事会決議で足りる等）が可能

### 特別決議事項（出席者の3/4以上）

- 規約の設定・変更・廃止
- 共用部分の重大変更（形状又は効用の著しい変更を伴うもの）
  - 議決要件は規約で**1/2超まで引下げ可**（2026改正: 従来の「区分所有者の定数のみ過半数まで減」から変更）
  - **瑕疵の除去・バリアフリー化**に必要な変更は**2/3以上**に緩和（2026改正）
- 義務違反者に対する専有部分の使用禁止・競売請求
- 管理組合法人の設立・解散
- 管理組合法人による区分所有権等の取得（2026改正で新設）

### 所在等不明区分所有者の除外（2026改正で新設）★

- **裁判所の裁判**により、所在等不明の区分所有者を集会の決議から**除外**できる（38条の2）
- 除外された者は**議決権を有しない** → 決議の母数から外れる

### 共有の場合の議決権行使者

- 専有部分が数人の共有 → 共有者は**持分の価格の過半数**で議決権を行使すべき者1人を定める（2026改正で決定方法を明文化）

### 小規模滅失の復旧

- 建物の価格の**1/2以下**の滅失 → **各区分所有者が単独**で復旧可能
- 集会の決議でも可能（普通決議）

## 4. 規約 ★★

- 設定・変更・廃止: **特別決議**（過半数出席＋出席者の3/4以上）
- 一部の区分所有者の権利に特別の影響を及ぼすとき → その者の**承諾**が必要
- 最初に建物の専有部分の全部を所有する者（分譲業者等）は、公正証書により**単独で**規約を設定できる
- 規約は**書面**又は**電磁的記録**で作成しなければならない
- 規約は、専有部分・共用部分等の形状・面積・位置関係・使用目的・利用状況・対価等を総合的に考慮して、区分所有者間の**利害の衡平**が図られるように定める
- 一部共用部分に関する事項で区分所有者全員の利害に関係しないもの → 一部区分所有者の規約で定められる（全員の規約で定める場合、一部共用部分を共用すべき区分所有者の**1/4超**又は議決権の1/4超が反対したときは設定・変更できない）
- 規約の保管: **管理者**（管理者がないときは、建物を使用している区分所有者又はその代理人で規約又は集会の決議で定める者）が保管
- 規約の**保管場所**は、建物内の見やすい場所に**掲示**しなければならない
- 利害関係人の閲覧請求: 正当な理由がある場合を除き拒否不可（電磁的記録の規約は、承諾を得て**電磁的方法による提供**も可 — 2026改正）

## 5. 義務違反者への措置 ★

| 措置 | 決議要件 | 訴訟の要否 |
|------|----------|------------|
| 行為の停止等の請求 | **普通決議** or 訴訟外でも可 | 訴訟外も可能 |
| 使用禁止の請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |
| 競売の請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |
| 占有者への引渡請求 | **特別決議**（出席者の3/4以上） | **訴訟による** |

- 行為の停止等の請求以外の措置（使用禁止・競売・引渡請求）の決議をするには、あらかじめ、その区分所有者（占有者）に**弁明する機会**を与えなければならない
- 使用禁止の期間は「相当の期間」。競売請求は、使用禁止等では共同生活の維持を図ることが困難な場合に限られる

## 6. 復旧と建替え等のまとめ

| 事由 | 要件 |
|------|------|
| 小規模滅失（1/2以下） | 各自単独 or 普通決議 |
| 大規模滅失（1/2超） | 過半数出席＋出席者の各**2/3以上**（2026改正） |

- 小規模滅失で共用部分を単独で復旧した区分所有者は、他の区分所有者に復旧費用を持分割合に応じて**償還請求**できる（ただし復旧工事着手前に復旧決議等があった場合は単独復旧不可）
- 大規模滅失の復旧決議があった場合: 決議の日から**2週間**を経過したとき、決議に**賛成しなかった**区分所有者は、決議賛成者に対し、建物・敷地に関する権利を**時価で買い取る**よう請求できる
- 大規模滅失の日から**6か月以内**に復旧決議・建替え決議等がない → 各区分所有者は、他の区分所有者に対し、建物・敷地に関する権利の**買取りを請求**できる
| 建替え | 区分所有者及び議決権の各**4/5以上**（緩和事由あれば**3/4以上**） |

### 建替え決議（4/5以上 → 緩和事由ありは3/4以上）★★

- 招集通知は会日の**2ヶ月前**までに発する（規約で伸長のみ可）
- 通知に加え、建替えに関する**説明会**を1ヶ月前までに開催
- 建替えに参加しない者に対して区分所有権の**売渡請求**が可能
- **3/4に緩和される客観的事由**（2026改正・62条2項）:
  1. 耐震性の不足
  2. 火災に対する安全性の不足
  3. 外壁等の剥落により周辺に危害を生ずるおそれ
  4. 給排水管等の配管設備の腐食・劣化（改修困難なもの）
  5. バリアフリー基準への不適合

### 新設された決議類型（2026改正）★

いずれも区分所有者及び議決権（敷地売却系は敷地利用権の持分価格も）の各**4/5以上**。建替え決議と同じ**3/4緩和**あり。

| 決議 | 内容 |
|------|------|
| 建物更新決議（64条の5） | 建物を取り壊さず主要構造部分の効用を維持・回復する大規模改修 |
| 建物敷地売却決議（64条の6） | 建物とその敷地をまとめて売却 |
| 建物取壊し敷地売却決議（64条の7） | 建物を取り壊して敷地を売却 |
| 取壊し決議（64条の8） | 建物の取壊しのみ |

## 7. 専有部分の管理に関する裁判所の命令（2026改正で新設）★

| 制度 | 内容 |
|------|------|
| 所有者不明専有部分管理命令（46条の2） | 区分所有者不明・所在不明の専有部分につき、裁判所が利害関係人の請求で**管理人**を選任 |
| 管理不全専有部分管理命令（46条の8） | 管理不適当で他人の権利を侵害するおそれのある専有部分につき管理人を選任 |
| 管理不全共用部分管理命令（46条の13） | 同上（共用部分版） |

- 民法の所有者不明土地・建物管理制度（2023年施行）の**区分所有建物版**（民法の同制度は専有部分・共用部分には適用されない）
