# 民法債権

> 債務不履行、契約不適合責任、賃貸借、連帯債務・保証は頻出。

## 1. 債務不履行 ★★★

### 類型

| 類型 | 内容 |
|------|------|
| 履行遅滞 | 履行期に履行しない |
| 履行不能 | 履行ができなくなった（契約締結前から不能＝原始的不能でも損害賠償請求は可能） |

### 履行遅滞となる時期

| 債務の種類 | 遅滞となる時期 |
|---|---|
| **確定期限**のある債務 | 期限が**到来した時** |
| **不確定期限**のある債務 | 期限の到来後に履行の**請求を受けた時**、又は期限の到来を**知った時**のいずれか早い時 |
| 期限の定めのない債務 | 履行の**請求を受けた時** |
| **不法行為**による損害賠償債務 | **不法行為の時**（請求不要） |

### 損害賠償

- **要件**: 債務不履行 + 債務者の帰責事由（契約その他の債務の発生原因及び取引上の社会通念に照らして判断）
  - 債務者が「自分に帰責事由がない」ことを証明しなければ責任を免れない
  - 履行遅滞中に当事者双方の帰責事由なく履行不能 → 債務者の帰責事由によるものとみなす
- 損害賠償の範囲: **通常生ずべき損害** + 当事者が**予見すべきであった特別損害**（416条）
- 過失相殺: 債権者にも過失があれば、裁判所は損害賠償の責任・額を定めるにあたり**必ず考慮しなければならない**（418条。責任を否定することも可）
- **損害賠償額の予定**: 当事者は債務不履行の損害賠償額を予定できる（予定しても履行請求・解除は可能。著しく過大な予定は公序良俗違反として一部無効となりうる）。違約金は賠償額の予定と推定
- **金銭債務の特則**:
  - **不可抗力**をもって抗弁にできない（無過失でも責任を負う）
  - 債権者は**損害の証明**をする必要がない
  - 損害賠償額は**法定利率**（年**3%**。3年ごとに見直し）による（約定利率がこれを超えるときは約定利率）

### 同時履行の抗弁権（533条）

- 双務契約の当事者は、相手方が債務の履行を提供するまで、自己の債務の履行を拒める
- 同時履行の関係にあるもの:
  - 売買の代金支払いと目的物の引渡し・登記
  - 契約解除による双方の**原状回復義務**
  - 弁済と**受取証書**（領収書）の交付
  - 請負の報酬支払いと目的物の引渡し
- 同時履行の関係に**ない**もの（一方が先履行）:
  - 建物明渡しと**敷金返還**（明渡しが先）
  - 弁済と**債権証書**の返還（弁済が先）
  - 被担保債務の弁済と**抵当権抹消登記**（弁済が先）

### 契約の解除 ★★

- **催告解除**（541条）: 相当の期間を定めて履行を催告 → 期間内に履行なし → 解除
  - 期間経過時の不履行が契約・取引上の社会通念に照らして**軽微**なときは解除不可
  - 催告期間が不相当に短くても、客観的に相当な期間が経過すれば解除できる（判例）
- **無催告解除**（542条）: 履行の**全部不能**、債務者が履行を**明確に拒絶**、**定期行為**（特定の日時に履行しなければ目的を達しない）の履行遅滞 等
- **解除に債務者の帰責事由は不要**（2020年改正の重要ポイント）
- **債権者**に帰責事由がある場合は解除不可
- 解除は相手方に対する**意思表示**で行い、撤回できない
- 当事者の一方が数人ある場合、解除は**全員から又は全員に対して**しなければならない（解除権の不可分性）
- **解除の効果**:
  - 各当事者は**原状回復義務**を負う（金銭を返還するときは受領の時からの**利息**、物を返還するときは**果実**も返還）
  - 解除前に利害関係を有するに至った**第三者の権利を害せない**（第三者は登記等の対抗要件が必要）
  - 解除しても損害賠償請求は可能

## 2. 危険負担（536条）

- 当事者双方の帰責事由によらず債務が履行不能 → 債権者は反対給付の**履行を拒絶できる**（例: 売買契約後、引渡し前に建物が地震で滅失 → 買主は代金の支払いを拒める）
- 債権者は、履行拒絶に加えて契約を**解除**して代金債務を消滅させることもできる
- 2020年改正: 旧534条の債権者主義（特定物は買主が危険を負担）は廃止
- **債権者**の帰責事由で履行不能 → 債権者は反対給付の履行を**拒めない**
- **引渡し後**の滅失・損傷（当事者双方の帰責事由なし）→ 買主は追完請求・代金減額・損害賠償・解除が**できず**、代金の支払いも**拒めない**（危険は引渡しで買主に移転）
  - 売主が履行を提供したのに買主が受領を拒んだ後の滅失・損傷も同様

## 3. 売買 ★★

### 契約不適合責任（562条〜572条）★★★

2020年改正で「瑕疵担保責任」から「契約不適合責任」に変更。引き渡された目的物が**種類・品質・数量**に関して、又は移転した**権利**が契約の内容に適合しない場合の売主の責任。

#### 買主の権利

| 権利 | 要件・内容 |
|------|------|
| **追完請求**（562条） | 目的物の**修補**、**代替物**の引渡し、**不足分**の引渡しを請求。方法は買主が選択（売主は買主に不相当な負担を課さなければ別の方法で追完可） |
| **代金減額請求**（563条） | 相当の期間を定めて追完を**催告**し、期間内に追完なし → 不適合の程度に応じて減額（追完不能・明確な追完拒絶等は**無催告**で可） |
| **損害賠償請求**（564条・415条） | 売主の**帰責事由**が必要 |
| **契約解除**（564条・541条・542条） | 売主の帰責事由**不要**（不適合が軽微なら催告解除不可） |

- 不適合が**買主の帰責事由**によるとき → 追完請求・代金減額請求・解除は**できない**
- 買主が契約時に不適合を**知っていた**場合でも、それが契約の内容に含まれていなければ責任追及できる（「契約の内容」で判断）

#### 期間制限

- **種類・品質**の不適合: 買主が不適合を**知った時から1年以内**にその旨を売主に**通知**しなければ、権利を失う
  - 通知で足り、1年以内に請求・訴訟提起まで必要ない
  - 売主が引渡し時に不適合を**知り、又は重過失で知らなかった**ときは期間制限なし
- **数量**・**権利**の不適合: 1年の通知期間制限はない（消滅時効の一般原則による）
- 通知をしても、消滅時効（知った時から5年・引渡しから10年）にかかる

#### 担保責任を負わない旨の特約

- 特約自体は有効
- ⚠ 売主が**知りながら告げなかった事実**、売主が自ら第三者のために設定・譲渡した権利については、責任を免れない
- 宅建業者が自ら売主・買主が業者でない場合は、宅建業法40条の制限あり（引渡しから2年以上の通知期間とする特約のみ有効）

#### 他人物売買

- 他人の物の売買契約も**有効**。売主は権利を取得して買主に移転する義務を負う
- 移転できない → 買主は債務不履行の一般原則により解除・損害賠償請求ができる

### 手付（557条）★★

- 特約がなければ**解約手付**と推定
- 買主: 手付を**放棄**して解除
- 売主: 手付の**倍額を現実に提供**して解除（口頭の提供・通知だけでは不可）
- **相手方**が契約の**履行に着手**するまでに限る
  - ⚠ **自分**が履行に着手していても、相手方が未着手なら解除できる
- 履行の着手: 客観的に外部から認識できる形で履行行為の一部をし、又は履行の提供のために欠くことのできない前提行為をした場合（中間金の支払い、登記申請等）
- 手付解除の場合、**損害賠償請求はできない**（手付の額で清算済み）
- 手付は解約手付であると同時に違約手付とすることもできる

## 4. 賃貸借 ★★★

### 存続期間

- 最長**50年**（604条。50年より長い期間を定めても50年に短縮）
- 最短の制限なし
- ⚠ 建物所有目的の土地賃貸借・建物賃貸借は借地借家法が優先（借地借家法の章を参照）

### 賃貸人の義務

- 目的物の使用収益をさせる義務
- **修繕義務**（606条）: 賃貸人が修繕義務を負う。賃借人の帰責事由による修繕は負わない
- 賃貸人が保存行為をしようとするとき、賃借人は拒めない
- **賃借人が自ら修繕できる場合**（607条の2）:
  - 賃借人が修繕が必要である旨を**通知**し（又は賃貸人が知り）、賃貸人が**相当の期間内**に修繕しないとき
  - **急迫の事情**があるとき

### 費用償還請求

| 費用 | 内容 | 請求時期 |
|---|---|---|
| **必要費**（雨漏りの修理等） | 賃借人が支出した額 | **直ちに**請求できる |
| **有益費**（改良費） | 賃貸借**終了時**に、支出額又は増価額のうち**賃貸人が選択**した額（価格の増加が現存する場合） | 賃貸借**終了時** |

- 費用償還請求は、賃貸人が目的物の返還を受けた時から**1年以内**に請求

### 賃借人の義務

- 賃料支払義務（特約がなければ**後払い**: 建物・宅地は毎月末）
- 善管注意義務、用法遵守義務
- **原状回復義務**（621条）: 受け取った後に生じた損傷を原状に復する。ただし**通常損耗・経年変化**、賃借人の帰責事由によらない損傷は除く（2020年改正で明文化）
- 賃借物の一部が賃借人の帰責事由によらず滅失等で使用収益できなくなった → 賃料はその割合に応じて**当然に減額**

### 賃借権の譲渡・転貸（612条）★★

- 賃貸人の**承諾**が必要
- 無断譲渡・転貸 → 賃貸人は解除可能
  - ただし、**背信的行為と認めるに足りない特段の事情**がある場合は解除不可（判例）
- **適法な転貸**の効果:
  - 転借人は、賃貸人に対して、原賃貸借の賃借人の債務の範囲を限度として**直接**義務を負う（賃貸人は転借人に直接賃料を請求できる）
  - 転借人は、賃料の**前払い**をもって賃貸人に対抗できない
- 原賃貸借の終了と転借人:

| 終了原因 | 転借人に対抗できるか |
|---|---|
| **合意解除** | 対抗**できない**（ただし解除の当時、賃借人の債務不履行による解除権を有していたときは対抗可） |
| 賃借人の**債務不履行**による解除 | 対抗**できる**（転借人に賃料支払いの機会を与える必要もない・判例） |
| 期間満了 | 建物賃貸借では、賃貸人は転借人に通知しなければ対抗できない（通知から6か月で終了・借地借家法） |

### 賃借権の対抗力・賃貸人の地位の移転

- 不動産の賃貸借は、**登記**をしたときは、その後に物権を取得した者に対抗できる（借地借家法では、建物の**引渡し**・借地上の建物の**登記**でも対抗可）
- 対抗要件を備えた賃借人がいる不動産が譲渡された → 賃貸人の地位は**当然に**新所有者に移転（605条の2。賃借人の承諾不要）
  - 新所有者が賃借人に賃料を請求するには、**所有権移転登記**が必要
  - **敷金返還義務**・**費用償還義務**も新所有者に承継
- 譲渡人と譲受人の合意で、賃貸人の地位を譲渡人に**留保**することもできる（譲受人が譲渡人に賃貸する場合）
- 対抗要件を備えた不動産賃借人は、占有を妨害する第三者に**妨害停止**・**返還**を請求できる
- **契約上の地位の移転**（539条の2）: 原則は譲渡人・譲受人の合意＋**相手方の承諾**が必要（例: 売主の地位の譲渡には**買主の承諾**が必要）
  - ⚠ 不動産の賃貸人の地位を**所有権とともに**譲渡する場合は、**賃借人の承諾不要**（605条の3）

### 賃貸借の解除・売買との比較

- 賃貸借の解除は**将来に向かってのみ**効力を生じる（620条。遡及しない）→ 契約時に遡る売買の解除とは違う
- **他人物**（他人所有の物）でも、売買・賃貸借とも契約は**有効**に成立する
- 売買の規定は有償契約に準用される（559条）→ 賃貸借の目的物が契約内容に適合しないとき、賃借人も**修補等の追完請求**ができる

### 敷金（622条の2）

- 賃料債務その他賃貸借に基づく債務を担保する目的で、賃借人が賃貸人に交付する金銭
- 返還義務の発生時期:
  - 賃貸借が終了し、かつ目的物が**返還された時**（明渡しが**先**。明渡しと敷金返還は同時履行の関係に**ない**）
  - 賃借人が適法に賃借権を**譲渡**した時
- 返還額: 敷金の額から、賃料不払い等の賃借人の債務額を**差し引いた残額**
- 充当: 賃貸人は敷金を未払賃料に**充当できる**。⚠ 賃借人から「敷金を未払賃料に充当してくれ」と請求することは**できない**
- 賃借権が譲渡された場合、敷金は**旧賃借人**に返還される（新賃借人に承継されない）
- 賃貸人が変わった場合、敷金は新賃貸人に**承継**される

## 5. 連帯債務 ★★

### 基本

- 各連帯債務者は全額について履行義務を負う
- 債権者はどの連帯債務者に対しても、同時に又は順次に、全部又は一部の請求可能
- 連帯債務者の一人について無効・取消しの原因があっても、他の連帯債務者の債務は影響を受けない

### 絶対的効力事由（他の連帯債務者にも効力が及ぶ）

| 事由 | 内容 |
|------|------|
| **弁済** | 全員の債務が消滅 |
| **更改** | 債務者の一人と更改 → 債権は全員の利益のために消滅 |
| **相殺** | 債務者の一人が相殺 → 全員の利益のために消滅 |
| **混同** | 債務者の一人と債権者の間で混同 → 弁済したものとみなす |

- 2020年改正で**請求・免除・時効の完成**は**相対的効力**に変更（原則。債権者と他の連帯債務者が別段の意思を表示すれば絶対的効力にすることは可能）
  - 例: 債権者がAに請求しても、Bの時効の完成は猶予されない
- 反対債権を有する連帯債務者が相殺しない間は、他の連帯債務者は、その連帯債務者の**負担部分の限度**で履行を**拒める**（相殺の援用はできない）

### 求償

- 弁済した連帯債務者は、他の連帯債務者に対して各自の**負担部分**について求償可能
  - ⚠ 自己の負担部分を**超えなくても**、弁済額に応じて求償できる
- 事前・事後の通知を怠ると、求償が制限される場合がある

## 6. 保証 ★★

### 保証契約の成立

- 保証契約は**債権者と保証人**の間の契約（主たる債務者の委託や同意は不要。主たる債務者の意思に反しても可）
- **書面**（又は電磁的記録）でしなければ効力を生じない
- 保証人の要件: 主たる債務者が保証人を立てる義務を負う場合は、行為能力者で弁済の資力を有する者

### 保証債務の性質

- **付従性**: 主たる債務がなければ保証債務もない／主たる債務より重くならない／主たる債務者に生じた事由（時効の完成猶予・更新、債務の減縮等）は保証人に**も**及ぶ
- **随伴性**: 主たる債務が移転すれば保証債務も移転
- **補充性**: 催告の抗弁権・検索の抗弁権（連帯保証にはない）
- 保証人は、主たる債務者が有する**相殺権・取消権・解除権**がある場合、その行使により主たる債務者が免れる限度で履行を**拒める**
- 保証人は、主たる債務の**消滅時効を援用**できる
- 保証人に生じた事由は、原則として主たる債務者に及ばない（弁済等を除く）
  - 例: 保証人が債務を承認しても、主たる債務の時効は更新されない

### 催告の抗弁権・検索の抗弁権

| 抗弁権 | 内容 | 連帯保証人 |
|---|---|---|
| **催告の抗弁権** | 債権者から請求を受けたとき、まず主たる債務者に催告せよと主張できる | **なし** |
| **検索の抗弁権** | 主たる債務者に弁済の資力があり、執行が容易であることを証明して、まず主たる債務者の財産に執行せよと主張できる | **なし** |

### 連帯保証 ★★

- **催告の抗弁権なし**・**検索の抗弁権なし**
- **分別の利益なし**（保証人が複数いても、各連帯保証人が全額の責任を負う。通常の保証人は頭数で分割された額のみ負担）
- 連帯保証人に対する**請求**は、主たる債務者に対して効力を生じない（2020年改正）
- 連帯保証人について生じた**更改・相殺・混同**は、主たる債務者にも効力が及ぶ

### 保証人の求償

- 委託を受けた保証人が弁済 → 主たる債務者に、支出額・弁済日以後の法定利息・費用等を求償できる
- 委託を受けた保証人は、一定の場合（主たる債務者の破産、弁済期到来等）に**事前求償**できる

### 個人根保証契約（465条の2〜）

- 一定の範囲に属する不特定の債務を主たる債務とする保証契約で、保証人が**個人**のもの
- **極度額の定めが必要**（書面に定めのない個人根保証契約は**無効**）
- 元本確定事由: 債権者が**保証人**の財産について強制執行・担保権の実行を申し立てた、**保証人**が破産手続開始の決定を受けた、**主たる債務者又は保証人**が死亡した
- 賃借人の債務を保証する個人の根保証も、**極度額**を定めなければ無効

### 保証人保護の規定

- **事業用融資の個人保証**: 契約締結前**1か月以内**に作成された**公正証書**で、保証人が保証債務を履行する意思を表示しなければ無効（465条の6）
  - 主たる債務者が法人である場合の**理事・取締役**、議決権の過半数を有する者、主たる債務者が個人である場合の**共同事業者**等は例外
- **情報提供義務**:

| 義務者 | 場面 | 内容 |
|---|---|---|
| **主たる債務者** | **事業**のために負担する債務の保証を**個人**に**委託**するとき | 財産・収支の状況、他の債務の有無、担保の内容等を情報提供（怠ると、債権者が知り又は知ることができた場合、保証人は保証契約を取り消せる） |
| **債権者** | 委託を受けた保証人から**請求**があったとき | 主たる債務の元本・利息等の不履行の有無、残額、弁済期到来額を遅滞なく提供（法人の保証人にも適用） |
| **債権者** | 主たる債務者が**期限の利益を喪失**したとき | 喪失を知った時から**2か月以内**に**個人**の保証人に通知（怠ると、その間の遅延損害金を請求できない） |

## 7. 弁済

- **第三者弁済**: 債務者以外の第三者も弁済できる
  - **正当な利益を有しない**第三者（親族・友人等）は、**債務者の意思に反して**弁済できない（債権者が債務者の意思に反することを知らなかったときは有効）
  - 正当な利益を有する第三者（物上保証人、抵当不動産の**第三取得者**、借地上の建物の**賃借人**＝地代の弁済）は、債務者の意思に反しても弁済できる
  - 当事者が第三者弁済を禁止・制限した場合は不可
- **受領権者としての外観を有する者への弁済**: 取引上の社会通念に照らして受領権者としての外観を有する者（預金通帳と印鑑の持参人等）に、**善意無過失**で弁済 → 有効
- 弁済者は、弁済と引換えに**受取証書**（領収書）の交付を請求できる（同時履行）
- **弁済の場所**: 特定物の引渡しは**債権発生時にその物が存在した場所**、その他（金銭債務等）は**債権者の現在の住所**
- **代物弁済**: 債権者との契約により、本来の給付に代えて他の給付をすることで債務を消滅させる（給付をした時に消滅）
- **弁済の供託**: 債権者が受領を拒んだ、受領できない、債権者を確知できない場合 → 供託所に供託して債務を免れる
- **弁済による代位**: 弁済をした第三者・保証人は、債権者が有していた権利（抵当権等）を行使できる

## 8. 相殺 ★

- **要件**（相殺適状）: ①同一当事者間に対立する債権 ②双方の債権が**同種**の目的 ③**自働債権**（相殺する側の債権）が**弁済期**にある ④債務の性質が相殺を許す
  - **受働債権**（相殺される側の債権）は弁済期前でも、期限の利益を放棄して相殺できる
- 相殺の意思表示には条件・期限を付けられない
- 相殺の効果: 相殺適状になった時に**遡って**対当額で消滅
- **相殺の禁止**:
  - **悪意**による不法行為に基づく損害賠償債務、**人の生命・身体の侵害**による損害賠償債務を**受働債権**とする相殺は不可（被害者側から相殺するのは可）
  - **差押え後**に取得した債権を自働債権とする相殺は、差押債権者に対抗できない（差押え**前**に取得した債権なら、弁済期の先後を問わず相殺できる）
  - 当事者が相殺禁止・制限の意思表示をした場合（悪意・重過失の第三者に対抗可）
- **時効消滅した債権**でも、消滅前に相殺適状にあれば、その債権を**自働債権**として相殺可能

## 9. 債権譲渡

- 原則として自由に譲渡可能。**将来**発生する債権も譲渡できる
- **譲渡制限特約**: 特約があっても譲渡は**有効**（2020年改正）
  - 譲受人が特約について**悪意・重過失**の場合、債務者は履行を拒絶でき、譲渡人への弁済等を譲受人に対抗できる
  - ⚠ **預貯金債権**の譲渡制限特約は、悪意・重過失の譲受人に対して譲渡自体を**無効**とできる
- **対抗要件**:

| 対抗する相手 | 対抗要件 |
|---|---|
| **債務者** | 譲渡人から債務者への**通知**、又は債務者の**承諾** |
| **債務者以外の第三者**（二重譲受人・差押債権者） | 上記の通知・承諾を**確定日付のある証書**（内容証明郵便等）で行う |

- ⚠ 通知は**譲渡人**から行う（譲受人からの通知は無効。譲受人が譲渡人に代位して通知することもできない）
- **二重譲渡**: 確定日付のある通知が債務者に**到達した日時**（又は確定日付ある承諾の日時）の先後で優劣を決める（確定日付の日付の先後ではない）
  - 同時に到達した場合 → 各譲受人は債務者に**全額**を請求できる
- 債務者は、対抗要件具備時までに譲渡人に対して生じた事由（弁済・相殺等）を譲受人に対抗できる

## 10. 請負・委任

### 請負

- 請負人が仕事の完成を約し、注文者がその結果に対して報酬を支払う契約
- 報酬は、仕事の目的物の**引渡しと同時**に支払う（引渡しを要しない場合は仕事完成後）
- 請負人の契約不適合責任: 売買の規定を準用（注文者が不適合を知った時から**1年以内**に通知）
  - ⚠ 注文者の提供した材料や注文者の指図によって生じた不適合 → 原則として責任を負わない
- 注文者は、仕事を完成しない間は、いつでも**損害を賠償して**契約を解除できる

### 委任

- 受任者は、**善良な管理者の注意**をもって委任事務を処理する（無償でも善管注意義務）
- 特約がなければ**無報酬**
- 各当事者は、**いつでも**契約を解除できる（相手方に不利な時期の解除等は、やむを得ない事由がなければ損害賠償が必要）
- 委任の終了事由: 委任者・受任者の**死亡**、**破産**手続開始、受任者の**後見開始**の審判
  - ⚠ 委任者の後見開始は終了事由ではない

## 11. 不法行為 ★

### 一般不法行為（709条）

- **要件**: ①故意又は過失 ②権利・法律上保護される利益の侵害 ③損害の発生 ④因果関係
- 立証責任は**被害者側**
- 損害賠償債務は、**不法行為の時**から当然に履行遅滞（請求不要）
- 過失相殺: 被害者に過失があれば、裁判所は損害賠償額を定めるにあたり考慮**できる**（任意的。債務不履行と異なり責任自体の否定は不可）
- **胎児**は、損害賠償請求権については既に生まれたものとみなす
- 責任能力のない者（未成年者で責任を弁識する知能のない者等）は責任を負わない → 監督義務者が責任を負う

### 使用者責任（715条）

- 被用者が**事業の執行について**第三者に損害 → **使用者も責任**
  - 「事業の執行について」は外形から判断（勤務時間外の社用車使用等でも外形上職務の範囲なら該当）
- 使用者は被用者の選任・監督に相当の注意をしたことを証明すれば免責（実際にはほぼ認められない）
- 被害者は、使用者と被用者の**どちらにも**全額請求できる
- 使用者から被用者への**求償**: 信義則上相当と認められる限度に制限される（判例）
- 被用者が賠償した場合、被用者から使用者への**逆求償**も認められる（判例）

### 工作物責任（717条）

- 土地の工作物（建物・塀等）の設置・保存の**瑕疵**による損害
- 第一次的に**占有者**が責任を負う（過失責任: 損害の発生を防止するのに必要な注意をしたことを証明すれば免責）
- 占有者が免責された場合 → **所有者**が責任を負う（**無過失責任**: 免責されない）
- 損害の原因について他に責任を負う者（施工業者等）がいるときは、占有者・所有者はその者に**求償**できる

### 共同不法行為（719条）

- 数人が共同の不法行為によって損害を加えた → 各自が**連帯**して損害賠償責任を負う
- 被害者は、各加害者に**全額**を請求できる。加害者間では過失割合に応じて求償

### 注文者の責任

- 注文者は、請負人がその仕事について第三者に加えた損害を賠償する責任を負わない（注文・指図に過失があった場合を除く）

### 損害賠償請求権の消滅時効

| 起算点 | 期間 |
|--------|------|
| 被害者又はその法定代理人が損害及び加害者を知った時 | **3年**（人の生命・身体の侵害は**5年**） |
| 不法行為の時 | **20年** |

## 12. 贈与・消費貸借・使用貸借 ★

### 贈与

- **書面によらない**贈与 → 各当事者が解除できる。ただし**履行の終わった部分**は解除できない（550条）
- 贈与者は、目的物を贈与の目的として**特定した時の状態**で引き渡すことを約したものと推定（551条）

### 消費貸借

- 原則は**要物契約**（金銭等を受け取って成立。587条）
- **書面でする消費貸借**は合意だけで成立（諾成。587条の2）
  - 借主は、金銭等を**受け取るまで**解除できる（貸主は損害賠償を請求できる）
  - 受取り前に当事者の一方が**破産**手続開始の決定を受けた → 効力を失う

### 使用貸借（無償で借りる契約）

- **諾成契約**（593条）
- **貸主**は、借主が借用物を**受け取るまで**解除できる。ただし**書面による**使用貸借は解除できない（593条の2）
- **借主**は、期間・目的の定めの有無にかかわらず**いつでも**解除できる（598条3項）
- 期間・目的を定めなかった → 貸主はいつでも解除できる
- 通常の必要費は**借主**が負担（595条）
- 使用借権には対抗力がない（借地借家法も適用されない）
- ⚠ 使用貸借は**借主の死亡**で終了（597条3項）。**貸主の死亡では終了しない**（書面か否かも無関係）

### 当事者の死亡と契約の終了

| 契約 | 貸主・委任者の死亡 | 借主・受任者の死亡 |
|---|---|---|
| 使用貸借 | 終了**しない** | **終了** |
| 賃貸借 | 終了しない（相続される） | 終了しない（相続される） |
| 委任 | **終了** | **終了** |
