# 都市計画法

> 法令上の制限から毎年2問出題。開発許可制度が最頻出。

## 1. 都市計画区域 ★★

### 区域の構造

```
都市計画区域
├── 市街化区域（すでに市街地 or 概ね10年以内に市街化を図る区域）
├── 市街化調整区域（市街化を抑制すべき区域）
└── 非線引き区域（区域区分を定めない区域）

準都市計画区域（都市計画区域外で一定の区域）

都市計画区域外
```

### 区域の指定

| 区域 | 指定する者 | 手続き |
|---|---|---|
| 都市計画区域（1つの都府県内） | **都道府県** | 関係市町村・都道府県都市計画審議会の意見を聴き、**国土交通大臣に協議・同意** |
| 都市計画区域（2以上の都府県にわたる） | **国土交通大臣** | 関係都府県の意見を聴く |
| 準都市計画区域 | **都道府県** | 関係市町村・都道府県都市計画審議会の意見を聴く |

- 都市計画区域は、市町村の行政区域にとらわれずに指定できる（複数の市町村にまたがってもよい）
- 準都市計画区域: 都市計画区域**外**で、そのまま放置すれば将来の都市としての整備等に支障が生じるおそれがある区域

### 市街化区域と市街化調整区域（区域区分）

| 区分 | 特徴 |
|------|------|
| 市街化区域 | 用途地域を**必ず定める** |
| 市街化調整区域 | 用途地域を**原則として定めない** |
| 非線引き区域 | 用途地域を定めることが**できる** |

- 区域区分（線引き）は**都道府県**が定める。定めるかどうかは原則として**任意**（三大都市圏の一定区域等は必ず定める）
- ⚠ **準都市計画区域**には区域区分を定めることは**できない**

### 準都市計画区域で定められる都市計画

- 定めることができる: **用途地域**、特別用途地区、特定用途制限地域、高度地区（最高限度のみ）、景観地区、風致地区、緑地保全地域、伝統的建造物群保存地区
- ⚠ 定めることができない: **区域区分**、**高度利用地区**、**特定街区**、**防火地域・準防火地域**、高層住居誘導地区、**市街地開発事業**、地区計画（都市施設は定めることができる）

## 2. 用途地域・地域地区 ★★

### 13種類の用途地域

| 用途地域 | 主な用途 |
|----------|----------|
| 第一種低層住居専用地域 | 低層住宅（10m or 12m高さ制限） |
| 第二種低層住居専用地域 | 低層住宅＋小規模店舗（150㎡以下） |
| 第一種中高層住居専用地域 | 中高層住宅＋一定の店舗等（500㎡以下） |
| 第二種中高層住居専用地域 | 中高層住宅＋店舗等（1,500㎡以下） |
| 第一種住居地域 | 住居＋店舗等（3,000㎡以下） |
| 第二種住居地域 | 住居＋大規模店舗等可 |
| 準住居地域 | 道路の沿道＋住居の調和 |
| 田園住居地域 | 農業＋低層住居の調和 |
| 近隣商業地域 | 近隣住民のための店舗等 |
| 商業地域 | 商業の利便 |
| 準工業地域 | 環境悪化のおそれのない工業 |
| 工業地域 | 工業の利便 |
| 工業専用地域 | 工業の利便（**住宅建築不可**） |

- **住宅が建てられない**: 工業専用地域のみ
- **すべての用途地域で建てられる**: 神社・寺院・教会、巡査派出所、公衆電話所、**診療所**、**保育所**、公衆浴場
  - ⚠ 老人ホーム・住宅・図書館は工業専用地域では建てられない／病院は診療所と異なり低層住居専用地域等では不可
- 用途地域で必ず定める事項: **容積率**、建蔽率（商業地域を除く）、敷地面積の最低限度（必要な場合）
- 第一種・第二種低層住居専用地域・田園住居地域では**建築物の高さの限度**（10m又は12m）も定める

### 用途地域以外の主な地域地区

| 地域地区 | 内容・ポイント |
|---|---|
| 特別用途地区 | 用途地域内で、用途地域の指定を補完して特別の目的から用途制限を強化・緩和 |
| 特定用途誘導地区 | 都市再生特別措置法による。立地適正化計画の**都市機能誘導区域**内で、**誘導施設**を有する建築物の容積率・用途制限等を**緩和**する地区（⚠「用途地域の指定を補完して定める」のは**特別用途地区**） |
| 特定用途制限地域 | 用途地域が定められていない区域（市街化調整区域を除く）で、特定の用途の建築物を制限 |
| 高度地区 | 用途地域内で、建築物の高さの**最高限度又は最低限度**を定める |
| 高度利用地区 | 用途地域内で、容積率の最高・最低限度、建蔽率の最高限度、建築面積の最低限度等を定める |
| 特定街区 | 市街地の整備改善のため、容積率・高さの最高限度・壁面の位置の制限を定める |
| 高層住居誘導地区 | 第一種・第二種住居、準住居、近隣商業、準工業地域で容積率400%のものに定める |
| 防火地域・準防火地域 | 市街地における火災の危険を防除 |
| 景観地区・風致地区 | 景観の形成、都市の風致の維持 |

- ⚠ 「高度**地区**」は高さ、「高度**利用**地区」は容積率等（混同注意）
- ⚠ 特定用途制限地域は**用途地域が定められていない**土地に定める（市街化調整区域には定められない）

### 都市施設

- **市街化区域**・**非線引き区域**: 少なくとも**道路・公園・下水道**を定める
- **住居系の用途地域**: さらに**義務教育施設**を定める
- 都市計画区域外でも、特に必要があるときは都市施設を定めることができる

## 3. 開発許可制度 ★★★

### 開発行為の定義

- 主として**建築物の建築**又は**特定工作物の建設**の用に供する目的で行う**土地の区画形質の変更**
- 特定工作物:
  - 第一種特定工作物: **コンクリートプラント**、**アスファルトプラント**、クラッシャープラント、危険物の貯蔵・処理施設
  - 第二種特定工作物: **ゴルフコース**（規模を問わない）、**1ha以上**の野球場・庭球場・陸上競技場・遊園地・動物園・墓園
- ⚠ 1ha未満の野球場・墓園等の建設のための造成、建築目的のない青空駐車場の造成は開発行為ではない

### 許可が必要な面積

| 区域 | 面積要件 |
|------|----------|
| 市街化区域 | **1,000㎡以上** |
| 市街化調整区域 | **面積に関わらずすべて** |
| 非線引き区域 | **3,000㎡以上** |
| 準都市計画区域 | **3,000㎡以上** |
| 都市計画区域外 | **10,000㎡（1ha）以上** |

- 許可権者: **都道府県知事**（指定都市・中核市等ではその長）
- 市街化区域の1,000㎡は、三大都市圏の一定区域等では条例で**300㎡**まで引き下げられる

### 許可不要の開発行為 ★★

| 許可不要 | 内容 |
|----------|------|
| 小規模開発 | 上記の面積未満（市街化調整区域は面積の例外なし） |
| 公益上必要な建築物 | **駅舎**、**図書館**、**公民館**、**変電所**等 |
| 農林漁業用建築物 | 市街化区域**以外**で農林漁業用の建築物（畜舎・温室等）・農林漁業従事者の住宅 |
| 都市計画事業・土地区画整理事業・市街地再開発事業等の施行 | 事業として行う場合 |
| 公有水面埋立地 | 埋立免許を受け、竣功認可の告示前の埋立地 |
| 非常災害のための応急措置 | — |
| 通常の管理行為・軽易な行為 | 仮設建築物の建築、車庫・物置等の附属建築物の建築 等 |

- ※ 農林漁業の例外は**市街化区域には適用されない**（市街化区域で1,000㎡以上なら許可必要）
- ⚠ **学校**・**病院**・**社会福祉施設**・**庁舎**は公益上必要な建築物の例外に**あたらない** → 許可が必要
- ⚠ 農産物の**加工・貯蔵**施設は農林漁業用建築物にあたらない
- ⚠ 「**土地区画整理事業の施行**として行う」場合は不要だが、土地区画整理事業の施行区域内で**事業としてでなく**行う開発行為は許可が必要

### 開発許可の手続き

1. **事前協議・同意**
   - 開発行為に関係がある**既存の公共施設の管理者**と協議し、その**同意**を得る
   - 開発行為により**新たに設置される公共施設を管理することとなる者**と**協議**する（同意までは不要）
   - 開発区域内の土地の所有者等の**相当数の同意**を得る（全員の同意は不要）
2. **書面**で都道府県知事に開発許可を申請（同意を得たことを証する書面・協議の経過を示す書面を添付）
3. 知事は**遅滞なく**許可・不許可の処分をし、**文書**で申請者に通知
   - 許可をしたとき → **開発登録簿**に登録（誰でも閲覧・写しの交付請求可）
   - 許可に際し、用途地域が定められていない区域では、建蔽率・高さ・壁面の位置等の制限を定めることができる
4. 工事完了 → 開発許可を受けた者が**知事に届出**
5. 知事は**遅滞なく検査** → 適合していれば**検査済証**を交付
6. 知事が**工事完了の公告**
7. 開発行為により設置された**公共施設**は、原則として公告の日の翌日に**市町村**の管理に属する
8. 公共施設の用地の帰属（40条）:
   - **新たに**設置された公共施設の用地 → 公告の日の翌日に、その公共施設の**管理者**に帰属
   - 従前の公共施設に代えて新たな公共施設を設置した場合の、**従前の**公共施設の用地（国・地方公共団体所有） → 公告の日の翌日に**開発許可を受けた者**に帰属

### 許可後の変更・廃止・承継

| 事由 | 手続き |
|---|---|
| 開発行為の内容を変更 | 知事の**許可**（軽微な変更は遅滞なく**届出**） |
| 工事を**廃止** | 遅滞なく知事に**届出**（許可ではない） |
| 相続・合併（一般承継） | 地位を**当然に承継**（承認不要） |
| 土地の所有権等を取得した者（特定承継） | **知事の承認**を受けて地位を承継 |

### 開発許可後の建築制限

| 時期 | 制限内容 |
|------|----------|
| 工事完了公告前 | 原則として建築物の建築・特定工作物の建設不可 |
| 工事完了公告後 | **予定建築物以外**は建築・用途変更不可 |

- 公告**前**でも建築できる場合:
  - 工事用の**仮設建築物**を建築するとき
  - 知事が**支障がない**と認めたとき
  - 開発行為に**同意していない土地所有者**等が、その権利の行使として建築するとき
- 公告**後**に予定建築物以外を建築できる場合:
  - 知事が**許可**したとき
  - 開発区域内に**用途地域等**が定められているとき（用途地域の規制で足りるため）

### 市街化調整区域の建築制限（43条）

- 市街化調整区域のうち**開発許可を受けた開発区域以外**で、建築物の**新築・改築・用途変更**、第一種特定工作物の新設をする場合 → **知事の許可**が必要
- 許可不要の例: 農林漁業用建築物・農林漁業者の住宅、公益上必要な建築物、都市計画事業の施行、非常災害の応急措置、**仮設建築物**の新築、通常の管理行為・軽易な行為

### 不服申立て

- 開発許可等の処分・不作為に不服がある → **開発審査会**に審査請求
- 不作為については、開発審査会に代えて知事に審査請求することもできる

## 4. 都市計画の決定手続き

### 決定権者

| 都市計画 | 決定権者 |
|----------|----------|
| 区域区分（市街化区域・市街化調整区域） | **都道府県** |
| 都市計画区域の整備・開発・保全の方針 | **都道府県** |
| 用途地域 | **市町村** |
| 地区計画 | **市町村** |
| 広域的・根幹的な都市施設 | 都道府県 |

- ⚠ 「都市計画区域の指定」は都市計画の決定ではなく、都道府県（又は国土交通大臣）が行う**区域の指定**
- 市町村が定めた都市計画が都道府県の都市計画と抵触 → **都道府県**の都市計画が優先

### 手続きの流れ

1. 必要に応じて**公聴会**の開催等、住民の意見を反映させる措置
2. 都市計画の案を、理由を記載した書面を添えて**2週間**公衆の**縦覧**に供する（あらかじめ公告）
   - 関係市町村の**住民**・**利害関係人**は、縦覧期間満了日までに**意見書**を提出できる
3. 都市計画審議会の議を経る
   - 都道府県が定める → 関係市町村の意見を聴き、**都道府県都市計画審議会**の議を経る（国の利害に重大な関係があるものは**国土交通大臣に協議・同意**）
   - 市町村が定める → **市町村都市計画審議会**の議を経て、あらかじめ**都道府県知事に協議**（⚠ 同意は不要）
4. 都市計画の**告示**
5. **告示の日**から効力を生ずる

### 都市計画の提案制度

- 土地所有者等は、**0.5ha以上**の一団の土地について、土地所有者等の**3分の2以上**の同意を得て、都市計画の決定・変更を**提案**できる
- まちづくりNPO法人等も提案できる

## 5. 都市計画制限

### 都市計画施設の区域・市街地開発事業の施行区域内（53条）

- 建築物の**建築** → **知事等の許可**が必要
- 許可不要: 政令で定める**軽易な行為**（階数2以下かつ地階を有しない木造建築物の改築・移転）、**非常災害**の応急措置、都市計画事業の施行として行う行為
- 許可基準（満たせば許可**しなければならない**）: **階数が2以下**かつ**地階を有しない**、主要構造部が**木造・鉄骨造・コンクリートブロック造**等で、容易に移転・除却できるもの
- ⚠ 対象は「建築物の建築」のみ（土地の形質変更は許可不要）

### 市街地開発事業等予定区域内（52条の2）

- 建築物の建築・工作物の建設・**土地の形質の変更** → **知事等の許可**が必要
- 許可不要: 通常の管理行為・軽易な行為、非常災害の応急措置、都市計画事業の施行として行う行為

### 都市計画事業の事業地内（65条）

- 都市計画事業の**認可・承認の告示**があった後、事業地内で次の行為をする → **知事等の許可**が必要
  - 土地の形質の変更、建築物の建築その他工作物の建設
  - 重量が**5トン**を超える移動の容易でない物件の設置・堆積
- ⚠ **軽易な行為**・**非常災害の応急措置**でも許可が必要（例外なし。53条との違い）
- 知事等は許可をしようとするときは、あらかじめ**施行者の意見**を聴く

### 事業地内の土地建物等の先買い（67条）

- 事業認可等の告示の日の翌日から起算して**10日**を経過した後に、事業地内の土地建物等を**有償で譲渡**しようとする者 → 予定対価の額・譲渡の相手方等を書面で**施行者に届出**
- 届出後**30日以内**に施行者が買い取る旨を通知 → 施行者との間に売買契約が成立したものとみなされる
- 届出をした者は、この30日の期間内は土地建物等を譲渡できない

## 6. 地区計画

- **市町村**が定める
- 地区計画の区域（**地区整備計画**が定められている区域等）内で、土地の区画形質の変更、建築物の建築、工作物の建設等を行う → **市町村長に届出**（行為に着手する日の**30日前**まで）
  - 届出事項を変更する場合も、変更に係る行為に着手する日の30日前までに届出
- ⚠ **許可**ではなく**届出**（知事ではなく**市町村長**）
- 届出に係る行為が地区計画に適合しない → 市町村長は設計の変更等を**勧告**できる
- 届出不要: 通常の管理行為・軽易な行為、非常災害の応急措置、**国・地方公共団体**が行う行為、開発許可を要する行為 等
- 地区計画は、用途地域が定められている土地の区域のほか、用途地域が定められていない一定の土地の区域にも定められる
