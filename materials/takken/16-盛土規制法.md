# 宅地造成及び特定盛土等規制法（盛土規制法）

> 2023年5月施行の新法。旧・宅地造成等規制法から大幅改正。出題頻度上昇中。

## 1. 法改正の概要

### 旧法からの主な変更点

| 項目 | 旧法（宅地造成等規制法） | 新法（盛土規制法） |
|------|------------------------|-------------------|
| 規制区域 | 宅地造成工事規制区域のみ | **宅地造成等工事規制区域** + **特定盛土等規制区域** |
| 規制対象 | 宅地造成 | 宅地造成 + **特定盛土等**（農地・森林での盛土等を含む） + **土石の堆積** |
| 許可を受ける者 | 造成主 | **工事主**（工事の注文者又は自ら工事をする者） |

- 熱海市の土石流災害（2021年）を受けて、宅地か否かを問わず危険な盛土等を規制

### 用語の定義

| 用語 | 意味 |
|---|---|
| 宅地 | **農地・採草放牧地・森林**（農地等）と、道路・公園・河川等の**公共施設用地**以外の土地 |
| 宅地造成 | **宅地以外**の土地を**宅地にするため**に行う盛土等の土地の形質の変更（一定規模以上） |
| 特定盛土等 | **宅地又は農地等**において行う盛土等の土地の形質の変更で、隣接・近接する宅地に災害を発生させるおそれが大きいもの（一定規模以上） |
| 土石の堆積 | 宅地又は農地等において行う土石の堆積で、一定期間後に除却するもの（一定規模以上） |
| 工事主 | 工事の請負契約の**注文者**、又は請負契約によらず**自ら工事をする者** |
| 災害 | **崖崩れ**又は**土砂の流出**による災害 |

- ⚠ 「宅地において行う」盛土等は、新法では「宅地造成」ではなく「**特定盛土等**」に分類される
- ⚠ 宅地を宅地以外（農地等）にするための盛土は「宅地造成」にあたらない

## 2. 規制区域 ★★

### 宅地造成等工事規制区域

- 宅地造成等に伴い災害が生ずるおそれが大きい**市街地・集落**、その周辺の区域等で、相当数の居住者等に危害を生ずるおそれがある区域
- **都道府県知事**（指定都市・中核市ではその長）が、基本方針・基礎調査の結果を踏まえて指定
  - 指定しようとするとき → **関係市町村長の意見**を聴く
  - 指定は**公示**によって効力を生ずる
  - 市町村長は、指定の必要があると認めるとき、知事に**申し出る**ことができる

### 特定盛土等規制区域

- **宅地造成等工事規制区域以外**の土地で、特定盛土等又は土石の堆積が行われた場合には市街地等区域等の居住者等に危害を生ずるおそれが特に大きい区域
- 市街地から離れた山間部等も対象
- **都道府県知事**（指定都市・中核市ではその長）が指定

## 3. 宅地造成等工事規制区域内の規制 ★★★

### 許可が必要な行為

| 行為 | 許可 |
|------|----------|
| **宅地造成** | 都道府県知事の許可 |
| **特定盛土等** | 都道府県知事の許可 |
| **土石の堆積** | 都道府県知事の許可 |

- 許可を受けるのは**工事主**（工事施行者＝請負人ではない）
- 工事に**着手する前**に許可を受ける
- 許可の申請前に、周辺地域の住民に対し**説明会**の開催等により工事の内容を**周知**させる
- 許可の基準: 工事計画が技術的基準に適合、工事主に**資力・信用**、工事施行者に工事を完成する**能力**、関係権利者の**同意**を得ていること
- 知事は許可に、災害防止のため必要な**条件**を付すことができる
- 国・都道府県・指定都市・中核市が行う工事 → 知事との**協議**が成立すれば許可があったものとみなす
- 規制区域の指定後に、都市計画法の**開発許可**を受けた宅地造成・特定盛土等 → 盛土規制法の**許可を受けたものとみなす**

### 宅地造成・特定盛土等の規模要件

| 行為 | 規模要件 |
|------|----------|
| **盛土**で高さ**1m超**の崖を生ずるもの | 許可必要 |
| **切土**で高さ**2m超**の崖を生ずるもの | 許可必要 |
| 盛土と切土を同時にする場合で、全体で高さ**2m超**の崖を生ずるもの（上記に該当しないもの） | 許可必要 |
| 崖を生じない**盛土**で、高さ**2m超**となるもの | 許可必要 |
| 盛土又は切土をする土地の面積が**500㎡超** | 許可必要 |

- ⚠ 「盛土1m・切土2m」の数字の取り違えに注意（盛土の方が危険なので基準が厳しい）

### 土石の堆積の規模要件

- 堆積の高さ**2m超**で、面積**300㎡超**
- 又は、堆積の面積**500㎡超**

### 許可後の手続き

| 手続き | 内容 |
|---|---|
| 変更 | 工事の計画を変更 → 知事の**許可**（軽微な変更は遅滞なく**届出**） |
| 中間検査 | 一定規模以上の工事で、特定工程を含む場合に知事の検査を受ける |
| 定期の報告 | 一定規模以上の工事は、定期的に（**3か月**ごと）工事の実施状況を知事に報告 |
| 完了検査 | 宅地造成・特定盛土等の工事完了 → 知事の**検査**を受け、適合すれば**検査済証**の交付 |
| 土石の堆積の確認 | 堆積した全ての土石を除却 → 知事の**確認**を受け、**確認済証**の交付 |

### 届出が必要な場合（宅地造成等工事規制区域内）

| 場面 | 届出期限 | 届出先 |
|---|---|---|
| 区域の**指定の際**、既に行われている宅地造成等の工事 | 指定があった日から**21日以内** | 都道府県知事 |
| 高さ2m超の**擁壁**・排水施設等の除却工事（許可を受けたものを除く） | 工事着手の日の**14日前**まで | 都道府県知事 |
| **公共施設用地**を宅地又は農地等に**転用**（許可を受けたものを除く） | 転用した日から**14日以内** | 都道府県知事 |

### 土地の保全義務・勧告・改善命令

- 区域内の土地の**所有者・管理者・占有者**は、災害が生じないよう、土地を**常時安全な状態に維持**するよう努めなければならない（区域指定**前**の工事による土地も含む）
- 知事は、災害防止のため必要があるとき → 土地の所有者等・工事主・工事施行者に、擁壁等の設置等を**勧告**できる
- 擁壁等が設置されていない・極めて不完全で、災害の発生のおそれが大きい → 知事は土地の所有者等に、擁壁等の設置・改造等の工事を**命ずる**ことができる（**改善命令**）
  - 所有者以外の者の不完全な工事等が原因であることが明らかなとき → その**原因行為者**に対しても命令できる

## 4. 特定盛土等規制区域内の規制 ★

### 届出制

- 一定規模以上の特定盛土等又は土石の堆積 → 工事主が工事着手の日の**30日前**までに、工事の計画を**都道府県知事に届出**
  - 規模要件は、宅地造成等工事規制区域の許可の規模要件と同じ
- 知事は、届出を受理した日から**30日以内**に限り、災害防止のため必要な措置を**勧告**できる → 正当な理由なく従わない場合は**命令**できる
- 計画を変更 → 変更後の工事着手の**30日前**までに届出
- 都市計画法の開発許可を申請した場合 → 届出をしたものとみなす

### 許可制（大規模なもの）

- 大規模な崖崩れ・土砂の流出を生じさせるおそれが大きい規模の特定盛土等・土石の堆積 → **都道府県知事の許可**
  - 例: 盛土で高さ**2m超**の崖、切土で高さ**5m超**の崖、盛土で高さ**5m超**、盛土又は切土の面積**3,000㎡超** 等
  - 土石の堆積: 高さ**5m超**かつ面積**1,500㎡超**、又は面積**3,000㎡超**
- 許可を受けた工事は、届出不要

## 5. 工事の技術的基準 ★

### 主な技術基準

| 基準 | 内容 |
|------|------|
| 地盤 | 地盤の沈下・崩壊が生じないように、地盤の改良等 |
| 擁壁の設置 | 切土で高さ2m超・盛土で高さ1m超の崖などの崖面は、原則として**擁壁**で覆う |
| 排水施設 | 地表水・地下水を排除できる施設の設置 |
| 盛土の締固め | 盛土は十分に締め固めて施工 |

- 高さ**5m超**の擁壁の設置、盛土・切土の面積**1,500㎡超**の土地における排水施設の設置 → 一定の**資格を有する者の設計**によらなければならない

### 工事施行者の義務

- 許可を受けた宅地造成等の工事は、技術基準に適合するよう施行

## 6. 監督処分 ★

### 知事の権限

| 処分 | 内容 |
|------|------|
| 許可の取消し | 偽りその他不正な手段で許可を受けた者、許可の条件に違反した者 |
| 工事停止命令 | 無許可・条件違反・技術的基準不適合の工事に対し停止を命令 |
| 原状回復・災害防止措置命令 | 工事主・工事施行者等に対し、擁壁等の設置等の措置を命令 |
| 改善命令 | 区域内の土地の所有者等・原因行為者に対し、擁壁等の設置等を命令 |

- 命令を受けた者が措置を講じない等の場合 → 知事が自ら措置を講じ（**代執行**）、費用を徴収できる
- **緊急**に災害防止措置を講ずる必要があり、所有者・工事主等に命ずる**いとまがない** → 知事は**自ら**災害防止措置の全部又は一部を講ずることができる
- 無許可工事・命令違反には重い罰則（**3年以下の拘禁刑又は1,000万円以下の罰金**、法人は**3億円以下**の罰金）

## 7. 造成宅地防災区域

- 宅地造成又は特定盛土等（宅地において行うもの）に伴う災害で相当数の居住者等に危害を生ずるおそれが大きい**一団の造成宅地**の区域
- **都道府県知事**（指定都市・中核市ではその長）が指定
  - ⚠ **宅地造成等工事規制区域内**の土地には指定できない（区域外の既存造成宅地が対象）
  - 擁壁等の設置等により指定の事由がなくなった → 指定を**解除**
- 区域内の造成宅地の所有者等は、擁壁等の設置・改造等の措置を講ずるよう**努めなければならない**
- 知事は、災害防止のため必要があるとき → 所有者等に**勧告**、災害の発生のおそれが大きいとき → **改善命令**
- 宅建業法の重要事項説明で、**造成宅地防災区域内**か否かを説明する

## 8. 頻出数字まとめ

| 項目 | 数字 |
|------|------|
| 盛土の崖の高さ | **1m超** |
| 切土の崖の高さ | **2m超** |
| 切土＋盛土の崖の高さ | **2m超** |
| 崖を生じない盛土の高さ | **2m超** |
| 盛土・切土の面積 | **500㎡超** |
| 土石の堆積 | 高さ2m超かつ300㎡超、又は500㎡超 |
| 届出期間（特定盛土等規制区域） | 着手の**30日前** |
| 届出期間（指定前からの工事） | 指定日から**21日以内** |
| 擁壁等の除却工事の届出 | 着手の**14日前** |
| 公共施設用地の転用の届出 | 転用から**14日以内** |
