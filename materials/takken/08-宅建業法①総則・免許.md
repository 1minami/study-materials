# 宅建業法① 総則・免許

> 宅建業法は全20問（問26〜45）。最も配点が大きく、18問以上正解を目指す科目。

## 1. 宅地建物取引業の定義 ★★★

### 「宅地」の定義

| 区分 | 内容 |
|------|------|
| ① 建物の敷地に供される土地 | 現に建物が建っている土地（地目不問） |
| ② 用途地域内の土地 | 都市計画法の用途地域内の土地（道路・公園・河川・広場・水路を除く） |
| ③ 将来建物の敷地に供する目的で取引される土地 | 登記上の地目不問 |

- 用途地域**内**の土地 → 現に農地・駐車場・資材置場でも**宅地にあたる**（建物を建てる予定がなくても該当）
- 用途地域**外**の土地 → 建物の敷地に供する目的で取引する場合のみ宅地（山林・農地として取引するなら宅地ではない）
- 道路・公園・河川・広場・水路の用に**現に**供されている土地は、用途地域内でも宅地ではない
- 「建物」には住宅だけでなく倉庫・店舗・工場、マンションの一室も含む

### 「取引」の定義

| 行為 | 自ら | 代理 | 媒介 |
|------|------|------|------|
| 売買 | ○ | ○ | ○ |
| 交換 | ○ | ○ | ○ |
| 貸借 | **×** | ○ | ○ |

- **自ら貸借は宅建業に該当しない**（最頻出ポイント）
  - 自ら貸主として賃貸する場合も、借り上げた物件を自ら**転貸**する場合（サブリース）も、取引にあたらない
  - ただし貸借の**代理・媒介**は取引にあたる → 免許が必要
- 宅地の**造成**・建物の**建築**・ビル**管理**は取引ではない（請負・管理業務にすぎない）

### 「業」の要件

- **不特定多数**の者を相手方として
- **反復継続**して行う
- 1回の取引でも反復継続の意思があれば該当
- 相手方が「自社の従業員のみ」「特定の1社のみ」など特定されていれば不特定多数ではない
- 一括して1人に売却 → 業にあたらない／複数人に分譲（区画分けして売却）→ 業にあたる
- 分譲を宅建業者に**代理・媒介**させても、売主本人の行為として扱われる → 売主本人も免許が必要

### 宅建業に該当しない行為・免許不要の者

- 自ら賃貸（自ら貸主・転貸主）
- **国・地方公共団体**（都市再生機構・地方住宅供給公社等を含む）には宅建業法が適用されない
  - ⚠ 国・地方公共団体から依頼を受けて代理・媒介する者は、免許が**必要**
- **信託会社・信託銀行**: 免許に関する規定が適用されない
  - 宅建業を営むときは、その旨を**国土交通大臣に届出**すれば足りる
  - 届出後は国土交通大臣の免許を受けた宅建業者と**みなされ**、免許以外の規定（営業保証金・業務規制等）は適用される

### 無免許営業・名義貸しの禁止

- 免許を受けない者は宅建業を営んではならない（無免許営業の禁止）
- 免許を受けない者は、宅建業を営む旨の**表示**・**広告**もしてはならない（実際の取引がなくても違反）
- 宅建業者は、自己の名義をもって他人に宅建業を営ませてはならない（名義貸しの禁止）
  - 名義を貸して他人に宅建業の表示・広告をさせることも禁止

## 2. 免許制度 ★★★

### 免許の区分

| 区分 | 事務所の設置 | 免許権者 |
|------|-------------|----------|
| 国土交通大臣免許 | 2以上の都道府県に事務所 | 国土交通大臣 |
| 都道府県知事免許 | 1つの都道府県のみに事務所 | 都道府県知事 |

- 案内所の設置だけでは免許の区分は変わらない
- 免許申請先: 大臣免許 → **国土交通大臣**に直接申請、知事免許 → 事務所所在地の**都道府県知事**に申請
- 大臣免許を受けるときは**登録免許税**、知事免許・大臣免許の更新は手数料を納付
- 免許権者は免許をしたときは**免許証**を交付する／免許しないときは理由を付した書面で通知

### 事務所の範囲

- **本店**（主たる事務所）: 常に事務所にあたる（本店で宅建業を行っていなくても、支店で宅建業を行えば本店も事務所）
- **支店**（従たる事務所）: 宅建業を営む支店のみ事務所にあたる（宅建業を行わない支店は事務所ではない）
- 継続的に業務を行うことができる施設を有し、契約締結権限を有する使用人（**政令で定める使用人**）を置く場所も事務所

### 免許換え

| 事務所の変更 | 申請先（新たな免許権者） |
|---|---|
| 大臣免許 → 1つの都道府県のみに事務所 | 事務所所在地の知事 |
| A県知事免許 → A県の事務所を廃止しB県のみに事務所 | B県知事 |
| 知事免許 → 2以上の都道府県に事務所 | 国土交通大臣 |

- 新しい免許権者に直接申請する（従前の免許権者を経由しない）
- 新たな免許を受けると従前の免許は**効力を失う**
- 免許換え後の免許の有効期間は、新たに**5年**（従前の残存期間を引き継がない）
- 免許換えの申請中に従前の免許の有効期間が満了 → 処分があるまで従前の免許は有効
- ⚠ 同一都道府県内での事務所移転・増設は免許換え不要（変更の届出で足りる）

### 免許の有効期間と更新

- 有効期間: **5年**
- 更新: 期間満了の**90日前から30日前**までに申請
- 更新申請をしている場合: 従前の免許は有効期間満了後も処分があるまで有効
  - 更新されたときの新免許の有効期間は、従前の免許の**有効期間満了日の翌日**から起算（処分の日からではない）
- 業務停止処分期間中でも更新申請はできる

### 免許の効力

- 免許を受ければ**全国どこでも**業務可能（免許の区分は事務所の設置場所による区別にすぎない）
- 知事免許の業者が他県に**案内所**を設けて契約しても免許換えは不要

### 変更の届出

- 宅建業者は次の事項に変更があったとき、**30日以内**に**免許権者**に届け出る
  - 商号又は名称
  - 法人の**役員**・**政令で定める使用人**の氏名（個人業者は本人・政令で定める使用人の氏名）
  - 事務所の名称・所在地
  - 事務所ごとに置かれる**専任の宅建士**の氏名
- ⚠ 役員・専任宅建士の**住所**、代表者の住所は届出事項ではない（宅建士の変更の登録とのひっかけ）

### 廃業等の届出

| 事由 | 届出義務者 | 期限 | 免許の失効時期 |
|---|---|---|---|
| 死亡 | **相続人** | 死亡を**知った日**から30日以内 | 死亡時 |
| 法人の合併による消滅 | 消滅した法人を代表する役員であった者 | 消滅の日から30日以内 | 合併時 |
| 破産手続開始の決定 | **破産管財人** | 30日以内 | 届出時 |
| 合併・破産以外の解散 | **清算人** | 30日以内 | 届出時 |
| 宅建業の廃止 | 個人業者本人／法人を代表する役員 | 30日以内 | 届出時 |

- 届出先は免許権者
- ⚠ 合併の届出は「消滅した」法人の代表役員が行う（存続会社の代表役員ではない）
- 相続人は、被相続人が締結した契約に基づく取引を結了する目的の範囲内で宅建業者とみなされる

## 3. 欠格事由 ★★★

### 免許を受けられない者

| 欠格事由 | 期間 |
|----------|------|
| **心身の故障**により宅建業を適正に営めない者として国土交通省令で定めるもの | — |
| 破産者で**復権を得ない者** | 復権まで |
| 拘禁刑以上の刑に処せられた者 | 刑の執行終了等から**5年** |
| 宅建業法違反、暴力的犯罪、背任罪で罰金刑 | 刑の執行終了等から**5年** |
| 不正手段による免許取得・業務停止処分事由に該当し情状が特に重い・業務停止処分違反で免許取消処分を受けた者 | 取消しの日から**5年** |
| 上記の免許取消処分の聴聞公示日前60日以内に役員であった者 | 取消しの日から**5年** |
| 上記の免許取消処分の聴聞公示後、処分前に解散・廃業の届出（相当の理由がある者を除く） | 届出の日から**5年** |
| 暴力団員 or 暴力団員でなくなった日から5年を経過しない者 | 5年 |
| 免許申請前5年以内に宅建業に関し不正又は著しく不当な行為をした者 | — |
| 宅建業に関し不正又は不誠実な行為をするおそれが明らかな者 | — |
| 営業に関し成年者と同一の行為能力を有しない未成年者で法定代理人が欠格 | — |
| 暴力団員等がその事業活動を支配する者 | — |
| 事務所に**専任の宅建士**を法定数置いていない者 | — |

> ※2025年6月1日施行の改正刑法により、従来の「懲役」と「禁錮」は「拘禁刑」に一本化されました。宅建業法の条文上も「禁錮以上の刑」は「拘禁刑以上の刑」に改められています。

### 欠格事由のひっかけポイント

- **成年被後見人・被保佐人**であることだけでは欠格事由にならない（心身の故障の有無を個別審査）
- 破産者でも**復権を得れば直ちに**免許を受けられる（5年待つ必要はない）
- **執行猶予**付きの判決 → 猶予期間中は欠格。猶予期間が**満了すれば直ちに**免許を受けられる（5年待つ必要はない）
- **控訴・上告中**は刑が確定していない → 欠格事由に該当しない
- 罰金刑で欠格になるのは、**宅建業法違反**・暴力団対策法違反、**傷害・現場助勢・暴行・凶器準備集合・脅迫・背任**等に限られる
  - ⚠ 過失傷害罪・道路交通法違反・詐欺罪・窃盗罪の**罰金**刑では欠格にならない（詐欺・窃盗でも**拘禁刑**なら欠格）
- 免許取消しで5年欠格となるのは「不正手段による免許取得」「情状が特に重い」「業務停止処分違反」の**3事由のみ**
  - 免許換え未了・欠格事由該当・1年以上事業を休止などによる取消しは5年欠格ではない
- 法人の欠格事由は「役員」で判断 → 役員には非常勤役員や、相談役・顧問など**同等以上の支配力**を有する者も含む

### 法人の欠格事由

- **役員**（非常勤含む）に欠格事由のある者がいる場合 → 法人は免許を受けられない
- **政令で定める使用人**（支店長等）に欠格事由のある者がいる場合 → 同様
- ⚠ 一般の従業員や、役員でない株主に欠格事由があっても法人は免許を受けられる

### 未成年者

- 営業に関し成年者と同一の行為能力を**有する**未成年者（法定代理人から営業の許可を受けた者）→ 本人のみで判断
- 営業に関し成年者と同一の行為能力を**有しない**未成年者 → **法定代理人**（法人なら役員）に欠格事由があれば免許を受けられない

## 4. 事務所 ★★

### 事務所の要件

| 要件 | 内容 |
|------|------|
| 専任の宅建士 | 事務所ごとに業務に従事する者**5人に1人以上**（**成年者**であること） |
| 標識の掲示 | 事務所ごとに掲示 |
| 報酬額の掲示 | 事務所ごとに掲示 |
| 帳簿の備付け | 取引の都度記載。各事業年度末日に閉鎖し、閉鎖後**5年**保存（業者自ら売主の新築住宅は10年） |
| 従業者名簿 | 最終記載から**10年**保存 |
| 従業者証明書 | 従業者に携帯させる |

- 専任の宅建士は**成年者**でなければならない
  - ⚠ 未成年の宅建士でも、本人が宅建業者（個人）又は法人の**役員**であれば、自ら主として業務に従事する事務所等の「成年者である専任の宅建士」と**みなされる**
- 専任の宅建士が退職等で不足 → **2週間以内**に補充等の必要な措置をとる
- 専任の宅建士の氏名は免許申請書の記載事項 → 変更時は**30日以内**に変更の届出

### 案内所等の届出

- 一団の宅地建物（10区画以上 or 10戸以上）の分譲の案内所等を設置する場合:
  - **標識**の掲示は、契約締結等を行わない案内所も含め、すべての案内所等で必要
  - **契約の締結・申込みの受付**を行う案内所等のみ:
    - **専任の宅建士1人以上**（成年者）を置く
    - 免許権者と案内所所在地の知事の**両方**に届出（業務開始の**10日前**まで）
    - 届出事項: 所在地・業務内容・業務を行う期間・専任の宅建士の氏名
  - ⚠ 報酬額の掲示・帳簿・従業者名簿は事務所のみ（案内所には不要）
- **販売代理・媒介**の業者が案内所（モデルルーム等）を設置した場合:
  - 届出・専任の宅建士の設置・案内所の**標識**の掲示 → 案内所を設置した**代理・媒介業者**の義務（⚠ 売主業者ではない）
  - **売主業者**は、物件の**所在する場所**（現地）に自己の標識を掲示する（代理業者は現地への標識不要）

## 5. 営業保証金 ★★

### 供託

| 事務所 | 金額 |
|--------|------|
| 主たる事務所 | **1,000万円** |
| 従たる事務所 | 1事務所につき**500万円** |

- 供託所: **主たる事務所**の**最寄りの供託所**（支店分もまとめて本店最寄りに供託。支店の最寄りではない）
- 金銭のほか**有価証券**による供託も可能、金銭と有価証券の併用も可（国債: 額面100%、地方債・政府保証債: 額面90%、その他: 額面80%）
  - ⚠ 株券では供託できない

### 事業開始までの流れ

1. 免許を受ける
2. 主たる事務所の最寄りの供託所に営業保証金を**供託**
3. 供託書の写しを添付して**免許権者に届出**
4. 届出後でなければ**事業を開始できない**（供託しただけでは開始不可）

- 免許権者は、免許をした日から**3か月以内**に届出がない → 届出をするよう**催告しなければならない**
- 催告が到達した日から**1か月以内**に届出がない → 免許を**取り消すことができる**（任意的取消し）

### 事務所を新設した場合

- 新設した事務所分（1か所500万円）を**主たる事務所の最寄りの供託所**に供託
- 供託後、免許権者に届出 → 届出後でなければ**新設事務所**で事業を開始できない

### 還付

- 還付を受けられる者: 宅建業者と**宅建業に関する取引**をした者（**宅建業者を除く**）
  - 宅建業に関する取引により生じた債権に限る
  - ⚠ 広告業者の広告代金債権、内装業者の工事代金債権、従業員の給与債権は還付の対象外
- 還付を受けられる額: その宅建業者が供託した営業保証金の額の範囲内
- 還付請求の相手方: 営業保証金が供託されている**供託所**に直接請求
- 還付により不足が生じた場合:
  1. 免許権者から不足額を供託すべき旨の**通知**を受ける
  2. 通知を受けた日から**2週間以内**に不足額を供託
  3. 供託した日から**2週間以内**に免許権者に届出

### 保管替え等

- 主たる事務所を移転し、最寄りの供託所が変わった場合（遅滞なく行う）:
  - **金銭のみ**で供託 → 従前の供託所に対し、新たな最寄りの供託所への**保管替え**を請求（費用は予納）
  - 有価証券を含む（金銭＋有価証券を含む）→ 新たな最寄りの供託所に**新たに供託**（二重供託）してから、旧供託所の営業保証金を取戻し
  - ⚠ 有価証券が含まれると保管替えはできない

### 取戻し

| 取戻し事由 | 公告の要否 |
|---|---|
| 免許の有効期間満了・廃業・免許取消し | **必要** |
| 一部の事務所の廃止（超過額を取戻し） | **必要** |
| 主たる事務所移転による二重供託後の旧供託所分 | 不要 |
| 保証協会の社員となった | 不要 |
| 取戻し事由発生から**10年**経過 | 不要 |

- 公告: 還付請求権者に対し、**6か月以上**の期間を定めて申し出るべき旨を公告
- 公告期間内に申出がなかった場合でなければ取り戻せない

## 6. 保証協会 ★★

### 保証協会の基本

- 保証協会は国土交通大臣が指定する一般社団法人（宅建業者のみを社員とする）
- 一の保証協会の社員は、**他の保証協会の社員になれない**（重複加入不可）
- 保証協会は、新たに社員が加入し又は社員が地位を失ったとき → **直ちに**その社員の**免許権者に報告**
- 保証協会の必須業務: **苦情の解決**・**研修**・**弁済業務**
  - 任意業務: **一般保証業務**・**手付金等保管事業**・研修費用の助成（承認不要）
  - 上記以外で宅建業の健全な発達を図るため必要な業務 → **国土交通大臣の承認**が必要
- 苦情の解決: 社員に対し文書・口頭による説明や資料の提出を求めることができ、社員は正当な理由なく拒めない
- 社員になる前の取引で弁済業務に支障のおそれがある → 保証協会はその社員に**担保の提供**を求めることができる

### 弁済業務保証金分担金

| 事務所 | 金額 |
|--------|------|
| 主たる事務所 | **60万円** |
| 従たる事務所 | 1事務所につき**30万円** |

- 宅建業者が保証協会に加入しようとする日までに、分担金を**保証協会に納付**
  - 分担金は**金銭のみ**（有価証券不可）
- 保証協会は納付を受けた日から**1週間以内**に、納付額相当の弁済業務保証金を**法務大臣及び国土交通大臣の定める供託所**（東京法務局）に供託
  - 弁済業務保証金の供託は**有価証券**でも可
  - 保証協会は、供託した旨を社員の**免許権者に届出**
- 社員が**新たに事務所を設置** → 設置した日から**2週間以内**に分担金を保証協会に納付
  - 期限までに納付しないと**社員の地位を失う**
- 保証協会の社員は営業保証金の供託が**免除**される → 既に供託していた営業保証金は**公告なし**で取り戻せる

### 還付

- 還付を受けられる者: 社員と宅建業に関し取引をした者（**宅建業者を除く**）
  - 社員が**社員となる前**に取引をした者も含む
- 還付限度額: その社員が社員でないとしたら供託すべき**営業保証金に相当する額**（主1,000万円 + 従500万円ベース）
  - ⚠ 納付した分担金の額（60万円等）が限度ではない
- 還付の手続き:
  1. 還付を受けようとする者は、弁済を受けられる額について**保証協会の認証**を受ける
  2. 認証を受けた上で、弁済業務保証金が供託されている**供託所に還付請求**
- ⚠ 認証を受けずに直接供託所へ請求することはできない／保証協会へ還付請求するのではない
- 還付後の補充の流れ:
  1. 保証協会は、国土交通大臣から還付の**通知**を受けた日から**2週間以内**に還付額相当の弁済業務保証金を**供託所に供託**
  2. 保証協会は、還付に係る社員（社員であった者）に対し、還付額相当の**還付充当金**を保証協会に納付するよう**通知**
  3. 社員は通知を受けた日から**2週間以内**に還付充当金を**保証協会に納付**（供託所に供託するのではない）
  4. 納付しない場合 → 社員の地位を失う → 地位を失った日から**1週間以内**に**営業保証金を供託**し、免許権者に届出

### 弁済業務保証金準備金・特別弁済業務保証金分担金

- 保証協会は、還付充当金が納付されない場合に備えて**弁済業務保証金準備金**を積み立てる
- 準備金でも不足 → 保証協会は全社員に**特別弁済業務保証金分担金**の納付を通知
  - 社員は通知を受けた日から**1か月以内**に納付（納付しないと社員の地位を失う）

### 弁済業務保証金の取戻し・分担金の返還

| 取戻し事由 | 公告 |
|---|---|
| 社員が**社員の地位を失った** | 保証協会が**6か月以上**の期間を定めて公告（認証の申出を求める） |
| 社員が**一部の事務所を廃止** | **不要** |

- 取戻しは**保証協会**が供託所から行い、取り戻した額に相当する分担金を社員（社員であった者）に**返還**
- ⚠ 公告をするのは**保証協会**（社員であった宅建業者ではない）
- 公告期間内に申出のなかった債権については、保証協会は認証できない
