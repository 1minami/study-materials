# 借地借家法

> 毎年1問出題（借地1問・借家1問）。借地権・借家権の存続期間と更新、対抗要件の違いが頻出。

## 1. 借地権 ★★★

### 借地権の定義

- **建物の所有を目的**とする**地上権**又は**土地の賃借権**
- ⚠ 建物所有目的でない土地の賃貸借（青空駐車場・資材置場・ゴルフ練習場等）には借地借家法は適用されない（民法のみ）
- **一時使用**のために借地権を設定したことが明らかな場合 → 存続期間・更新・建物買取請求権・定期借地権等の規定は適用されない

### 存続期間

| 種類 | 当初 | 1回目更新 | 2回目以降更新 |
|------|------|-----------|--------------|
| 普通借地権 | **30年**以上 | **20年**以上 | **10年**以上 |

- 当事者が期間を定めなかったとき → **30年**
- 30年より短い期間を定めた場合 → **30年**（30年より長い期間を定めればその期間）
- 更新後の期間も、定めがない・短い場合は上記の期間（20年・10年）

### 更新 ★★

| 更新の種類 | 要件 |
|---|---|
| **合意更新** | 当事者の合意（期間は上記の最短期間以上） |
| **請求による更新** | 期間満了時に**建物がある**場合に、借地権者が更新を請求 → 従前と同一条件で更新 |
| **法定更新（使用継続による更新）** | 期間満了後も借地権者が土地の使用を継続 + **建物がある** → 従前と同一条件で更新 |

- 請求更新・使用継続更新は、借地権設定者が**遅滞なく異議**を述べたときは更新されない
  - 異議には**正当事由**が必要
- **正当事由**: 借地権設定者・借地権者（転借地権者を含む）が土地の使用を必要とする事情のほか、借地に関する従前の経過、土地の利用状況、借地権設定者が土地の明渡しの条件として又は明渡しと引換えに借地権者に対して財産上の給付をする旨の申出（**立退料**）を考慮
- ⚠ 期間満了時に**建物がない**場合は、請求・使用継続による更新はない（合意更新のみ）

### 対抗要件 ★★

- **原則**: 借地権の**登記**（地上権は登記請求権あり、賃借権は特約がなければ登記請求権なし）
- **特例**: 借地上に**借地権者名義**の**登記された建物**があればよい（借地借家法10条）
  - 建物の登記は**表示の登記**（表題登記）でもよい（判例）
  - ⚠ **家族名義**（妻・長男等）の建物登記では対抗力なし（判例）
  - 建物の登記の所在地番が実際と多少異なっていても、建物の同一性が認識できれば対抗力あり（判例）
  - 借地が2筆にわたり、一方の筆にのみ登記された建物がある → 建物のない筆には対抗力は及ばない（判例）
- 建物が**滅失**した場合: 借地権者が、建物を特定するために必要な事項、滅失の日、建物を新たに築造する旨を土地上の見やすい場所に**掲示** → 滅失日から**2年間**は対抗力を維持（2年以内に建物を新築し登記すれば以後も継続）

### 建物の滅失と再築

| 時期 | 借地権設定者の承諾あり | 承諾なし |
|---|---|---|
| **当初の存続期間中**の滅失 | 承諾日又は築造日の**いずれか早い日**から**20年**間存続（残存期間の方が長ければ残存期間） | 再築は可能だが、期間は延長されない（当初期間満了時に更新の問題） |
| **更新後**の滅失 | 同上（20年に延長） | 借地権設定者は**解約の申入れ**ができる（申入れから**3か月**で消滅） |

- 当初の存続期間中に、借地権者が再築する旨を**通知**し、借地権設定者が通知を受けた後**2か月以内**に**異議を述べなかった** → 承諾があったものとみなす（⚠ 更新後の通知には適用なし）
- **更新後**に建物が滅失した場合、借地権者は**地上権の放棄**又は**賃貸借の解約の申入れ**ができる（申入れから3か月で消滅）
- 更新後にやむを得ない事情があるのに借地権設定者が承諾しない → 借地権者は裁判所に承諾に代わる**許可**を求めることができる

### 借地権の譲渡・転貸

- 借地権が**賃借権**の場合: 借地権設定者の**承諾**が必要（地上権なら承諾不要）
- 借地上の建物を譲渡すると、借地権も**従たる権利**として譲渡される → 承諾が必要
- ⚠ 借地上の建物を**賃貸**することは、借地の転貸にはあたらない（承諾不要）
- 借地権設定者が承諾しない場合:
  - 借地権者は、裁判所に借地権設定者の承諾に代わる**許可**を求めることができる（借地権設定者に不利となるおそれがないとき）
  - 借地権設定者が、自ら建物の譲渡を受ける旨を申し立てたとき → 裁判所は相当の対価等で譲渡を命ずることができる（**介入権**）
  - **競売**・公売で建物を取得した第三者 → 代金を支払った後**2か月以内**に裁判所に許可を申し立てられる
- **第三者の建物買取請求権**: 借地上の建物を取得した第三者に対し、借地権設定者が譲渡・転貸を承諾しない → 第三者は建物を**時価**で買い取るよう請求できる

### 建物買取請求権

- 借地権の**存続期間が満了**し、契約の**更新がない**とき → 借地権者は借地権設定者に、建物その他借地権者が権原により附属させた物を**時価**で買い取るよう請求できる
- ⚠ 借地権者の**債務不履行**（地代不払い等）により契約が**解除**された場合は、建物買取請求権は**認められない**（判例）
- 建物買取請求権を行使した借地権者は、代金の支払いを受けるまで建物の引渡しを拒める（同時履行・留置権）。ただし、その間の**地代相当額**は支払う
- 建物買取請求権を排除する特約は**無効**（定期借地権を除く）

### 地代等増減請求権

- 地代等が経済事情の変動等により不相当となった → 当事者は将来に向かって増減を請求できる
- **一定期間増額しない**特約 → **有効**
- ⚠ **減額しない**特約 → **無効**（借地権者に不利）
- 増額請求で協議が調わない → 借地権者は、裁判確定までは**相当と認める額**を支払えば足りる（不足額は裁判確定後に年1割の利息を付して支払う）
- 減額請求で協議が調わない → 借地権設定者は、裁判確定までは相当と認める額の支払いを請求できる（超過額は年1割の利息を付して返還）

### 自己借地権

- 借地権設定者が自ら借地権者となることは原則としてできないが、**他の者と共に**有することとなるときは設定できる（例: 地主が建てたマンションの敷地に、自己と分譲購入者の準共有の借地権を設定）

## 2. 定期借地権 ★★

| 種類 | 存続期間 | 方式 | 利用目的 | 特徴 |
|------|----------|------|------|------|
| 一般定期借地権 | **50年**以上 | **書面**（公正証書でなくてもよい。電磁的記録も可） | 制限なし（居住用も可） | 更新なし・建物築造による延長なし・建物買取請求権なしの**特約** |
| 事業用定期借地権（30年以上50年未満） | **30年以上50年未満** | **公正証書** | **専ら事業用**（居住用不可） | 更新なし等を**特約で**定めることができる |
| 事業用借地権（10年以上30年未満） | **10年以上30年未満** | **公正証書** | **専ら事業用**（居住用不可） | 更新・延長・建物買取請求の規定は**当然に適用されない** |
| 建物譲渡特約付借地権 | **30年**以上 | 方式の制限なし（口頭でも可） | 制限なし | 設定後30年以上経過した日に建物を借地権設定者に**相当の対価**で譲渡する特約 |

- ⚠ **事業用**定期借地権は**公正証書**に限る（一般の書面では不可）／**一般**定期借地権は公正証書以外の書面でもよい
- ⚠ 事業用でも、**社宅**・**賃貸マンション**など居住用建物の所有を目的とする場合は不可
- 建物譲渡特約付借地権で借地権が消滅した後、建物の使用を継続している借地権者・建物賃借人が請求 → **期間の定めのない建物賃貸借**がされたものとみなす

## 3. 借家権 ★★★

### 適用範囲

- **建物**の賃貸借に適用（居住用・事業用を問わない）
- ⚠ **使用貸借**（無償）、**一時使用**のための建物賃貸借が明らかな場合には適用されない

### 存続期間

- **1年以上**（上限なし。民法の50年制限も適用されない）
- **1年未満**の期間を定めた場合 → **期間の定めのない**賃貸借とみなす（定期建物賃貸借を除く）

### 更新 ★★

- **期間の定めのある場合**:
  - 当事者が期間満了の**1年前から6か月前**までに、相手方に**更新をしない旨の通知**（又は条件を変更しなければ更新しない旨の通知）をしなければ → 従前と同一条件で**更新**したものとみなす（法定更新）
  - 賃貸人からの通知には**正当事由**が必要
  - 通知をした場合でも、期間満了後に賃借人が**使用を継続**し、賃貸人が**遅滞なく異議**を述べなかった → 更新したものとみなす
- **法定更新後**: **期間の定めのない**賃貸借になる（期間以外は従前と同一条件）
- **期間の定めのない場合**の解約申入れ:

| 申入れをする者 | 終了時期 | 正当事由 |
|---|---|---|
| **賃貸人** | 解約申入れの日から**6か月**経過 | **必要** |
| **賃借人** | 解約申入れの日から**3か月**経過（民法） | 不要 |

- 賃貸人の解約申入れ後も、6か月経過後に賃借人が使用を継続し、賃貸人が遅滞なく異議を述べなかった → 更新
- 正当事由の考慮要素: 賃貸人・賃借人（転借人を含む）が建物の使用を必要とする事情、従前の経過、建物の利用状況・現況、**立退料**の申出

### 対抗要件 ★★

- 賃借権の**登記**、又は**建物の引渡し**を受けていれば、その後にその建物について物権を取得した第三者に対抗可能（借地借家法31条）
- 登記がなくても引渡しで足りる

### 借賃増減請求権

- 借地の地代等と同様（一定期間**増額しない**特約は**有効**、**減額しない**特約は**無効**）
- ⚠ 定期建物賃貸借で借賃の改定に係る特約がある場合は、借賃増減請求権の規定は適用されない（減額しない特約も有効）

### 造作買取請求権

- 賃貸人の**同意**を得て付加した造作（畳・建具・エアコン等）、賃貸人から買い受けた造作 → 賃貸借が**期間満了**又は**解約申入れ**で終了するときに、賃貸人に**時価**で買取請求可能
- **特約で排除可能**（強行規定ではない）
- ⚠ 賃借人の**債務不履行**による解除で終了した場合は請求できない（判例）
- ⚠ 造作代金の支払いを受けるまで建物を**留置することはできない**（同時履行も否定・判例）
- 転借人も、賃貸人に対して造作買取請求ができる

### 転貸借の保護

- 建物の賃貸借が**期間満了**又は**解約申入れ**で終了する場合 → 賃貸人は**転借人に通知**しなければ、その終了を転借人に**対抗できない**
- 通知をしたとき → 転貸借は通知の日から**6か月**を経過することで終了
- ⚠ 賃借人の**債務不履行**で解除された場合 → 転借人に通知・催告をしなくても対抗できる（判例）
- 合意解除の場合 → 原則として転借人に対抗できない（民法613条）

### 居住用建物の賃貸借の承継

- 居住用建物の賃借人が**相続人なしに死亡** → 事実上の夫婦・養親子と同様の関係にあった**同居者**（内縁の配偶者等）が賃借人の権利義務を**承継**
- 同居者が相続人なしに死亡したことを知った後**1か月以内**に賃貸人に**反対の意思**を表示すれば承継しない
- ⚠ 相続人がいる場合は、相続人が賃借権を相続する（内縁の配偶者は相続人の賃借権を援用して居住できる・判例）

## 4. 定期建物賃貸借（定期借家）★★

| 項目 | 内容 |
|------|------|
| 方式 | **公正証書による等書面**（公正証書でなくてもよい。電磁的記録も可）+ **事前説明書面**の交付 |
| 期間 | 制限なし（**1年未満**も可能） |
| 更新 | なし（再契約は可能） |
| 中途解約 | 原則不可。ただし**居住用**で床面積**200㎡未満** + 転勤・療養・親族の介護等の**やむを得ない事情** → 賃借人から解約申入れでき、申入れの日から**1か月**で終了 |
| 終了通知 | 期間**1年以上**の場合、期間満了の**1年前から6か月前**まで（通知期間）に、賃貸人が期間満了により終了する旨を通知しなければ終了を対抗できない |

- **事前説明**: 賃貸人は、契約の前に、あらかじめ賃借人に対し、契約の更新がなく期間満了により終了する旨を記載した**書面を交付して説明**しなければならない（賃借人の承諾を得て**電磁的方法**による提供も可）
  - 説明書面は、契約書とは**別個独立**の書面であることが必要（判例）
  - 事前説明をしなかった場合 → 「更新がない」旨の定めは**無効**（普通借家になる）
- 通知期間の経過後に通知した場合 → 通知の日から**6か月**を経過した後は終了を対抗できる
- 期間1年未満の定期借家 → 終了通知は不要
- 賃借人に不利な特約（中途解約の制限・通知の省略等）は無効

### 取壊し予定の建物の賃貸借

- 法令又は契約により一定期間経過後に建物を取り壊すべきことが明らかな場合 → 建物を取り壊すこととなる時に賃貸借が終了する旨を定められる
- 特約は、取り壊すべき事由を記載した**書面**（電磁的記録も可）でしなければならない

## 5. 借地借家法の強行規定 ★

### 借地

- 借地権者に不利な特約は無効（9条、16条、21条等）
- 例: 存続期間を30年未満とする特約、更新を認めない特約、建物買取請求権を排除する特約（定期借地権を除く）

### 借家

- 建物の賃借人に不利な特約は無効（30条、37条等）
- 例: 正当事由なく賃貸人が解約できる特約、法定更新を排除する特約 → 無効
- 例外: **造作買取請求権の排除**は有効（任意規定）

## 6. 比較まとめ

| 項目 | 借地権 | 借家権 |
|------|--------|--------|
| 最短期間 | 30年（短い定めは30年） | 1年（1年未満は期間の定めなし） |
| 最長期間 | 制限なし | 制限なし |
| 対抗要件 | 借地上の**本人名義の登記建物** | 建物の**引渡し** |
| 更新拒絶 | 遅滞なく異議＋正当事由 | 1年前〜6か月前の通知＋正当事由 |
| 賃貸人からの解約申入れ | — | 6か月で終了（正当事由必要） |
| 買取請求 | 建物買取請求権（特約で排除不可） | 造作買取請求権（特約で排除可） |
| 定期の方式 | 一般定期: 書面／事業用: 公正証書／建物譲渡特約: 制限なし | 書面＋事前説明書面 |
