# 農地法

> 毎年1問出題。3条・4条・5条の許可権者と要件の違いが問われる。

## 1. 農地法の目的

- 農地の権利移動・転用を規制し、耕作者の地位の安定と農業生産力の増進を図る

## 2. 農地・採草放牧地の定義

- **農地**: 耕作の目的に供される土地（登記簿上の地目に関わらず、**現況**で判断）
  - 登記簿上の地目が「山林」「原野」でも、現に耕作されていれば農地
  - 現在耕作されていない**休耕地**・耕作放棄地も、いつでも耕作できる状態なら農地
  - ⚠ 住宅の庭先の**家庭菜園**は農地ではない
- **採草放牧地**: 農地以外の土地で、主として耕作又は養畜の事業のための採草又は家畜の放牧の目的に供される土地

## 3. 3条許可（権利移動）★★★

### 概要

- 農地又は採草放牧地について**権利の移転・設定**をする場合
- 農地→農地のまま、採草放牧地→採草放牧地のまま権利移動
- 採草放牧地を**農地にする**目的での権利移動も3条

### 許可権者

- **農業委員会**

### 許可が必要な場合

- **所有権**の移転（売買、**贈与**、交換、**競売**による取得、**相続人以外への特定遺贈**等）
- **賃借権**・**使用貸借**による権利・地上権・永小作権・質権の設定・移転
- ⚠ 相続人に対する特定遺贈・包括遺贈は許可不要

### 許可不要の場合

- **相続**・**遺産分割**・**包括遺贈**・**法人の合併**等
  - 許可は不要だが、権利を取得した者は**遅滞なく農業委員会に届出**が必要
- 権利を取得する者が**国・都道府県**である場合
- 土地収用法等による**収用**・使用
- 民事調停法による**農事調停**
- **抵当権**の設定（使用収益を目的とする権利ではないため）

### 許可の基準（許可できない主な場合）

- 権利を取得しようとする者又はその世帯員等が、取得後の農地の**全部を効率的に耕作**すると認められない
- 農地所有適格法人以外の**法人**が権利を取得しようとする場合（所有権の取得は不可）
  - ⚠ ただし、**賃借権・使用貸借**による権利の設定で、地域の他の農業者と適切に役割分担する等の要件を満たすときは、一般法人でも許可を受けられる（解除条件付き）
- 取得者又はその世帯員等が農作業に**常時従事**すると認められない（個人の場合）

### 許可なくした行為の効果

- **無効**（所有権等は移転しない）
- 罰則の対象

### ポイント

- 3条許可には**市街化区域の特例はない**（4条・5条と異なる）
  - 市街化区域内の農地でも、農地のまま売買すれば3条許可が必要
- 抵当権の設定には3条許可は不要
- 3条許可を受けた土地取引は、国土利用計画法の事後届出が**不要**

## 4. 4条許可（転用）★★★

### 概要

- **農地を農地以外**のものに転用する場合（自己の農地を転用）
- 権利移動を伴わない
- ⚠ 採草放牧地の転用は4条の対象外（許可不要）
- **一時的**な転用（工事の資材置場・駐車場として一時的に使用し、後で農地に戻す）でも許可が必要

### 許可権者と申請の流れ

- **都道府県知事**（農林水産大臣が指定する**指定市町村**では市町村長）
- 申請書は**農業委員会を経由**して知事等に提出 → 農業委員会は意見を付して知事等に送付
  - 30a超の転用は、農業委員会が都道府県機構（農業会議）の意見を聴く
- ※4haを超える場合でも知事等の許可に一元化（2016年4月施行。従前は農林水産大臣の許可）

### 市街化区域の特例 ★★

- 市街化区域内の農地 → あらかじめ**農業委員会に届出**をすれば許可不要
- ⚠ 届出先は知事ではなく**農業委員会**

### 許可不要の場合

- **国・都道府県等**が、道路・農業用用排水施設等の地域振興上・農業振興上必要性の高い施設の用に供するため転用する場合
  - ⚠ 国・都道府県等が**学校・病院・庁舎**等のために転用する場合は、知事等との**協議**が成立すれば許可があったものとみなされる（協議は必要）
- 土地収用法等により収用・使用した農地をその目的に供する場合
- 耕作の事業を行う者が、**2a（200㎡）未満**の農地を**農業用施設**（畜舎・農機具の格納庫等）に転用する場合
- 5条許可を受けた農地をその目的に供する場合

### 許可なくした行為の効果

- **原状回復命令**・工事の停止命令等の対象（知事等）
- 罰則の対象

## 5. 5条許可（転用目的の権利移動）★★★

### 概要

- **農地を農地以外**のもの、又は**採草放牧地を採草放牧地以外**のもの（農地を除く）にするため、権利の移転・設定をする場合
- 転用＋権利移動の両方を含む
- 例: 住宅を建てる目的で農地を購入する、駐車場にする目的で農地を借りる
- ⚠ 採草放牧地を**農地**にするための権利移動は5条ではなく**3条**

### 許可権者

- **都道府県知事**（指定市町村は市町村長）
- 申請は当事者（売主・買主）が**連署**して、**農業委員会を経由**して提出

### 許可の基準（許可できない主な場合）

- 申請者に転用行為を行うために必要な**資力及び信用**があると認められない
- 転用行為の妨げとなる権利を有する者の同意を得ていない
- 申請に係る用途に**遅滞なく**供すると認められない
- 周辺の農地の営農条件に支障を生ずるおそれがある

### 市街化区域の特例 ★★

- 市街化区域内の農地 → あらかじめ**農業委員会に届出**をすれば許可不要

### 許可不要の場合

- 国・都道府県等が、道路・農業用用排水施設等のために権利を取得する場合
- 土地収用法等による収用・使用
- 市街化区域内で農業委員会に届出をした場合
- ⚠ **抵当権の設定**は権利移動に当たらない → 3条・5条とも許可不要（市街化区域外でも同じ）
- ⚠ 市街化**調整**区域は市街化区域の特例の対象外 → 届出では足りず許可が必要

### 許可なくした行為の効果

- **無効**（権利移動としての効力が生じない）+ 原状回復命令等
- 罰則の対象

## 6. 3条・4条・5条の比較表 ★★★

| 項目 | 3条 | 4条 | 5条 |
|------|-----|-----|-----|
| 内容 | 権利移動（農地のまま） | 転用（自己所有地） | 転用目的の権利移動 |
| 許可権者 | **農業委員会** | **都道府県知事** | **都道府県知事** |
| 市街化区域の特例 | **なし** | 農業委員会に届出 | 農業委員会に届出 |
| 対象 | 農地＋採草放牧地 | **農地のみ** | 農地＋採草放牧地 |
| 国・都道府県 | 許可不要 | 一定の施設は許可不要／その他は協議 | 一定の施設は許可不要／その他は協議 |
| 許可なしの効果 | 無効 | 原状回復命令 | 無効＋原状回復命令 |

## 7. その他の規制

### 農地の賃貸借

- **対抗力**: 農地の賃貸借は、登記がなくても農地の**引渡し**があれば、その後に所有権を取得した第三者に対抗できる
- 存続期間: 最長**50年**（民法の賃貸借の規定による）
- 書面による契約: 当事者は賃貸借の存続期間・借賃等を**書面**で明らかにしなければならない

### 農地の賃貸借の解約等

- 賃貸借の解除・解約の申入れ・**合意解約**・**更新拒絶の通知** → 当事者は**知事の許可**が必要
- 許可不要の主な場合:
  - 農地を引き渡す期限前**6か月以内**に成立した**合意解約**で、その旨が**書面**で明らかなもの
  - **10年以上**の期間の定めがある賃貸借の**更新拒絶**の通知
- 許可不要で解約等をした場合 → **農業委員会に通知**
- 許可を受けないでした解約等は**無効**

### 罰則

- 無許可の権利移動・転用: **3年以下の拘禁刑又は300万円以下の罰金**
- 4条・5条違反（無許可転用）、原状回復命令違反 → 法人は**1億円以下**の罰金（法人重科）

> ※2025年6月1日施行の改正刑法により、従来の「懲役」と「禁錮」は「拘禁刑」に一本化されました。
