## 1. 個人情報保護法★最重要（一般知識の中で）

### 基本概念

| 用語 | 定義 |
|------|------|
| **個人情報** | 生存する個人に関する情報で、特定の個人を識別できるもの（氏名、生年月日等の記述等）又は個人識別符号が含まれるもの |
| **個人識別符号** | 指紋、顔認識データ、マイナンバー、パスポート番号等 |
| **要配慮個人情報** | 人種、信条、社会的身分、病歴、犯罪歴、障害等（不当な差別につながるおそれ）→ 取得に**本人の同意**が必要 |
| **仮名加工情報** | 他の情報と照合しない限り特定の個人を識別できないように加工した情報★2020年改正 |
| **匿名加工情報** | 特定の個人を識別できないように加工し、復元できないようにした情報 |
| **個人情報取扱事業者** | 個人情報データベース等を事業の用に供している者（法人・個人を問わない）★2015年改正で件数要件撤廃 |

### 個人情報取扱事業者の義務★頻出

| 義務 | 内容 |
|------|------|
| 利用目的の特定（17条） | できる限り具体的に特定 |
| 利用目的の制限（18条） | 特定した目的の範囲内で利用。範囲外利用には**本人の同意**が必要 |
| 適正な取得（20条） | 偽りその他不正の手段により取得してはならない |
| 取得時の利用目的の通知等（21条） | 速やかに本人に通知又は公表 |
| 正確性の確保（22条） | 利用目的の達成に必要な範囲内で正確かつ最新の内容に保つ |
| 安全管理措置（23条） | 個人データの漏えい等の防止 |
| 第三者提供の制限（27条） | 原則として**本人の同意**が必要 |
| 開示請求（33条） | 本人からの開示請求に応じる義務 |
| 訂正等（34条） | 本人からの訂正・追加・削除請求に応じる義務 |
| 利用停止等（35条） | 本人からの利用停止・消去請求に応じる義務 |

### 第三者提供の例外（本人の同意不要）

1. 法令に基づく場合
2. 人の生命・身体・財産の保護に必要で本人の同意を得ることが困難
3. 公衆衛生の向上・児童の健全な育成の推進に特に必要
4. 国の機関等への協力

### オプトアウト（27条2項）
- 一定の事項を個人情報保護委員会に届け出れば、本人の同意なく第三者提供可能
- ただし**要配慮個人情報はオプトアウト不可**

### 個人情報保護委員会
- 独立した行政機関（内閣府の外局）
- 監督権限: 報告徴求、立入検査、指導助言、勧告、命令

### 2020年・2022年改正のポイント
- 仮名加工情報の新設
- 個人関連情報の第三者提供規制
- 漏えい等報告・本人通知の義務化
- 法定刑の引上げ
- 越境移転の規制強化

## 4. 文章理解（3問）

### 出題パターン

| パターン | 内容 | 対策 |
|----------|------|------|
| 要旨把握 | 文章の主旨を問う | 結論・主張を探す |
| 空欄補充 | 文中の空欄に入る語句を選ぶ | 前後の文脈から論理的に推測 |
| 文章整序 | バラバラの文を正しい順序に並べる | 接続詞・指示語に注目 |

### 解法のコツ
1. **接続詞に注目**: 「しかし」「つまり」「したがって」等が文の論理構造を示す
2. **指示語に注目**: 「これ」「その」が何を指すか特定する
3. **消去法**: 明らかに誤りの選択肢から排除する
4. **筆者の主張を探す**: 「〜べきだ」「〜が重要だ」「〜ではないだろうか」等の表現
5. 練習量が成果に直結する科目。毎日1〜2問解く習慣をつける
