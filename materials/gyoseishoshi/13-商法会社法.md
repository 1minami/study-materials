# 商法・会社法（配点20点・5問）

## 商法総則・商行為

### 商人・商行為

| 概念 | 内容 |
|------|------|
| 固有の商人（商法4条1項） | 自己の名をもって商行為をすることを業とする者 |
| 擬制商人（商法4条2項） | 店舗等で物品の販売を業とする者 |

| 商行為の種類 | 内容 | 例 |
|-------------|------|-----|
| 絶対的商行為（501条） | 行為の性質上当然に商行為 | 投機売買、手形行為 |
| 営業的商行為（502条） | 営業としてするときに商行為 | 賃貸業、運送業、銀行取引 |
| 附属的商行為（503条） | 商人がその営業のためにする行為 | 商人の営業付随行為 |

### 名板貸し（商法14条・会社法9条）★頻出
- 自己の商号の使用を他人に許諾した者は、誤認して取引した**善意無過失の**第三者に対し連帯して弁済の責任を負う

### 商事時効・商事法定利率★改正で変更
- 商事消滅時効（旧商法522条）: **削除**→ 民法の消滅時効に統一（5年/10年）
- 商事法定利率（旧年6%）: **廃止**→ 民法の法定利率に統一（年3%、変動制）

## 会社法

### 会社の種類

| 種類 | 特徴 | 社員の責任 |
|------|------|-----------|
| **株式会社** | 所有と経営の分離、株式の譲渡可能 | 間接有限責任 |
| 合名会社 | 社員全員が無限責任社員 | 無限責任 |
| 合資会社 | 無限責任社員＋有限責任社員 | 混合 |
| **合同会社** | 社員全員が有限責任社員 | 間接有限責任 |

合名・合資・合同会社 = **持分会社**（組織法制で一括規律）

---

### 株式会社の設立（25-103条）★頻出

#### 設立方法

| | 発起設立（25条1項1号） | 募集設立（25条1項2号） |
|---|---|---|
| 株式引受 | 発起人が全株式を引受け | 発起人以外にも引受けを募集 |
| 利用頻度 | 実務上ほとんどこちら | まれ |
| 創立総会 | 不要 | 必要（65条） |

#### 定款の絶対的記載事項（27条）★頻出

1. **目的**
2. **商号**
3. **本店の所在地**
4. 設立に際して出資される**財産の価額又はその最低額**
5. **発起人の氏名又は名称及び住所**

※ 定款は**公証人の認証**が必要（30条）

#### 変態設立事項（28条）★頻出
定款に記載しなければ効力を生じない（検査役の調査対象）

1. 現物出資（金銭以外の財産の出資）
2. 財産引受け（会社成立後に特定の財産を譲り受ける契約）
3. 発起人の報酬その他の特別の利益
4. 設立費用

#### 設立の無効
- **設立無効の訴え（828条1項1号）**: 設立の日から2年以内に株主等が訴えで主張
- 将来に向かって効力を失う（形成判決）

---

### 株式★頻出

**株主の権利**

| 分類 | 権利 |
|------|------|
| **自益権** | 剰余金配当請求権（453条）、残余財産分配請求権（504条） |
| **共益権** | 議決権（308条）、株主代表訴訟提起権（847条）、株主総会招集請求権（297条） |
| 単独株主権 | 1株でも行使可能（議決権、代表訴訟等） |
| 少数株主権 | 一定割合以上の保有が必要（株主総会招集請求=3%以上等） |

**株式譲渡の自由と制限**
- 原則: 株式は**自由に譲渡**できる（127条）
- 例外: **譲渡制限株式**（107条1項1号・108条1項4号）→ 譲渡に**取締役会（又は株主総会）の承認**が必要

---

### 機関★最重要

#### 機関設計のパターン★頻出

| | 公開会社 | 非公開会社 |
|---|---|---|
| **大会社** | 取締役会＋監査役会＋会計監査人（必置）or 指名委員会等設置 or 監査等委員会設置 | 取締役会＋監査役＋会計監査人（会計監査人は必置） |
| **非大会社** | 取締役会＋監査役（必置） | **取締役1人以上**で足りる（最小構成） |

※ 大会社 = 資本金5億円以上 or 負債200億円以上
※ 公開会社 = 譲渡制限のない株式を発行する会社（上場会社とは異なる概念）
※ 公開会社は取締役会を必ず設置

#### 株主総会（295-320条）

**権限（295条）**:
- 取締役会設置会社: 会社法に規定する事項＋定款で定めた事項
- 取締役会非設置会社: 一切の事項

**招集通知（299条）**

| 区分 | 期間 |
|------|------|
| 公開会社 | **2週間前**まで |
| 非公開会社（取締役会設置） | **1週間前**まで |
| 非公開会社（取締役会非設置） | **1週間前**まで（定款で短縮可） |

**決議要件★超頻出**

| 決議 | 定足数 | 表決数 | 主な対象 |
|------|--------|--------|----------|
| **普通決議（309条1項）** | 議決権の**過半数**出席 | 出席議決権の**過半数** | 役員の選任・解任、剰余金配当等 |
| **特別決議（309条2項）** | 議決権の**過半数**出席 | 出席議決権の**2/3以上** | 定款変更、事業譲渡、合併承認、譲渡制限株式の承認等 |
| **特殊決議（309条3項）** | 議決権の**半数以上**の株主 | 議決権の**2/3以上** | 全部の株式に譲渡制限を付す定款変更 |

**決議の瑕疵★頻出**

| 訴えの種類 | 瑕疵の内容 | 出訴期間 | 原告 |
|-----------|-----------|---------|------|
| **決議取消しの訴え（831条）** | 招集手続・決議方法の法令定款違反、特別利害関係人の議決権行使 | 決議の日から**3ヶ月以内** | 株主・取締役等 |
| **決議無効確認の訴え（830条2項）** | 決議**内容**の法令違反 | 制限なし | 誰でも |
| **決議不存在確認の訴え（830条1項）** | 決議自体が存在しない | 制限なし | 誰でも |

#### 取締役（330-373条）

| 項目 | 内容 |
|------|------|
| 任期 | 原則**2年**。非公開会社は定款で**10年**まで延長可能（332条） |
| 義務 | 善管注意義務（330条→民法644条）、忠実義務（355条） |
| 競業取引の制限（356条1項1号） | 取締役会（又は株主総会）の承認が必要 |
| 利益相反取引の制限（356条1項2・3号） | 取締役会（又は株主総会）の承認が必要 |

**取締役会（362条）**:
- 決議: 議決に加わることができる取締役の**過半数**が出席＋出席取締役の**過半数**（369条）
- 代表取締役の選定（362条3項）

#### 監査役
- 任期: **4年**（短縮不可）（336条1項）
- 権限: 業務監査＋会計監査（381条）
- 非公開会社の監査役: 定款で**会計監査に限定**可能（389条）

---

### 取締役の責任★頻出

**任務懈怠責任（423条1項）**: 取締役が任務を怠ったときは会社に対し損害賠償責任

**株主代表訴訟（847条）**★頻出

| 項目 | 内容 |
|------|------|
| 原告適格 | 6月前から引き続き株式を有する株主（公開会社の場合。非公開会社は不要） |
| 手続 | ① 会社に対し**提訴請求**（847条1項）→ ② **60日**経過しても会社が訴えを提起しない場合に株主が提訴（847条3項） |
| 例外 | 会社に回復不能の損害が生じるおそれがある場合は60日の待機不要（847条5項） |

**経営判断原則（判例法理）**: 取締役の経営判断については、判断の過程・内容に著しく不合理な点がない限り、善管注意義務違反にならない

### 責任の免除・一部免除

| 方法 | 要件 |
|------|------|
| 総株主の同意（424条） | 全額免除 |
| 株主総会の特別決議（425条） | 最低責任限度額まで一部免除 |
| 定款の定めに基づく取締役会決議（426条） | 同上（取締役会設置会社のみ） |
| 責任限定契約（427条） | 社外取締役・社外監査役等と事前に締結 |
