# 地方自治法★頻出（5問前後出題）

## 1. 地方自治の基本原理

| 概念 | 内容 |
|------|------|
| **団体自治** | 地方公共団体が国から独立して自治を行う（対国家の自律性） |
| **住民自治** | 地方の行政が住民の意思に基づいて行われる（民主主義的要素） |

### 地方公共団体の種類

| 分類 | 種類 |
|------|------|
| 普通地方公共団体 | 都道府県、市町村 |
| 特別地方公共団体 | 特別区、地方公共団体の組合、財産区 |

---

## 2. 条例制定権★頻出

### 根拠
- **憲法94条**: 地方公共団体は法律の範囲内で条例を制定できる
- **地方自治法14条1項**: 法令に違反しない限りにおいて条例を制定できる

### 条例と法律の関係
- **徳島市公安条例事件（最大判昭50.9.10）**: 条例が国の法令に違反するかは、両者の趣旨・目的・内容・効果を比較して判断する

### 条例で定められる事項

| 項目 | 内容 |
|------|------|
| 権利義務の規制 | 義務を課し、又は権利を制限するには**条例による**必要あり（14条2項） |
| 罰則 | **2年以下の懲役・禁錮、100万円以下の罰金、拘留、科料、没収、5万円以下の過料**（14条3項） |
| 長の規則 | 長は法令に違反しない限りにおいて規則を制定できる（15条） |

## 3. 議会（89-138条）

### 議会の権限

| 権限 | 内容 | 条文 |
|------|------|------|
| **議決権** | 条例の制定改廃、予算の議決、決算の認定等 | 96条 |
| **検閲検査権** | 書類の検閲、事務の検査 | 98条1項 |
| **監査請求権** | 監査委員に監査を求める | 98条2項 |
| **調査権** | 事務に関する調査（100条調査権） | 100条 |
| **意見書提出権** | 国会又は関係行政庁に意見書を提出 | 99条 |
| **同意権** | 副知事等の選任への同意 | |

### 議決事件（96条1項）★頻出

1. 条例の制定・改廃
2. 予算の議決
3. 決算の認定
4. 法律・政令に基づく使用料等の徴収
5. 条例で定める契約の締結
6. 条例で定める財産の取得・処分
7. 損害賠償の額の決定
8. 権利の放棄 等（全15号）

### 会議の原則

| 原則 | 内容 |
|------|------|
| 定足数 | 議員の**半数以上**が出席（113条） |
| 表決 | 出席議員の**過半数**で決定、可否同数は議長が決定（116条） |
| 会議公開の原則 | 原則公開（115条）、秘密会は出席議員の2/3以上の多数 |

## 4. 長と執行機関

### 長の権限

| 条文 | 権限 |
|------|------|
| 147条 | **統轄代表権**: 地方公共団体を統轄し代表する |
| 148条 | 事務の管理・執行 |
| 149条 | **担任事務**: 予算の調製・執行、議案の提出、規則の制定等 |
| 15条 | **規則制定権** |
| 154条 | 職員の指揮監督権 |

### 長と議会の関係★超頻出

#### 再議制度

| 種類 | 要件 | 再議に付す期限 | 議会の再議決要件 |
|------|------|---------------|-----------------|
| **一般再議（176条1項）** | 長が議決に異議がある場合 | 送付を受けた日から**10日以内** | 出席議員の**2/3以上** |
| **違法再議（176条4項）** | 議決が法令に違反すると認める場合 | 理由を示して | 再議決しても長が違法と認める場合 → 都道府県は総務大臣、市町村は都道府県知事に審査申立て |
| **義務的経費の削除・減額（177条1項）** | 法定の経費を削除・減額した場合 | 理由を示して再議に付す | 再議に付しても同じ議決の場合 → 長がその経費等を予算に計上して執行可能 |

#### 不信任議決と解散（178条）★超頻出

```
議会が長の不信任議決
（議員数の2/3以上の出席 ＋ 出席議員の3/4以上の同意）
  ↓
長は通知を受けた日から10日以内に議会を解散できる
  ↓
【解散した場合】→ 選挙後の初議会で再度不信任議決
 （出席議員の過半数で足りる）→ 長は失職
  ↓
【解散しなかった場合】→ 10日を経過した日に長は失職
```

### 補助機関

| 機関 | 選任方法 | 定数 |

## 5. 直接請求制度★超頻出

| 請求の種類 | 必要署名数 | 請求先 | 手続 |
|-----------|-----------|--------|------|
| **条例の制定改廃の請求（74条）** | 有権者の**1/50**以上 | **長** | 長が20日以内に議会を招集し付議。長は意見を付す |
| **事務の監査請求（75条）** | 有権者の**1/50**以上 | **監査委員** | 監査委員が監査を実施 |
| **議会の解散請求（76条）** | 有権者の**1/3**以上★ | **選挙管理委員会** | 住民投票で**過半数**の同意→解散 |
| **議員の解職請求（80条）** | 有権者の**1/3**以上★ | **選挙管理委員会** | 住民投票で**過半数**の同意→解職 |
| **長の解職請求（81条）** | 有権者の**1/3**以上★ | **選挙管理委員会** | 住民投票で**過半数**の同意→解職 |
| **主要公務員の解職請求（86条）** | 有権者の**1/3**以上★ | **長** | **議会**で議員の2/3以上出席＋3/4以上の同意→解職 |

★ 有権者数が**40万**を超える部分は**1/6**に緩和（大規模自治体の特例）

**注意点**:
- 条例の制定改廃請求から除外: **地方税の賦課徴収・分担金等に関する条例**
- 主要公務員: 副知事・副市町村長、選挙管理委員、監査委員、公安委員会委員

## 6. 住民監査請求と住民訴訟★超頻出

### 住民監査請求（242条）

| 項目 | 内容 |
|------|------|
| 請求権者 | **住民であれば1人でも可能**（選挙権不要、法人も可） |
| 対象 | 違法又は**不当**な財務会計上の行為（公金の支出、財産の管理処分、契約の締結履行、債務の負担、公金の賦課徴収の怠り等） |
| 期間 | 当該行為のあった日又は終わった日から**1年以内**（正当な理由があれば例外） |
| 監査結果 | 60日以内に通知 |

### 住民訴訟（242条の2）

| 項目 | 内容 |
|------|------|
| 前提 | **住民監査請求を経ていること**（前置主義）★超重要 |
| 原告適格 | 住民監査請求をした住民 |
| 出訴期間 | 監査結果通知から**30日以内** |
| 対象 | 違法な財務会計上の行為（**不当は対象外**→行政訴訟なので違法性のみ審査） |

### 住民訴訟の4類型（242条の2第1項）

| 号 | 内容 |
|----|------|
| 1号請求 | 行為の差止め請求 |
| 2号請求 | 行政処分の取消し又は無効確認請求 |
| 3号請求 | 怠る事実の違法確認請求 |
| **4号請求** | 職員等に対する**損害賠償請求・不当利得返還請求**を地方公共団体に代位して行う★最重要 |

### 住民監査請求 vs 住民訴訟

| | 住民監査請求 | 住民訴訟 |
|---|---|---|
| 審査機関 | 監査委員 | 裁判所 |
| 審査範囲 | 違法 ＋ **不当** | 違法のみ |
| 請求者 | 住民1人でも可 | 住民監査請求をした住民 |
| 前置 | 不要 | **住民監査請求前置** |
| 期間 | 行為から1年以内 | 監査結果通知から30日以内 |

## 7. 公の施設（244条-244条の4）

| 条文 | 内容 |
|------|------|
| 244条1項 | 公の施設: 住民の福祉を増進する目的をもってその利用に供するための施設 |
| 244条2項 | **正当な理由**がない限り、住民が利用することを拒んではならない |
| 244条3項 | 住民に対して**不当な差別的取扱い**をしてはならない |
| 244条の2第3項 | **指定管理者制度**: 条例の定めにより法人その他の団体に管理を行わせることができる |
| 244条の2第6項 | 公の施設の**廃止**・**長期独占的利用**: 議会の出席議員の**2/3以上の同意**が必要 |
