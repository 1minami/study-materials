# 行政手続法（行政法の重要法令①）★超頻出

## 1. 総則（1-4条）

- **目的（1条）**: 行政運営における**公正の確保**と**透明性の向上**を図り、もって国民の権利利益の保護に資する

### 適用除外（3条1項）
- 国会の両院・各議院・議員、裁判所の裁判官の行為
- 検査官会議の決定、会計検査
- 刑事事件の捜査、租税の賦課徴収等

### 地方公共団体への適用（3条3項・46条）

| 行為類型 | 地方公共団体への適用 |
|----------|---------------------|
| 処分（申請に対する処分・不利益処分） | **適用あり**（法律に基づく処分のみ） |
| 行政指導 | **適用あり** |
| 届出 | **適用あり** |
| 命令等制定手続（意見公募手続） | **適用なし**（努力義務：46条） |

※ 条例・規則に基づく処分・行政指導は行政手続法の適用対象外 → 各地方公共団体が行政手続条例で対応

---

## 2. 申請に対する処分（5-11条）

| 条文 | 内容 | 義務/努力義務 |
|------|------|--------------|
| 5条 | **審査基準**の設定 | **義務** |
| 5条3項 | 審査基準の**公表** | **義務**（行政上特別の支障がない限り） |
| 6条 | **標準処理期間**の設定 | **努力義務** |
| 6条 | 標準処理期間の**公表** | **義務**（定めた場合は公にする） |
| 7条 | 申請の**到達主義** | 到達した時点で審査開始義務発生 |
| 8条 | **理由の提示** | **義務**（拒否処分の場合） |
| 9条1項 | 情報の提供 | **努力義務** |
| 9条2項 | 申請者が求めた場合の進行状況の情報提供 | **努力義務** |
| 10条 | 公聴会の開催等 | 努力義務的規定 |
| 11条 | 複数の行政庁が関与する処分の迅速処理 | **努力義務** |

**ポイント**:
- 申請が到達したら遅滞なく審査を開始しなければならない（7条）
- 申請の形式上の要件に適合しない場合: ① 補正を求める or ② 拒否処分（7条後段）

## 3. 不利益処分（12-31条）★超頻出

### 処分基準（12条）

| 項目 | 義務/努力義務 |
|------|--------------|
| 処分基準の設定 | **努力義務** |
| 処分基準の公表 | **努力義務** |

※ 審査基準（申請に対する処分）は設定・公表とも**義務**であるのに対し、処分基準は**いずれも努力義務**

### 不利益処分の手続の選択（13条）★超頻出

| 手続 | 対象となる不利益処分 |
|------|---------------------|
| **聴聞** | ① 許認可等の取消し ② 資格・地位の直接剥奪 ③ 法人の役員解任命令・法人等の設立認可取消し ④ その他行政庁が聴聞が相当と認めた場合 |
| **弁明の機会の付与** | 上記以外の不利益処分 |

### 理由の提示（14条）
- 不利益処分をする場合、理由を示さなければならない（**義務**）
- 差し迫った必要がある場合は処分後に理由を示すことができる

### 聴聞と弁明の機会の付与の比較★超頻出

| 項目 | 聴聞 | 弁明の機会の付与 |
|------|------|-----------------|
| 対象 | 重い不利益処分 | それ以外の不利益処分 |
| 方式 | 口頭審理が原則（20条） | 書面が原則（29条） |
| 主宰者 | 行政庁が指名する職員（19条） | 規定なし |
| 代理人 | 選任可能（16条） | 選任可能（31条→16条準用） |
| 参加人 | あり（17条） | なし |
| 文書等の閲覧 | あり（18条） | なし |
| 聴聞調書・報告書 | 作成義務あり（24条） | なし |
| 不服申立て制限 | 聴聞を経た不利益処分は審査請求不可の場合あり（27条2項→行審法適用なし） | 制限なし |

### 聴聞手続の流れ

```
① 聴聞の通知（15条）: 処分の原因事実・聴聞の期日・場所等を書面で通知
  ↓ （相当な期間をおいて）
② 文書等の閲覧（18条）: 当事者・参加人は関係書類の閲覧を請求できる
  ↓
③ 聴聞期日の審理（20条）: 意見陳述・証拠書類の提出・質問
  ↓
④ 聴聞調書・報告書の作成（24条）: 主宰者が作成
  ↓
⑤ 行政庁の判断（26条）: 聴聞調書・報告書を十分に参酌して処分を決定
```

## 4. 行政指導（32-36条の2）

| 条文 | 内容 |
|------|------|
| 32条1項 | 行政指導の一般原則: 任務又は所掌事務の範囲内で行う |
| 32条2項 | 行政指導に従わないことを理由に不利益な取扱いをしてはならない |
| 33条 | 申請の取下げ・内容の変更を求める行政指導: 申請者が従わない意思を表示したにもかかわらず継続してはならない |
| 34条 | 許認可等の権限に関連する行政指導: 権限を行使できる旨を殊更に示してはならない |
| 35条1項 | 行政指導の方式: 趣旨・内容・責任者を明示 |
| 35条2項 | 口頭の行政指導について、相手方が書面の交付を求めたら書面を交付しなければならない |
| 36条 | 複数の者を対象とする行政指導: **指導指針**を定め公表する（努力義務） |
| **36条の2** | **行政指導の中止等の求め**★2014年改正で新設 |

### 行政指導の中止等の求め（36条の2）★重要

- 法令に違反する行為の是正を求める行政指導の相手方は、当該行政指導が法律の要件に適合しないと思料するときは、行政指導の中止等を求めることができる
- 申出先: 当該行政指導をした行政機関
- 申出を受けた行政機関: 必要な調査を行い、行政指導が法律の要件に適合しないと認めるときは中止等の措置をとる

---

## 5. 届出（37条）

- **到達主義**: 届出が届出先の機関の事務所に到達したときに届出の義務は履行されたものとする
- 届出が形式上の要件に適合している限り、行政庁は受理を拒否できない
- 届出 ≠ 申請（届出は一方的な通知、申請は許認可等を求める行為）

---

## 6. 意見公募手続（パブリックコメント）（38-45条）

### 対象: 命令等の制定

**「命令等」の定義（2条8号）**
- 法律に基づく命令（政令・省令等）
- 審査基準・処分基準
- 行政指導指針

### 手続の流れ

```
① 命令等の案及び関連資料の公示
  ↓
② 意見公募期間: 30日以上
  ↓
③ 提出された意見の考慮
  ↓
④ 結果の公示（提出された意見＋それに対する考え方を含む）
```

### 適用除外（39条4項）
- 公益上緊急に命令等を定める必要がある場合
- 委員会等の議を経て定める命令等
- 法律の施行期日を定める政令等
- 他の行政機関が意見公募手続を実施して定めた命令等に基づく場合

---

## 7. 処分等の求め（36条の3）★2014年改正で新設

- **何人も**、法令に違反する事実を発見した場合、権限ある行政庁に対し、処分又は行政指導を求めることができる
- 申出を受けた行政庁: 必要な調査を行い、必要があると認めるときは処分又は行政指導を行う
- 「何人も」= 利害関係の有無を問わない

---

## 重要な比較表

### 審査基準 vs 処分基準

| | 審査基準（5条） | 処分基準（12条） |
|---|---|---|
| 対象 | 申請に対する処分 | 不利益処分 |
| 設定 | **義務** | **努力義務** |
| 公表 | **義務** | **努力義務** |

### 聴聞 vs 弁明 vs 意見公募手続

| | 聴聞 | 弁明 | 意見公募手続 |
|---|---|---|---|
| 場面 | 重い不利益処分 | 軽い不利益処分 | 命令等の制定 |
| 方式 | 口頭が原則 | 書面が原則 | 書面提出 |
| 期間 | 相当な期間 | 相当な期間 | 30日以上 |

### 2014年改正で新設された制度

| 制度 | 条文 | 内容 |
|------|------|------|
| 行政指導の中止等の求め | 36条の2 | 行政指導の相手方が中止等を求められる |
| 処分等の求め | 36条の3 | 何人も法令違反の事実を通報し処分等を求められる |
