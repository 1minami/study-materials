# 民法債権（民法第3編）★2020年大改正

## 1. 債務不履行（415条）★頻出

### 類型
- **履行遅滞**: 履行期に履行しない
- **履行不能**: 履行が不可能になった
- **不完全履行**: 履行はしたが不完全

### 損害賠償（415条）★改正
- 帰責事由の判断: 「**契約その他の債務の発生原因及び取引上の社会通念**に照らして」判断
- 債務者の帰責事由がない場合は免責

### 損害賠償の範囲（416条）
- **通常損害**: 債務不履行から通常生ずべき損害
- **特別損害**: 特別の事情によって生じた損害で、当事者がその事情を**予見すべきであった**とき★改正

## 2. 債権者代位権（423条）★改正で大幅整備

| 項目 | 内容 |
|------|------|
| 要件 | ① 被保全債権の存在 ② 債務者が自ら権利を行使しない ③ 保全の必要性 |
| 行使方法 | 自己の名で債務者の権利を行使（423条の2で裁判上・裁判外いずれも可） |
| 直接引渡し | 金銭等は**直接自己への引渡し**を請求可能（423条の3）★改正で明文化 |
| 範囲 | 被保全債権の額の限度（423条の2） |
| 行使できない権利 | 一身専属権（423条1項ただし書き）、差押禁止債権 |

### 転用型（登記請求権の代位行使等）
- 明文規定なし。判例法理を維持

## 3. 詐害行為取消権（424条）★改正で大幅整備

| 項目 | 内容 |
|------|------|
| 要件 | ① 被保全債権（**詐害行為前**に発生）② 詐害行為 ③ 債務者の悪意 ④ 受益者の悪意 |
| 行使方法 | **訴えによる**（裁判上の行使のみ） |
| 出訴期間 | 知った時から**2年**、行為時から**10年**（426条）★改正で延長 |

### 2020年改正の新設規定

| 条文 | 内容 |
|------|------|
| 424条の2 | **相当価格処分行為の特則**: 要件が加重（隠匿等の処分のおそれ等） |
| 424条の3 | **偏頗行為の特則**: 支払不能時等に特定の債権者に弁済等をした場合 |
| 424条の5 | **転得者に対する取消し**: 転得者が悪意の場合 |

## 5. 債権譲渡（466-469条）★改正

| 項目 | 旧法 | 新法 |
|------|------|------|
| 譲渡制限特約の効力 | 特約違反の譲渡は無効（判例） | **特約があっても譲渡は有効**（466条2項）★ |
| | | 悪意又は重過失の第三者には債務者は履行拒絶可能（466条3項） |
| 将来債権の譲渡 | 判例で認容 | **明文化**（466条の6）★ |

**対抗要件（467条）**:
- 債務者に対する対抗要件: 譲渡人からの**通知**又は債務者の**承諾**
- 第三者に対する対抗要件: **確定日付のある証書**による通知又は承諾

## 6. 契約総論

### 危険負担（536条）★改正

| 項目 | 旧法 | 新法 |
|------|------|------|
| 特定物の債権者主義（534条） | 債権者が負担 | **廃止**★ |
| 債務者主義（536条） | - | 反対給付の**履行拒絶権**★（消滅ではない） |

### 契約の解除★改正

| 項目 | 旧法 | 新法 |
|------|------|------|
| 帰責事由 | 必要（債務者に帰責事由がないと解除不可） | **不要**★（帰責事由がなくても解除可能） |
| 催告解除（541条） | - | 相当の期間を定めて催告→不履行が軽微でないとき解除可能 |
| 無催告解除（542条） | 限定的 | **要件を明確化**★（全部又は一部の履行不能等） |

**解除の効果（545条）**: 遡及的に契約が消滅。原状回復義務
- 第三者の権利を害することはできない（545条1項ただし書き）

### 定型約款（548条の2-548条の4）★2020年新設

- **定型約款**: 不特定多数を相手方として行う取引の内容を画一的に定めた条項の総体
- みなし合意（548条の2）: 定型取引の合意 + 定型約款を契約の内容とする旨の合意等があれば各条項に合意したとみなす
- **不当条項の排除（548条の2第2項）**: 相手方の利益を一方的に害する条項は合意しなかったものとみなす
- **変更（548条の4）**: 相手方の一般の利益に適合するとき等に一方的変更可能
