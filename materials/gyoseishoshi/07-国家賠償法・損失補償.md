# 国家賠償法・損失補償

## 1. 国家賠償法1条（公権力の行使に基づく賠償）★頻出

### 要件（5つ）

1. **国又は公共団体の公権力の行使**に当たる公務員が
2. その**職務を行うについて**
3. **故意又は過失**によって
4. **違法に**
5. 他人に**損害**を加えたとき

### 各要件の解説

**「公権力の行使」の範囲**
- **広義説（判例・通説）**: 純粋な私経済作用と国賠2条の対象を除く、すべての行政作用を含む
- 権力的作用だけでなく、非権力的作用（行政指導・公立学校の教育活動等）も含む

**「職務を行うについて」**
- **外形標準説（判例）**: 客観的に職務行為の外形を備えていればよい
- 主観的に職務を行う意思がなくても、外形上職務行為と認められれば該当
- 例: 非番の警察官が制服を着用して犯罪を行った場合 → 該当する

**「違法に」**
- **職務行為基準説（判例）**: 公務員が職務上通常尽くすべき注意義務を尽くすことなく漫然と行為した場合に違法
- 結果違法ではなく、行為の態様から判断

**公務員の個人責任**
- **否定（最判昭30.4.19）**: 公務員個人は被害者に対して直接損害賠償責任を負わない
- 国又は公共団体が賠償責任を負う

**求償権（1条2項）**
- 国又は公共団体は、公務員に**故意又は重大な過失**があった場合に限り、求償権を有する
- 軽過失の場合は求償不可

### 重要判例

| 判例 | 争点 | 結論 |
|------|------|------|
| 在宅投票制度廃止事件（最判昭60.11.21） | 立法不作為と国賠 | 違法とならない（例外的場合を除き） |
| 在外邦人選挙権訴訟（最大判平17.9.14） | 立法不作為の違法 | 違法（国民の権利行使の機会を確保しなかった立法不作為は国賠法上違法） |
| 筑豊じん肺訴訟（最判平16.4.27） | 規制権限の不行使 | 違法（規制権限の不行使が著しく合理性を欠く場合は国賠法上違法） |
| 関西水俣病訴訟（最判平16.10.15） | 規制権限の不行使 | 違法 |
| 芦別国賠訴訟（最判昭53.10.20） | 逮捕・勾留と国賠 | 無罪判決＝違法とは限らない |

## 2. 国家賠償法2条（公の営造物の設置管理の瑕疵）★頻出

### 要件

1. **公の営造物**の
2. **設置又は管理に瑕疵**があったために
3. 他人に**損害**を生じたとき

### 特徴: **無過失責任**（1条と異なり過失は不要）

### 各要件の解説

**「公の営造物」**
- 道路、河川、港湾、公園、学校、公立病院等の有体物
- 動産も含む（パトカー、消防車等）
- 国又は公共団体が**設置・管理**するもの（所有権の有無は問わない）

**「瑕疵」**
- **客観説（判例）**: 通常有すべき安全性を欠いていること
- 営造物自体の物理的欠陥だけでなく、利用者以外の第三者の行為による場合も含む

### 重要判例

| 判例 | 争点 | 結論 |
|------|------|------|
| 高知落石事件（最判昭45.8.20） | 道路の瑕疵（落石防止設備なし） | 国賠2条の責任あり。**予算不足は抗弁にならない** |
| 大東水害訴訟（最判昭59.1.26） | 河川の管理の瑕疵 | 河川の特殊性：**過渡的安全性論**（改修の段階に応じた安全性で足りる） |
| 多摩川水害訴訟（最判平2.12.13） | 河川管理の瑕疵 | 同様の過渡的安全性論を適用 |
| 赤色灯事件 | 道路に放置された故障車の赤色灯 | 道路管理の瑕疵 |

## 3. 国家賠償法3-6条

| 条文 | 内容 |
|------|------|
| 3条 | **費用負担者の責任**: 設置費用を負担する者も賠償責任を負う（設置者と費用負担者が異なる場合） |
| 4条 | **民法の適用**: 国賠法に定めがない場合は民法の規定による |
| 5条 | **他の法律の適用**: 民法以外の法律に別段の定めがある場合はそちらによる |
| 6条 | **外国人への適用**: **相互保証主義**（その外国人の本国が日本人に同様の保護を与える場合のみ適用） |

## 4. 損失補償

### 憲法上の根拠
- **憲法29条3項**: 「私有財産は、正当な補償の下に、これを公共のために用ひることができる」

### 損失補償の要件: **特別の犠牲**

| 判断基準 | 内容 |
|----------|------|
| 形式的基準 | 特定の人に対する侵害か、一般的な制約か |
| 実質的基準 | 財産権の本質的内容を侵害するほどの強度の制約か |

両基準を総合的に判断して「特別の犠牲」に当たるかを決定

### 補償の内容

| 学説 | 内容 | 判例 |
|------|------|------|
| 完全補償説 | 市場価格の全額を補償 | 土地収用の場合（最判昭48.10.18） |
| 相当補償説 | 合理的に算出された相当な額 | 農地改革事件（最大判昭28.12.23） |

- 土地収用: 完全補償が必要（判例）
- 農地改革: 相当補償で足りる（判例）→ 社会政策的措置の場合

### 直接憲法29条3項に基づく補償請求
- 法律に補償規定がない場合でも、憲法29条3項に基づいて直接補償を請求できる（通説・河川附近地制限令事件：最大判昭43.11.27）

### 国家賠償と損失補償の谷間
- 適法な行為によって特定の者に損害が生じたが、損失補償の規定がない場合
- 例: **予防接種禍訴訟** → 国賠1条で対応（過失認定）or 29条3項に基づく損失補償

## 国家賠償法1条 vs 2条 比較

| | 1条（公権力の行使） | 2条（営造物の設置管理） |
|---|---|---|
| 行為主体 | 公務員 | 営造物 |
| 責任の性質 | **過失責任** | **無過失責任** |
| 「違法」の要件 | 必要 | 不要（瑕疵があれば足りる） |
| 主観的要件 | 故意又は過失 | 不要 |
| 求償権 | 故意又は重過失の場合 | 規定なし（解釈による） |
