# 民法 親族・相続（民法第4編・第5編）★記述式でも出題

## 親族編

### 婚姻

**婚姻の成立要件**

| 要件 | 内容 |
|------|------|
| 婚姻意思の合致 | 法律上の夫婦関係を形成する意思 |
| 婚姻適齢 | **18歳**（731条）★2022年改正で男女とも18歳に統一 |
| 重婚の禁止 | 配偶者のある者は重ねて婚姻不可（732条） |
| 再婚禁止期間 | **廃止**★2024年改正 |
| 近親婚の禁止 | 直系血族・3親等内の傍系血族間は婚姻不可（734条） |
| 届出 | 婚姻届の提出（739条）= 形式的要件 |

**離婚の原因（770条1項）**:
1. 不貞行為
2. 悪意の遺棄
3. 3年以上の生死不明
4. 強度の精神病で回復の見込みなし
5. その他婚姻を継続し難い重大な事由

**有責配偶者からの離婚請求**: 判例は長期間の別居＋未成熟子なし＋相手方が過酷な状況に置かれない場合に例外的に認容

### 親子

**嫡出推定（772条）**★2024年改正

| 項目 | 旧法 | 新法 |
|------|------|------|
| 推定 | 婚姻中に懐胎→夫の子と推定 | 同様 |
| 再婚後の推定 | 規定なし（前婚・後婚の推定が重なる問題あり） | 再婚後に生まれた子は**再婚後の夫の子**と推定★ |
| 嫡出否認の訴え | 夫のみ | **夫・母・子**にも否認権★ |
| 否認権の行使期間 | 子の出生を知った時から1年 | 原則**3年**に延長★ |

### 親権
- 親権は父母が共同して行使（818条3項）
- 利益相反行為（826条）: **特別代理人の選任**が必要（家庭裁判所に請求）

## 相続編★超頻出

### 法定相続人と相続順位★最頻出

| 順位 | 相続人 | 代襲相続 |
|------|--------|---------|
| 常に | **配偶者** | - |
| 第1順位 | **子**（実子・養子とも） | あり（直系卑属に限り**再代襲あり**） |
| 第2順位 | **直系尊属**（親等が近い者が優先） | なし |
| 第3順位 | **兄弟姉妹** | あり（甥姪まで。**再代襲なし**） |

### 法定相続分（900条）★超頻出

| 組み合わせ | 配偶者 | 他の相続人 |
|-----------|--------|-----------|
| 配偶者 ＋ 子 | **1/2** | **1/2**（子で均分） |
| 配偶者 ＋ 直系尊属 | **2/3** | **1/3**（直系尊属で均分） |
| 配偶者 ＋ 兄弟姉妹 | **3/4** | **1/4**（兄弟姉妹で均分） |

- 非嫡出子の相続分 = 嫡出子と同じ（900条4号。旧法の1/2規定は違憲決定により削除）
- 父母の一方のみを同じくする兄弟姉妹の相続分 = 父母双方を同じくする兄弟姉妹の**1/2**（900条4号）

### 代襲相続（887条）
- 原因: 相続開始**前**の死亡、相続欠格、廃除（**相続放棄は代襲原因にならない**★重要）
- 子の代襲: 直系卑属が代襲（再代襲あり）
- 兄弟姉妹の代襲: 甥姪まで（再代襲なし）

### 相続欠格（891条）と廃除（892-895条）

| | 欠格 | 廃除 |
|---|---|---|
| 事由 | 殺人・遺言の偽造等（法定） | 被相続人に対する虐待・重大な侮辱等 |
| 効果 | 当然に相続資格喪失 | 家庭裁判所の審判で資格喪失 |
| 対象 | すべての相続人 | 遺留分を有する推定相続人 |
| 代襲相続 | あり | あり |

### 特別受益と寄与分

| 制度 | 内容 |
|------|------|
| 特別受益（903条） | 生前贈与等を相続財産に持ち戻して計算 |
| 寄与分（904条の2） | 被相続人の財産の維持増加に特別の寄与をした相続人に認められる |
| 特別寄与料（1050条）★新設 | 相続人以外の親族（例: 長男の妻）の寄与に対する金銭請求権 |

### 配偶者居住権★2020年新設

| 制度 | 内容 | 条文 |
|------|------|------|
| 配偶者居住権 | 遺産分割等により配偶者が居住建物に無償で住み続ける権利（存続期間中） | 1028条 |
| 配偶者短期居住権 | 遺産分割が確定するまでの間の居住権（最低6ヶ月） | 1037条 |

### 相続の承認・放棄★頻出

| | 単純承認 | 限定承認 | 相続放棄 |
|---|---|---|---|
| 効果 | 無限に権利義務を承継 | 相続財産の限度で債務を弁済 | 初めから相続人でなかったとみなす |
| 手続 | 不要（意思表示 or 法定単純承認） | 家庭裁判所に**相続人全員**で申述 | 家庭裁判所に**各自で**申述 |
| 期間 | 熟慮期間（3月）経過で法定単純承認 | 3月以内 | 3月以内 |

**熟慮期間（915条）**: 自己のために相続の開始があったことを知った時から**3ヶ月以内**
**法定単純承認（921条）**: ① 相続財産の全部又は一部の処分 ② 熟慮期間の経過 ③ 限定承認・放棄後の財産隠匿等

### 遺言★頻出

**遺言能力**: **15歳**以上（961条）。制限行為能力者の規定は適用されない（962条）

**遺言の方式**

| 種類 | 要件 | 特徴 |
|------|------|------|
| **自筆証書遺言（968条）** | 全文を自書＋日付＋氏名＋押印 | ★改正: **財産目録はパソコン作成可**（各頁に署名押印要） |
| **公正証書遺言（969条）** | 証人2人以上＋公証人の筆記 | 最も確実。偽造変造のリスクなし |
| **秘密証書遺言（970条）** | 署名押印した遺言書を封印＋公証人＋証人2人 | 内容秘密。実務ではまれ |

- 遺言の撤回: いつでも可能（1022条）。前の遺言と後の遺言が抵触する場合は後の遺言が優先（1023条）
- **自筆証書遺言の保管制度**★新設: 法務局で保管可能（検認不要に）

### 遺留分★超頻出★2019年大改正

**遺留分権利者**: 兄弟姉妹**以外**の相続人（配偶者・子・直系尊属）

| 場合 | 遺留分の割合 |
|------|-------------|
| 直系尊属のみが相続人 | 被相続人の財産の**1/3** |
| その他の場合 | 被相続人の財産の**1/2** |

**個別的遺留分** = 総体的遺留分 × 法定相続分

**遺留分侵害額請求権★2019年改正の核心**

| 項目 | 旧法 | 新法 |
|------|------|------|
| 名称 | 遺留分減殺請求権 | **遺留分侵害額請求権**★ |
| 効果 | **物権的効力**（目的物の返還） | **金銭債権**★（金銭での支払い請求） |
| 裁判所の関与 | - | 裁判所は支払いに相当の期限を許与可能（1047条5項）★ |

**期間制限**:
- 遺留分侵害を知った時から**1年**（時効）
- 相続開始から**10年**（除斥期間）
