# 基礎法学（配点8点・2問）

## 1. 法の分類

### 成文法と不文法

| 分類 | 定義 | 例 |
|------|------|-----|
| 成文法 | 文書の形式で制定された法 | 憲法、法律、命令、条例、規則 |
| 不文法 | 文書化されていない法 | 慣習法、判例法、条理 |

### 公法と私法

| 分類 | 定義 | 例 |
|------|------|-----|
| 公法 | 国家と国民の関係、国家機関相互の関係を規律 | 憲法、行政法、刑法、訴訟法 |
| 私法 | 私人間の関係を規律 | 民法、商法 |
| 社会法 | 公法と私法の中間領域 | 労働法、社会保障法、経済法 |

### 実体法と手続法

| 分類 | 定義 | 例 |
|------|------|-----|
| 実体法 | 権利義務の内容を定める法 | 民法、刑法 |
| 手続法 | 権利義務を実現する手続を定める法 | 民事訴訟法、刑事訴訟法、行政手続法 |

### 一般法と特別法

| 分類 | 定義 | 例 |
|------|------|-----|
| 一般法 | 広く一般に適用される法 | 民法（私法の一般法）、行政手続法 |
| 特別法 | 特定の人・事項・地域に適用される法 | 商法（民法の特別法）、借地借家法 |

**原則**: 特別法は一般法に優先する（特別法優先の原則）

## 2. 法の効力

### 時間的効力
- **法律不遡及の原則**: 法律は原則として施行日以降の事実に適用される（遡及適用しない）
- 刑罰法規の遡及適用は憲法39条で明文禁止
- 民事法の遡及適用は原則禁止だが、例外あり（経過措置で対応）

### 場所的効力
- 日本の法律は原則として日本国内に効力が及ぶ（属地主義）
- 例外: 刑法の国外犯規定（属人主義的要素）

### 人的効力
- 日本の法律は原則として日本国内のすべての人に適用
- 例外: 外交特権（外交官への刑事裁判権の免除）

## 3. 法の解釈

### 有権解釈と学理解釈

| 種類 | 主体 | 拘束力 |
|------|------|--------|
| 有権解釈（公権的解釈） | 国家機関（立法・行政・司法） | あり |
| 学理解釈（私的解釈） | 学者・実務家 | なし |

### 学理解釈の方法

| 方法 | 内容 | 例 |
|------|------|-----|
| 文理解釈 | 法文の文言どおりに解釈 | 条文の文言に忠実に解釈 |
| 拡張解釈 | 文言より広く解釈 | 「汽車」に電車を含める |
| 縮小解釈 | 文言より狭く解釈 | 「人」を「自然人」に限定 |
| 類推解釈 | 類似の事項に規定を適用 | 明文なき事項に類似規定を適用 |
| 反対解釈 | 規定の反面を解釈 | 「Aの場合はBする」→「A以外はBしない」 |
| 勿論解釈 | 当然に含まれると解釈 | 小を禁ずれば大も当然禁止 |
| 目的論的解釈 | 法の目的から解釈 | 立法趣旨に沿って解釈 |

**注意**: 刑法では罪刑法定主義により類推解釈は禁止（被告人に不利な方向の類推）

## 4. 法の適用

### 三段論法
1. **大前提**: 法規範（〜の場合は…の効果が生じる）
2. **小前提**: 具体的事実（本件は〜の場合に該当する）
3. **結論**: 法的判断（よって…の効果が生じる）

### 法律要件と法律効果
- **法律要件**（構成要件）: 法律効果が発生するための条件
- **法律効果**: 法律要件を充足した場合に発生する権利義務の変動

## 5. 法源

| 法源 | 内容 | 優先順位 |
|------|------|----------|
| 憲法 | 最高法規（98条） | 1位 |
| 条約 | 国際法上の合意 | 2位（通説） |
| 法律 | 国会が制定（59条） | 3位 |
| 命令 | 行政機関が制定（政令・省令等） | 4位 |
| 条例 | 地方公共団体が制定 | 5位 |
| 慣習法 | 社会で反復継続された慣行に法的確信が加わったもの | 補充的 |
| 判例 | 裁判所の判断（事実上の拘束力） | 補充的 |
| 条理 | 物事の道理・社会通念 | 最終補充 |

## 6. 重要な法律用語★頻出

### 「及び」と「並びに」（併合的接続）
- **及び**: 同一レベルの語句を結ぶ（A及びB）
- **並びに**: 異なるレベルの語句を結ぶ（大きい接続に「並びに」、小さい接続に「及び」）
- 例: 「A及びB**並びに**C及びD」= (A+B) と (C+D)

### 「又は」と「若しくは」（選択的接続）
- **又は**: 最も大きい選択的接続に使用
- **若しくは**: 小さい選択的接続に使用
- 例: 「A**若しくは**B**又は**C**若しくは**D」= (AかB) または (CかD)

### 「推定する」と「みなす」

| 用語 | 意味 | 反証 |
|------|------|------|
| 推定する | 一応そのように扱う | 反証を挙げれば覆せる（反証可能） |
| みなす | そのように確定的に扱う | 反証を挙げても覆せない（反証不可） |

### 「善意」と「悪意」

| 用語 | 法律上の意味 | 日常語の意味と異なる |
|------|-------------|---------------------|
| 善意 | ある事実を知らないこと | ≠ 良い心、親切 |
| 悪意 | ある事実を知っていること | ≠ 悪い心、悪意 |

### 時間に関する用語

| 用語 | 意味 | 緊急度 |
|------|------|--------|
| 直ちに | 一切の遅延なく即座に | ★★★ 最も急ぐ |
| 遅滞なく | 正当な理由による遅延は許される | ★★☆ |
| 速やかに | 訓示的（できるだけ早く） | ★☆☆ 最も緩い |

### その他重要用語

| 用語 | 意味 |
|------|------|
| 以上・以下 | その数を含む（10以上 = 10を含む） |
| 超える・未満 | その数を含まない（10を超える = 11以上） |
| 適用 | 法律の規定をそのまま当てはめる |
| 準用 | 他の規定を必要な修正を加えて当てはめる |
| 科する | 刑罰を課す場合 |
| 課する | 行政上の義務や税金を課す場合 |

## 7. 裁判制度

### 三審制
- **第一審** → **控訴審**（第二審） → **上告審**（第三審）
- 上訴: 控訴（第一審→第二審）、上告（第二審→第三審）

### 裁判の種類

| 種類 | 内容 |
|------|------|
| 民事裁判 | 私人間の紛争を解決 |
| 刑事裁判 | 犯罪の有無と刑罰を決定 |
| 行政裁判 | 行政処分の適法性を審査 |

### 裁判員制度
- 対象: 重大な刑事事件（地方裁判所の第一審のみ）
- 構成: 裁判官3人＋裁判員6人
- 裁判員は有権者から無作為抽出
- 事実認定と量刑の判断に参加（法律問題は裁判官のみ）

## 8. 法学の基本概念

### 法の支配と法治主義

| 概念 | 起源 | 内容 |
|------|------|------|
| 法の支配 | 英米法 | 法の内容の正当性を重視。議会の法律も違憲審査の対象 |
| 法治主義 | 大陸法 | 法律の形式（手続）を重視。法律に基づく行政を要求 |
| 形式的法治主義 | ドイツ | 法律の内容は問わない（悪法も法なり） |
| 実質的法治主義 | 現代 | 法律の内容も適正であることを要求（日本国憲法はこれ） |

### 権利能力・意思能力・行為能力

| 能力 | 定義 | 開始時期 |
|------|------|----------|
| 権利能力 | 権利義務の主体となれる資格 | 出生（民法3条） |
| 意思能力 | 法律行為の結果を判断できる精神能力 | 概ね7〜10歳程度 |
| 行為能力 | 単独で有効な法律行為ができる能力 | 成年（18歳） |
