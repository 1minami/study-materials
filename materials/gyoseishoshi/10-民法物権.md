# 民法物権（民法第2編）★頻出

## 1. 物権総論

### 物権法定主義（175条）
- 物権は民法その他の法律に定めるもののほか創設できない

### 物権変動★超頻出

**意思主義（176条）**: 物権の設定及び移転は、当事者の意思表示のみによって効力を生ずる

#### 不動産の対抗要件: 登記（177条）★最頻出

**「第三者」の範囲**: 当事者もしくはその包括承継人以外の者で、登記の欠缺を主張する正当な利益を有する者

**第三者に当たる者**: 二重譲受人、差押債権者、賃借人等
**第三者に当たらない者**: 不法占拠者、不法行為者、背信的悪意者

**背信的悪意者排除論（判例）**: 単なる悪意者は第三者に当たるが、信義則に反するような悪意者（背信的悪意者）は第三者から排除される

**登記と各制度の関係**★超頻出

| 場面 | 登記の要否 |
|------|-----------|
| 取消し前の第三者 | 善意無過失の第三者に対抗不可（96条3項等） |
| **取消し後の第三者** | **登記の先後**で決まる（対抗問題：最判昭32.6.5） |
| 解除前の第三者 | 善意の第三者に対抗不可（545条1項ただし書き）。登記必要（判例） |
| **解除後の第三者** | **登記の先後**で決まる（対抗問題：最大判昭35.11.29） |
| **時効完成前の第三者** | 時効取得者は登記なくして対抗可能 |
| **時効完成後の第三者** | **登記の先後**で決まる（対抗問題：最判昭33.8.28） |
| 相続と登記 | 法定相続分を超える部分は登記なくして第三者に対抗不可（899条の2）★改正 |

#### 動産の対抗要件: 引渡し（178条）

| 引渡しの種類 | 内容 | 条文 |
|-------------|------|------|
| 現実の引渡し | 物を現実に移転する | 182条1項 |
| 簡易の引渡し | 既に占有している者に意思表示で引渡し | 182条2項 |
| 占有改定 | 引き続き占有するが他人のために占有する意思表示 | 183条 |
| 指図による占有移転 | 第三者に占有させている場合にその者への引渡しを命じる | 184条 |

## 2. 占有権

### 即時取得（192条）★頻出

**要件**:
1. **動産**の取引行為であること
2. **善意無過失**であること
3. **平穏公然**に占有を開始したこと
4. 占有の開始（**占有改定では即時取得は成立しない**：判例）

**盗品・遺失物の特則（193-194条）**:
- 盗品・遺失物は被害者・遺失者が2年以内に回復を請求できる
- 占有者が善意で**競売・公の市場・同種の物を販売する商人**から買い受けた場合 → 回復者は代価を弁償する必要あり（194条）

## 3. 所有権

### 共有（249-264条）★頻出

| 行為の種類 | 必要な同意 | 条文 |
|-----------|-----------|------|
| **保存行為** | 各共有者が**単独**で | 252条5項 |
| **管理行為** | 持分の**過半数** | 252条1項 |
| **軽微変更**★2021年改正 | 持分の**過半数** | 251条1項 |
| **変更行為（重大な変更）** | 共有者**全員**の同意 | 251条1項 |

- 共有物の使用: 各共有者は共有物の全部についてその持分に応じた使用ができる（249条）
- 持分の処分: 各共有者は自由に持分を処分できる
- 分割請求: 各共有者はいつでも分割を請求できる（256条1項本文）。5年以内の不分割特約は可能

### 所在等不明共有者がいる場合の特則★2021年改正
- 裁判所の決定により、所在不明共有者の持分を他の共有者が取得可能

## 4. 担保物権★超頻出

### 担保物権の通有性

| 性質 | 内容 |
|------|------|
| 付従性 | 被担保債権に従って成立・消滅する |
| 随伴性 | 被担保債権が移転すると担保物権も移転する |
| 不可分性 | 被担保債権の全部の弁済を受けるまで目的物の全部について権利を行使できる |
| 物上代位性 | 目的物の売却代金・賃料・保険金等に対しても権利を行使できる |

### 留置権（295-302条）

| 項目 | 内容 |
|------|------|
| 要件 | ① 他人の物を占有 ② 被担保債権がその物に関して生じた（牽連性） ③ 弁済期到来 |
| 義務 | 善管注意義務（298条1項） |
| 特徴 | 優先弁済権**なし**（留置するだけ）、競売権はある（民事執行法） |
| 消滅 | 占有を失った場合（302条）、担保の提供による消滅請求（301条） |

### 抵当権（369-398条の22）★最重要

**抵当権の特徴**: 目的物の占有を移さず、設定者が使用収益を継続できる

**抵当権の効力の及ぶ範囲（370条）**: 付加一体物（付合物・従物等）

**物上代位（372条→304条）**★頻出
- 目的物の売却代金・賃料・損害賠償金・保険金等に対して行使可能
- 要件: 払渡し又は引渡し前に**差押え**をしなければならない
- 賃料への物上代位: 認められる（最大判平1.10.27）
- 転貸賃料への物上代位: 原則認められない（最判平12.4.14）

**法定地上権（388条）**★超頻出

**要件**:
1. 抵当権設定**時**に土地上に**建物が存在**すること
2. 抵当権設定時に土地と建物が**同一人所有**であること
3. 土地又は建物（又は双方）に抵当権が設定されたこと
4. 競売により土地と建物の所有者が**別人**になったこと

**応用パターン**:

| パターン | 法定地上権 |
|----------|-----------|
| 更地に抵当権設定後、建物が建築された場合 | **成立しない**（設定時に建物なし） |
| 土地と建物が別人所有で抵当権設定 | **成立しない**（設定時に同一人所有でない） |
| 共有地上の建物に抵当権設定 | 他の共有者の利益を害するため原則**成立しない** |

**抵当権と賃借権の関係**:
- 抵当権設定**前**の賃借権: 抵当権に対抗できる（対抗要件を備えている場合）
- 抵当権設定**後**の賃借権: 原則として抵当権に対抗できない
- **明渡猶予期間（395条）**: 抵当権に対抗できない建物賃借人は、競売による買受人の買受けの時から**6ヶ月間**は明渡しを猶予される

### 根抵当権（398条の2-398条の22）★頻出

| 項目 | 内容 |
|------|------|
| 意義 | 一定の範囲に属する不特定の債権を**極度額**の範囲内で担保 |
| 極度額 | 必ず定める必要あり（398条の2第1項） |
| 被担保債権の範囲 | 債務者との一定の種類の取引から生じる債権等（398条の2第2項） |
| 元本確定前 | 付従性・随伴性が緩和される（被担保債権の譲渡に伴わない等） |
| 元本確定後 | 通常の抵当権と同様の扱い |
| 元本確定事由 | 確定期日の到来（398条の6）、確定請求（398条の19）、法定確定事由（398条の20） |

### 譲渡担保（判例法理）

- 法律上の規定なし。判例で認められた担保
- 所有権を担保目的で移転し、弁済されれば返還
- **清算義務**: 担保権者は目的物の価額が被担保債権額を超える場合、差額を返還する義務（判例）
- 集合動産譲渡担保も判例で認められている
