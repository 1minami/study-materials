# 行政法総論（行政法112点中の基礎）

## 1. 行政法の基本原理

### 法律による行政の原理

| 原則 | 内容 |
|------|------|
| 法律の法規創造力 | 国民の権利義務に関する法規範は法律（国会の制定する法）によってのみ定立できる |
| 法律の優位 | 行政活動は法律に違反してはならない |
| 法律の留保 | 一定の行政活動には法律の根拠が必要 |

**法律の留保の範囲に関する学説**

| 学説 | 内容 | 備考 |
|------|------|------|
| 侵害留保説 | 国民の権利自由を侵害する行政活動にのみ法律の根拠が必要 | 伝統的通説 |
| 全部留保説 | すべての行政活動に法律の根拠が必要 | 少数説 |
| 権力留保説 | 権力的な行政活動に法律の根拠が必要 | |
| 重要事項留保説（本質性理論） | 国民にとって重要な事項に法律の根拠が必要 | 有力説 |

### 信義則・権利濫用の禁止
- 民法1条2項（信義則）・3項（権利濫用禁止）は行政法にも適用される（判例）
- 租税法律関係でも信義則の適用あり（最判昭62.10.30：限定的に適用）

## 2. 行政行為（行政処分）★超頻出

### 行政行為の分類

#### 命令的行為（自然の自由の制限・回復）

| 種類 | 内容 | 例 |
|------|------|-----|
| 下命 | 一定の作為義務を課す | 違法建築物の除却命令 |
| 禁止 | 一定の不作為義務を課す | 営業停止命令 |
| 許可 | 一般的禁止を特定の場合に解除 | 飲食店の営業許可、自動車運転免許 |
| 免除 | 一定の作為義務を解除 | 予防接種の免除 |

#### 形成的行為（新たな法的地位の設定）

| 種類 | 内容 | 例 |
|------|------|-----|
| 特許 | 新たな権利・能力を設定 | 公有水面の埋立免許、鉱業権の設定、外国人の帰化許可 |
| 認可 | 私人の法律行為を補充して効力を完成 | 農地の権利移転の許可、銀行の合併の認可 |
| 代理 | 第三者のなすべき行為を行政庁が代わりに行う | 土地収用裁決 |

**許可と特許の違い**
- 許可: もともとある自由を回復する（一般的禁止の解除）
- 特許: 新たな権利を与える（本来持っていない権利の付与）

### 行政行為の効力★超頻出

| 効力 | 内容 |
|------|------|
| **公定力** | 行政行為は、たとえ違法であっても、権限ある機関（裁判所・審査庁）によって取り消されるまでは有効として扱われる。ただし無効の行政行為には公定力はない |
| **不可争力** | 出訴期間・審査請求期間が経過すると、もはや争えなくなる効力（形式的確定力） |
| **不可変更力** | 裁決・決定など紛争裁断的行為について、行政庁自身が変更・取消しできなくなる効力（実質的確定力）。一般の行政行為にはない |
| **自力執行力** | 行政行為の内容を行政庁が自ら強制的に実現できる効力。法律の根拠が必要。すべての行政行為にあるわけではない |

### 行政行為の瑕疵★頻出

#### 無効と取消しの区別

| | 取消しうべき行政行為 | 無効の行政行為 |
|---|---|---|
| 瑕疵の程度 | 通常の違法 | 重大かつ明白な瑕疵 |
| 公定力 | あり（取り消されるまで有効） | なし（当初から無効） |
| 不可争力 | あり（出訴期間の制限） | なし（いつでも争える） |
| 争い方 | 取消訴訟（出訴期間内） | 無効等確認訴訟・当事者訴訟・民事訴訟 |
| 主張できる者 | 取消訴訟の原告適格者 | 誰でも・いつでも |

**重大かつ明白な瑕疵の理論（最判昭36.3.7）**
- 重大性: 法規違反が重大であること
- 明白性: 瑕疵の存在が外観上一見して明らかであること

#### 瑕疵の治癒と違法行為の転換
- **瑕疵の治癒**: 行政行為の瑕疵が事後的に補完されること（例: 理由の追完）→ 判例は限定的に認める
- **違法行為の転換**: 違法な行政行為を他の適法な行政行為として効力を維持する → 判例は原則否定的

### 行政行為の取消しと撤回★頻出

| | 取消し | 撤回 |
|---|---|---|
| 理由 | 成立時の瑕疵（当初からの違法・不当） | 成立後の事情変更（後発的事由） |
| 効果 | 遡及的に無効（当初に遡る） | 将来に向かって効力消滅 |
| 権限者 | 処分庁＋上級行政庁 | 原則として処分庁のみ |
| 例 | 許可の要件を満たしていなかった場合 | 許可後に法令違反が生じた場合 |

### 行政行為の附款

| 附款 | 内容 |
|------|------|
| 条件 | 将来の不確実な事実にかからしめる（停止条件・解除条件） |
| 期限 | 将来の確実な事実にかからしめる（始期・終期） |
| 負担 | 主たる意思表示に付加された従たる義務 |
| 撤回権の留保 | 一定の場合に行政行為を撤回できる旨を留保する |

## 3. 行政裁量★頻出

### 裁量行為と覊束行為

| | 覊束行為 | 裁量行為 |
|---|---|---|
| 定義 | 法律が一義的に行為の内容を定めている | 行政庁に判断の余地がある |
| 司法審査 | 全面的に審査可能 | 裁量の逸脱・濫用のみ審査（行訴法30条） |

### 裁量の分類（伝統的分類）

| 分類 | 内容 | 司法審査 |
|------|------|----------|
| 覊束裁量（法規裁量） | 法解釈の問題 | 全面審査可能 |
| 自由裁量（便宜裁量） | 行政庁の判断に委ねられた裁量 | 逸脱・濫用のみ審査 |

※ 現在の判例は厳密な区別よりも、処分の性質に応じた裁量の広狭を検討する傾向

### 裁量の逸脱・濫用（行訴法30条）
- 裁量権の逸脱: 裁量の範囲を超えた場合
- 裁量権の濫用: 裁量の範囲内であるが不正な目的・動機で行使した場合

**重要判例**

| 判例 | 内容 |
|------|------|
| マクリーン事件（最大判昭53.10.4） | 外国人の在留期間更新は法務大臣の広範な裁量。裁量の逸脱濫用がある場合のみ違法 |
| エホバの証人剣道拒否事件（最判平8.3.8） | 信仰を理由とする剣道実技の拒否に対し退学処分は裁量権の逸脱濫用で違法 |
| 小田急高架訴訟（最大判平18.11.2） | 都市計画決定の裁量は広いが、考慮すべき事項を考慮せず考慮すべきでない事項を考慮した場合は違法 |
| 日光太郎杉事件（東京高判昭48.7.13） | 他事考慮・考慮不尽は裁量の逸脱濫用 |

## 4. 行政上の強制手段★頻出

### 行政上の強制執行

| 種類 | 内容 | 法律の根拠 |
|------|------|------------|
| **行政代執行** | 代替的作為義務の不履行を他の者が代わりに執行 | 行政代執行法（一般法） |
| 執行罰（間接強制） | 過料を課して間接的に義務の履行を強制 | 個別法（砂防法36条のみ現存） |
| 直接強制 | 義務者の身体・財産に直接力を加えて義務を実現 | 個別法（成田新法3条等） |
| 行政上の強制徴収 | 金銭債権の強制的徴収 | 国税徴収法が一般法的役割 |

### 行政代執行法の手続★頻出

```
義務の不履行
  ↓
① 戒告（文書で期限を定め履行を催告）
  ↓
② 代執行令書の通知（代執行の時期・費用の概算）
  ↓ ※非常の場合は①②を省略可能（3条3項）
③ 代執行の実施（証票の携帯・提示が必要）
  ↓
④ 費用の徴収（実際に要した費用を義務者から徴収）
```

**代執行の要件（行政代執行法2条）**
1. 法律により命ぜられた行為又は法律に基づき行政庁により命ぜられた行為
2. 代替的作為義務の不履行
3. 他の手段によってはその履行を確保することが困難
4. 不履行を放置することが著しく公益に反する

### 即時強制
- 義務の命令を前提とせず、直接に身体・財産に実力を行使
- 法律の根拠が必要
- 例: 警察官の保護（泥酔者の保護）、消防活動のための建物破壊、感染症患者の強制入院

### 行政調査

| 種類 | 内容 | 例 |
|------|------|-----|
| 任意調査 | 相手方の同意に基づく | 行政指導に伴う調査 |
| 間接強制調査 | 拒否に対して罰則 | 税務調査（質問検査権） |
| 直接強制調査 | 実力を行使 | 犯則事件の臨検・捜索 |

- 川崎民商事件（最大判昭47.11.22）: 質問検査権に基づく税務調査は、令状なしでも35条に反しない（刑事手続ではないため）

### 行政罰

| 種類 | 内容 | 科す手続 |
|------|------|----------|
| 行政刑罰 | 行政法規違反に対する刑罰（拘禁刑・罰金等） | 刑事訴訟法の手続（裁判所が科す） |
| 秩序罰（過料） | 軽微な義務違反に対する金銭的制裁 | 非訟事件手続法・地方自治法の手続 |

> ※2025年6月1日施行の改正刑法により、従来の「懲役」と「禁錮」は「拘禁刑」に一本化されました。行政刑罰として科される自由刑も「拘禁刑」です。

## 5. 行政契約・行政指導・行政計画

### 行政指導
- **法的性質**: 非権力的事実行為（法的拘束力なし）
- 相手方に任意の協力を求めるもの
- 行政指導に従わなくても不利益な取扱いをしてはならない（行政手続法32条2項）
- 行政指導に対する不服申立て: 処分ではないため、取消訴訟の対象にならない（原則）

**品川マンション事件（最判昭60.7.16）**
- 行政指導に従わないことを理由に給水拒否→違法
- 行政指導は任意の協力を求めるものであり、従わないことを理由に不利益な取扱いはできない

### 行政立法

| 種類 | 内容 | 法的効力 |
|------|------|----------|
| 法規命令 | 国民の権利義務に関する定め | 法規としての効力あり |
| 　├ 委任命令 | 法律の委任に基づく（例: 政令、省令） | 法律の範囲内で有効 |
| 　└ 執行命令 | 法律の執行に必要な細則 | |
| 行政規則 | 行政組織内部の定め | 法規としての効力なし |
| 　├ 訓令 | 上級行政庁から下級行政庁への命令 | 国民を直接拘束しない |
| 　└ 通達 | 法令の解釈・運用方針 | 国民を直接拘束しない |

**委任立法の限界**
- 白紙委任の禁止（委任の範囲は具体的・限定的でなければならない）
- 委任命令が委任の範囲を超えた場合は無効
